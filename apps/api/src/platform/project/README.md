# apps/api/src/platform/project

共用项目服务，提供创建、列表、详情与永久删除。项目列表含工作流/业务空间筛选、搜索及资产数量；具体工作流数据仍由各工作流模块维护。

`DELETE /api/projects/:projectId` 返回 202，只冻结项目并提交持久化后台任务。请求可携带 `currentProjectId`，与删除目标相同则拒绝；浏览器同时禁用当前项目删除。活动生成、返修或上传任务未结束时拒绝删除。

后台任务复用独立 `ProjectDeletionCleanup` 表，按数据库和文件两个阶段执行；完成后删除任务及列表快照。数据库失败有限重试后显示失败，可重新提交；文件和项目缓存失败持续重试。租约允许服务重启后恢复，并阻止旧请求覆盖新任务。数据库事务包含关联业务清理，存储与 Redis IO 在事务外。共享文件与其他项目仍引用的文件保留。

项目处于删除阶段时禁止进入或修改；项目行删除后，列表用最小快照继续展示文件清理状态。`GET /api/projects/:projectId/deletion` 可读取任务状态；没有项目和任务记录表示已完成。验证范围见[异步删除验收](../../../../../docs/project-assets/reports/2026-10-08-async-project-deletion.md)。
