# 定制类分镜创作前端

第三节点通过 `CustomizedStoryboardWorkspace` 接入正式六节点画布及专用 `projects/:projectId/workflows/customized/storyboard` API。直接读取当前项目 / 定制类 Run 已确认的 `customized-brief`，以 `artifactId + revision + fingerprint` 固定创作来源。

`CustomizedStoryboardNodePage` 负责创作设置、方案卡、脚本概述、逐镜脚本、整套对比和导出；`StoryboardShotCard` 负责单镜头局部编辑与取消。共享画布、版本树仍由外层管理，按钮、信息字段、确认、加载、工作流弹窗、底部导航及标题按钮尺寸复用系统组件与样式。

## 当前能力

- 手工新建空白方案，编辑概述，逐镜添加、编辑、删除、拖动或按钮排序。
- 双方案比较完整故事和全部镜头，不按镜号强行配对。导出完整选定脚本 TXT / JSON；导入本节点导出的 JSON，生成独立身份，不覆盖已有方案。
- 创作设置包含目标时长、方案数量、叙事结构和可选要求。镜头字段包含镜号、景别、运镜、画面、台词 / 口播、时长、音效 / 音乐，以及可折叠的衔接说明。
- 每镜右侧由 `StoryboardAssetRequirements` 展示人物、产品、场景三类需求。对象的稳定身份、名称及公共外观属于本脚本；镜头仅关联对象并维护独立呈现要求。支持新建、跨镜复用、编辑公共定义、移除本镜关联，以及区分尚未定义与本镜不需要。
- 对象与镜头一起暂存，保存镜头才应用到脚本；取消丢弃全部局部修改，切换镜头前使用共享确认。公共定义编辑提示关联镜头数，不自动改写画面正文。移除关联不删除项目资产或其他镜头的对象。
- 对比、TXT 与 JSON 导出包含三类需求；导入重建对象身份并重映射引用。旧 v1 文件缺少资产字段时正常读取，显示尚未定义，不从画面猜测实体，也不主动重写历史草稿。
- AI 创作读取真实任务，逐份展示已发布脚本，支持取消与恢复未完成方案；后台自动恢复预算由现有 Worker 管理，不在前端模拟成功或执行百分比。进度条只在排队和执行中展示，终态直接消失；失败原因、恢复入口和顶部查看工作流保留，阶段详情通过真实接口分页查看。
- 手工新建、导入、编辑、草稿暂存、取消、保存及脚本永久删除均使用专用 API，写入携带 expectedRevision。删除清除当前脚本及全部后代分支的数据，独占文件由持久后台队列清理；共享上游和兄弟脚本保留。编辑草稿独立于确认版本，显式保存才提交；同内容不增加业务 revision，409 保留本地内容，重新加载前确认。
- 每份成功脚本独立发布兄弟 Run 和 `customized-script:<scriptId>`；同一信息卡下的全部脚本共同属于当前工作流，版本树同时高亮。列表和树中的脚本点击仅切换查看、保存查看偏好，不激活分支、不发布版本；刷新优先恢复查看偏好。没有主脚本设置，从分镜点击下一步或画布后续节点时，使用当前已确认且来源有效的脚本实际 Run。
- 生产页面不再提供界面示例、虚构脚本或未接通的单镜头重新创作按钮。测试数据只位于 `__fixtures__`，隔离浏览器入口在 `tests/browser/storyboard.html`，不被生产工作区导入。
- 只读状态隐藏重复的禁用逐镜操作，真实编辑态仍保留添加、编辑、删除及排序。空台词、音效和衔接不显示占位区，实际内容仍完整展示或可展开查看。
- 创作依据与高级设置按需展开；方案对比补齐衔接说明。脚本资产目录列出全部对象及镜头使用位置，未引用对象也可查看，不因界面精简丢失后端业务内容。

## 能力边界

分镜专用 AI 任务、正式脚本 WorkingArtifact 与独立分支发布已经接通。Prompt 模型及后续生产任务未在本模块实现，不用导航可用性冒称整条生产链路完成。历史多方案草稿保留读取兼容，仅用户主动编辑时迁移；打开页面不自动创建脚本任务或发布分支。

产品信息不从品牌图片推断；资产需求是文字定义与脚本内引用，不是已生成的 ProjectAsset。页面不提前绑定人物音色、素材、产品图或视频资产。图片生成与实际绑定仍归逐镜工作台。
