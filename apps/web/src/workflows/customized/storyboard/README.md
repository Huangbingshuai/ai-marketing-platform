# 定制类分镜创作前端

第三节点通过 `CustomizedStoryboardWorkspace` 接入正式六节点画布。直接读取当前项目 / 定制类 Run 已确认的 `customized-brief`，用 `artifactId + revision` 记录手工草稿来源。

`CustomizedStoryboardNodePage` 负责创作设置、方案卡、脚本概述、逐镜脚本、整套对比和导出；`StoryboardShotCard` 负责单镜头局部编辑与取消。共享画布、版本树仍由外层管理，按钮、信息字段、确认、加载、工作流弹窗、底部导航及标题按钮尺寸复用系统组件与样式。

## 当前能力

- 手工新建空白方案，编辑概述，逐镜添加、编辑、删除、拖动或按钮排序。
- 双方案比较完整故事和全部镜头，不按镜号强行配对。导出完整选定脚本 TXT / JSON；导入本节点导出的 JSON，生成独立身份，不覆盖已有方案。
- 创作设置包含目标时长、方案数量、叙事结构和可选要求。镜头字段包含镜号、景别、运镜、画面、台词 / 口播、时长、音效 / 音乐，以及可折叠的衔接说明。
- 每镜右侧由 `StoryboardAssetRequirements` 展示人物、产品、场景三类需求。对象的稳定身份、名称及公共外观属于本脚本；镜头仅关联对象并维护独立呈现要求。支持新建、跨镜复用、编辑公共定义、移除本镜关联，以及区分尚未定义与本镜不需要。
- 对象与镜头一起暂存，保存镜头才应用到脚本；取消丢弃全部局部修改，切换镜头前使用共享确认。公共定义编辑提示关联镜头数，不自动改写画面正文。移除关联不删除项目资产或其他镜头的对象。
- 对比、TXT 与 JSON 导出包含三类需求；导入重建对象身份并重映射引用。旧 v1 文件缺少资产字段时正常读取，显示尚未定义，不从画面猜测实体，也不主动重写历史草稿。
- 通过已有 WorkflowNodeState API 保存 `STORYBOARD` 草稿。写入携带 expectedRevision；同内容不重写，查看其他方案不构成内容修改。409 保留本地内容，主动重新加载前确认。
- 显式“查看界面示例”进入独立的虚构青梅酱演示。默认关闭，编辑和候选选择不写入项目，退出还原真实草稿。

## 尚未接通

分镜专用 AI 任务、正式脚本 WorkingArtifact、分支发布与主脚本下游绑定。本轮保存只形成编辑草稿；主脚本选择仅为草稿候选，不能作为 Prompt 输入。AI 创作及下一步禁用，工作流弹窗明确为预定步骤，不模拟执行进度。

产品信息不从品牌图片推断；资产需求是文字定义与脚本内引用，不是已生成的 ProjectAsset。页面不提前绑定人物音色、素材、产品图或视频资产。图片生成与实际绑定仍归逐镜工作台。通用草稿 API 不等于正式分镜确认 API。
