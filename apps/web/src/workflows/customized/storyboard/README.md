# 定制类分镜创作前端

第三节点通过 `CustomizedStoryboardWorkspace` 接入正式五节点画布及专用 `projects/:projectId/workflows/customized/storyboard` API。直接读取当前项目 / 定制类 Run 已确认的 `customized-brief`，以 `artifactId + revision + fingerprint` 固定创作来源。

`CustomizedStoryboardNodePage` 负责创作设置、方案目录、完整正文、创作说明、对比和导出；历史逐镜组件保留兼容代码，不在当前脚本页展开。共享画布、版本树仍由外层管理，按钮、信息字段、确认、加载、工作流弹窗、底部导航及标题按钮尺寸复用系统组件与样式。

## 当前能力

当前脚本页展示单份完整正文；设置为视频类型、参考时长，每次创作固定新增一份，不展示数量选择。脚本结构支持经典结构及逐段增删、编辑、排序，留空由系统编排；移除创作要求输入。进度位于设置下方，任务结束后消失；暂时查询失败自动退避恢复，不显示大块失败横幅，不提供页面取消入口。新脚本显示类型、实际预计时长及原参考时长，导出保留这三项。下文逐镜编辑组件保留作旧版兼容，新脚本不在此节点拆镜。

- 手工新建空白脚本；只读状态直接阅读完整正文，进入编辑后修改正文，辅助概述与结构在创作说明中维护。概述不代替正文。
- 双方案比较完整正文、结构及产品呈现。导出完整选定脚本 TXT / JSON；导入本节点导出的 JSON，生成独立身份，不覆盖已有方案。
- 视频类型包括口播带货、同城到店、品牌广告、剧情短片。新草稿默认品牌广告，历史未设置类型时兼容剧情短片；新任务不消费历史创作要求。参考时长仅指导规模，结构按有序标题逐段落实。
- 导入旧版文件保留镜头与资产；导入为独立身份并重映射引用。新脚本在资产准备节点拆分对象，在视频制作节点分镜、绑定与生成提示词。
- AI 创作读取真实任务，逐份展示已发布脚本，支持取消与恢复未完成方案；后台自动恢复预算由现有 Worker 管理，不在前端模拟成功或执行百分比。进度条只在排队和执行中展示，终态直接消失；失败原因、恢复入口和顶部查看工作流保留，阶段详情通过真实接口分页查看。
- 手工新建、导入、编辑、草稿暂存、取消、保存及脚本永久删除均使用专用 API，写入携带 expectedRevision。删除清除当前脚本及全部后代分支的数据，独占文件由持久后台队列清理；共享上游和兄弟脚本保留。编辑草稿独立于确认版本，显式保存才提交；同内容不增加业务 revision，409 保留本地内容，重新加载前确认。
- 每份成功脚本独立发布兄弟 Run 和 `customized-script:<scriptId>`；同一信息卡下的全部脚本共同属于当前工作流，版本树同时高亮。列表和树中的脚本点击仅切换查看、保存查看偏好，不激活分支、不发布版本；刷新优先恢复查看偏好。没有主脚本设置，从脚本创作点击下一步或画布后续节点时，使用当前已确认且来源有效的脚本实际 Run。
- 生产页面不再提供界面示例、虚构脚本或未接通的单镜头重新创作按钮。测试数据只位于 `__fixtures__`，隔离浏览器入口在 `tests/browser/storyboard.html`，不被生产工作区导入。
- 创作依据、结构设置与创作说明按需展开。终态不显示常驻进度条；工作流详情显示持久化正文、四项创意、具体审校及真实修改前后内容。

## 能力边界

脚本专用 AI 任务、正式脚本 WorkingArtifact 与独立分支发布已经接通。Prompt 模型及后续生产任务未在本模块实现，不用导航可用性冒称整条生产链路完成。历史多方案草稿保留读取兼容，仅用户主动编辑时迁移；打开页面不自动创建脚本任务或发布分支。

产品信息不从品牌图片推断；资产需求是文字定义与脚本内引用，不是已生成的 ProjectAsset。页面不提前绑定人物音色、素材、产品图或视频资产。资产定义归资产准备，实际镜头绑定归视频制作；图片与视频渲染尚未接通。
