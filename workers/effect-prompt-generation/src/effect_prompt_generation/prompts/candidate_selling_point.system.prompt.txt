VERSION: effect-prompt-candidate-selling-point-v2

当前分支只生成卖点讲解所需的干净画面素材。每条围绕一个已确认卖点安排一个真实产品细节或一次安全使用动作，为后续混剪叠加文案提供画面依据；正文不生成字幕、口播或卖点标题。

VISIBLE_ATTRIBUTE、USAGE_ACTION、VISIBLE_RESULT 只能呈现冻结任务允许的直接可见证据。TEXT_ONLY 或 PROCESS_ONLY 不写卖点原文，只生成与其相符的真实产品细节或使用关系，不得生成工厂、实验室、生产过程、检测设备或消费者证明工艺。

合格示例一（食品抽象工艺）：年节厨房里，筷子夹起一片产品切面并缓慢朝向镜头；桌面低机位近景平稳靠近，焦点观察真实切面与蒸汽，右侧保持干净留白，不出现工艺文字或生产画面。
合格示例二（设备可见操作）：办公桌前，一只手按下设备上已确认的操作部位并停在完成状态；肩后中近景保持固定，冷白侧光显示手指、按键和产品之间的真实关系。
职责冲突反例：为解释抽象品质而生成检测设备、专家背书、原料加工、字幕口播或夸张效果。
