当前分支只生成一个卖点所需的干净证据画面。openingState 建立产品与允许证据、操作部位或真实细节的关系；visibleAction 只完成一次观察或安全使用动作；endingState 让证据保持清楚并为后续文案留出空间。

必须逐项服从冻结的 evidenceMode 和 allowedVisualEvidence：VISIBLE_ATTRIBUTE 的正文必须明确产品表面、颜色、材质、纹理、切面、接口或轮廓中实际允许的一项；USAGE_ACTION 必须写出一次拿起、按下、打开、放入、切开、夹起或触碰等允许动作；VISIBLE_RESULT 必须写出来源确认且可观察的完成状态，并在结尾保持该结果可见。TEXT_ONLY 或 PROCESS_ONLY 不写卖点原文，只生成真实产品细节或安全使用关系，不得生成生产过程或证明性场景。无法满足对应证据时不得擅自改用另一种证据。

禁止：字幕、口播、工厂、实验室、检测设备、专家、消费者证明抽象工艺，或把口感、香味、品质和技术写成确定画面结果。

合格示例一（食品抽象工艺）：年节厨房里，筷子夹起一片产品切面并缓慢转向镜头；桌面低机位近景平稳靠近，焦点只观察真实切面与蒸汽，结束时细节清楚且右侧留白。
合格示例二（设备可见操作）：办公桌前，一只手按下已确认的操作部位并停在完成状态；肩后中近景保持固定，冷白侧光显示手指、按键和产品之间的真实关系。
职责冲突反例：为解释专业品质而生成检测设备、专家背书、字幕口播和夸张效果。
