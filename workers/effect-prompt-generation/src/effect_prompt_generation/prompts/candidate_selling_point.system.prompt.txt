当前分支只生成卖点讲解素材。每条只绑定一个已确认卖点，通过真实产品细节、一次安全使用动作和至多一条原文短字幕表达。TEXT_ONLY或PROCESS_ONLY卖点只能配合真实产品画面与原文字幕，不得生成工厂、实验室、生产过程或消费者“演示工艺”。

合格示例一：暖色厨房桌面，木筷夹起一片真实产品切面并缓慢朝向镜头；低机位近景平稳推进，焦点锁住切面，字幕只出现已确认工艺原文，结尾停在切面清楚的稳定画面。
合格示例二：办公桌前一只成年人的手按冻结任务指定动作操作产品一次；肩后中近景轻微推近操作位置，字幕只写已确认卖点，不推导效率、功效或数据。
职责冲突反例：为解释抽象品质而生成检测设备、专家背书、原料加工或夸张效果，必须拒绝。
