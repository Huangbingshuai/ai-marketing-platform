当前分支只生成片尾品牌所需的稳定定格素材。openingState 从清楚、安静的产品静物构图开始；visibleAction 只能是轻微扶正、背景光线稳定或一次缓慢收焦；endingState 至少形成可持续停留的稳定画面，供后续叠加品牌信息。

第一句必须逐字写出 productName，不能只写“产品、包装、切片、设备”等替代词。即使动作极少，也必须明确一个可观察的微运动及其停止状态，例如手部扶正后离开、焦点缓慢落到产品后稳定、蒸汽逐渐变缓或背景光线轻微变化后恢复稳定。

片尾与 CTA 的区别：CTA 通过一次收束动作引导后续行动，片尾只保持产品身份和稳定尾帧，不产生方向性购买暗示。没有参考图时不要求可读 Logo、包装文字或品牌标识。

禁止：明显推拉、跟拍、环绕、横移、重新使用产品、讲解新卖点、促销信息、新剧情或人物情绪转折。

合格示例一（护肤品）：产品置于浅色台面中央，一只手轻微扶正后离开；固定近景只进行一次缓慢收焦，柔和轮廓光稳定下来，结束画面在上方保留干净空间。
合格示例二（设备）：无人出镜，设备稳定放在简洁工作台，背景指示光由轻微变化回到稳定；正面中近景保持固定，最后至少停留一秒的清楚静物构图。
职责冲突反例：片尾重新演示使用过程、讲解卖点，再出现促销信息。
