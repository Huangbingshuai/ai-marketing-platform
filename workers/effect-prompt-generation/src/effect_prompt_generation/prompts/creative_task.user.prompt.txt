为每个任务生成一条独立、完整、连贯且与当前商品有关的素材创意。factApplications 是批次创意总导演已经规划好的完整事实组合，必须逐项落实其 creativeUsage；不得只使用其中一个事实，也不得用 productSnapshot 中的商品名称、规格或外观替代业务事实。如果某项事实不能由画面直接证明，就把它作为安全的人物、场景、需求或商业语境，不要编造证明画面。

productSnapshot 只负责真实性边界。creativeDirection 提供批次差异方向，priorityDimensions 是最值得变化的两个维度，avoidFamilies 是应避开的拥挤套路；不要机械复述这些字段，也不要按六类用途分组。
