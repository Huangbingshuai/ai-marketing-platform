当单条重新生成上下文非空时，本次三个任务是提供给用户比较的三个备选，而不是后台自动替换结果：
- FULL_REGENERATE：把每条任务当作 Prompt 节点的一次完整新生成。只依据 factApplications、事实视觉策略、共用约束、目标时长和用户可选要求，一次性重新生成创意主线、六维与正文；不得延续或猜测旧 Prompt、旧六维及旧创意方向。
- AUTO_DIVERSE：用户不需要预先选择改动幅度；必须按每条任务的 regenerationVariantRole 执行互补分工。
- PRESENTATION_VARIATION：保持 factApplications 的产品事实关系和产品表现重点，至少在场景、主动作、叙事、镜头中选择两个维度形成肉眼可辨的新实现；不得只换措辞、人物性别或景别名称。
- PRODUCT_FOCUS_VARIATION：以本任务重新分配的 factApplications 建立不同的产品表现重点，同时继续遵守当前商品身份和全部真实性边界。
- FEEDBACK_OPTIMIZATION：优先解决 reasons 和 instruction；若用户没有提供意见，则在保持 factApplications 的前提下给出事实清晰、动作可执行且与原文差异明显的平衡方案。
- PRESERVE_PRODUCT_RELATION：保留原条目的已确认产品关联事实，重点改变未锁定的场景、主动作、叙事或镜头实现。
- NEW_CREATIVE：允许在已分配的确认事实范围内更换创意方向，但仍必须与当前商品直接相关。
- CUSTOM：优先满足用户修改意见，同时遵守事实和共用约束。
- preservedDimensions 中列出的维度必须保持原值的业务含义；未列出的维度可自主变化，不要机械照抄旧正文。
- reasons 用来说明用户不满意之处。三个备选必须分别形成肉眼可辨的场景、主动作或镜头差异，不能只替换措辞、人物性别或景别名称。

为每个任务生成一条独立、完整、连贯且与当前商品有关的素材创意。factApplications 是批次创意总导演已经规划好的完整事实组合，必须逐项落实其 creativeUsage；不得只使用其中一个事实，也不得用 productSnapshot 中的商品名称、规格或外观替代业务事实。如果某项事实不能由画面直接证明，就把它作为安全的人物、场景、需求或商业语境，不要编造证明画面。

coverageFocusFactIds 为空表示常规生成；非空表示这些事实曾被独立评估器判定为尚未真正落实。本次必须把每个焦点事实放在创意主线的中心，使它在 creativeCore、对应六维字段和 content 中都形成自然且不可误解的业务作用。不要机械照抄事实原文，不要把抽象配方、工艺、品质或效果伪装成画面证据；应结合 creativeUsage 和视觉使用策略，把它转化为真实的需求、人物顾虑、使用场景、动作动机或商业语境，同时不得削弱其他已分配事实。仅出现一个宽泛地点、普通人物或商品品类，不算落实焦点事实；必须保留该事实中区分于其他需求、受众、动机或目标的关键限定，并让它真实改变人物关系、选择行为、动作因果、场景状态或商业收束。若原方向只能把焦点事实当成模糊氛围，应在同一合法版图内重新设计具体人物关系和动作，而不是继续产出泛化背景。

directionId 相同的任务属于同一创意方向下的兄弟变体；同一请求内出现多个兄弟时，必须把它们作为一组先相互比较、再分别创作，不能复用同一场景骨架、同一主要动作、同一人物关系或只做近义改写。siblingVariation.index/total 表示该任务在整组兄弟中的位置，focusDimensions 是本条必须重点变化的两个结构维度。每条都沿用该方向的事实关系，但须在 focusDimensions 上形成肉眼可辨的具体实现差异，并同步调整开端状态、人物关系、动作阶段、观察角度或结束状态中的至少一项。若整组因安全长度被拆成多个请求，仍须依据 index 与 focusDimensions 设计独立实现。priorityDimensions 仍是方向层的优先建议，不得覆盖本条 focusDimensions。不得只替换形容词、人物性别、景别名称或同一动作的近义说法；也不得为了差异改变已确认事实。Worker 只轮换六维枚举，不会替你选择任何商品语义，具体变化仍由你结合事实自然完成。
