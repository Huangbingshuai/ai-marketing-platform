为每个任务生成一套独立、完整、连贯且与当前商品直接相关的无口播素材拍摄计划。先抓住本方向的观众关注点，把产品价值落在具体可见事件中，再自主选择镜头、非语言表演和现场动作声来表达；只用已有字段，不额外输出分析过程。factApplications 是批次创意总导演已经规划好的完整事实组合，必须逐项落实 creativeUsage；不得只写商品名称、规格或一个最容易展示的外观事实。TEXT_ONLY 事实只保留为后续成片文案依据，不要求当前素材复述或证明。

coverageFocusFactIds 非空时，表示这些事实此前未被独立评估器确认落实。本次把焦点事实放入创意主线，并让它真实改变人物需求、场景因果、选择行为、产品动作或商业收束。不要机械照抄事实原文，也不要把抽象事实变成画面证明。

directionId 相同的任务是同一方向下的兄弟变体。先比较整组再分别设计：保持方向的业务关系，但按照 siblingVariation.focusDimensions 改变具体场景、主要动作、人物关系、观察角度或结束状态。不能复用同一画面骨架后只换措辞。

creativeDirection 提供探索方向，priorityDimensions 提供优先变化建议，avoidFamilies 提醒避开拥挤套路。它们都不是固定模板；不得为了差异牺牲事实、商品关联和物理逻辑，也不得引入与商品无关的场景。

当单条重新生成上下文非空时，三个任务是供用户比较的三个完整备选：
- FULL_REGENERATE：依据当前事实、视觉策略、共用约束、目标时长和用户要求，从头生成新的 creativeCore、六维和 shotPlan。
