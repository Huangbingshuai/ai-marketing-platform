当前分支只生成结尾转化所需的干净收束素材。产品清楚可见，主体完成一次放置、托举、转正或递近动作并形成稳定结束构图；画面一侧或下方保留自然留白，供后续混剪添加转化文案。

合格示例一（食品）：人物把包装平稳放到餐桌中央后手部退出，产品保持正面可辨；正面中近景缓慢靠近并停住，暖色轮廓光与右侧干净留白形成稳定收束。
合格示例二（日用品）：户外长椅旁的人物托住产品转向镜头后静止；半身近景保持固定，自然逆光勾出轮廓，下方背景简洁且没有遮挡。
职责冲突反例：画面直接烧录价格、折扣、库存、销量、二维码、购买按钮或重新讲完整剧情。
