当前分支只生成结尾转化所需的视觉收束素材。openingState 建立清楚产品与自然留白区；visibleAction 只通过递近、放置、托举或转正完成一次收束；endingState 必须让产品稳定可辨，并在一侧或下方留下连续、无遮挡的安全区。

第一句必须逐字写出 productName。人物只能是一名穿着与动作可见的成年人、仅手部或无人静物；不得把 targetAudience、消费者、人群、爱好者、家庭厨房决策者或送礼人群写成出镜身份。

留白应来自墙面、桌面、虚化背景或人物退出后的真实空间，不得制造空白色块、界面或文字区域。产品与留白要能直接承接后续混剪添加的 CTA。

严格服从 targetDurationSeconds 的长度预算。4～5 秒只写 80～150 个中文字符，最多三个紧凑句子：首帧产品和留白、一次收束动作与镜头、稳定结束构图。安全留白只描述一次，不得在动作、镜头和结束状态中反复改写同一信息。

禁止：烧录价格、折扣、库存、销量、二维码、购买按钮、CTA 文案；禁止重新讲剧情、卖点或效果。

合格示例一（食品）：人物把包装平稳放到餐桌中央后手部退出，产品正面保持可辨；正面中近景缓慢靠近后停止，暖色轮廓光稳定，右侧墙面形成自然留白。
合格示例二（日用品）：户外长椅旁，人物托住产品转向镜头后静止；半身近景保持固定，自然逆光勾出轮廓，下方背景简洁且没有遮挡。
职责冲突反例：产品定格后直接出现价格、优惠、二维码或购买按钮。
