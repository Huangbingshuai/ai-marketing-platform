输入 original 是原候选，task 是已确认事实、真实性快照、目标时长和原素材任务，sharedPrompt 是镜头外约束。task 中 executionRoute 的拍摄方法不是事实，不能据此补造商品能力。只返回：原 slotId、完整 shotPlan，以及确有变化时的 cameraDimension。不得修改 slotId、事实引用、creativeCore、叙事、场景、人物、产品关联点或情绪维度；不得增加新卖点、产品结构、功效、使用方式或包装信息。

你可以重组节拍数量、顺序和 durationWeight，以便真正解决跨字段冲突；但总素材时长不变，仍然只表达原来的独特观看事件。不要另起场景、换掉产品价值、扩写成完整广告，也不要用静止展示或延长停留逃避动作问题。9～15 秒通常使用 1～2 个节拍；只有同一动作必须分两个观察阶段时才使用第二拍。

整份 shotPlan 采用单一职责：
- overview.visualIntent：只写观众最终看见的素材事件与商品价值，不重复逐拍动作和运镜。
- overview.visualStyle：只写光线、色彩、材质与真实拍摄质感。
- scene.environment、lighting：只交代唯一主场景和布光。
- scene.initialState：只写开拍前已经成立的商品、人物、工具、支撑、开合、朝向与空间关系；后续动作依赖的准备状态必须在这里明确。
- beat.framing：只写景别与拍摄角度。
- beat.action：只写本节拍的一个主要动作，明确谁对什么做什么。
- beat.camera：只写相机自身的位置与运动；固定、平移、推进、环绕不能在同一时段互相矛盾。
- beat.focus：只写对焦对象或焦点转移；对焦不会移动相机或改变可见面。
- beat.motionSource：只写物体运动的真实驱动和支撑；静物可为 null，运动物体必须有足以到达终态的操作者、工具、重力、拍摄支撑或已确认机构。
- beat.visibleResult：只写该动作在当前视角下真正能看见的即时变化。
- beat.sound：只保留同步自然环境声或产品动作 Foley，不得加入音乐、人声、台词、旁白或歌词。
- finalFrame：只写由前述动作自然到达、仍有支撑且当前观察位可见的稳定结束状态。

先在内部重建一条因果链：首帧状态 → 动作主体与对象 → 驱动和支撑 → 实际状态变化 → 相机看到的变化 → 自然终帧。再从头复读一次，确保同一信息没有在多个字段中以不同说法互相打架。

重点核对：
1. 多物体或多工具：不要在短时片段内依次完成一组精细操作。保留最有营销价值的一次局部操作；其他已经完成的对象可在首帧静置。两只手已经占用时，不能同时拿第三件物品；工具退出接触路径后，物体才能闭合、收纳或移动。
2. 相对运动与镜头动机：分别确定相机、主体和焦点谁在动，并说清移动要新增展示哪项商品信息、动作结果、结构关系或尺度关系；没有信息增量时使用清楚的固定观察。需要移动时从起始机位沿可执行路径到达能看清 visibleResult 的结束观察位。相机与主体同向同速移动不能凭空看到新的一面；固定机位不能同时物理推进。需要换观察面时，明确一次切镜或可实现的连续路径。商品轮廓、关键结构、标签和操作接触点不能因相机与主体同时复杂运动而丢失。
3. 材料行为：浓稠、黏附或柔软不自动推出拉丝、回弹、悬空定型、恒速流动、完全均匀或精准停住。没有已确认依据时，改为正常接触痕迹、自然下垂、局部附着或已有表面细节。
4. 时间：片段时长是真实播放时间。较长加工、烹制、充电、干燥、装配等过程不能靠切镜瞬间完成；必要完成态可在首帧已经成立，本段只拍一个能在目标时长内完成的可见片刻。
5. 商品图和事实：图片只帮助认识外形、开口、持握尺度与可见部位，不证明材料、功效、配方或内部机构。事实作为背景不等于画面必须证明它。
