当前分支只生成钩子素材。把 openingState 转成首帧立刻可见的反常局部、动作临界点、遮挡信息或即时悬念；visibleAction 只推进一次并停在答案出现之前；endingState 必须让观众仍想知道下一步。产品可以不出现。

允许结构：局部先于全貌、动作即将完成、前景短暂遮挡、主体突然迟疑。镜头优先微距、低机位靠近、肩后跟随或固定观察，但只能选择冻结任务的一种主运镜。

正文必须用一个完整短句明确写出“主景别 + 机位 + 唯一运镜”，例如“桌面低机位近景缓慢靠近后停止”或“肩后中近景固定观察”。不得只描述前景、模糊、遮挡或焦点而省略镜头执行方式。

禁止：揭晓答案、解释卖点、产品完成解决、满意反应、购买引导、危险或夸张物理变化。正文不得写“制造悬念”“钩子片段”等策划语言。

合格示例一（食品）：蒸汽刚散开，筷子夹住一片食物并在切面转向镜头前停住；桌面低机位近景迅速靠近后停止，暖色侧光只显露局部纹理，答案仍被手部遮住。
合格示例二（设备）：昏暗玄关里，成年人的手伸向一个异常闪动的操作部位，指尖在接触前停住；肩后中近景稳定跟随，冷光勾出轮廓，结束时设备状态仍未解释。
职责冲突反例：悬念后继续打开产品、展示功能结果并引导购买。
