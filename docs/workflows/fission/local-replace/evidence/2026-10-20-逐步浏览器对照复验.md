| 问题                                                    | 修复与复验                                                                                                                                |

| 横屏来源仍标注竖屏分辨率，本地非标准比例被简化成横/竖屏 | 来源、素材库与范围编辑器统一按来源比例/真实像素显示；实际导入 640×480、3 秒视频，页面显示 4:3、640×480，原生视频读数与播放位置 1.2 秒一致 |
| 未设置范围时，出点手柄出现在 4 秒，输入却为 0           | 手柄始终使用真实范围值；入出点重叠时上下错开，保留两个可操作入口                                                                          |
| 默认时间轴宽度和尺标密度偏离原型                        | 采用原型的每秒 30 px、最小 920 px 及按时长切换刻度；32 秒在 1 倍缩放下为 960 px，4 秒一格                                                 |
| 涉及镜头统计使用固定 4 秒                               | 按原型 8 个演示帧计算，4–16 秒显示 3 个涉及镜头                                                                                           |
| 解析前页尾缺少明确的下一步条件                          | 显示“请先完成所选时间范围解析”                                                                                                            |
| 质量面板名称、门槛与原型不一致                          | 对齐光影匹配、透视关系、色彩风格、边缘接缝、结构保真、音画同步；门槛依次为 85、85、85、85、100、90，均明确为模拟评分                      |
| 输出入库项缺少素材清单                                  | 输出入库项补齐素材清单、质量报告、替换成片演示记录                                                                                        |
| 提示词复制/重生按钮的可访问名称混入上下文               | 三个字段均使用独立明确的按钮名称                                                                                                          |
| 本地视频刷新后丢失文件，却显示食品样例预览              | 范围播放器改为明确提示重新导入本地视频；已保存范围和配置保留                                                                              |
