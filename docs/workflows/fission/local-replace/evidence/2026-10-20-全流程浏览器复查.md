# 局部元素替换全流程浏览器复查

2026-10-20，在冻结原型与正式 Vue 页面中逐步操作五个节点、来源弹窗、替换素材库和模拟入库弹窗。复查使用独立开发 Mock 草稿，不执行真实生成、服务器入库或付费任务。

## 发现及修复

| 问题                                                   | 修复与复查                                                                                                       |

| 1280×720 弹窗底部确认按钮被裁切                        | 弹窗头尾固定，内容区可收缩和滚动；确认底部位于视口内                                                             |
| 430 窄屏固定弹窗超过内容宽度                           | 为遮罩网格设置可收缩列，弹窗适应含滚动条的实际内容宽度；实测右边界约 405，内容宽度 415                           |

另外移除卸载时重复回写草稿，避免旧组件退出覆盖新状态。开发预览新增可选 `mockProject` 草稿隔离参数，供多个回归窗口独立操作。

## 实际走过的流程

1. 从成片默认态打开来源库，检查工作流、项目、成片/渲染素材分类及默认选中；取消、ESC 关闭和焦点恢复。
2. 设置 4–16 秒范围，验证默认引导、非法范围禁用、0.1 秒键盘微调和实际鼠标拖动。
3. 执行解析，进入人物/产品/场景三维度；预览、确认绑定、解除绑定和重新绑定；检查素材搜索及空态。
4. 打开素材库，选择并搜索后取消，确认外部预览和主搜索不受影响；再次选择后确认替换。
5. 通过文件选择器导入一张由本轮 Mock 页面截图构成的测试 PNG，确认本地图片可预览和绑定，无服务器上传。
6. 三维度聚合为一条范围提示词。复制后读取当前测试剪贴板，确认包含范围；下载 Prompt JSON，确认 `mock=true`、三条绑定和正文。
7. 人工编辑整片合成约束，仅重新生成范围提示词，确认人工内容保留。
8. 模拟入库后刷新，再打开弹窗确认标签、说明及已入库状态恢复。
9. 渲染依次检查失败、重试、质量预警、禁用导出、成功；取消运行后刷新，确认保留可重试状态；再次渲染成功。
10. 下载素材清单与 Mock 结果，读取下载文件确认三条绑定、4–16 秒范围及六项质检。返回选择成片，确认其他已完成节点状态保留。
11. 修改负面约束后进入输出，确认待更新提示和导出禁用；再次渲染成功。
12. 检查 1440、1920、430 和 1280×720；430 弹窗确认按钮可见、页面没有横向溢出，且只存在一套局部替换画布。
