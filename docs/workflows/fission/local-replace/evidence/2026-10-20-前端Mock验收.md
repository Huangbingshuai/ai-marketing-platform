# 局部元素替换前端 Mock 验收

日期：2026-10-20。范围：当前冻结原型的局部元素替换工作台、正式 Vue 组件和独立开发预览。没有运行真实模型、渲染 Worker、入库或付费任务。

## 已实现与观察

- 系统入口复用 `ProjectManagementPage`，裂变子模块共用 `FissionWorkflowPage`。独立开发预览：[局部元素替换 Mock](http://localhost:5173/?mock=local-replace)。
- 五步与冻结原型一致：选择成片、选择时长范围、范围解析与替换、生成提示词、渲染输出。
- 对照冻结原型检查蓝色画布、节点卡、双区域工作台、原范围及目标素材预览、候选素材卡、Prompt 左右栏和渲染双卡/质量面板。样式从原型对应模块提取，再移除未使用规则；未复制原型运行时或挂载整个 HTML。
- 1440、1920、430 宽度完成浏览器检查；430 页面实际内容宽度等于视口宽度，未发现页面级横向溢出，流程卡与时间轴使用各自滚动区域。
- 验证成片清空、来源弹窗、范围有效性、0.1 秒键盘微调、解析加载、素材搜索空态、预览/确认绑定、Prompt 生成、渲染运行/失败/重试/质量预警/成功、编辑提示词后的待更新。
- 验证刷新恢复绑定和当前节点、子模块切换后恢复且只存在一套局部替换画布；ESC 关闭素材弹窗后焦点回到“全局资产库”按钮；窄屏入库弹窗和模拟记录可用。
- 修复独立预览切换到需要系统项目上下文的子模块时的空白，预览使用入口提示，系统入口继续使用现有上下文。

## 有意差异与未验证范围

- 系统入口沿用正式系统顶部导航；独立预览只提供简化标题。额外添加显式 Mock 工具条，可选择成功、失败和质量预警。
- 冻结原型中跨项目候选在正式 Mock 里收敛为当前项目样例，以保持项目隔离；来源视频仍可浏览多个来源空间并保留来源快照。
- 导出交付 JSON 演示数据，不伪造 MP4；入库只保存浏览器模拟记录。外部替换素材尚未接入真实上传，选择后明确提示使用样例。
- 本地视频元数据读取与预览已经实现，但本轮浏览器验收未上传真实视频文件。
- 独立开发预览完成浏览器验收；未启动 API，未验证登录后的真实项目数据、服务端持久化或供应商生成质量。截图不代表逐像素完全一致或真实任务可交付。

## 命令

- `pnpm --filter @ai-marketing/web exec vitest run src/workflows/fission/local-replace/local-replace.mock.spec.ts src/platform/project/project-workflow-switch.spec.ts src/platform/project/project-context.spec.ts`：3 个测试文件、17 项测试通过。其中 7 项覆盖局部替换范围、绑定唯一性、重复绑定、两轮范围变化、来源变化、项目隔离、刷新中断、Prompt 约束及单字段重新生成。
- `pnpm --filter @ai-marketing/web typecheck`：通过；生产构建也包含 `vue-tsc`。
- `pnpm --filter @ai-marketing/web build`：通过，存在主包超过 500 kB 的构建提示。
- 变更文件的 ESLint、Prettier 和 `git diff --check`：通过。
