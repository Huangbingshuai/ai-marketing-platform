# 局部元素替换前端原型还原

## 范围与验收

- 以 `references/prototypes/fission/fission-workflows.html` 中实际挂载的局部元素替换工作台为视觉和交互基线，复用正式系统项目入口，不引入第二套系统导航。
- 五步为选择成片、选择时长范围、范围解析与替换、生成提示词、渲染输出。冻结原型已经使用连续时间范围，早期指南的单镜头/片段/全局粒度不适用于本次 UI。
- 还原来源选择弹窗、时间轴和范围属性、范围主体解析、人物/产品/场景素材预览和绑定、提示词编辑和导出、渲染进度及质量报告、模拟入库弹窗。
- 显式启用 Mock 后加载固定样例。所有结果仅为浏览器演示草稿，不写项目资产、不创建真实任务、不调用付费供应商。

## 数据与边界

当前 API、Worker 的局部替换目录为预留目录，无可复用的节点业务接口。此次不新增跨进程 DTO、WorkingArtifact key 或业务 revision；后续真实接入须另行定义服务端契约。

| 节点           | 直接上游                         | 编辑/确认边界                              | 下游               |
| -------------- | -------------------------------- | ------------------------------------------ | ------------------ |
| 选择成片       | 项目素材（Mock 来源快照）        | 选择来源，改变来源清除后续演示结果         | 时长范围           |
| 选择时长范围   | 当前来源 ID/版本                 | 输入、拖动入出点，合法范围才能继续         | 范围解析           |
| 范围解析与替换 | 来源版本、范围、当前项目素材样例 | 解析成功后选择预览，再确认单维度绑定       | 提示词             |
| 生成提示词     | 范围与确认绑定                   | 模拟生成、独立文本编辑                     | 渲染               |
| 渲染输出       | 当前提示词与替换方案             | 显式点击模拟渲染；质量异常不得直接改为通过 | Mock 清单/报告导出 |

演示草稿使用项目 ID + 局部替换工作流 + 固定演示 Run 标识隔离。来源/范围变更清除解析及下游；绑定变更清除提示词和渲染；编辑提示词使已有渲染待更新。定时器在退出时释放，运行中草稿刷新后恢复为可重试状态。无真实资产迁移。

## 组件映射

- 系统外壳：现有 `ProjectManagementPage`，裂变页增加子模块入口。
- 工作流画布和五个节点：`LocalReplaceWorkspace`，只出现一套画布。
- 原型场景与资产缩略图：独立 Vue 预览组件，使用冻结原型的 CSS 形态，不引入远程图片或大 Data URL。
- 样例与隔离、失效、校验：独立 Mock 状态模块；弹窗封装焦点约束、ESC 和焦点恢复。

## 验证

覆盖范围有效性、来源/范围变化失效、单维度唯一绑定、项目隔离和刷新恢复的单测；运行 Web 类型检查、构建、相关测试及 `git diff --check`。浏览器比较 1440、1920 和窄屏的五步、弹窗、空态、加载、错误、待更新、质量预警及成功状态。截图保存在本工作流证据目录，验证不执行真实生成。
