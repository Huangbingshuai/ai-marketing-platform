# 裂变类·局部元素替换工作流指南

当前冻结原型流程：`选择成片 → 选择时长范围 → 范围解析与替换 → 生成提示词 → 渲染输出`。

## 当前实现边界

前端已按 `references/prototypes/fission/fission-workflows.html` 的实际局部替换工作台实现 Vue 页面。2026-10-20 的还原需求以该原型为准：使用连续时间范围，解析人物、产品、场景三类主体。下文早期单镜头 / 片段 / 全局粒度和七类维度是历史业务目标，不属于此次界面。

正式入口为系统“裂变类 → 局部元素替换 → 加载 Mock 示例”。开发模式可通过 `/?mock=local-replace` 打开独立预览；生产模式仍要求正常登录。

API、Worker 尚无真实节点链路。本页模拟解析、提示词生成、渲染、评分及入库，不调用供应商，不创建真实任务、正式工作副本或资产，不增加业务 revision。“导出 Mock 结果”交付 JSON 演示记录，不冒充真实视频。本地视频及替换图片支持浏览器预览，文件不上传服务器；图片导入记录按当前项目保存元数据，刷新后须重新选择文件以恢复本地预览。

### 范围、绑定和失效

- 入点不小于 0、出点不超过原片时长，范围至少 0.1 秒；输入、播放头设置、轨道手柄和键盘微调使用同一范围。
- 将选中的连续时段作为整体，不拆分显示多个镜头；每个维度只存在一条生效绑定，先预览再确认。重复确认相同素材不清空下游。
- 更换原片重置范围及全部下游；改变范围清除解析、绑定、提示词和输出；改变绑定清除提示词与输出；编辑提示词使已有输出待更新。
- 导航不触发任务；模拟任务由用户主动触发，运行中禁止切换节点，可以取消。失败、取消或刷新中断保留可重试草稿。
- Mock 草稿以项目 ID、`FISSION_LOCAL_REPLACE` 和固定演示 Run 隔离，仅存于当前浏览器；退出、切换子模块释放定时器和临时预览 URL。本地视频刷新后需重新导入以恢复播放。
- 解析区展示范围原素材和主体解析，素材区展示前后对比及候选库，保持当前冻结原型上下工作区布局，窄屏自适应。
- 替换候选只展示当前项目、当前类型样例；来源视频弹窗可浏览其他来源空间，选择后只复制来源快照到当前演示草稿。
- 入库弹窗只记录模拟选择、标签与说明；真实 WorkingArtifact key、实际消费的 artifactId + revision 和确认边界须由后续服务端契约定义。
- 质量预警禁用交付导出，须重新触发渲染与校验，不能直接将预警改成通过。当前评分全部为显式 Mock 数值。

相关范围和验证见[还原计划](plans/2026-10-20-局部元素替换前端原型还原.md)及[验收记录](evidence/2026-10-20-前端Mock验收.md)。

## 历史业务目标（真实链路待定义）

在不重制整片的情况下，对已有视频执行产品、人物、场景、字幕、贴纸、BGM 或口播替换，同时保持原片结构、节奏与范围外内容。

| 节点       | 作用                                                 | 直接上游             | 主要工作副本       | 直接下游      |
| ---------- | ---------------------------------------------------- | -------------------- | ------------------ | ------------- |
| 选择成片   | 从当前项目资产选择或本地导入原片                     | 当前项目资产         | 待替换原片         | 替换粒度      |
| 替换粒度   | 单选单镜头、片段级或全局统一                         | 原片                 | 粒度配置           | 解析与替换    |
| 解析与替换 | 按粒度解析目标范围，并将当前项目素材绑定到可替换维度 | 原片、粒度、项目资产 | 解析报告、替换方案 | 生成提示词    |
| 生成提示词 | 根据实际目标范围、解析和资产版本生成替换提示词包     | 替换方案             | 替换提示词包       | 渲染输出      |
| 渲染输出   | 执行局部跟踪、融合、合成和质量检测                   | 提示词包、替换方案   | 替换成片、质量报告 | 项目归档/交付 |

## 粒度决定界面和数据

- 单镜头：左侧逐镜时间线；一条绑定只影响当前镜头。
- 片段级：左侧叙事片段卡和所属镜头缩略条；绑定覆盖片段内实际支持该维度的镜头。
- 全局统一：左侧整片概览和全镜头缩略带；每个维度只配置一次，覆盖全片实际适用镜头。
- 切换粒度必须清空或重建旧解析、映射、提示词和渲染结果，不能把镜头级状态硬套到片段或全局。

## 解析与替换 UI

- 使用一套工作流画布，不显示第二套内嵌流程、识别框或“识别结果预览”。
- 第三步使用隔离清晰的双栏工作台：左侧原素材，右侧资产候选与替换前后对比。
- 视觉素材优先展示真实形态的本地预览；景别、运镜、转场、构图等解析字段默认折叠。
- 右侧候选只显示当前项目、当前类型资产；外部或跨项目资产先导入当前项目。
- 同一粒度上下文与同一维度只能存在一条生效绑定；不同维度可并行。

## 提示词与质量

- 单镜头按镜头聚合、片段按片段聚合、全局生成一套全局替换提示词；都必须引用真实范围、资产 ID/版本和需要保留的原内容。
- 渲染校验光影、透视、色彩、接缝、穿模、主体稳定性、结构保真、音频卡点和口播同步。
- 修正异常必须重新经历相关生成与校验，不能直接把告警状态改成通过。
