# 裂变类·局部元素替换工作流指南

固定流程：`选择成片 → 替换粒度 → 解析与替换 → 生成提示词 → 渲染输出`

## 业务目标

在不重制整片的情况下，对已有视频执行产品、人物、场景、字幕、贴纸、BGM 或口播替换，同时保持原片结构、节奏与范围外内容。

| 节点 | 作用 | 直接上游 | 主要工作副本 | 直接下游 |
| --- | --- | --- | --- | --- |
| 选择成片 | 从当前项目资产选择或本地导入原片 | 当前项目资产 | 待替换原片 | 替换粒度 |
| 替换粒度 | 单选单镜头、片段级或全局统一 | 原片 | 粒度配置 | 解析与替换 |
| 解析与替换 | 按粒度解析目标范围，并将当前项目素材绑定到可替换维度 | 原片、粒度、项目资产 | 解析报告、替换方案 | 生成提示词 |
| 生成提示词 | 根据实际目标范围、解析和资产版本生成替换提示词包 | 替换方案 | 替换提示词包 | 渲染输出 |
| 渲染输出 | 执行局部跟踪、融合、合成和质量检测 | 提示词包、替换方案 | 替换成片、质量报告 | 项目归档/交付 |

## 粒度决定界面和数据

- 单镜头：左侧逐镜时间线；一条绑定只影响当前镜头。
- 片段级：左侧叙事片段卡和所属镜头缩略条；绑定覆盖片段内实际支持该维度的镜头。
- 全局统一：左侧整片概览和全镜头缩略带；每个维度只配置一次，覆盖全片实际适用镜头。
- 切换粒度必须清空或重建旧解析、映射、提示词和渲染结果，不能把镜头级状态硬套到片段或全局。

## 解析与替换 UI

- 使用一套工作流画布，不显示第二套内嵌流程、识别框或“识别结果预览”。
- 第三步使用隔离清晰的双栏工作台：左侧原素材，右侧资产候选与替换前后对比。
- 视觉素材优先展示真实形态的本地预览；景别、运镜、转场、构图等解析字段默认折叠。
- 右侧候选只显示当前项目、当前类型资产；外部或跨项目资产先导入当前项目。
- 同一粒度上下文与同一维度只能存在一条生效绑定；不同维度可并行。

## 提示词与质量

- 单镜头按镜头聚合、片段按片段聚合、全局生成一套全局替换提示词；都必须引用真实范围、资产 ID/版本和需要保留的原内容。
- 渲染校验光影、透视、色彩、接缝、穿模、主体稳定性、结构保真、音频卡点和口播同步。
- 修正异常必须重新经历相关生成与校验，不能直接把告警状态改成通过。
