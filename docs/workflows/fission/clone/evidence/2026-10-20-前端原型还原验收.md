# 爆款复刻前端原型还原验收

日期：2026-10-20。范围：正式 Vue 前端和本地 Mock；不涉及真实生成费用、正式资产入库或 API/Worker 实现。

## 页面与边界

入口：系统顶部“裂变类”→“爆款视频复刻”。复用统一项目上下文、裂变公共导航、工作流画布及节点页脚。冻结视觉基线为 `references/prototypes/fission/fission-workflows.html` 中的参考生成增强、独立元素映射及成片列表样式；已在浏览器打开原型对比。

原型保留了旧五/六节点和爆款采集桥接，以当前业务指南的四节点为准。正式页面不设置独立 Prompt 或渲染节点。保留原型蓝灰色、卡片层级、上传双栏、六维顺序、纵向镜头时间线、左侧元素导航与右侧候选素材、成片双列列表。窄屏切换为纵向布局，时间线及节点导航允许横向滚动。

有意差异：复用正式系统顶栏；确认与归档仅作用于本地 Mock；演示成片仅提供封面和任务信息，下载明确命名的 Mock 清单；本地文件刷新后保留元数据，媒体预览需重新选择文件。模拟资产目录保留来源项目与版本，导入副本不接触正式资产库。
