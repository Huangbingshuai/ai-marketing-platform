# 爆款复刻前端原型还原

## 范围与验收

将冻结原型中的上传双栏、六维报告、纵向镜头时间线、元素映射工作区和成片列表迁入正式 Vue 前端。复用统一项目上下文、现有工作流画布和页脚。固定四节点：上传素材 → 深度拆解 → 元素映射 → 成片生成。

原型仍含旧版爆款采集、独立 Prompt 和渲染桥接逻辑，以业务指南的四节点为准；不搬入这些脚本。数字人口播与局部替换只保留原型导航，不在本任务实现。

## 数据与边界

API 的 clone 目录目前仅预留，本次不新增真实接口、Worker、数据库迁移或正式 WorkingArtifact。所有演示操作经显式 Mock 工作区运行，界面持续显示本地 Mock；不调用供应商或将演示产物写入正式项目资产库。

直接上游依次为复刻输入包、六维报告、元素映射配置和锁定结构。当前尚无这些正式工作副本及 revision；Mock 使用输入内容快照表达依赖，不伪造服务端 revision。节点编辑保存在隔离的本地演示草稿；确认输入、确认报告、确认映射时更新各自演示快照。已有下游引用旧快照时显示待更新，不自动生成。

复用 ProjectContext 中的当前项目，按项目 + FISSION_CLONE + mock Run 隔离本地数据。未绑定项目时只展示明确的未绑定演示，不建立另一套项目。刷新恢复演示数据和运行进度，卸载释放定时器及媒体 URL。跨项目素材选择为独立模拟资产目录，导入仅复制到演示候选区并保留来源说明。

## 验证

针对 Mock 恢复、作用域隔离、必换产品校验、来源变化待更新、任务快照冻结和重复操作编写单测。执行 Web 类型检查、构建、相关测试、格式与 diff 检查。浏览器对比 1920、1440、390 宽度，覆盖上传、空态、报告编辑、映射搜索/保留/替换/导入、生成/失败重试、选择/分页/删除/演示清单导出和刷新恢复。无真实付费集成验证。
