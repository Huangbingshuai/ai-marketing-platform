# 裂变类·爆款复刻工作流指南

固定流程：`上传素材 → 深度拆解 → 元素映射 → 成片生成`

## 当前前端实现

正式系统的“裂变类 → 爆款视频复刻”已接入四节点 Vue 页面，并提供明确标识的本地 Mock。沿用冻结原型的上传双栏、六维可编辑报告、纵向镜头时间线、元素映射与锁定结构、成片双列列表及资产导入弹窗。

演示草稿按当前项目及 Mock Run 隔离，支持刷新恢复、待更新提示、失败重试、数量/选择/分页/删除，以及本地演示清单导出。未绑定项目可查看隔离演示；素材导入和产物入库只写入本地 Mock，不进入正式项目资产库。样例成片没有真实视频文件；API、Worker 与真实生成交付链路尚未接通。

原型中旧版爆款采集、独立 Prompt 和独立渲染桥接不作为当前节点定义。验证与有意差异见 [2026-10-20 前端验收](evidence/2026-10-20-前端原型还原验收.md)。

## 业务目标

继承参考视频的结构与节奏，通过商品和元素映射直接生成复刻成片。前台不设置独立 Prompt 页面，也没有独立“视频渲染”节点。

| 节点     | 作用                                                  | 直接上游               | 主要工作副本 | 直接下游      |
| -------- | ----------------------------------------------------- | ---------------------- | ------------ | ------------- |
| 上传素材 | 上传参考视频和商品素材，填写所属项目                  | 项目资料               | 复刻输入包   | 深度拆解      |
| 深度拆解 | 按结构、创意、产品、镜头、音频、视觉六维分析          | 复刻输入包             | 六维拆解报告 | 元素映射      |
| 元素映射 | 将原片产品、人物、场景、字幕、BGM、口播映射为目标元素 | 拆解报告、当前项目资产 | 元素映射配置 | 成片生成      |
| 成片生成 | 设置数量并直接创建成片生成任务，管理进度和结果        | 映射配置、锁定结构     | 复刻成片批次 | 项目归档/交付 |

## 固定规则

- 上传页不展示本地素材预处理卡片。
- 深度拆解按六维固定顺序展示；镜头维度使用纵向时间线，不再追加重复镜头表格。
- 元素映射后直接进入成片生成；不要恢复独立 Prompt 生成或独立渲染节点。
- 每条任务保存当时的映射快照，同时锁定参考视频镜头顺序、阶段占比和音频卡点。
- 必换产品未完成映射时不能生成。
- 成片生成页负责数量、进度、失败重试、删除、选择、分页与导出。

## 资产规则

上传素材与生成报告先进入工作区；当前项目选择器只看当前项目。来自其他项目或系统公共库的素材必须先复制为当前项目资产，并保留来源项目、来源资产与来源版本。
