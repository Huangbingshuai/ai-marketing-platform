# 裂变类·数字人口播工作流指南

固定流程：`选择形象 → 口播文案 → 唇形驱动 → 背景配置 → 渲染输出`

## 业务目标

使用当前项目中的数字人、音色、文案和场景配置生成音画同步的口播视频。

| 节点     | 作用                                 | 直接上游             | 主要工作副本   | 直接下游      |
| -------- | ------------------------------------ | -------------------- | -------------- | ------------- |
| 选择形象 | 选择数字人版本、服装、姿态和授权范围 | 当前项目资产         | 数字人绑定     | 口播文案      |
| 口播文案 | 导入、生成或编辑口播稿并确认时长     | 项目资料、数字人绑定 | 口播稿版本     | 唇形驱动      |
| 唇形驱动 | 选择音色、语速、情绪并生成同步任务   | 口播稿、音色资产     | 唇形与音轨任务 | 背景配置      |
| 背景配置 | 配置场景、字幕、画幅和品牌元素       | 同步结果、项目资产   | 背景合成方案   | 渲染输出      |
| 渲染输出 | 合成视频、校验同步并提供导出         | 背景方案、同步结果   | 数字人口播成片 | 项目归档/交付 |

## 固定规则

- 数字人、音色、场景和字幕样式必须保存具体资产版本和授权状态。
- 文案确认新 revision 后，唇形驱动结果待更新；只改背景不应让口播稿或音轨重新生成。
- 长视频音画同步误差目标不超过 0.1 秒；超标时阻断最终导出并允许重新对齐。
- 公共数字人不能被工作流直接引用，必须先导入当前项目。
