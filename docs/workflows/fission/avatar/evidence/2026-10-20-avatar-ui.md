# 数字人口播前端验收 · 2026-10-20

范围：正式 Vue 数字人工作台与冻结 `fission-workflows.html` 的数字人区域对照。全部操作为独立 Mock 预览，不产生付费任务，也不验证真实生成质量或服务端提交。当前工作区另有定制类和其他裂变子模块的并行改动，本记录只说明数字人范围。

## 已验证

- 桌面 1440×1000、1920×1080 与 430×932 窄屏；430 视口的文档滚动宽度未超过视口，无页面横向溢出。桌面工作台宽 1312px、高 822px，与同尺寸原型的主体一致。正式页面复用系统外壳；独立开发预览省略登录和系统顶部栏。
- 素材选择、背景变更、口播编辑；背景变化保留音轨和字幕，文案变化显示来源待更新。刷新后保留文案与已有轨道。
- Mock 视频生成进度、禁用状态、完成后视频/音频轨；独立字幕生成；字幕多选、批量字体设置、分割、撤销与重做；实际指针拖动片段、边缘裁切、字幕轨空白区拖框多选。
- 形象弹窗使用仓库公开 Logo 作为非人物测试图片，验证本地读取、模拟生成、返修 v2、采用及分页增长。没有上传到外部服务；该测试只验证交互，不评估形象质量。
- 入库与导出设置弹窗；入库弹窗 ESC 关闭和焦点恢复；Mock 工程导出完成反馈。
- 空资产列表、加载中、加载失败与重新加载；生成失败保留旧轨道；调整为正常结果后重新生成成功。
- 数字人 → 局部替换 → 数字人切换后，DOM 只有 1 个数字人工作台、0 个局部替换工作台；草稿恢复，无重复组件。
