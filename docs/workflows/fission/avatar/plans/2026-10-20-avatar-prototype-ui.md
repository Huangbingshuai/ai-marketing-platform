# 数字人口播冻结原型前端实现

范围：按 `references/prototypes/fission/fission-workflows.html` 浏览器实际展示的数字人口播自由配置工作台实现 Vue UI，并接入现有裂变类入口。原型以数字人、音色、背景、文案、字幕工具页、预览、参数和时间轴表达五个固定业务节点，不额外增加第二套节点导航。

映射：系统外壳和项目绑定复用 ProjectManagementPage / ProjectContext；原型模块选择区复用共用 FissionWorkflowPage；数字人入口由 AvatarWorkspace 承载，工作台拆为 AvatarStudio、字幕参数和时间轴组件；样式只迁移冻结原型数字人区域，以 fas 前缀隔离，不使用其编译脚本、全局变量或其他工作流样式。

数据边界：本次只实现前端 Mock。显式启用后加载 fixture，按当前 projectId + FISSION_AVATAR + mock-run-v1 分离本地演示草稿，不调用任务/资产写 API、不创建 WorkingArtifact、不增加服务端 revision。数字人选择、文案、音色、背景是可编辑草稿；Mock 生成成功建立演示视频/音频轨，字幕单独生成。文案/音色变化使已有演示同步结果待更新；背景变化只影响合成，不清空音频；导航不生成任务。真实链路尚无已确认产物及上游 revision，本次不推测契约键名、不迁移数据库。

功能：资产搜索与选择、参考图生成/返修/采用弹窗、本地素材导入、文案编辑、语速语调、背景配置、模拟生成与失败重试、独立字幕生成、字幕样式/多选/分割/拖动/裁切、时间轴撤销重做、导出设置和显式 Mock 导出、模拟入库弹窗、刷新恢复。离开工作台释放计时器和临时 URL。

验证：相关状态单测、Web 类型检查/构建、ESLint/Prettier、git diff --check；浏览器与原型对比 1440/1920/窄屏，检查空/加载/错误/生成/完成/待更新、弹窗键盘、刷新、项目隔离和模块切换。付费生成与真实服务端持久化不在本次范围。
