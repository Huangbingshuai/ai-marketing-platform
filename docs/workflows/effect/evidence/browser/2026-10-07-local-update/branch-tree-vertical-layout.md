## 调整范围

仅修改现有版本树的展示坐标。父节点对齐按创建时间排序的首个子节点，项目对齐首个导入节点；其他兄弟子树预留右侧独立列。保留版本归属、状态、黄边、红色活动路径、切换与持久化逻辑，不创建或覆盖任何工程数据。

原来父节点取最左/最右子节点的中点，而项目取整张画布中点，后代数量不均衡时会造成项目与导入错位。新算法不再因分支宽度增加而移动原始主干。
