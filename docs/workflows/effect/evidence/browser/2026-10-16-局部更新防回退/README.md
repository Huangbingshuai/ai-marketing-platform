## 发现与处理

工作区安装已有草稿 revision 栅栏，但异步模板目录没有同等保护。目录只在素材轮询 epoch 改变时保留新投影；任务完成或保存先接受新工作区、旧目录随后返回时，旧工程缓存和待归槽计数仍可能被安装。模板切换会读取该缓存，因此不能只把目录当成无影响的只读展示。

修复按同一Run的草稿revision保留较新的完整工作区，替换迟到的旧缓存；不比较不同Run的revision，不改写独立历史分支。返回混剪节点重新读取已保存工作区及模板当前路径。普通工作台轮询也检查当前路径变化，不再永久轮询旧路径；显式历史查看、在途任务、未保存编辑继续保持各自作用域。

隔离复现脚本使用34→39→40的两轮完成结果和旧目录响应：旧逻辑回到34条、待归槽1条；修复后保持39条、待归槽0条；第二轮保持40条。此为机械竞态复现，不是新增真实付费生成。数据见 [目录竞态复现](directory-race-repro.json)。
