# 混剪工作台基础交互浏览器验收

日期：2026-10-16。环境：[运营部署站点](https://marketing.richbest.cn/)，广式腊肠项目，效果类模板混剪节点。使用独立 Chrome 浏览器会话与真实服务端；前期候选 Web 资源经浏览器路由加载，最终移除路由，直接访问部署资源复测。

本轮范围为轨道、素材库与播放器日常操作，未启动智能填充、智能包装、配音、音乐生成或最终导出。创建临时成片 40、41 与一个本地合成的 8 秒 MP3，结束后通过现有删除/归档入口清理。原模板与 39 条已交付成片保留。

## 发现与修复

| 问题                                                                 | 修复与实际回归                                                                                                                                                                               |
| -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 素材拖入空白视频轨道没有落位，空隙也可能被当成最后一条素材的替换目标 | 按指针所在行和时间新增片段；轨道边界继续新增行，已有素材区域继续替换。真实拖放验证空工程首次落位及同一行空隙追加。                                                                           |
| 视频轨道已锁定，Delete 仍能删除选中素材                              | 删除入口检查视频、音频和字幕实际所属轨道的锁定状态。线上依次先选中、再锁定、按 Delete，数量分别保持 3、3、2；解锁后字幕删除与撤销正常。                                                      |
| 裁剪/分割的界面变化无法保存                                          | 模板生成时长与手动时间轴片段校验分开。短片段保存成功并刷新恢复；人工输出机械校验允许同一源视频的分割片段，自动填充去重和源文件区间校验继续保留。无口播的叠加画面不再误用口播槽位的最小时长。 |
| 复制已包装口播/配乐后，服务端拒绝保存                                | 补齐文件来源标记，复制时保留口播/音乐种类与音乐循环属性。跨成片复制的口播、24 秒配乐均得到真实保存回执，口播分割与音量修改也能保存。                                                         |
| 裁剪后的短视频无法粘贴                                               | 手动粘贴按实际源视频截取范围检查有限数值及有效时长。线上复现 1.9 秒片段被拒绝；修复后保存为时长 1.9 秒、源偏移 1.3 秒，并保留素材引用。                                                      |
