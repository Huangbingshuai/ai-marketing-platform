# 智能填充完成后的结果展示衔接验收

日期：2026-10-14。范围：效果类第五节点模板混剪 Web。依据：[实施计划](../../plans/2026-10-14-智能填充完成展示衔接.md)。

## 原因与修正

服务端先将任务和草稿记为完成，之后确认工程及发布分支；前端原来仅显示排队/运行任务，完成回执先到时立即隐藏进度，工作区尚未载入就出现空白等待。完成函数又会停止原轮询并中止其控制器，后续结果读取异常不能依靠该轮询的异常分支恢复。

现在保留同一真实任务的完成回执，以项目、来源/执行 Run、模板和任务隔离。原进度条显示“正在同步成片工程”，不改变服务端终态或按时间虚增百分比；工程身份、同任务完成记录、模板确认版本及解锁状态已载入后才收起。读取失败、revision fence 拒绝及分支尚未发布均自动续读，不再次生成、不新建付费任务。后台重新填充保留父分支，子分支已确认且发布才交接。刷新只恢复真实锁定模板的最新任务，旧完成任务不会占用新任务锁。

- `pnpm --filter @ai-marketing/web build`：通过，包含 vue-tsc 类型检查；保留 Vite 大于 500 kB chunk 提示。
- 范围内 `git diff --check`：通过，只有 Windows 行尾转换提示。

此次未改 API、Contracts、Worker 或数据库，不重启服务、不部署、不执行真实付费填充、不提交 Git。真实供应商生成、实际素材解码与全量测试失败项仍不在本次验证通过范围。
