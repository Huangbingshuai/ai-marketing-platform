# 全画幅播放器贴合回归

日期：2026-10-16。效果类模板混剪播放器及共用导出画幅适配。

## 范围与修复

全部九个菜单画幅：16:9、4:3、2.35:1、2:1、1.85:1、9:16、3:4、9:19.5、1:1。另检查 7:5、1:4、4:1 自定义比例。

共用 2.5% 对称容差已经覆盖所有画幅，不是 9:16 特例。此次全量补测另发现：4:3、16:9、2.35:1、3:4 在部分窗口宽度下，原生视频合成器对小数像素边缘取整，仍可能留下 1px 黑线。

新增只影响预览的像素对齐：依容器实时重新计算画布尺寸，将尺寸和位置对齐设备物理像素。等比缩放时以 `cover` 保持视频比例并消除亚像素边线；显式非等比缩放继续使用 `fill`，保留用户拉伸效果。窗口、面板、画幅及缩放变化重新适配，卸载清理观察器和事件；不修改工程内容、来源、分支或 revision。
