# 9:16 播放器上下黑边修复

验证日期：2026-10-16。作用域：部署站点的效果类「广式腊肠」项目、模板混剪精修播放器。浏览器只读取已有素材并播放，不启动 AI、包装或导出任务。

## 原因与处理

素材名义画幅为 9:16，真实文件是 496×864，相对标准比例偏宽约 2.06%。旧的 1% 匹配容差将其当成不同画幅，居中完整容纳，因此在 374px 高画布中只显示 366px 高的画面，上下各约 4px 黑边。

共享画幅适配容差与 FFmpeg 导出处理统一调整为对称 2.5%。此范围内等比铺满、居中裁去少量边缘；496×864 在 9:16 画布中高度为 100%、内容宽度约 102.058%，不拉伸。真正不同画幅仍完整容纳，用户显式空间变换继续生效。
