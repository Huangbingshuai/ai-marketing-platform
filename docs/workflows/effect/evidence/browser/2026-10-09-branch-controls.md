# 分支树工具栏遮挡修复验收

日期：2026-10-09。作用域：localhost 效果类「紫苏梅子酱」版本分支树。

## 边界与修复

仅调整共用版本树的视图工具栏布局。不修改分支归属、编号、待更新状态、
WorkingArtifact、业务 revision，不切换业务分支或启动模型任务。

原工具栏绝对定位在画布底部，覆盖滚动视口；1280×720 下工具栏顶部为
660.4px，画布底部为 720px。改为画布外的独立 flex 行，缩放、全图及定位
均使用已经扣除工具栏的真实画布视口。窄屏保留横向溢出访问能力。

## 实际检查

- 1920×1080：查看全图后 11 个节点全部处于画布视口内；工具栏与视口不相交。
- 1440×900：定位当前、放大到 110%、滚动到底部，两张输出节点完整可见，
  不被工具栏遮挡。画布底部 842.4px，工具栏顶部 850.4px。
- 390×844：查看全图 50% 时所有视图按钮均在屏内；定位当前恢复 100% 后
  当前聚焦节点完整可见。工具栏与画布仍不相交。
- 三套相关测试共 57 项通过；定向 ESLint 和 git diff --check 通过。
- 执行 Web build，但 vue-tsc 被本轮未修改的
  `customized-extraction-view.spec.ts` 的 node:fs/promises 类型声明及可选字符串
  类型错误阻断，没有宣称全量构建通过。
