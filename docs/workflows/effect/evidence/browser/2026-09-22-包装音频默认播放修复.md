# 包装音频默认播放修复

## 问题与范围

用户反馈主播放器播放时没有声音。包装组件的 `previewEnabled` 初始值及项目上下文重置值均为 `false`，生成的口播和纯音乐需要另外点击“开启同步试听”才会进入播放。这与主播放器应播放完整草稿的预期不符。

只修改模板混剪 Web 包装组件的本地播放行为。不调用生成服务，不修改时间轴、包装内容、revision 或工作副本确认状态。

## 修复

- 有效且已完成的包装默认随主播放器播放；不再要求单独开启试听。
- 保留“静音口播与配乐 / 开启口播与配乐”开关及明确状态文字。
- 将实际启用状态立即通知原素材音量混音；缺失、未完成和过期包装不启用。
- 暂停、恢复、拖动和更换成片继续使用主播放器时钟；浏览器拒绝播放时显示可操作的重试提示。

## 实际验证

广式腊肠项目、18 条工程模板，使用已保存的真实音频，没有发起任何付费任务：

- 成片 01 直接点击主播放：口播与配乐均 `paused=false`、`muted=false`、`readyState=4`，时间由约 0.1 秒继续增长。
- 主暂停：两条音轨均暂停。
- 播放中静音：包装音轨暂停，画面继续播放；恢复后音乐跳到约 19 秒，口播跟随对应句内时间。
- 播放进度 Home 回到起点：包装音乐回到约 0.02 秒；更换成片 02 后新音轨处于暂停状态。
- 冷刷新重新进入工作台：默认显示“口播与配乐随画面播放”；直接主播放，两轨均正常解码与启动，无需点击试听开关。
- 1920、1440、800 像素视口下包装状态条无内部横向溢出，静音和结果按钮均保留完整宽度；测试后恢复原视口。
- 读取成片 01 已存 WAV 检查非静音：首句口播 RMS 0.08695、峰值 0.4010、配置音量 1；音乐 RMS 0.08176、峰值 0.6817、配置音量 0.12。

以上验证的是页面媒体播放链路和音频文件信号，不声称能够替用户验证 Windows 输出设备、系统音量或实际扬声器听感。

自动检查：包装音频及进度相关 11 项测试通过；Web 类型检查和生产构建通过（保留既有大包提示）；`git diff --check` 通过。

## 后续交互收敛：仅主播放器控制

按用户后续要求，移除整条包装试听状态/静音/查看结果控制栏，不再保留独立音轨开关。主播放器统一驱动视频原声、口播和音乐；播放失败可通过主播放器暂停后再播放重试，不会每帧重复请求失败播放。原有“查看当前工作流”保留包装结果与单条详情入口。

浏览器实测：控制栏不存在；直接主播放，视频原声与两条包装音轨均为未静音且播放中；主暂停后在播放的媒体全部暂停；工作流弹窗和结果区域仍可打开。更新后的 11 项测试、类型检查和构建通过。未产生任何模型调用或修改业务产物。
