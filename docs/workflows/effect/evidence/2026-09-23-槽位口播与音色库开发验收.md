# 槽位口播与火山音色库：开发验收

日期：2026-09-23。范围为效果类模板混剪节点，不重新生成现有 100 条成片。

## 已实现

- 槽位容量由时长决定，6 秒以上检查最低朗读容量；长钩子/结尾不再固定限制为 15 字。策划过长/过短共用一次修正，实际 TTS 超时最多缩句一次，继续禁止跨槽位。
- 每槽位保存字符数、最小/目标/最大容量、真实音频时长和利用率。上传后检查点丢失可补齐指标，不重新调用 TTS。
- 左侧音频页新增服务端精选音色目录、选择保存、固定文案真实试听、缓存播放、取消及状态提示。切换只影响新包装/主动口播重做。
- 试听使用已有 Worker/队列；事务锁串行登记缓存和幂等别名；付费前记录提交标记。租约失效的未提交任务可重领，结果不明的已提交任务明确失败，不自动再次付费。
- 项目/Run/模板隔离；文件与试听完成原子绑定；重复上传相同文件可重放；未授权版本从目录屏蔽，包装创建同时拒绝。
- 音色目录收录用户从已开通 TTS 2.0 账户控制台提供的全部 99 个标准音色，speaker ID 固定维护在 API 源码目录中，不放入 `.env`，不向浏览器返回 speaker/resource 配置。

## 边界与待验证

- 本次没有付费重做长槽位，也没有启动 100 条包装。字符预算、缩句、音色冻结、局部重做和边界校验通过可控测试；新预算的真实口播自然度及利用率仍需后续小样本验收。
- 未用真实账户故意制造未授权/超时任务；这些路径通过可控测试覆盖。99 个真实请求只针对用户提供的账号控制台清单，不扫描或探测清单外的音色。
- 复用原服务、容器和队列，未新增服务、Compose profile 或队列；保留其他工作区改动，没有自动提交 Git。
