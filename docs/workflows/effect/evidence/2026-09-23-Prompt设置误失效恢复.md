- 广式腊肠项目 `65458686-034c-4258-b2dd-027d4ad15132`，效果类 Run `0504ef7a-114a-483d-afef-909639076508`。

- 修复：Prompt 设置草稿不再触发已确认产物的失效传播。确认产物变化后的 revision 传播、其他节点的失效规则、生成任务的设置指纹校验保持不变。

- 在事务中逐项验证项目/Run、来源 revision、内容哈希、输入指纹、文件状态和媒体可读取性。
- 恢复 102 个误标副本：1 个 Prompt、100 个渲染片段、1 个素材池索引。
