# 效果类恢复缓存扩展验收

日期：2026-10-08。本地开发 API（3100）、Web（5173）、PostgreSQL、Redis 7.4.10。仅本次扩展及相关缓存验证；没有执行付费任务。

## 当前缓存范围

| 读取     | 缓存范围                                                                    |
| -------- | --------------------------------------------------------------------------- |
| 资料导入 | 工作区、草稿/资料元数据、产品分页、移除列表；模式、关键词、分类、页码进入键 |
| 信息提炼 | revision 校验的恢复工作区                                                   |
| Prompt   | 恢复工作区、产品/过滤/分页结果                                              |
| 视频渲染 | 完整产品工作区、稳定批次展示；执行任务和返修绕过缓存                        |
| 模板混剪 | 工作区、来源素材投影                                                        |
| 成片输出 | 模板交付目录，活动任务绕过缓存                                              |
| 共用     | 效果类版本树、限定已审核节点及 Run 的确认产物读取                           |

没有将通用 Run 概览、混合节点产物列表、原始文档正文、二进制、签名 URL 或实时任务权威状态放入此缓存。每个命中请求仍读 PostgreSQL 依赖版本和项目权限；不能理解为完全停止访问数据库。

默认最低加载门槛由 50ms 调为 0，TTL 由 300 秒调为 1800 秒（±10%）；有界载荷、校验和、single-flight、超时断连回退保持有效。Redis 实例内存预算 256MiB，allkeys-lru；只读检查观察使用约 5.7MiB、尚无淘汰，属于实例整体数据，不是本功能独占统计。

## 修正的恢复开销

- 完整导入工作区初始化采用只读路径，反复 GET 不更新 updatedAt/xmin，不再使后续缓存失效。
- 页面读取不等待对象存储清理；持久化清理队列仍由后台处理器消费。过期预览在缓存命中期间也独立清理。
- 渲染工作区缓存覆盖原来的重复 Prompt、产品、设置和批次读取。
- 模板路径读请求和队列补偿保留原有隔离/修复语义；未缓存写操作。

## 实际限制

- 活动任务、来源版本变化、Redis 失败或载荷超过上限时仍走数据库；首读仍需构建投影。
- 同机其他构建和任务会影响数据库/事件循环，已观察并发负载下即使命中也可能耗时超过一秒；上表不是压力测试 SLA。
- 本次未执行全 API 历史测试、生产部署、付费生成端到端或大型数据压力测试；既有全套测试的基线失败见前一份 Redis 验收记录。
- 运行服务使用开发 watcher，生产 dist 构建不会更新生产进程。没有修改真实 .env 或重启 Redis。
