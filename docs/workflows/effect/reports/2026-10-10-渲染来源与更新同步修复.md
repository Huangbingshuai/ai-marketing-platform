# 渲染来源与局部更新同步修复

日期：2026-10-10。范围：效果类片段渲染及其宿主页面。按工作流节点 Skill 复用现有隔离编辑、提交与轮询链路，不修改 Worker、生成输入或数据库结构。

## 原因与修改

- `presentTask` 原先用“有输出但没有 providerTaskId”判断人工导入。替换 AI 视频时保留旧视频、清空本轮 providerTaskId，误将其标成导入。改为读取冻结输入中的持久化 `importedMaterial`，同时稳定来源名称；读投影版本升级到 4，避免复用旧标签缓存。
- 宿主页面原先在已有 Run 刷新进行时直接返回同一个 Promise，后来的完成通知可能丢失。现使用串行最新通知队列，迟到读取不应用；项目切换、显式分支加载和卸载使旧读取失效。同 Run 的连续更新也会重新读取。
- 局部更新的 Run 同步不展示整页切换遮罩。渲染预取不再先等待完成再挂载节点，而是与节点共享在途读取。后台同步不强制恢复旧节点或旧滚动位置。
- 渲染轮询忽略旧批次/旧 Prompt 响应后仍安排后续请求；定时回调清理已消费的句柄，临时失败后自动重试。已取消、旧作用域的错误不再创建定时器或提示。
