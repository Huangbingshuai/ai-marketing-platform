# 音乐库与时间轴音频素材

## 范围

- 将混剪工作台音乐库调整为参考图的交互：搜索/筛选、音乐卡片、选中后底部播放条；不复刻截图配色，不添加收藏或下载按钮。
- 保留项目级音乐资产导入；导入时将音频关联到当前项目与工作流运行可消费的 `FileObject`。
- 音乐卡片可拖到音频轨道。时间轴草稿保存项目资产来源、文件对象和裁剪/音量几何；包装快照和最终输出须实际消费该音频。

## 非目标

- 不改口播音色目录、包装生成音乐或口播生成链路。
- 不在本次增加服务端音乐搜索供应商、收藏、下载快捷操作或音乐版权判断。
- 不改变混剪模板、智能填充与成片输出的确认/提交边界。

## 数据与交互

- 项目音乐仍是 `Asset(type=VOICE_AUDIO, directory=AUDIO_ASSETS, tag=模板混剪音乐库)`。
- 导入请求携带当前 `workflowRunId`。API 在同一数据库事务内保存 Asset/AssetVersion 和指向其 storage key 的 `FileObject`，记录实际 SHA-256；项目/Run 隔离由 API 校验。
- 资产读取返回可选的 workflow FileObject ID，仅供当前项目素材交互使用。
- 新增时间轴音乐片段采用现有 `detachedAudios` 承载，扩展契约支持无视频槽位的音乐来源，并保留原视频分离音频的 `sourceSlotId` 约束。
- 包装快照校验音乐 Asset、项目、标签、FileObject、音频类型与时间范围；最终输出沿用既有 detached audio FileObject 输入/混音路径。

## 测试

- Contracts：新旧 detached audio 结构兼容、视觉 hash 不受音乐编辑影响。
- API：导入 FileObject 链接、Run 隔离、合法音乐拖入快照、失效/越权资产拒绝、包装 worker 文件读取授权。
- Web：参考布局、音乐搜索/播放/导入、原生拖拽和音频轨道落点、保存后恢复与播放。
- Worker：多个独立音乐素材按时间/裁剪/音量混音，超出时长和非音频输入拒绝。
- 浏览器回归：宽屏与窄素材栏、加载/空/失败、有曲目/播放、拖入时间轴和完成输出前的草稿恢复。
