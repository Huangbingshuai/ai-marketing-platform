# 叠化预览连续播放修复

## 范围

- 修复模板混剪播放器播放期间叠化进度因低频 Vue 状态更新而停顿、跳变的问题。
- 使用浏览器原生 Web Animations API 在合成器上连续驱动叠化透明度，不在每个动画帧触发整个编辑器重渲染。
- 保持暂停、逐帧、拖动播放针时按时间轴位置确定性显示静帧。
- 为 FFmpeg 导出增加真实编码帧验证，确保叠化起始、中点和结束顺序及中间帧混合正确。

## 非目标

- 不改动模板混剪时间轴、转场时长或 WorkingArtifact 提交语义。
- 暂不引入 MLT/Kdenlive 运行时依赖，也不切换到空间化 `dissolve` 像素转场。
- 不执行未经色彩管理的线性光转换；需先验证目标源片色彩元数据与部署 FFmpeg 能力。

## 验收

- 播放时叠化从当前进度连续运行到结束；暂停和 seek 后显示的进度准确。
- 播放器点击暂停、切换工程、卸载页面时不残留动画。
- FFmpeg 导出的真实帧在转场开始偏前以出场素材为主，中点混合两素材，结束偏后以入场素材为主。
- 运行模板混剪前端单测、Worker 成片输出测试、类型检查以及 `git diff --check`。
