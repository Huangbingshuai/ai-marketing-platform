# 精修工作台进入性能与包装按钮就绪

## 范围与边界

效果类第五节点模板混剪的配置到精修入口及包装只读状态查询。直接上游仍是同项目、效果类 Run 已确认的 Prompt、render-batch/render-clip 工作副本及其实际 revision；复用现有模板配置、WorkflowNodeState 草稿和包装任务接口。进入页面不生成工程、不调用付费服务、不增长业务 revision。人工保存及任务成功的 timeline-project/timeline-package 提交边界、下游成片输出均不改变。

## 诊断

- 包装按钮和 ACTION 入口把历史任务 loading 当作运行锁；首次进入、空任务列表的周期读取均会暂时禁用按钮。
- 当前模板的后台包装任务在组件初始化和历史列表返回时重复查询。
- 首屏卡片、模板待更新计数和包装准入反复执行相同素材差异扫描。现有42条工程的本地浏览器观察到约520毫秒主线程长任务；该记录不是全环境性能保证。

## 实施

1. 保留既有计算规则，以成片对象及素材池对象为键，复用响应式 computed 的素材净差异结果。真实绑定、来源 revision/文件/删除、槽位时长或素材池变化自动失效；不同池和作用域不混用，不复制业务状态。
2. 历史读取不禁用包装按钮、不吞掉点击；任务提交、真实活动任务、来源待更新和编辑冲突仍受现有准入及 API 幂等校验约束。
3. 同作用域并发后台任务读取合并；切换作用域或卸载取消，旧读取不能覆盖用户刚创建的新任务。保留后台任务发现及进度恢复。
4. 不改视觉布局，不新增缓存表/字段/供应商，不隐藏真实运行锁，不改变包装分支或付费语义。

## 验证

- 响应式缓存覆盖重复读取、单条编辑、两轮来源变化、删除/新增、不同素材池及兄弟工程隔离。
- 延迟初次历史读取时包装按钮仍可点击，点击只提交一次；真实活动任务保持禁止重叠启动。
- 后台查询合并、切换后迟到响应、创建后迟到读取、错误后的重新读取。
- 相关 Web 单测、类型检查、构建及 diff --check；1920/1440/窄屏下进入、返回、按钮状态和首屏时序。浏览器不点击确认付费生成。
- 不自动部署、付费测试或提交 Git。

## 本次验证记录

- 9 组相关 Web 测试共 113 项通过；Web 类型检查、生产构建通过，构建保留原有大分包告警。
- 扩大混剪目录回归：668 项通过、23 项失败。用只读测试插件撤除本次页面改动后，五个失败文件仍有相同 23 项源码断言失败；未修改这些既有断言或其他工作区改动。
- 浏览器隔离挂载真实 42 条工程的读取快照，所有写请求均拦截，历史及后台包装读取人为延迟 5 秒。1920、1440、390 宽度下按钮首次挂载分别约 72、59、75 毫秒，历史仍在 loading 时按钮均启用。该结果是本机配置到编辑视图的 DOM 就绪观察，不代表冷启动、远程网络或媒体全部加载耗时。
- 单测覆盖提交中防双击、真实任务锁、空工程准入、查询合并、卸载/切换/新任务使旧读取失效；浏览器未启动付费生成，也未编辑或发布业务产物。
