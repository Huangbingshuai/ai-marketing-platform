# 模板列表即时切换作用域修复

## 范围与边界

效果类模板混剪 Web 导航。上游仍为已确认渲染素材与模板工作副本，保存按各自真实 Run 的草稿 revision 校验；下游时间轴与成片输出规则不变。不创建任务、全局分支或业务 revision，不启动付费生成。

## 问题

列表已经缓存各模板所属 Run 的完整工作区，但跨 Run 点击提前把“已安装作用域”改成目标作用域，再安装缓存。后台同步保留选择的逻辑因此误判为同工作区刷新；目标 Run 中继承了旧模板时，会继续选中旧模板。原有测试用安装 mock 且每个 Run 只有一个模板，未覆盖真实安装与继承目录。

## 实施

- 已确认的缓存命中时同步安装目标完整工作区；先安装成功，再更新已安装作用域，明确保留用户这次指定的模板，不等待请求或导航保存。
- 缓存草稿中可能包含其他继承模板；它们不能取代本次点击指定的目标，目录投影仍不混入可写草稿。
- 已修改内容先按旧作用域保存；失败保留原编辑。过期缓存、缺失缓存仍读取权威工作区，不绕过 revision 栅栏。
- 取消旧读取，保留跨项目、连续选择、任务锁及未保存编辑保护；不改变普通模板选择与版本树切换的职责。

## 验证

新增真实安装回归：两个 Run 各包含多个继承模板，缓存点击立即显示目标模板与配置，不调用 load，不保存导航；连续 A/B 切换保持 owner 和 revision。运行导航、后台同步、目录、草稿竞争、工作区读取相关测试及 Web 类型检查、构建、`git diff --check`。浏览器检查已有模板来回切换及桌面/窄屏，不新开付费任务。
