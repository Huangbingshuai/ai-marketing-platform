# 模板删除非阻塞交互修复

## 范围与原因

后台删除已有持久化回执和分阶段清理，本次修复效果类模板混剪及成片输出的页面交互。删除请求之后不再等待整个工作区刷新，不以创建新版本的方式刷新父页面，不锁住其他模板。共享渲染素材和其他模板的数据不变。

## 实施

- 提交期间仅目标条目显示“正在提交删除”；受理后立即移除模板，提示后台清理仍在进行。失败保留原条目，允许重试。
- 使用已安装工作区的 revision 提交删除，保留服务端冲突校验。回执可选返回该请求作用域的新草稿 revision 及移除的 Run 身份；兼容旧回执，不额外读取全部历史工程作为删除前置条件。
- 当前模板被删除时选择仍存在的模板，退出被删除的工程；删除非当前模板不打断当前编辑。清除已取消任务和旧导航产生的锁定状态，保留无关编辑与任务。
- 父页面无蒙层刷新版本树；仅当前全局 Run 确实被删除时刷新其活动上下文，不将普通后台清理当成新版本发布。
- 复用成片同步事件，使成片节点及时移除模板、预览、交付列表及设置，阻止迟到请求复活条目。后台读取失败时保留其他可用内容并提供重试。

## 验证

- 回执受理不等待文件/Redis，目标及非目标模板、当前及非当前 Run、最后一个模板、重复提交、失败重试和迟到响应。
- Web/API/Contracts 相关测试、类型检查、构建与差异空白检查；浏览器验证删除确认/取消、列表与成片交互。
- 不实际删除用户模板，不启动付费任务，不部署、不自动提交 Git；真实删除成功与后台彻底清理应分别说明。

## 实施验证记录（2026-10-09）

- 增加删除受理回执的可选草稿 revision、退休 Run 身份；删除 API 的文件/Redis 清理仍在原后台队列中执行。
- SFC 实际删除函数以延迟 POST 和永不完成的刷新测试：受理后按钮恢复，非当前模板编辑保留；失败、取消、保存失败及项目/模板切换均覆盖。成片 SFC 的实际同步处理测试覆盖隐藏页面、重复事件、删除预览和其他交付保留。
- Web 定向回归、Contracts 来源/时长回归、API 单元及随机隔离 PostgreSQL schema 删除集成通过；Contracts 构建、API 类型检查/构建、Web 类型检查/构建通过。具体总数以本轮最终执行输出为准。
- 浏览器取消真实删除弹窗，随后切换剩余模板、查看成片列表；1920、1440、390 宽度模板按钮可用，无页面横向溢出或控制台错误。未确认删除任何用户数据，未执行付费生成。
- 扩大成片导航/布局回归仍有既有断言失败：预览测试缺少 `emit` mock、旧轮询文本断言，以及旧导出进度/标题布局断言。未以恢复旧轮询或改写无关导出行为处理这些失败。
- 当前本地 API 已由 `dist-dev/main` 热更新入口运行，删除回执编译产物早于当前进程启动时间，健康检查正常；本轮未手动重启或执行外部部署。
