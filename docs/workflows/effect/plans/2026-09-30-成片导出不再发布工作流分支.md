# 成片导出不再发布工作流分支

## 范围与非目标

- 模板混剪成功填充、包装仍按现有规则创建分支；成片输出不是新的混剪输入，不应占用混剪编辑分支。
- 点击导出或重新导出时，沿用当前模板混剪 Run 中的 `EffectFinalOutputRun`，不为 `FINAL_OUTPUT` 新建、发布工作流子 Run。每条完成时仍保存 `final-video:*` 工作副本、文件及项目资产；重导期间旧文件指针保留，成功上传后替换。
- 全部条目成功且有文件、资产，即为成片导出成功。`final-delivery:*` 交付清单可自动提交和幂等恢复，但不再是用户完成状态或混剪准入的条件。
- 不改变 FFmpeg、供应商任务、队列、重试或混剪节点自己的分支规则；不删除历史成片和文件。

## 兼容与迁移

- 旧版已创建但未发布的 `FINAL_OUTPUT` 自动子 Run 保留审计和输出。活动的此类 Run 可作为下一次混剪自动分支的来源；其它未发布编辑态继续拒绝跨节点写入。
- 历史已发布成片分支保留在树中。新导出不再产生此类分支；同一混剪分支里的重复导出只推进本地交付清单 revision。
- 不直接改写历史 PostgreSQL 记录，不重渲染或重复付费生成。

## 验证

- API 单测：首导、重导不调用 `beginEffectNodeEdit(FINAL_OUTPUT)`，不切换 Run；非活动 Run、并发导出、失败恢复与文件替换仍有保护。
- 分支测试：旧未发布成片子 Run 可发起混剪自动分支，其它未发布子 Run 不可跨节点编辑。
- Web：导出后保持当前混剪 Run；全部成片成功即显示完成，无发布或完成校验交互。
- 执行 API/Web 类型检查、相关测试和 `git diff --check`，不自动触发真实付费渲染。
