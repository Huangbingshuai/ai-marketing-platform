# 包装自动恢复与 100 条付费复测

- 范围：广式腊肠／测试1 的 100 条成片，全量重生成槽位口播、配音、字幕和配乐；不提交工作副本、不启动最终输出、不修改时间轴。
- 复用现有 Worker/队列/Run/检查点，参考 Prompt 的有界重试与已成功结果复用原则。每条最多自动补跑 2 次，持久化次数，重启不得重置预算。
- 重试网络暂态、模型明确可重试错误、TTS 429/5xx 或不完整流；不自动重试来源、版本、配置、槽位越界错误。音乐提交结果不明时禁止重发；已取得 TaskID 只继续查询和下载。
- 新增兼容可选检查点字段 automaticRetries；API 校验整数 0–2。重新生成组件是新任务，可重置自动重试预算，恢复同任务保留预算。
- 验证：暂态恢复、次数耗尽、取消/旧租约、永久错误、未知音乐提交、成功检查点不重做；Contracts/API/Web 类型检查、Worker 测试与类型检查。
- 实测记录：创建/开始/结束时间、成功失败数、自动重试次数、阶段耗时、缓存命中率。首轮与后续人工修复恢复耗时分开统计，服务中断如实记录。
