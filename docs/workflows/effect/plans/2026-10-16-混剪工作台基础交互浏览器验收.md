# 混剪工作台基础交互验收

范围为用户要求的工作台日常操作：素材库分类/筛选/搜索/预览/上传与引用，成片选择，视频/音频/字幕轨道，拖放、移动、截取、分割、删除、撤销/重做，轨道锁定/可见/静音、参数面板、播放器跳转/播放/缩放、草稿保存、刷新恢复及响应式。具体入口以当前正式页面实际存在的功能为准，不假设每一种编辑方式都已实现。

不触发智能填充、智能包装、配音/音乐生成、最终导出或其它付费能力。使用已完成的广式腊肠素材与包装工程；修改测试优先使用现有复制/新建机制产生可识别的临时工程或模板，保留原 39 条交付和原模板内容。记录基线与真实 API 回执，清理本轮创建的临时对象，不能删除用户素材或借数据库改写代替交互。

所属流程/节点为效果类 TEMPLATE_MIX。直接来源为服务端已确认 Prompt 和渲染素材实际 artifact/revision，工作台草稿沿用 WorkflowNodeState revision 和已有模板/成片身份。普通导航和编辑自动保存不伪造 WorkingArtifact 提交；确认时间轴/包装以及输出的既有边界保持不变。下游 FINAL_OUTPUT 只显示真实工程差异，不自动付费重渲染。

先复现并记录 Bug，再沿现有 Web/API/Contracts 实现修复，必要时补充机械契约回归。修改后执行相关单测、类型/构建、diff 检查；在 1920/1440/窄屏和刷新恢复情况下回到真实浏览器验证。源码在本地修改后同步服务器，Web 原子替换入口且设置可读权限；API/Worker 只有需要修改且无活动任务时才重启。不提交或推送 Git。
