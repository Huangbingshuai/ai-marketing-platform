# 模板混剪包装：口播字幕按标点拆分

## 范围与非目标

- 每个素材槽位仍只生成一条口播和一份配音；字幕仅在逗号、句号、感叹号、问号、分号、冒号、省略号处拆为多个相邻的时间轴素材。顿号 `、` 保留在字幕中；不按固定字数拆开词语。
- 保留当前包装 Run、工作副本、统一完成边界和成片输出节点；不增加供应商请求、容器或队列，不重新生成已保存口播与音乐。
- 本次不自动改写已确认的历史包装。旧版字幕继续播放；用户可逐条或在工作流面板一次性发起整模板“批量重做字幕”，从保存的口播和音频重建字幕草稿，再按原提交边界确认。

## 数据与兼容

- 新生成的包装使用字幕布局标记 `SEGMENT_V2`；历史 `SEGMENT_V1` 和更早字幕继续兼容播放，重做字幕时升级到 V2。字幕仍用 `voiceLineId`、`segmentIndex` 和 `segmentCount` 绑定原配音并检出缺段。
- 新字幕 ID 根据口播行 ID 与片段序号稳定生成。单槽位重做只删除该槽位关联的字幕；字幕位置框按原行继承到新片段，已有其它槽位不变。
- 服务端校验字幕属于现有口播、V2 文本不含需切分的标点、无缺段或重复段、按顺序覆盖该口播文字、相邻段没有间隙、不越过配音和槽位。V1 保持原来的无标点校验；最终输出仍只消费已确认副本。

## 生成与对齐

- Worker 保留原口播文案和整条 TTS 音频，仅切分展示字幕；连续分界符不产生空字幕，顿号不触发切分。
- 直接使用已保存的真实配音时长，按子句字数比例估算字幕边界。各段严格首尾相接，全部位于原配音区间内；这是低开销的句级估算，不声称字级精确对齐。
- 新生成和仅重做字幕都无需读取或分析 WAV，不增加供应商调用与音频下载；保留用户已调整的配音、音乐和裁剪设置。
- 字幕-only 批次采用本地处理的独立预计耗时基线；失败恢复时吞吐只根据最近完成项计算，避免沿用整片包装的付费阶段耗时。

## 验证

- 覆盖顿号保留、中文/英文分界符和连续标点、无标点长句不强制断词、空段、相邻区间边界、旧结果兼容、单槽位重做与字幕只重做且不读取媒体。
- 执行 Worker、API、Contracts、Web 类型与相关测试；检查时间轴和最终烧录逐段展示。对现有数据只进行明确触发的字幕重做，不暗中增加工作副本 revision。
