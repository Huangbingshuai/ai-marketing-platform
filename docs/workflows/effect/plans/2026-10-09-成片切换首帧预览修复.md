# 成片切换首帧预览修复

## 边界

效果类第五节点精修播放器，复用服务端返回的素材 URL、内容哈希、revision 和工程截取起点。
只改变媒体加载与展示，不改变 render-batch、mix-template、timeline-project 或包装工作副本，
不提交 revision，不影响成片输出依赖，不启动模型或编码任务。

## 实施与验收

- 视频来源变化时按素材身份隔离元素，Vue 完成地址更新后再同步截取时间。
- 复用既有缩略图缓存，成片封面按实际首槽截取起点预热，切换时显示对应预览。
- 新首帧必须完成 seek 和绘制后才撤下预览；旧元素事件和迟到绘制回调不能发布新成片状态。
- 连续切换、同来源不同截取、元数据未就绪、空槽/隐藏轨道、媒体失败和退出释放均须覆盖。
- 执行相关媒体单测、Web 类型/构建与 diff 检查，在当前项目中验证切换、播放和刷新。
  不对网络首次下载承诺零耗时，未缓存时显示明确加载状态而不是无解释黑屏。

- 首帧绘制门控、seek 队列、播放时钟、媒体缓存、模板导航五套聚焦单测共 48 项通过。
  覆盖元数据未完成、错误截取、来源替换、连续请求覆盖及退出取消。

  构建仍提示既有大包体积警告，未因本次修复引入其它依赖。
- 扩展执行布局与编辑上下文套件时，共 100 项中 73 项通过、27 项失败，
