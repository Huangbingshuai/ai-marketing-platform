# 智能成片包装：自动重试、实时结果与单成片包装

## 目标与边界

一次点击完成整批包装，失败步骤自动重试，尽量在本轮完成全部成片。最终失败的成片恢复包装前原样，可随后单独包装或手动编辑，不提供恢复未完成项入口。

属于效果类模板混剪节点。直接上游是冻结的时间轴、素材及产品事实工作副本与其实际 revision；输出为逐成片 timeline-project、timeline-package，成片输出由用户另行导出。复用任务、Outbox、检查点、租约、attempt token，不新增数据库表。

## 包装范围与分支

- 整批按钮每次创建新任务，在独立子 Run 对全部可包装成片重新包装，不恢复旧任务，不沿用旧口播、字幕或配乐。
- 完成一条立即持久化并展示，可预览。整批结束至少一条成功就发布新包装分支，失败条目保留包装前原样；全部失败不发布无变化分支。
- 时间轴工具栏新增成片包装按钮，只处理当前成片，原位覆盖当前分支，不新增分支。局部更新追加的自动包装继续原位执行。
- 保留项目、Run、模板、来源就绪、文件及编辑冲突校验；不代替素材局部更新，不自动编码最终视频。

## 清理、顺序与锁定

- 冻结完整包装前基线；运行工作视图仅保留视频画面，清除口播、字幕、配乐、独立音频、分离原声等非视频轨道，不物理删除历史文件。
- 成功事务提交新包装；失败或取消恢复包装前全部内容，不留下半套结果。
- 按实际画面开始时间排序，使用明确 slotId 保持用途关联；保留间隙、空槽、时间位置与总时长，空白区间无口播字幕，叠加画面不参与口播，配乐覆盖原总时长。
- 锁仅覆盖尚未结束的目标成片，防止编辑、删除和重叠任务，允许播放查看切换；结束后解除锁定。其他成片、模板、工作流不受影响，结束汇总不得覆盖已解锁后的人工编辑。

## 自动重试与持久化

- 同一任务与冻结输入自动续跑缺失步骤，成功步骤不重复。按环节持久化次数、等待状态、耗时，重启不重置预算，避免层层叠加重试。
- 配音明确未连接最多8次、600秒；其他可恢复步骤默认追加2次，指数退避上限30秒，遵守可靠的供应商等待指示。单条40分钟总上限含等待，可配置。
- 临时网络、限流、可恢复服务错误自动处理；权限、配置、文件失效、来源冲突、取消、旧 attempt 不盲目重试。付费响应不明先查询已有任务，无法确认则停止，避免重复计费。
- 复用 Outbox 与过期租约恢复，等待不占供应商并发；页面退出不影响任务。分支发布与下游同步失败幂等续办，不重调模型。
- Contracts 增加可选整批/单条执行语义、清理前基线和重试进度，复用创建接口及 variantId。历史协议兼容，不自动启动旧失败任务。

## 界面

- 成片包装按钮位于时间轴操作提示与缩放控件之间；右侧绿色进度条，再右侧阶段与真实进度，提交期间立即显示正在提交。
- 整批一条进度，显示完成数量、阶段和自动重试；逐条刷新结果，不刷新整个工作台或重置播放滚动位置。
- 移除恢复入口、失败恢复横条及所有包装状态卡片标签。最终失败集中在任务结束摘要和工作流详情，说明保留原样；普通包装按钮始终表示创建新任务。
- 终态不保留运行百分比，不把部分失败伪装全部成功。刷新和切换恢复任务与锁，迟到响应不可跨作用域覆盖。

## 验证

- 整批首次、再次、部分失败、全部失败分支；单条原位且其他成片/历史分支不变。
- 自动成功、耗尽、响应不明、重启、重复消息、取消、迟到回调、成功步骤不重复。
- 全部旧音轨字幕运行时清理，成功无残留，失败完整恢复，恢复后可单条包装或人工编辑。
- 首中末空槽、多间隙、画面重排、实时可播放、成片粒度锁、切换与人工编辑不被覆盖。
- Contracts/API/Web/Worker相关测试、类型检查、构建、git diff --check；浏览器1920、1440、窄屏。
- 同步效果类指南。默认不启动付费任务、不部署、不自动提交 Git。
