# 成片工程增删与输出局部同步

## 范围与边界

- 精修工作台每个成片工程提供删除操作，确认后只删除当前模板、当前 Run 的工程草稿。允许删除最后一个工程。
- 已导出分支的工程新增、删除由当前工程集合与输出快照按 variantId 比较，计入待更新；不根据名称匹配，不自动付费渲染。
- 成片节点的局部更新是显式确认点：移除已删除工程的输出条目，追加并渲染新工程，仅重渲染选中的已变化工程，其他成片文件保持不变。
- 历史和其他模板分支独立；不删除共享文件、归档资产或历史版本，不新增分支。完整重新导出仍沿用原有分支流程。

## 数据与接口

- 复用 TEMPLATE_MIX 草稿、timeline-project 工作副本及 FINAL_OUTPUT 批次、交付清单，不新增表或平行状态。
- 工程删除接口复用 workflowRunId、expectedRevision 校验和混剪 mutation 保存机制。
- 输出读取接口增加可选 projectChanges（新增工程 ID/名称、已删除工程的输出 itemId）；counts.stale 包含新增工程。
- 局部更新增加可选 syncProjects；旧调用仍只更新所选条目。同步工程集合时允许 itemIds 为空；无变化请求拒绝，重复请求不重复追加。
- 新增工程复用现有校验及时间轴提交能力，缺少素材或源文件失效时整体拒绝，先保留旧输出。复用已完成包装；未包装工程按现有纯画面/人工音频规则输出。

## 事务、并发与失败

- 在当前模板分支、输出批次和草稿锁内校验工程集合与版本，确认新时间轴、删除条目和追加队列在同一事务内完成。
- 只有新增或变更条目进入现有 Outbox/Worker；仅删除时直接更新交付清单，无任务、无费用、无分支。
- 全部删除支持空交付清单，模板本身保留。旧文件仍供历史分支使用。
- 混合更新任务失败保留其他完成项和旧文件；恢复失败项复用既有重试入口。

## 验收

- 删除任意/最后一个工程，按钮不触发卡片选择，取消确认不修改草稿；revision 冲突和跨模板 ID 拒绝。
- 已导出后新增/删除工程准确待更新，其他模板、项目、历史分支不串数据。
- 仅删除无 Outbox；仅新增及混合更新只渲染必要条目，规格沿用旧批次，现有文件不变，交付清单同步。
- 无效新工程、不可用源文件、重复请求、并发和失败重试不会重复追加或丢失旧结果。
- 运行相关 API/Contracts/Web 测试、类型检查、构建、浏览器交互回归及 git diff --check；已有失败单独记录。
