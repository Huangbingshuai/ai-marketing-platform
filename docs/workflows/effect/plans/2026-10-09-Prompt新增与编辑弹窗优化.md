# Prompt 新增与编辑弹窗优化

## 目标与范围

- 效果类素材 Prompt 节点的新增和编辑弹窗复用独立组件，沿用系统白底、蓝色主操作及浅灰边框。
- 正文为主要输入；新增时的创意方向及六大维度默认折叠、逐项选填，可全部留空或仅填写部分。
- 去除“待补齐”的条目展示；人工条目不因缺少可选信息阻断保存及后续渲染。
- 编辑仍只修改正文，展示固定时长和时长不变提醒。取消继续丢弃临时修改，保留来源标签与语义重复度。
- 根据视觉反馈采用克制的编辑工作台布局：新增左侧正文、右侧素材设置，编辑保持单栏大正文；轻量图标、细边框与字号层次替代大渐变及装饰卡片。窄屏自动单列。参考 UI Skill 的留白和输入层次，不采用其珊瑚色主题或新增依赖。

## 参考与采用点

- [Open WebUI 提示词编辑器源码](https://github.com/open-webui/open-webui/blob/main/src/lib/components/workspace/Prompts/PromptEditor.svelte)：正文与元信息分组、可选信息不强制输入。
- [Open WebUI 文档](https://docs.openwebui.com/features/workspace/prompts/)：只将真正必要的输入设为必填。
- [shadcn/vue Dialog](https://www.shadcn-vue.com/docs/components/dialog)、[Collapsible](https://www.shadcn-vue.com/docs/components/collapsible)：清晰标题、正文滚动、稳定操作区和渐进展开。
- 采用布局和交互方式，不引入上游组件依赖，不复制上游业务逻辑或配色。

## 数据与边界

上游仍为当前营销洞察工作副本及实际 revision；人工编辑保留所属 Prompt 批次来源。请求允许省略创意主线或任意维度，持久化维持现有字段与完整六轴键，空内容保存为空字符串，不填造占位语义。AI 条目仍要求完整创意信息。同步 TypeScript 请求、JSON Schema、API 解析和 Worker 的人工条目结构解析。

新增及正文编辑仍只修改隔离编辑态，用户保存列表修改时沿用既有 Prompt 工作副本提交边界；下游按实际内容变化更新。无模型调用、无付费测试、无数据库迁移。

## 验收

- 只填正文、部分填写、完整填写均能新增并读回；空正文、非法时长、未知维度或超长字段仍被拒绝。
- 人工空创意信息不进入待补齐状态、不被结果解析过滤；AI 条目结构校验保持严格。
- 浏览器检查新增/编辑、展开收起、取消恢复、键盘操作及宽屏/窄屏布局。
- 运行相关 Web/API/Contracts/Worker 测试、类型/语法检查、构建及差异检查。

### 时长输入上下限补充

- 人工新增继续复用契约的 4～30 秒整数范围，不调整批量生成 4～15 秒或已有条目只读规则。原生 min/max 外增加实际输入纠正：超过上限即时回到 30，非正数回到 4，小数四舍五入；低于下限的 1～3 允许作为键入 15、25 的中间态，失焦时回到 4，清空失焦也回到 4。提交前再次机械归一化，仍保留原生表单及服务端校验。
- Web 状态、布局、保存请求相关 52 项测试通过；浏览器组件验收覆盖 50、100、1、0、负数、小数、空值、逐键输入 15/25、上下箭头边界及提交值，并检查 1920 / 1440 / 390 宽度。未连接项目 API 或模型。
- 输入框新增范围说明，见 [时长上下限](../evidence/browser/2026-10-09-prompt-dialog/duration-limits-1440.png)。临时验收页已移除。

### 兼容片段类型交互与排列补充

- 按最新确认需求，切换主用途时清空全部额外兼容选择，包括之前用户主动勾选的用途；新主用途继续按既有契约包含在兼容数组中，但不展示为额外选项。用户须基于新主用途重新勾选，连续切换不累计或恢复旧勾选。
- 兼容用途改成等宽单列，选中图标预留位置，勾选前后不改变控件宽度、不产生两项一行加一项落单的跳动。
- Web 相关 55 项测试及生产构建通过；最新正式组件独立浏览器验收覆盖主动勾选多个额外用途后切换主用途全部清空、连续切换及切回不恢复旧勾选、重新勾选后的提交数组。此前布局验收覆盖 1920 / 1440 / 390 宽度。未连接项目 API 或模型，临时验收页已移除。[布局截图](../evidence/browser/2026-10-09-prompt-dialog/compatible-purposes-fixed-1440.png)
