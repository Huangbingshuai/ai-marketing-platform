# 混剪波形可见性与时间对齐修复

范围：效果类第五节点精修时间轴，复用当前 Run/模板/成片的已确认素材与包装文件。波形仅为媒体派生显示，不写 WorkingArtifact、不推进 revision、不触发下游或付费任务。

## 已确认原因

- 视频源波形 READY，但包装流程将原声音量设为0，波形显示乘以0后退化为不足1px的底线。
- 波形柱存在 max-width，长音频达到柱数上限后，实际柱列短于音频条；短条又因 min-width 与 gap 溢出，破坏时间映射。
- 原采样窗口把超出源文件的区间压缩到已有样本范围，不应让截取/延长后的显示与实际播放时间不一致。

## 实施与验收

1. 源视频波形独立于播放增益，原声零音量仍保留绿色源波形；用户明确关闭视频轨声音时沿用原有置灰规则，不擅自恢复声音。
2. 每根柱按等宽时间桶铺满整个条目，取消固定柱宽上下限；真实静音保留底线，未解码/失败不伪造波形。
3. 按源偏移和时间轴时长采样；源结束后的范围显示静音，不伸缩或循环伪造数据。淡入淡出和音频增益继续按现有规则展示。
4. 单测覆盖截取、源末尾、跨末尾时间桶、静音、空/失败和柱数；浏览器核对视频高度、音乐最末柱与音频边缘、主要宽度及缩放；类型检查、生产构建、diff检查。

非目标：不重做包装、不调整文件、音量或导出行为、不修改全局业务默认值。
