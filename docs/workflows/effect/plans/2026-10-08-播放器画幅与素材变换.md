# 播放器画幅与素材变换

## 范围与边界

效果类模板混剪精修工作台新增每条视频片段的空间变换和每条成片工程的画幅选择。直接消费同项目、同 Run 已确认的 render-clip / render-batch revision；复用 TEMPLATE_MIX 草稿 revision、自动保存、撤销重做及 timeline-project 工作副本。已导出的成片仍保留旧文件，由用户主动局部更新采用新画面。不生成新分支，不调用付费模型，不自动提交 Git。

## 交互

- 按用户后续确认取消固定锁定：所有工程均可选画幅；未人工选择时默认使用渲染节点画幅，adaptive 默认统计当前有效素材池出现最多的实际比例，不随播放针或试听素材改变。等价比例合并计数；数量并列优先 9:16，未包含 9:16 时按比例升序稳定选择；空池兜底 9:16。人工选择优先保留，“默认画幅”清除人工选择、恢复上述默认规则。支持自定义比例，以及 16:9、4:3、2.35:1、2:1、1.85:1、9:16、3:4、5.8寸、1:1。5.8寸按常见全面屏 9:19.5 比例实现。
- 选中当前可见视频后显示白色边框与角点，允许移动、缩放。复用字幕辅助线样式，支持中心横纵线及四边吸附。原素材试听不修改工程。
- 视频控件位于三个面板与时间轴之间，横向排列：缩放滑杆/百分比、等比开关、X/Y、旋转、左/水平居中/右/顶/垂直居中/底对齐；多选时开放横纵等距分布。无关键帧。位置按当前素材分辨率对应的画布像素标尺显示，持久化按画布宽高归一化，避免预览尺寸或导出分辨率改变导致位置漂移。
- 保留独立预览缩放；不会混淆成素材缩放。动作按一次手势进入撤销历史，不逐帧增加 revision；只在手势结束保存。锁定或运行中不可编辑。

## 数据与导出

- 向现有 Variant 增加可选 canvasRatio 与 videoTransforms（按 slotId），历史缺失为居中、100%、0°。变换使用中心位置归一化偏移、X/Y 缩放与角度；不新增表或第二套状态。
- API 验证有限数值、比例、范围和合法片段 ID；渲染画幅只提供默认值，不再拒绝人工画幅覆盖。保留历史内容兼容读取，不自动迁移或增 revision。
- 输出快照、画面差异指纹及迟到回调校验包含变换和画幅；包装来源不因空间变换失效，保留独立口播/字幕/音乐。
- FFmpeg 按 contain 基准缩放、旋转、定位并裁切到黑底画布；预览与输出使用同一几何规则。自定义比例支持有限正数及合理长宽比，保持偶数输出尺寸。

### 时间轴单击素材按钮栏修复（2026-10-09）

原因：选中视频后清空音频/字幕选择，异步发出的空选择事件又清除了父页面的视频变换选择；已高亮或恢复选中的视频再次单击时，旧处理还会跳过选择事件。修复为空选择只清理所属轨道状态，真实音频/字幕选择才隐藏视频按钮；再次单击已高亮视频也重新发送上下文选择。仅修改界面选择同步，不更改工程内容、来源 revision、API 或输出任务。
