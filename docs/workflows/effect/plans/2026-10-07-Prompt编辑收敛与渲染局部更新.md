# Prompt 编辑收敛与渲染节点局部更新计划

## 目标与边界

复用现有编辑分支、局部更新、异步任务和工作副本链路，补齐 Prompt 修改、新增、删除向渲染素材池的同步。不重跑历史成片、不自动触发混剪或包装、不物理删除历史文件、不自动提交 Git。

输入是已确认 marketing-insight 与 prompt-batch 工作副本；Prompt 草稿在保存时提交 prompt-batch，渲染编辑在保存/完成校验时提交 render-clip 和 render-batch。依赖记录实际 artifactId、revision 与哈希，只有受影响下游待更新。

## Prompt 节点

- 移除卡片复制、单条重新生成、候选采用/撤销入口和无用 UI 状态，保留整批生成/重新生成、人工后台评估及历史任务兼容；禁止新建单条 Prompt 重生成请求。
- 编辑/删除两按钮横向等宽、高 34px，窄屏移到卡片底部且保持一行，复用现有样式与确认组件。
- 已有条目时长只读且服务端拒绝修改；人工新增整数 4～30 秒，契约/API/Worker/评估/保存校验同步支持。整批 AI 默认时长规则不变。
- 人工新增超过 15 秒时渲染路由使用 2.5，不改全局设置；新增混剪模板上限仍按原批次统一时长，不受人工长 Prompt 或导入素材影响。

## 渲染局部更新

按稳定 Prompt ID 比较已采用来源与最新已确认 Prompt：正文/渲染输入变化重渲染；仅创意/六维/用途变化同步信息复用文件；新增补渲染；删除从当前池移除。修改显示黄色边框、待更新及更新素材；删除显示待移除。

- 顶部一次处理全部差异；单卡只处理当前素材，不顺带新增/删除其他素材。
- 确认弹窗拆分重渲染/新增/同步/删除数量，仅前两类产生视频费用；纯同步/删除无模型任务。
- 导入和未变化素材不动；手动删除素材不自动补回，删除不导致永久整批更新。
- 保留原分支、旧文件预览与已成功任务；新视频通过文件/来源校验后采用，失败定向重试。
- 沿用保存/校验提交边界，未确认草稿不影响混剪；保存后复用替换、删除来源传播。
- 人工全删允许保存空编辑结果，局部清空对应池；AI 生成不能以空结果冒充成功。

## 接口、并发与兼容

- 扩展既有 refresh 可选 taskIds（省略为全部）；继续校验批次 revision、Prompt revision 和幂等键。响应保留字段并增加更新类型、待删除 ID。
- 同一事务统一处理生成、同步、删除；仅真正生成写 Outbox。前端不创建第二套待更新状态。
- 保留已采用 Prompt 比较基线，排队请求不能提前清除待更新；期间再次保存仍显示新差异。
- 复用 JSON 快照与删除标记，不新增状态表、不批量迁移历史数据；缺失历史元数据不能触发无依据付费重渲染。
- 历史读取、在途回调与后台评估协议继续兼容。

## 验收

覆盖四类及混合更新、全删、未保存/取消、单卡隔离、无费用同步/删除、导入/未变保留、4/15/16/30及越界时长、固定已有时长、槽位上限、幂等/revision冲突/迟到回调/部分失败/项目和分支隔离。执行 Web/API/Contracts/Worker 相关测试、类型/语法检查、构建、git diff --check；浏览器回归宽窄屏及加载/空/错误/待更新/运行/完成状态。使用模拟供应商和事务回滚，不发起真实付费任务。

## 实施记录

已完成本计划范围内的实现，沿用既有编辑分支、工作副本、事务、Outbox 和系统确认弹窗；未新增状态表。

- Prompt 卡片移除复制和单条重生成及候选交互，保留整批生成、人工后台评估和历史协议兼容。编辑/删除等宽、高 34px，已有时长只读且接口拒绝改时长；人工新增支持整数 4～30 秒。
- 渲染 refresh 支持可选 taskIds，服务端区分重渲染、信息同步、新增和移除；信息同步及移除不入生成队列，导入素材及人工删除记录不被补回。排队不提前覆盖已采用基线，新结果通过原文件及来源校验后才采用。
- 人工长 Prompt 使用既有 2.5 能力路由，原批次统一时长继续作为模板上限。保存空人工 Prompt 可清空对应素材池，AI 空生成仍拒绝。
- 保留未变化素材的工作副本 revision 与所消费的 Prompt 来源；整批 revision 改变但该素材输入未变时，不误将其关联下游标为过期。明确的来源失效标记及实质输入变化仍生效。
