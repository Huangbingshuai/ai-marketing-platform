# 局部更新进度不回退与静默重连

## 边界与原因

效果类模板混剪节点，仅修正现有 Web 进度投影和只读重连提示；继续消费已确认 Prompt、渲染工作副本及任务冻结的实际 revision，不修改任务执行、提交、包装、下游输出或分支。

追加完成后衔接进度被固定重置到 50%；异步包装读取尚未返回或自动重试时会切换进度来源。包装组件已自动轮询重试，但仍把读取超时显示成错误横条和“重新读取”按钮。

## 改动

- 已完成 APPEND 的持久化衔接从追加阶段终点恢复，实际 APPEND_PACKAGE 优先于旧阶段投影。
- 同项目、Run、模板和本轮来源操作保留已经真实观察到的最高百分比；重试、衔接或迟到的较低进度不回退，阶段及数量继续实时更新。不按时间虚增，不提前显示 100%，终态立即隐藏。不同作用域及新来源操作不继承旧进度。
- 包装组件接收当前局部更新执行态；期间读取超时仅由既有轮询器退避自动恢复，保留已读取任务与结果，不显示恢复横条、按钮或 toast。局部更新结束时清除本轮遗留读取提示，真正提交/来源校验与播放异常仍按原边界处理。
- 无 Contracts/API/Worker 或数据库迁移，不重启 Worker、不重新付费生成，不自动提交 Git。

## 验证

覆盖追加到衔接、包装优先、自动重试低进度、同百分比更新阶段、新操作重置、跨模板/Run/项目隔离、终态隐藏与刷新后已完成追加恢复。覆盖读取超时自动重试及旧响应丢弃；浏览器检查 1920、1440、窄屏，不启动付费任务。执行相关 Web 测试、类型检查、构建和 diff 检查。
