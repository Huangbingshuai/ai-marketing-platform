# 包装流程图状态同步修复

## 范围与边界

仅修正效果类模板混剪包装流程图的读取与展示。读取现有 PackagingRun API，沿用同项目、同 workflowRun、同模板隔离；不创建付费任务、不改检查点、视觉/包装工作副本或 revision，不执行成片输出。

## 修复

- 摘要、流程图、详情、恢复按钮统一读取当前运行批次（优先活动批次，否则最新批次），不锁定过往批次。
- 读取设置 15 秒超时，迟到响应不得覆盖新响应；失败自动重连，切换作用域/卸载清理；回到页面和打开弹窗立即重新读取。
- 显示本次批次创建时间、总计、最后读取时间与明确的同步失败提示。
- 并发执行的阶段分开统计完成、运行、失败、等待和前序受阻；单条失败不掩盖同阶段仍在运行的其他成片；来源失效与执行完成区分。

## 验证

单测覆盖 100 条完成、并发混合状态、失败恢复、来源失效、最新批次选择、超时重连、乱序响应和卸载。执行 Web 类型检查/构建。浏览器读取测试1真实已完成批次，验证节点详情、刷新和不同宽度；不重新付费生成。
