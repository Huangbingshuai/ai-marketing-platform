## 实现

1. AI读取完整卖点与已有视觉策略，一次安排精确目标数的素材任务：自然相关卖点可组合，数量不足时为可延展卖点设计不同观看事件，不靠换词或机位凑数。每任务仅有事实引用、观看事件、差异意图和可选六维变化建议。抽象卖点保留可信背景，不强制画面证明。
2. 内部计划保存到现有阶段检查点，包含同Run输入、设置、模板和图片哈希；保留所有任务身份与原始事实关联。机械结构错误最多修复一次；不静默回退旧空间工作流。生成仍按容量分片并恢复有效候选。
3. 一次调用同步生成创意主线、六维及结构化镜头正文。取消正常批次所有候选必经的前置执行编辑；沿用一次独立质量评估，仅有明确AI问题时定向修正并复核改变后的内容。
4. 评估AI读取全部确认事实及视觉边界。预分配事实是创作意图，不限制合法实际绑定；Worker只校验当前来源ID、结构和报告内部一致性，不判断语义、不定位证据原文。
5. 初始只生成目标数，数量/覆盖/近似缺口最多合并为一次补充安排；AI读取缺失事实、已有事件和评估问题，重新设计具体任务，不循环旧方向。普通相似仅提醒与MMR排序，不阻断数量。
6. 复用现有租约保护的商品图读取、大小/哈希核验与压缩处理。Turbo候选生成可读取上游已提交资料图片，图片仅帮助外形、构图、支撑和操作，不能新增配方、功效或材质事实；无图片仍可运行。图片数据不进入日志、公开节点详情或Graph State。按Run内存复用已核验图片，新的Run仍重新核验。
7. API右侧详情改为素材任务数量、卖点安排和最多三条安全样例，旧Run仍读取原安全详情；不将新计划冒充旧空间。

## 验收

- 覆盖卖点少于/等于/多于数量、只有背景事实、组合、同卖点多创意、100条边界和不同品类。
- 新任务不调用空间/关系复核/旧路线规划；初始任务数精确且身份稳定；同Run恢复不重生成计划，新Run不复用。
- 允许绑定已确认但未预分配事实；未知ID仍不接受，PARTIAL不得冒充FULL。
- 图片仅来自快照、通过哈希验证；无图/损坏/取消/重试/旧数据兼容；图片进入候选请求但不进入评分请求或公开详情。
- Worker单测、mypy src、Ruff；API/契约/前端相关回归、类型检查和构建；git diff --check。
- 自动回归后通过正式浏览器付费对照文字/图片输入，固定同项目、上游、数量、时长与模型，检查全部最终Prompt、重复度、卖点实现、操作与镜头风险及耗时。不生成视频、不完成校验；不把自动测试或高AI分等同质量达标。
