# 渲染素材删除联动混剪局部更新

## 范围和提交边界

渲染删除先进入隔离草稿，保存成功才在已确认 render-batch 中发布删除身份。混剪素材库随当前来源刷新，只有引用已删除素材的工程待更新。历史文件、旧分支、未使用素材的工程保持不变，不新增素材状态表。

## 局部更新

复用 source-update / FINAL_OUTPUT 来源更新链路。明确区分素材替换、删除和来源异常，替换优先于同来源的历史删除记录。删除清除每个引用片段、关联原声、口播和字幕，保留工程、槽位位置和时长；以显式空槽及保留结束位置支持末段及全黑工程。音乐及独立编辑内容保留。缺少可靠槽位关联的历史口播不猜测删除。

纯删除在事务中确认工程及包装，不调用模型或最终编码；混合删除和替换冻结共同输入，成功才整体回写。已导出文件保持可用并待更新，用户在成片节点主动局部更新后覆盖当前分支。

## 完整重做

重新智能填充创建独立分支，全部当前有效素材重新归槽，清除旧分类、人工归槽、匹配和截取结果；只允许同一新任务恢复自身检查点。素材不足明确失败，父分支不变。新增素材追加路径不变。

## 验证

覆盖 AI/导入素材删除、保存和取消、重复请求、分支映射、删除与替换并存、来源异常、并发输入变化、末段及全部画面删除时长保留、关联包装清理、BGM保留、成片按需覆盖及整批重新归槽。执行 Contracts/API/Web/Worker 相关测试、类型检查、构建、浏览器回归和 git diff --check。不物理删除历史文件，不自动提交 Git。

## 实施结果与兼容

- 渲染任务保留 `MATERIAL_DELETED` 身份记录，正常供应商失败不视为删除。保存后的 `render-batch.payload.removedSources` 发布删除身份，旧文件及片段工作副本保留。删除任务不再计入失败数或可见素材卡；已明确删除的 Prompt 不当作尚未渲染的新 Prompt。
- 素材来源契约增加可选 `sourceRemoved` 和来源变更 `kind: REMOVED`。有效新版本优先处理为替换；已删除的同文件别名不能藏住其他有效来源，也不能再次粘贴或手动归槽。
- 工程增加可选 `intentionallyEmptySlotIds` 和 `preservedTimelineEnd`。保存接口只接受服务端已有空位授权，不能用伪造空位绕过新工程完整性校验。
- 包装清理按槽位、口播 ID 或唯一文件来源关联。字幕裁剪保存可选 `sourceSlotId`，口播/原声裁剪沿用现有 `sourceSlotId`；无法唯一关联的历史口播保留原结果并拒绝不安全清理，不按时间重叠猜测。
- 纯删除事务不写任务 Outbox。删除与替换并存仍使用来源更新任务，准备完成前不修改旧工程；成功后同步工程、包装及包装文件关联，保留底层文件。
- 已导出文件保持原快照，工程更新后继续显示待更新；用户主动成片局部更新才覆盖输出。删除更新和成片覆盖都不增加分支。
- 完整重新智能填充不继承分类检查点、手动归槽或旧工程的使用次数。首次填充、指定工程填充和新增素材追加继续使用各自原有规则。
- 无数据库表或历史文件迁移。历史缺少删除证据的数据不自动推断为删除。
