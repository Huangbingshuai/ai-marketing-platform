# 人工导入素材内容查重

## 范围与边界

- 效果类视频渲染节点的新增外部素材导入，沿用当前项目、当前渲染批次、隔离编辑态及保存版本流程。
- 以服务端流式 SHA-256 识别完全相同文件，改名不影响判断；不做视觉近似、转码后相似识别，不调用 AI。
- 检查未过期且未取消的待确认草稿，以及当前批次已确认的人工导入素材（包括编辑分支继承的素材）。已确认后关闭弹窗、刷新或重新进入编辑仍查重。
- 人工导入素材返修后仍保留原导入文件的身份；删除素材或取消草稿后可以重新导入。其他项目或独立批次不互相限制。
- 不删除历史重复条目，不更改已有提示词、用途、混剪工程、工作副本 revision，不改变旧的替换素材接口。

## 数据和实现

- 复用导入草稿 sha256、素材 outputContentHash、generationRequestSnapshot.importedMaterial 和稳定 promptId 指向的原导入草稿，不增加契约字段或迁移。
- 上传前检查既有幂等键及内容；重复时不再转存到 TOS。持久化草稿时复用批次行锁再检查，处理并行上传竞争；竞争失败的新存储对象回收。
- 确认时在现有批次事务内检查同一次确认的内容去重及已导入素材，拒绝后不写 FileObject、任务、receipt 或 revision。幂等重放优先处理。
- 复用导入列现有错误反馈；错误用安全中文提示待确认/已导入及素材编号，不输出哈希、存储路径或签名。

## 验收

- 单测：改名文件、同名不同内容、待确认、已确认、继承及返修、取消/过期/删除、项目和批次隔离、幂等、并行上传与确认兜底、重复不调用存储/AI、失败列不影响其他列。
- 数据库：新建隔离测试项目，强制外层事务回滚；确认后查重、旧重复草稿不能再次确认、继承、删除可重导入，验证无额外任务/文件/revision。
- API 类型检查、构建，Web 导入协调器回归及 git diff --check。
- 浏览器实际上传两份相同内容不同名的小测试视频和不同内容视频，不确认进用户工程；验证列内提示、确认/识别禁用、其他列可编辑，测试后取消自建草稿并清理文件。
