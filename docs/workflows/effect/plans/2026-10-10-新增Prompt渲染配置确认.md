# 新增 Prompt 渲染配置确认

## 范围与边界

- 效果类片段渲染节点，直接消费已确认 `prompt-batch:<productId>` 的 artifactId/revision；输出仍为 `render-batch:<productId>` 与 `render-clip:<taskId>`。
- 顶部设置定位为新任务默认配置，不修改已有素材、Prompt、下游 revision。局部更新成功沿用现有原位自动提交及下游失效规则。
- 人工新增/导入 Prompt 与默认模型时长、分辨率或画幅冲突时，集中弹窗逐条配置；取消不创建任务，不静默换模型或降低分辨率。覆盖配置只用于本次对应 Prompt。
- 首次生成、整批重新渲染和新增 Prompt 局部补渲染均校验配置。已有素材局部重生成仍使用其原任务快照；人工导入视频及返修不在本次调整范围。

## 实现

- 契约增加轻量 Prompt 渲染摘要及可选逐条配置；服务端机械校验来源、ID、能力、设置 revision，创建任务时冻结实际配置。
- 局部更新在创建编辑副本前冻结默认设置；副本复制补齐 `SEGMENT_RENDER_SETTINGS:`，避免遗漏后回退历史配置。
- 未传逐条配置的旧客户端保留合法请求兼容；冲突请求明确拒绝，不继续沿用自动升级行为。Worker 消费既有 requestSnapshot，不增加消息或 Worker 协议。

## 弹窗调研与设计

- 视觉基线：现有 Prompt 编辑弹窗、渲染预览弹窗与系统选择器，白底、蓝色主按钮、灰蓝细边框，保留系统字体和间距，不另引入视觉主题。
- 一张可滚动表单集中展示冲突条目，编号/只读时长/冲突原因与模型、画幅、分辨率三个字段分层；页脚固定取消和“使用这些配置”，不直接触发付费任务。
- 每条提供“查看提示词”按钮，在本条下方只读展开当前已确认正文；支持独立收起、长文本滚动与换行，不编辑正文或改变配置，也不使用旧素材的历史提示词代替新增 Prompt。
- 操作参考 [WAI 模态弹窗规范](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) 的焦点限制、ESC、关闭后焦点恢复；参考 [Atlassian 按钮规范](https://atlassian.design/components/button/usage) 使用明确动作名称。采用原生 dialog 承担模态与焦点边界。

## 验收

- 15/16/30 秒边界；mini/4K 与 2.5/4K 冲突；合法画幅保留；多条逐项配置；未知/重复/越权 Prompt 拒绝。
- 新增任务使用当前已保存设置，旧素材保持原设置；设置在确认期间变化拒绝；两轮更新、编辑副本及整批重渲染设置继承。
- 单测、类型检查、构建、diff 检查；浏览器检查取消、非法配置禁用、确认、焦点、1920/1440/390 布局。浏览器仅使用隔离模拟 API，不创建付费任务。
