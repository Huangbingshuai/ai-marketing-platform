# 智能填充后台同步不重置工作台

## 范围

效果类模板混剪 Web 交互。直接上游是已确认的渲染素材和模板 revision；智能填充仍按既有冻结任务运行，完整成功后提交混剪模板、时间轴工程并同步待渲染成片。本次不改变任务、模型、工作副本 revision 或提交边界，不启动付费任务。

## 已查明的问题

- 工作区安装无条件重置视频解码/播放状态，即使当前工程与素材没有变化。
- 同 Run 后台重新读取也重新执行运行中任务的导航恢复，可清空用户已选择的成片和槽位。
- 填充开始/结束刷新父级 Run 时使用通用全屏切换反馈；后台暂时读取失败也可能把可用工作台替换为整页错误。

## 修复

- 同作用域、同模板、同成片及实际播放来源不变时保留播放器、播放时间及解码状态。真正切换作用域、工程或绑定来源变化仍正常重置。
- 按内容复用未变化的工程及素材引用，只同步真实变化；后台安装保留当前模板、成片、槽位、筛选和布局，不回写导航到服务端。
- 运行中任务的自动导航恢复仅用于首次进入或实际切换 Run；任务完成仍安装真实结果。
- 完成时已打开的工作台不再无条件清空素材搜索、分类和分页；初次进入仍使用默认布局。
- 填充/包装的 Run 刷新保留已挂载页面，不使用全屏切换遮罩；原有作用域栅栏、锁定、旧响应与并发编辑保护不变。
- 同作用域后台读取失败保留当前界面并提示，首次进入/新作用域失败仍显示可重试错误。

## 验证

单测覆盖重复进度、后台安装、选择保留、素材/工程真实变化、跨 Run、旧响应、并发编辑及失败；执行相关 Web 测试、类型检查、构建、`git diff --check`。浏览器检查已有真实工程的试听、翻页、切换及 1920 / 1440 / 窄屏；不为验收新开付费智能填充。
