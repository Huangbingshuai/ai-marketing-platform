# 效果类 Prompt：精确数量择优与单轮补充实施方案

状态：已完成

## 一、范围与边界

- 所属工作流：效果类第 3 节点“Prompt 生成”。
- 改造阶段：`EXACT_SELECTION_AND_SUPPLEMENT`，不增加用户可见节点。
- 直接输入：当前 Run 中已经生成并经 AI 评估的候选、评估器返回的 `realizedFactIds`、硬问题、五项分数、AI 六轴语义分类和正文向量。
- 领域输出：精确数量的 Prompt 批次草稿；只有用户完成校验后才提交 `prompt-batch:{productId}` WorkingArtifact。
- 下游边界：不修改视频渲染契约、上游营销洞察 revision 或现有 WorkingArtifact 提交规则。
- Worker 只处理稳定 ID、集合、数量、结构、向量和哈希，不读取正文判断事实、场景、动作或视觉语义。

## 二、问题

真实 50 条任务在首轮 70 条候选中已有 66 条安全候选，数量已经足够，但系统仍因少量必用事实未被评估器判为完整实现，连续生成 10 条、4 条并准备第三轮补充。当前实现把数量缺口和事实覆盖缺口放在同一个最多三轮的恢复循环中，放大了偶发模型判断，增加等待和费用；新一轮阶段元数据还会覆盖首轮累计统计。

## 三、实施方案

### 1. 覆盖优先择优

- 继续只排除 AI 硬问题和结构上完全相同的候选。
- 先根据 AI 返回的 `realizedFactIds` 机械选择能够覆盖最多尚未覆盖必用事实的安全候选，再用当前向量 MMR 填满剩余数量。
- 如果已有安全候选可以覆盖事实，不进行新模型调用。
- 普通相似、用途偏斜、场景或动作簇集中只参与排序或提醒，不触发数量阻断。

### 2. 分离数量补充与覆盖补充

- 数量补充：只有安全且非完全重复的候选少于目标数时触发；按缺口的 `120%` 且至少“缺口 + 1”生成，继续受候选总容量保护。
- 覆盖补充：只有最终候选已足量、且整个安全候选池都没有实现某项必用事实时触发。
- 覆盖补充最多一次，数量为 `max(缺失事实数 × 2, 缺失事实数 + 1)`，且不超过目标数量的 20%。
- 补充候选继续经过相同 AI 评估和向量择优，不绕过质量流程，不由 Worker补挂事实。

### 3. 终态处理

- 一次覆盖补充后仍缺少事实：保留精确数量草稿并标记 `NEEDS_REVIEW`，明确列出安全的缺失统计；不得继续烧费，也不得通过完成校验或覆盖旧 WorkingArtifact。
- 数量补充后仍达不到目标：任务失败，不保存短批次、不覆盖旧有效结果。
- 去同质化继续由创意规划、AI 六轴分类和向量 MMR负责，不执行额外生成轮次。

### 4. 累计可观测性

阶段元数据累计展示：初始候选、累计候选、AI 硬淘汰、完全重复、可选候选、最终选择、数量缺口、缺失事实、数量补充、覆盖补充及补充后结果。新一轮不得覆盖首轮统计。

## 四、兼容与非目标

- 不修改公开 HTTP 路径、Prisma Schema、Prompt 批次结果 Schema或八阶段拓扑。
- 不改变 AI 评分问题码、五项分数、共用提示词、人工编辑、单条重生成和 V5 历史读取。
- 不新增字符匹配、商品关键词、正则语义词库或 Worker 业务语义判断。
- 不恢复片段类型配额，不增加多样性硬门禁。

## 五、测试

- 70 条候选中 66 条安全时直接选满 50 条，不触发数量补充。
- 已有安全候选覆盖全部必用事实时不调用覆盖补充。
- 整个安全池缺少事实时只触发一次覆盖补充，50 条任务最多补充 10 条、100 条最多补充 20 条。
- 一次覆盖补充仍缺失时保存精确数量 `NEEDS_REVIEW` 草稿，不进入第二轮覆盖补充。
- 数量仍不足时失败并保留旧有效结果。
- 累计指标在补充前后保持首轮数量与分项损耗。
- 回归人工保留、单条重生成、向量 MMR、分片恢复、旧 attempt token和WorkingArtifact边界。
- 执行 Worker pytest、mypy、Ruff、相关 API 测试及 `git diff --check`。

## 六、实施结果

- 数量补充与事实覆盖补充已拆开计数，两类补充在一次 Run 中各最多执行一次。
- 覆盖补充只在整个安全候选池都缺少必用事实时触发，补充上限固定为目标数的 20%。
- 补充后仍缺事实时，系统保留精确数量草稿并标记 `NEEDS_REVIEW`；只有安全候选数量不足才终止任务。
- Worker 只使用 AI 返回的 `realizedFactIds` 做集合差运算，不读取 Prompt 正文推断事实语义。
- 节点详情已区分初始候选、累计候选、可参与择优、AI 择优入选、硬问题淘汰、合格未入选、数量补充和事实覆盖补充。
