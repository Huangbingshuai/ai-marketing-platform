# 成片待更新与分支树同步修复

## 已确认问题

紫苏梅子酱当前测试3成片列表有一条已完成成片待更新，分支树成片输出仍为 CONFIRMED。列表比较已保存工程和最终渲染快照，分支树仅比较 WorkingArtifact 的依赖；自动保存未推进产物 revision 时遗漏工程变化。

## 边界与实现

- 效果类成片输出，直接上游为当前 Run、模板的已保存时间轴和已完成包装；最终成片及交付清单只在主动输出成功后提交。
- 抽取共用的已保存工程/导出快照比较、工程增删判断；成片列表和分支树复用，不增加新状态表或修改草稿、revision。
- 树读取同项目各分支的输出快照，按交付清单绑定的实际批次比较。每个分支只比较自身工程，不能用活动 Run 覆盖兄弟历史版本。
- 仅存在交付版本时补充输出待更新；空新增工程不提示，有效新增、删除及编辑可提示。缺失历史快照或无法确认的草稿不能被当成删除。
- 保留工作副本依赖警告与当前红色路径，额外差异只标记对应成片输出；缓存按修复后投影版本隔离，已保存草稿和输出条目参与缓存新鲜度校验。
- 保存工程的素材来源差异复用现有 `projectEffectBranchFreshness`：临时图输入仅用于只读计算，不入库、不进入产物数量、不增加 revision，且仍沿实际渲染头隔离。
- 不触发 Worker 或付费模型，不更新历史文件，不自动提交 Git。保留已有相关改动。

## 验证

- API 共用比较和树投影测试：画面位置/截取/变换、独立音频、字幕/包装、增删/全删、空新增、同内容不变化、缺失草稿、任务执行及失败恢复、兄弟分支与模板隔离。
- Web 画布、树布局相关测试，类型检查、构建和 git diff --check。
- 用现有项目只读回归：成片列表与树对应输出警告一致；宽屏、窄屏、刷新恢复。模拟成功更新快照验证清除，不对真实成片执行付费更新。
