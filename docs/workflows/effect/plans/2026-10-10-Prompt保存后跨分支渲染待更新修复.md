# Prompt 保存后跨分支渲染待更新修复

## 范围与原因

效果类 Prompt → 片段渲染。广式腊肠当前混剪分支已保存 Prompt revision 12，但素材池仍正确归属祖先渲染头；工作区展示祖先批次时却也读取祖先 Prompt，遗漏当前分支保存的增删改。画布同样只判断渲染头的原依赖。

## 实施

- 保留权威素材池读取，不回退到当前分支的旧素材副本。
- 批次展示明确区分素材所有者与查看工作区，按当前已确认 Prompt 计算净差异；保留原素材来源、文件和实际采用输入。
- 局部更新确认先校验查看作用域确实引用该权威批次，在当前查看分支创建隔离编辑，冻结该分支 Prompt；不跳回祖先分支执行。
- 轮询使用当前工作区投影，避免原始批次投影清除当前 Prompt 差异。
- 版本树与画布按权威素材和当前 Prompt 共同投影，不标记无关兄弟、祖先或未生成节点；恢复原内容仍可抵消。
- 不修改数据库结构、历史素材或文件；不启动付费任务，不自动提交 Git。

## 验证

覆盖同数量增删改、连续编辑与恢复、旧素材池副本、当前分支隔离、作用域验证、差异签名和轮询；运行相关单测、类型检查、构建、diff 检查。浏览器只读检查实际项目，不修改真实 Prompt 或调用模型。
