# 效果类 Prompt：重复度聚类与源头多样性修复方案

## 状态

已完成（2026-09-07）。

## 问题与证据

2026-09-07 对“紫苏梅子酱”执行 50 条、15 秒真实批次，最终语义重复度显示为 54%。排查确认：

- 50 条共有 1225 个两两组合，其中 51 对超过 0.82 相似阈值，占 4.16%。
- 当前通过单链连通分量统计重复条目；只要 A 接近 B、B 接近 C，即使 A 与 C 不接近，也会进入同一重复组。
- 六个连通组大小为 18、6、3、2、2、2，按每组只保留一个代表计算出 27/50=54%，最大 18 条组混入了沙拉落酱、产品微距、开瓶取用和瓶身观察等不同视觉事件。
- 数值存在链式放大，但最终内容仍真实集中于吐司涂抹、开盖舀取、酱体微距、沙拉落酱和小食蘸取等少数套路；不能只修改显示公式掩盖源头问题。
- 当前 AI 返回的场景族和动作族标签过细，同属厨房台面的内容可能得到不同自由文本标签，导致簇新颖度错误奖励表面差异。

## 工作流边界

- 所属节点：效果类第 3 节点“Prompt 生成”，保持现有八阶段拓扑。
- 直接上游：当前商品已确认的营销洞察 WorkingArtifact revision，以及本节点保存的数量、时长、渠道、视觉风格和禁用元素。
- 草稿与提交：真实测试只更新 Prompt 领域草稿和 WorkflowNodeState；不点击“完成校验”，不覆盖 `prompt-batch:{productId}` WorkingArtifact。
- 直接下游：视频渲染继续读取已提交 Prompt 工作副本；本次不修改第 4～6 节点。
- 不修改公共 HTTP 路径、Prisma Schema、Prompt 结果结构和 0.82 对比阈值，不新增商品关键词或字符语义规则。

## 实施方案

### 1. 修正重复组统计

- 将单链连通分量改为确定性的“完全连接分组”：候选加入某组时，必须与组内每一条都达到 0.82，而不是只接近某个代表。
- 不允许仅靠 A-B、B-C 的关系把 A 与 C 自动视为同一创意；输入顺序不影响分组结果。
- 继续保存所有高风险直接配对数，并新增受影响条目数。阶段元数据持久化完全连接组的组边，避免 API 在删除或重算时又恢复成旧的链式放大。
- 完全重复仍单独统计；一般语义相似仍只作软排序和提醒，不硬删候选。

### 2. 收敛 AI 六轴上位类别

- 全批创意方向复核请求新增 `canonicalProfiles`，由 AI 为每个方向返回叙事、场景、人物、产品动作、镜头和情绪的全批共用上位语义族。
- 复核提示词明确要求合并同义叫法，不把只换人物、材质、景别名称或措辞的同一主视觉事件当成新类别。
- Worker 只校验结构、稳定方向 ID 和“每个方向恰好一份归一化结果”，不使用商品关键词、字符相似度或自由文本规则解释语义。

### 3. 源头方向去同质化

- 在既有产品专属创意版图和 20 个动态方向基础上，强化全批方向复核，同时返回必要的局部修订和全批归一化六轴。
- 新生成批次必须完整覆盖全部方向的归一化结果；一次结构异常可恢复一次，仍无效则明确失败，不静默使用失真分类。
- 保持事实真实性和自然关系优先，不增加商品专用关键词或硬场景配额。

### 4. 簇感知 MMR

- MMR 的簇负载基于完全连接分组，不再基于单链连通组。
- 高重复候选池继续使用 60% 质量、40% 多样性；低重复候选池保持 70%/30%。
- 同一稳定上位组合被重复选中时降低新颖度，但不得阻断精确数量或破坏事实覆盖。
- 多样性补充输入改为拥挤代表簇及缺少的上位组合，由 AI 规划新方向后生成，不由 Worker编写或推断创意。

## 测试与验收

- 单元测试证明 A-B、B-C 接近但 A-C 不接近时不会形成三条重复组。
- 顺序变化不得改变完全连接分组结果和重复度。
- AI 必须为本批每个创意方向返回恰好一份归一化六轴；Worker 只校验方向 ID 集合，不使用关键词、包含关系、编辑距离或自由文本规则解释语义。
- MMR 能降低代表簇重复，同时保持数量、事实覆盖和质量优先级。
- 回归人工编辑、单条重生成、历史草稿、WorkingArtifact 边界和浏览器刷新恢复。
- 执行 Worker pytest、mypy、Ruff 和 `git diff --check`。
- 自动测试通过后，以刚才 54% 的“紫苏梅子酱、50 条、15 秒”批次为基线执行一次真实 Ark 浏览器测试；要求一次任务成功、严格 50 条、硬问题不增加、质量均分下降不超过 1 分，且修正口径后的重复度显著下降。完整 Prompt 不写入仓库。

## 真实验收结果

2026-09-07 在正式浏览器链路中，对同一“紫苏梅子酱”、50 条、15 秒设置执行了一次真实 Ark 付费批次。未调用 Seedance，未点击“完成校验”。

| 指标 | 基线 | 修复后 | 变化 |
| --- | ---: | ---: | ---: |
| 页面语义重复度 | 54% | 30% | -24 个百分点（相对下降 44.4%） |
| 最终直接高风险对 | 51 | 27 | -47.1% |
| 候选池正文重复信号 | 72.22% | 52.38% | -19.84 个百分点 |
| 严格数量 | 50/50 | 50/50 | 保持 |
| 完全重复 / 硬问题 | 0 / 0 | 0 / 0 | 保持 |
| 产品相关性 | 95.46 | 95.34 | -0.12 |
| 创意连贯性 | 93.22 | 93.12 | -0.10 |
| 画面可执行性 | 91.42 | 91.28 | -0.14 |
| 商业素材价值 | 90.58 | 90.56 | -0.02 |
| 视觉表达清晰度 | 93.60 | 93.58 | -0.02 |

结论：下降不是单纯修改页面公式。将旧批次的 51 对直接相似关系按新分组法重算时，基线会从 54% 修正为 36%；新批次仍进一步降到 30%。同时，直接高风险对从 51 降到 27，候选池正文重复信号降低 19.84 个百分点，证明生成源头和择优结果都有实际改善。

已通过 Worker 全量 pytest 和 `mypy src`，且浏览器刷新后恢复 50 条节点草稿。本次付费批次用时约 24 分 15 秒；期间的结构化返回异常由现有分片恢复机制处理，任务在第 1 次尝试内完成。

仍有两项可见余量：页面重复度 30% 仍高于理想提醒线；本批事实覆盖为 28/33，比基线 29/33 少 1 条，因此保持 `NEEDS_REVIEW`，没有宣称已经完全消除同质化或达到可提交状态。

## 第二阶段：15% 可验收目标

### 状态

已完成（2026-09-07）。

### 问题定位

- 50 条 Prompt 要达到不超过 15%，最多只能有 7 条簇内冗余项，即候选池至少要有 43 个可用的独立完全连接组。
- 当前页面警告线是 15%，但多样性付费补充只在超过 30% 时触发；结果恰好 30% 时会停止。
- 当前补充数固定为目标数的 20%，没有根据“还缺多少独立组”计算；新候选稍有重叠时便无法填满缺口。
- 创意方向的兄弟任务虽有两个优先变化维度，但没有事先分配互不相同的主视觉事件，仍可能用同一画面骨架换措辞。

### 实施设计

1. 将多样性补充触发线与用户可见的 15% 目标统一。
2. 用 `目标数 - 允许冗余数` 计算所需独立组；根据候选池的独立组缺口动态生成补充候选，而不是固定补 10 条。
3. 创意方向由 AI 为预计的兄弟数量同步规划简短 `executionRoutes`，每条只定义主视觉事件、场景关系、产品主动作和结束状态；候选生成仍自主完成镜头和细节。
4. Worker 只校验路线 ID、数量、结构和稳定分配，不解释主视觉事件的自由文本语义。
5. MMR 继续优先从每个独立组取一条；超过 15% 的批次保留精确数量草稿，但不标记为质量达标，不通过改阈值或减少条数伪造成功。

### 验收

- 50 条时独立组目标为 43，最多 7 条簇内冗余项；100 条时独立组目标为 85。
- 候选池组数不足时补充数随缺口增长，但只执行一次多样性补充并受总候选容量限制。
- 一个方向下的兄弟任务稳定获得不同路线，恢复和重试不改变路线分配。
- 不新增关键词、字符相似度或商品专用规则；不修改 0.82 阈值。
- 自动测试后执行真实浏览器付费批次，严格 50 条、页面重复度不超过 15%、硬问题不增加且五项质量均分下降不超过 1 分。

### 实施结果

- 创意方向新增 2～5 条由 AI 规划的执行路线；路线只描述主视觉事件、场景关系、产品主动作和结束状态。Worker 仅按稳定 ID 和兄弟序号分配路线，不解释自由文本语义。
- 15% 页面目标与多样性补充触发线统一。补充数量按独立语义组缺口动态计算，并继续受单次补充和总候选容量限制。
- 最终择优先从不同完全连接语义组中选出满足目标所需的最少独立组，再将剩余名额交回常规质量与 MMR 排序，避免为了追求 0% 重复率持续牺牲质量。
- 第二阶段新增路线数量、分配稳定性、动态补充数量、独立组目标和质量回归测试；Worker 全量 pytest、Ruff、mypy 与 API 类型检查通过。

试验 1 把重复度压到 4%，但产品相关性和商业素材价值分别比第一阶段下降 1.08 和 1.02 分。随后将择优改为“达到 43 个独立组即停止组优先”，冻结结果稳定在 8%，五项质量相对第一阶段分别变化 -0.46、+0.24、+0.48、-0.92、-0.12，全部控制在 1 分以内。

冻结批次共生成并评估 72 条候选，72 条全部通过 AI 评估，最终保留 50 条；候选池语义重复度为 30.56%，最终降至 8%，证明改善来自路线规划与择优共同作用，不是放宽统计口径。批次补充 2 条事实覆盖候选，最终仍缺 1 项必用事实，因此正确保存为 `NEEDS_REVIEW`，没有覆盖有效 WorkingArtifact。

真实联调期间 API 曾因工作区已有的片段渲染可选字段类型错误无法启动；修正编译错误后，租约恢复机制续跑了已完成分片，任务没有重复调用所有模型分片。该故障与 Prompt 多样性算法无关，但验证了中断恢复链路。
