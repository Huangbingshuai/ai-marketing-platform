# 模板混剪 Ctrl+B 分割素材

## 目标

在模板混剪时间轴中提供标准剪辑器的 `Ctrl+B` 分割操作。仅当时间轴素材处于选中状态时执行；以当前播放针时间为分割点，只分割播放针穿过的选中素材。支持视频、音频和字幕，保留来源文件、轨道、音量/淡化及字幕内容；切点不在素材内部时不改动。

## 范围

- 时间轴组件识别快捷键、忽略文本输入/可编辑控件，并向节点页提交显式分割请求；不得回退到“当前槽位”或其他默认目标。
- 视频槽位拆成左段及同轨右段：复用相同素材和来源 revision，调整源截取偏移与时长；模板槽位原身份保留在左段，右段作为工程私有画面片段。
- 音频拆段复用相同 FileObject/资产，左右段分别保存时间、源偏移、音量和边界淡化；已包装音频的右段转成工程时间轴音频，不篡改其他字幕/台词。
- 字幕拆成两个连续、文本一致的时间轴片段，保留轨道和显示样式。
- 新右段成为选中项；整个操作纳入现有草稿自动保存、撤销/重做和版本分支机制。
- 后端只做结构、项目文件归属、时间范围、ID 唯一性和数组容量校验；Worker 按保存的片段、偏移和淡化参数混音。

## 非目标

- 不自动移动素材、不改变播放针、不改写台词或判断字幕语义。
- 不允许在切点处生成零长度片段；不改变转场设置、除切点外的时间轴片段或其他成片分支。
- 不将空白轨道或未选中素材作为隐式目标。

## 验收

1. 无选中素材按 Ctrl+B 不执行任何改动；输入框/字幕文本编辑时快捷键不触发。
2. 仅选中一个素材时，只切开播放针严格落在其内部且所在轨道未锁定的项；多选、播放针处于头尾或素材之外时不拆分。
3. 视频/音频/字幕切开后首尾连续、源内容不中断，刷新后保持拆分结果；每次只处理当前选中的单个素材。
4. 一次撤销恢复原素材，再次重做还原切分；时间轴保存和成片导出保留两段安排。
5. 覆盖前端边界测试、API 契约/结构校验和 Worker 混音淡化测试；执行相关类型检查、测试和 `git diff --check`。
