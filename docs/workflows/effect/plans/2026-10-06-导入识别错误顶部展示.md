# 导入识别错误顶部展示

## 范围与边界

效果类视频渲染节点的人工导入弹窗：每列顶部复用现有错误提示展示该视频的失败原因。识别输入仍为当前项目、批次的冻结视频文件；结果仅更新导入草稿，确认导入及素材池工作副本提交边界不变，不使下游版本变化。

## 跨层实现

- 共享契约增加向后兼容的识别失败码；Worker 回调只传枚举，不传异常原文、供应商响应、视频内容或地址。
- API 从共享失败码确定性映射安全中文说明，写入已有 `errorMessage`。沿用租约、项目隔离与幂等，无数据库迁移。
- 区分读取/完整性/抽帧、模型超时/连接/限流/服务失败、输出截断/结构/模板校验及任务超时；未知及旧任务继续使用通用说明，不虚构历史原因。
- 列头下方显示错误，正文滚动不隐藏；上传/确认/轮询错误同处展示，不重复堆到页脚。重识别时清除旧失败提示，失败不覆盖已有人工编辑。

## 验证

Contracts 枚举、JSON Schema 与 Python 模型一致；API 回调非法码及成功/失败冲突、保存/读取、旧回调兼容、幂等与旧 attempt；Worker 分类、脱敏、并发独立；Web 顶部结构、失败恢复和用户字段保留。执行相关单测、类型/构建与差异检查，浏览器检查 1920/1440/窄屏。浏览器不触发付费识别、不确认测试素材；无活动任务时更新 API/Worker。

## 验证结果

- Contracts：7 项；API 单测：53 项；数据库隔离事务回滚：1 项；Web：46 项；Worker：89 项，均通过。
- Contracts/API/Web 构建与类型检查、Worker 变更模块 mypy、差异检查通过；Web 有既有 chunk 大小警告。
- 浏览器以一条损坏测试文件和一条正常合成视频验证顶部错误、列隔离、关闭重开及 1920/1440/768 布局；截图见 `../evidence/browser/2026-10-06-import-error-top.jpg`。没有点击 AI 按钮或确认导入。
- 测试草稿已取消，状态 CANCELLED/IDLE、未生成正式素材；保留用户编辑态及原有素材。
- 无活动任务时更新 API 与混剪 Worker；没有数据库结构迁移，也没有付费调用。
