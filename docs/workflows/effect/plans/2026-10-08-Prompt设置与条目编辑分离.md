# Prompt 设置与条目编辑分离

## 范围

- 批次数量、默认时长、渠道、风格、禁用元素自动保存为下一次整批生成的输入草稿，无需进入条目编辑。
- 提示词列表承接进入编辑、取消编辑、保存修改；人工新增、编辑、删除继续使用原隔离编辑与提交链路。
- 修改生成设置不改动已有 Prompt 结果、确认 revision 或下游素材，不触发局部更新。
- 已生成结果保留实际生成时的设置快照；任务创建、领取、回调和整批自动提交继续校验当前输入设置，防止旧任务提交。

## 实现边界

效果类第三节点消费 `marketing-insight:<productId>` 的实际 revision，输出 `prompt-batch:<productId>`，视频渲染消费该确认工作副本。批次设置为 `WorkflowNodeState`，不代表新的 Prompt 工作副本。保留现有 API、契约、数据库和任务状态。

## 检查

核对列表操作位置、设置可编辑性、修改设置后已有结果和下游状态不变、恢复后条目仍受编辑锁保护，以及隔离编辑保存与整批任务输入校验。执行 Web/API 类型和构建检查、格式及差异检查；浏览器检查桌面和窄屏布局，不发起付费生成。
