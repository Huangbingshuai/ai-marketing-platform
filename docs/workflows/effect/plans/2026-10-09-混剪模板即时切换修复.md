# 混剪模板即时切换修复

普通模板选择是导航，不等待重新读取完整工作区。复用目录已读取的目标 Run 完整快照，按原项目、Run 和 revision 安装，不把跨路径列表投影写入草稿。当前已保存工程离开前更新其缓存，避免返回时回退到旧内容。

首次进入、显式历史切换、缓存缺失或低于已知 revision 时保留权威读取；普通已缓存切换不创建请求、任务或分支，不因导航触发草稿保存。来源轮询和写入的服务端冲突校验继续生效。有未保存修改时仍先保存，失败保留原编辑。

验证即时切换、来回切换保留最新保存、迟到读取、失效缓存、删除隐藏、任务中的导航及项目/Run 隔离；执行相关测试、Web 类型检查、构建、diff 检查及浏览器三宽度回归。不启动付费任务、不提交 Git。

## 实施与验证记录

- 普通 CONFIG 选择同步安装同项目目标 Run 的完整已读取快照；在离开前缓存已保存工程和实际 draftRevision，禁止使用低于已知 revision 的旧快照。切换不会再触发整页读取或导航自动保存，取消旧读取防止迟到响应恢复旧选择。编辑或付费操作的服务端校验保持原样。
- 素材缓存的浏览器重试计时器明确使用 number 类型，避免测试引入 Node 类型后与 window.setTimeout 冲突。
- 六个相关测试文件共 58 项通过；直接 Vite 打包和 git diff --check 通过。浏览器在 1920、1440、390 宽度下验证测试2/测试3连续切换，名称即时改变、输入框未禁用、列表无切换加载提示、无页面横向溢出。未修改真实模板内容或发起付费任务。
- 完整 Web 类型检查/构建未通过：验证时定制类 customized-extraction-view.spec.ts:99 存在 Input.buffer 类型错误，非本次修改范围。缩略图缓存没有单独同名测试文件，不能把该单独测试命令记录为通过。
