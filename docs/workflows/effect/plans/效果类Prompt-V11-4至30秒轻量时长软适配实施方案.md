# 效果类 Prompt V11：4～30 秒轻量时长软适配实施方案

## 1. 文档状态

- 状态：已完成
- 最后更新：2026-08-31
- 所属工作流：效果类
- 所属业务节点：第 3 节点“Prompt 生成”
- 当前图版本：`CURRENT`

## 2. 目标

新生成的 Prompt V6 批次允许用户选择 4～30 秒的统一默认片段时长。时长作为结构化数据传给 Worker，Worker 根据时长给生成模型一段轻量的时序节奏意图，不把时长、画幅、分辨率或批次共用提示词写入单条 Prompt 正文。

## 3. 边界与兼容

- 直接上游仍为已提交且为 CURRENT 的 `marketing-insight:{productId}` 工作副本。
- 节点内生成、评估和人工修改只更新领域草稿与 `WorkflowNodeState`。
- 只有用户完成校验后，才提交 `prompt-batch:{productId}` WorkingArtifact。
- V5 历史结果继续保持 4～15 秒校验；V6 新结果使用 4～30 秒。
- Prompt 节点不感知具体视频厂商或模型，不新增 Seedance 2.5 能力枚举，不修改第 4～6 节点。

## 4. 时长软适配

Worker 为每个已持久化的创意任务根据 `targetDurationSeconds` 编译时序意图：

- 4～8 秒：快速建立商品与视觉重点，减少铺垫。
- 9～15 秒：在同一主场景中完成一条连续动作。
- 16～22 秒：允许展开渐进过程，并进行自然的构图或视角变化。
- 23～30 秒：形成连贯的长素材片段，可分为前后衔接的拍摄阶段，但必须保持同一商品、时空和创意目标。

时序意图不规定机械的动作数、镜头数或正文字数。模型返回结果不需要回传时长，Worker 以 `CreativeShardPlan.tasks` 中的权威时长恢复每条结果。

## 5. 评估与择优

- 评估输入为“候选创意 + 该条的目标时长”，不增加新模型调用。
- 评估器通过现有 `visualExecutability` 分数判断动作密度与目标时长是否匹配。
- 新增软提醒 `DURATION_TOO_DENSE` 和 `DURATION_TOO_SPARSE`；轻微不匹配不作为硬问题。
- 多场景时间线、完整广告时间线等现有硬问题保持不变。
- 择优继续使用当前向量 MMR 口径：70% 独立质量 + 30% 相对新颖度。时长提醒不直接阻断数量补齐。

## 6. 人工操作

- 单条重生成继承原条目时长。
- 人工新增或修改后的 `ITEM_EVALUATE` 使用条目结构化时长评估。
- Prompt 正文复制与展示仍只包含干净正文。

## 7. 验证计划

- Contracts：V5 4～15 秒与 V6 4～30 秒分版校验、JSON Schema 对齐。
- API：V6 设置和条目允许 30 秒，V5 仍拒绝超过 15 秒。
- Worker：四个时长区间的软提示正确；评估输入带每条时长；恢复分片后时长不丢失。
- Web：时长控件可在 4～30 秒内调整，越界值被正确纠正。
- 运行相关单测、类型检查、生产构建与 `git diff --check`。

## 8. 非目标

- 不执行付费 Ark 或 Seedance 调用。
- 不调整分片大小、并发数、输出 Token 上限、重试次数或模型路由。
- 不为时长新增评估输出字段、反向推导字段或新的公开节点。
- 不修改视频渲染请求编译器的厂商能力校验。

## 9. 实施结果

- 当前 V11/V6 的设置、单条 Prompt、Pydantic 和 JSON Schema 已统一支持 4～30 秒，没有新增 Schema 版本。
- Worker 已将时长编译为四档 `temporalIntent`，并删除“允许 2～3 个衔接微动作”的统一限制。
- 评估请求会带入每条 `targetDurationSeconds`，但不改变评估输出结构，新增两个非阻断软提醒。
- 分片恢复会从已持久化的 `CreativeShardPlan.tasks` 恢复 `slotId → 时长`，单条重生成和 `ITEM_EVALUATE` 继续使用原条目时长。
- 自动验证：Contracts 17 项、API 299 项、Web 160 项、Prompt Worker 184 项通过，1 项付费集成测试按预期跳过；Contracts/API/Web 类型检查、API/Web 生产构建、Worker mypy 和 `git diff --check` 通过。
- 浏览器验收：30 秒可正常自动保存，31 秒会收敛到 30 秒，无保存失败或控制台错误；验收后已恢复测试商品原有的 15 秒草稿。
- 本次没有执行付费 Ark 或 Seedance 调用。当前 Worker 虚拟环境未安装 Ruff，因此未将 Ruff 记录为通过项。
