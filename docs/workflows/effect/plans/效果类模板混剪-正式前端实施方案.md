# 效果类模板混剪正式前端

## 范围

保留用户确认的模板配置 → 原型精修工作台 → 返回配置流程，删除演示素材、预制工程、假保存/校验和演示开关。初始无模板，新建提供可编辑的六槽位默认结构，不配置区间、总时长和初次生成数量。

读取同项目同效果类 Run 已确认素材池，按用途/时长/工程内去重填充，每次追加一个工程，不覆盖已有工程。支持配置、替换、排序、裁切、撤销/重做、字幕编辑及真实预览。

## 数据与提交

TEMPLATE_MIX 草稿使用乐观并发；模板编辑序号不等于工作副本 revision。每个工程保留模板快照，只在手动同步时更新同模板其他工程并保留人工选片。素材绑定 SEGMENT_RENDER render-batch 的精确 artifactId/revision/fileObjectId，不静默重绑定过期素材。确认时服务端校验草稿、时长、去重及上游有效性，事务提交 mix-template:<templateId>、timeline-project:<templateId>:<projectId>；相同内容不增 revision，下游沿统一依赖机制待更新。

## 非目标与验证

不改数据库/Prompt/渲染 Worker，不实现属于成片输出的编码。自动配音、ASR、节拍分析没有服务，明确标记未接入，不伪造结果。播放器提供素材顺序预览，转场由最终渲染消费。旧演示状态不迁移，未知 schema 明确失败。测试空数据、时长/去重、模板隔离、同步快照、人工保护、冲突、上游过期；执行 Contracts/Web/API 类型检查、相关单测、Web 构建、diff check；浏览器回归加载/空/错误/保存/刷新恢复及宽窄屏，缺实媒时记录未验收项。
