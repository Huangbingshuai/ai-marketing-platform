# 效果类模板混剪正式前端

## 范围

保留用户确认的模板配置 → 原型精修工作台 → 返回配置流程，删除演示素材、预制工程、假保存/校验和演示开关。初始无模板，新建提供可编辑的六槽位默认结构，不配置区间、总时长和初次生成数量。

读取同项目同效果类 Run 已确认素材池，并按 `promptId` 回连当前 `prompt-batch:*` 工作副本中的原始 Prompt。分类模型只接收六槽位定义、素材 ID/编码与 Prompt 正文，不读取上游推荐用途。Prompt 归槽沿用 Prompt 生成节点的批次可靠性策略：按真实 Prompt 长度和结构化输出预算动态装箱，限制单片认知负载，以有限并发执行分片链；每个成功分片立即保存检查点，超时、截断或结构异常时递归二分，Worker 重启后只补未完成素材。API 在分类检查点齐备后，按模型对六槽位的真实分数建立可兼容素材池；同一素材可进入多个得分不低于 `0.6` 的槽位，某槽位无及格素材时只展示该槽位真实得分最高的低匹配候选。初次 AI 填充用最大权重匹配选出多组六条不重复素材，Worker 对选中视频最多抽取 12 帧，由多模态模型选择等长截取起点，并逐条保存截取检查点。AI 初次任务最多 20 条；之后算法组合复用已有有效裁剪池自动扩展至单模板 100 条，不编码最终视频。

## 数据与提交

后续批量成片优先复用已有工程中仍然有效的六槽 AI 绑定与截取起点作为槽位素材池。服务端确定性平衡各槽位素材使用次数，允许跨成片复用，但每条成片内部六素材不同，六素材组合也不与已有成片重复；单模板最多 100 条，不再为每个算法组合支付模型裁剪费用。素材 revision、模板槽位时长或源视频长度失效时不得复用旧截取。算法组合仍只写 TEMPLATE_MIX 草稿，必须经完成校验才提交工作副本。尚无完整 AI 素材池时先走真实智能填充。媒体预览从正式后端内容代理读取视频，服务不可用时明确报错，不能把不可读取的工程标为“已经播放”。

TEMPLATE_MIX 草稿使用乐观并发；模板编辑序号不等于工作副本 revision。AI 任务快照冻结草稿 revision、模板 editVersion、Prompt 工作副本与每条视频片段的 artifactId/revision/contentHash；任一输入变化后拒绝旧回调。AI 完成只更新节点草稿，人工“完成校验”才提交 `mix-template:<templateId>` 与 `timeline-project:<templateId>:<variantId>`，时间轴依赖同时记录 Prompt 批次和实际六条渲染片段。相同内容不增 revision，下游只因已确认产物变化待更新。

## 非目标与验证

不实现属于成片输出的编码，也不进入配音、ASR、字幕自动生成、BGM 卡点与人工配置批量数量。模型配置使用 `ARK_TEMPLATE_MIX_MODEL`，为空时回退通用 Ark 模型；缺少真实配置直接失败，禁止静默 Mock。旧 schema v1 草稿继续可读，缺绑定元数据时按历史/人工结果展示。测试分类输入边界、最大匹配、低分补位、时长与去重、租约/幂等/旧回调、模板隔离、人工保护及上游过期；执行 Contracts/Web/API/Worker 检查和浏览器宽窄屏回归。

## 后端基础能力接入

混剪节点提供独立的工作区读取和草稿保存接口，不再由 Web 拼装通用节点状态与工作副本列表。智能填充通过持久化异步任务执行，阶段为 `CLASSIFYING → MATCHING → SAMPLING → TRIMMING → COMPLETED`。公开接口负责创建/读取任务；专用 Worker 使用 token、claim、lease、heartbeat、重试和安全失败回写。所有写入都校验 `projectId + workflowRunId + expectedRevision`，页面刷新后从工作区的活动任务继续轮询。

模板更新只命中请求中的 `templateId`。重新智能填充保留目标工程已人工选定且仍合法的槽位，其余槽位按 Prompt 匹配分、时长、工程内去重和跨工程低复用重新计算；低于 `0.6` 的结果允许补位但展示醒目警告，不足六条不同可用素材时任务失败且不生成伪时间轴。模板时长是权威值，模型只给截取起点，结束时间由服务端确定性计算。

## 工作台交互边界

模板配置页只维护名称、六槽位顺序、时长和转场，不创建 AI 任务。用户点击“进入精修工作台”只切换视图：未执行智能填充时，页面展示全部可用素材、空播放器、空成片列表和空轨道，不预建成片工程、不按槽位筛选素材，也不展示任何伪归槽结果。用户在工作台右上角主动点击“AI 智能填充”后才创建真实异步任务；任务成功时由服务端原子创建一批完整成片工程并分别铺入六段素材，失败时不留下空白工程。已有工程可“重新智能填充”，右侧“算法批量组合”复用仍有效的 AI 归槽与裁剪结果自动新增不同的六素材组合，跨工程允许复用，不恢复“初次生成数量”输入。完成 Prompt 归槽后，素材库显示“全部 + 六槽位”筛选项及各自素材数；后续算法组合不重新调用模型。

任务进度只在精修工作台展示，并复用前序节点的统一进度条；“查看工作流”可查看 `Prompt 归槽 → 唯一素材匹配 → 视频抽帧 → AI 截取 → 时间轴生成` 五阶段的功能说明和当前状态。时间轴按剪映式编辑画布实现：轨道头与可横向滚动的时间区域分层，标尺、片段、播放头共享统一的 `pixelsPerSecond` 坐标，播放头作为贯穿全部轨道的独立覆盖层；字幕、主视频、口播和 BGM 四条轨道固定存在，空轨道只展示空状态，不伪造媒体内容。片段单击只选中、不移动播放头；空白轨道或标尺点击负责定位，播放头手柄可独立拖动，左右键按 30fps 单帧步进。播放状态由工程级 `requestAnimationFrame` 时钟推进，视频元素仅提供当前槽位画面；经过素材缺口时持续计时并显示纯黑画面，不因 DOM 中没有视频而中断。时间轴工程的六个已绑定视频预加载在独立播放器层，切换点只有新素材达到可显示状态后才原子切换画面，加载期间保留上一帧，避免片段贴合处闪黑。中间播放器不叠加槽位名称或素材编码遮罩，预览容器根据素材画幅动态计算宽高并在可用区域内等比放大。素材库卡片单击只切换中间播放器并自动播放完整素材，不修改时间轴；拖放到主视频轨才填补缺口或替换现有绑定，并继续执行时长、工程内去重和人工来源校验。已占用素材在素材库中直接显示占用槽位，重复拖入时使用可关闭的系统通知明确说明冲突来源，不以无文字色块遮挡播放器。桌面宽度下左侧素材库、中间播放器和右侧成片列表之间提供可拖动分隔条；左右栏宽度属于本地 UI 状态，不增加草稿 revision。素材网格使用自适应列宽，拖宽左栏时每行素材数自动增加，拖窄时自动减少；分页数量始终按当前列数的整倍数计算，非末页不出现缺一格的残行。素材卡片与时间轴胶片条共用限并发的静态缩略帧缓存，翻页和重绘期间先展示系统浅色占位，不回退为黑色视频元素。预览区和时间轴之间的父级横向分隔条同时改变上下区域高度，使分界线跟随指针移动；轨道控制区与时间画布之间提供纵向分隔条用于调整轨道头宽度，双击任一分隔条恢复默认尺寸，相关尺寸只属于本地 UI 状态。主视频片段展示缓存后的真实素材缩略帧；浏览器读取每条素材文件并解码真实音轨 PCM，根据当前截取区间计算峰值后绘制细密中轴波形，加载失败或素材没有音轨时只显示空基线，禁止用随机数、三角函数或固定图案伪造波形。时间轴支持框选、多选、拖拽幽灵预览、插入位置提示、边界吸附、边缘定长调整源截取、轨道锁定/显隐/静音和单步撤销重做。时间轴采用与正式系统一致的浅色表面和蓝色交互色，不建立独立黑色主题；缩放以鼠标位置为锚点，普通滚轮横向滚动。排序只改变模板槽位顺序，裁剪只改变素材起点且不修改槽位权威时长。业务状态仍以现有 `EffectTemplateMixVariant` 为唯一事实源。通用动作块时间轴组件不再作为依赖，避免其表格行、游标和选中模型与视频剪辑语义冲突。刷新时若存在运行任务，页面恢复对应模板工作台并继续轮询；新建工程任务尚无 `targetVariantId` 时也必须恢复，不能只恢复已有工程的重填任务。
