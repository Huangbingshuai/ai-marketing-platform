# 成片输出按模板当前路径导出

## 范围与边界

待渲染区使用分支树模板配置视图同一当前路径规则；不要求用户切换全局活动分支。导出在选中模板路径下创建输出子分支，整批成功后才发布节点。六节点职责、历史交付冻结及局部更新规则不变。

## 实施

- Contracts 提供模板路径纯函数，树和成片 API 共用；按视频渲染/手动复制谱系隔离，不跨上游版本借用工程。
- 成片列表逐模板读取当前路径。服务端导出重新确认所选输出批次仍是该模板当前批次，冻结全局活动指针；创建子分支事务内校验指针，冲突时拒绝，不自动重试。
- 移除客户端的全局分支切换提示、按钮及导出前切换确认。保留重新导出确认和异步作用域保护。
- 不迁移数据库，不删除旧交付。2026-10-04 活动分支漂移计划中的手动切换方案由本计划取代。

## 验收

当前模板与全局分支不同也能导出；新输出父节点为模板当前路径。覆盖历史批次拒绝、跨项目拒绝、手动复制隔离、上游分支隔离、并发活动指针变化、失败不发布。运行 Contracts/API/Web 测试、类型检查和 diff 检查，浏览器检查三个宽度及真实本地成片导出。
