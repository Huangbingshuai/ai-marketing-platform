# 混剪界面断言排查

## 范围

针对模板混剪 Web 全量检查中 22 项失败逐项核对实现与当前效果类规则。直接上游仍为同项目/Run 的已确认素材与实际 revision；草稿保存、`mix-template` / `timeline-project` 自动提交、包装及成片输出边界不变。本次不修改 Contracts/API/Worker、数据库或真实项目，不触发任务、费用或提交 Git。

## 方法

- 固定失败清单，逐项检查源码、已确认业务规则和现有行为测试；区分代码格式/截取失效、测试落后于需求及真实功能错误。
- 不删测试、不跳过失败、不恢复已移除的手动重试按钮或无条件包装分支；维护每项原有有效保护目标。
- 格式断言改用空白无关检查；易误截取的回调/键盘函数按 TypeScript 语法边界读取，关键锁定及键盘规则增加执行测试。
- 确需修实现才作最小补丁；否则只改测试。保留用户现有未提交改动。

## 验收

重跑四个失败文件、模板混剪全部测试、Web 类型检查和构建及差异检查。若涉及实现，按原型规范浏览器回归相关 1920、1440、窄屏行为；测试修正也通过正式组件的隔离浏览器检查按钮、空槽及键盘行为。记录每项原因、修复依据及真实限制。

## 实施结果

22 项均为测试过时或源码格式/截取失效；仅修正测试并补充键盘和锁定执行保护，未改生产功能。模板混剪 823 项通过，Web 类型检查、构建及范围内差异检查通过。逐项原因、浏览器观察和未验证范围见[验收记录](../evidence/browser/2026-10-14-ui-assertion-audit.md)。
