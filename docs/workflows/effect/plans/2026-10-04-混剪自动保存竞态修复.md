# 混剪自动保存竞态修复

## 范围与边界

效果类模板混剪草稿自动保存及同 Run 工作区重读。沿用当前 Prompt、渲染片段工作副本输入、模板/时间轴确认提交和成片输出局部更新边界；不新增接口、业务 revision、任务或分支，不强制覆盖跨页面更新。

## 原因与实施

- 保存返回无条件将 dirty 改成 saved，可能漏存请求期间的新编辑；保存队列应继续保存最新快照，退出时等完整队列。
- 工作区后台读取没有本地编辑/写入代际保护，旧响应可能回退 revision 或覆盖新编辑；使用请求代际阻止安装过时响应。
- 409 时保留本地草稿，仅以最新工作区对基线做模板级三方合并。不同模板、相同修改以及仅 UI 选择/服务端派生状态变化可重试一次；同一模板不同内容或删除与编辑冲突不自动覆盖。仍使用服务端 expectedRevision 和所有锁定/来源校验。
- 作用域切换后旧排队保存不得写入新项目/Run。

## 数据与迁移

无数据库或跨进程契约迁移。基线和代际仅是前端请求协调数据，不是第二套业务状态。

## 验收

回归请求期间继续编辑、重读晚于保存返回、同 Run 不同模板更新、同模板冲突、删除冲突、切换作用域、保存失败及退出 flush。运行 Web 单测、类型检查、构建、diff 检查，并浏览器复查快速连续编辑后草稿保存及页面导航；不执行付费任务。

## 已执行验证

- 新增竞态及三方合并测试 12 项；连同工作区加载、API、画布新鲜度、成片状态测试共 32 项通过。
- 浏览器在测试7成片01快速分离音频、撤销、重做、撤销，保存完成后导航至成片输出，保持原有仅成片02待更新。
- 两页同时读取同一草稿，另一页仅切换至测试6并保存后，旧 revision 页面继续编辑测试7并保存成功；随后撤销临时编辑恢复原时间轴。未执行智能填充、包装或渲染任务。
- Web 类型检查及构建通过，构建仅有既有大包提醒；已调整保存串行化的旧源码断言以匹配新队列。验收截图：`../evidence/browser/2026-10-04-output-freshness/autosave-race-restored.png`。
