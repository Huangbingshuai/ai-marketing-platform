# 连续播放遮罩与片段交接修复

## 范围

效果类第五节点精修播放器。消费现有同项目/Run 的素材 URL、哈希、
绑定 revision 和工程截取时间，不改变 `mix-template`、`timeline-project`、
包装或成片输出工作副本，不保存业务 revision、不启动生成或编码任务。

## 原因与实施

- 静止首帧绘制校验不能使用固定时间去校验持续前进的视频时钟。
- 播放中的片段切换不显示整块缩略图加载占位；下一片段复用已有预加载，
  就绪前保留上一片段已解码画面，准备完成后切换，空槽仍按真实空画面显示。
- 首次起播尚无已解码画面时，允许继续显示已缓存的真实首帧图片，
  但不得显示尚未生成图片的灰色加载占位，避免回归切换工程的首帧体验。
- 暂停/切换工程保留首帧预览；校验当前媒体身份及 seek，旧回调不能撤销新作用域遮罩。
- 正常跨片段只做一次定位，不被首帧身份监听反复 seek。

## 验证

- 单测覆盖运动时间超过一帧、暂停精确定位、来源替换、迟到回调、重复绘制请求。
- 断言自然播放交接清除遮罩且不重新 seek，预览加载占位不遮住播放画面。
- 浏览器连续播放六片段，特别观察 34–40 秒，检查暂停/恢复、拖动与切换成片。
- Web 类型/构建、相关媒体测试及 diff 检查；按 1920/1440/窄屏验证。

## 验证记录（2026-10-09）

- 首帧呈现、seek、播放时钟、媒体缓存及模板导航五套聚焦测试 55 项通过。
  新增运行时钟推进、元数据未完成/旧来源/seek 中不交接、播放接管取消静止绘制等覆盖。
- Web 构建含 vue-tsc 通过；媒体模块及测试 ESLint、定向 diff 检查通过。
  仍有既有大包体积警告，没有把本次聚焦检查当成全仓库门禁。
- 在“紫苏梅子酱 / 测试3”从 0 秒连续播放到 48 秒，30 秒和 41 秒
  均观察到当前原生视频 readyState=4、时间推进，无首帧占位。
- 拖动到约 36 秒后等待定位完成再起播，实际视频 readyState=4、paused=false，
  显示当前效果片段。`playback-36s-1440.jpg` 记录 36 秒播放画面，不是封面或静止截图。
- 切换成片 03 后播放、7 秒暂停及恢复，暂停保留当前画面、不弹加载占位。
  1920/1440/768 宽度检查通过；浏览器验证只操作导航/播放/进度条，不启动付费生成。
- 调试期间其他工作区热更新曾使页面返回配置，因此重新进入后补测。
  未验证真实断网/文件损坏的端到端场景；元数据及旧来源的机械拒绝由单测覆盖。
