# 配乐差异化与连续播放修复

## 范围与证据

效果类模板混剪内的包装及工程预览。消费冻结时间轴、实际素材依赖 revision 和确认事实，仍由既有包装任务提交 `timeline-project` / `timeline-package`；下游只在用户主动导出时编码。不重写历史音乐、不新增任务表或供应商、不自动运行付费生成。

只读检查既有44条包装：44份配乐描述和44个文件ID；抽查3份文件内容哈希不同，均被预处理为单声道24kHz。描述集中于温暖家常、轻快民乐，证明提示趋同但不能据此量化听感相似度。普通画面交接遇到暂停的预加载视频也调用缓冲流程，该流程停止并重建全部音频。最终输出则独立混入整条音乐，不按画面切割。

## 开源调研（2026-10-11）

- [MLT框架设计](https://mltframework.org/docs/framework/)：独立定位音轨，不随其它轨道剪切重置。采用独立连续音频运输时钟；不引入原生MLT依赖。
- [Waveform Playlist](https://github.com/naomiaro/waveform-playlist)：浏览器多轨、片段位置与淡入淡出分离。沿用现有Web Audio采样调度，不替换编辑器或引入第二套轨道状态。
- [MusicGen官方说明](https://github.com/facebookresearch/audiocraft/blob/main/docs/MUSICGEN.md)：描述可具体区分曲风、节奏、乐器，支持立体声模型。采用具体、多轴编曲描述和立体声音乐处理思路；不复制其代码或模型。[模型权重许可证](https://github.com/facebookresearch/audiocraft/blob/main/LICENSE_weights)含NonCommercial限制，因此不将权重接入商业生产。
- [VidTune论文](https://arxiv.org/abs/2601.12180)：以视频上下文辅助生成配乐方向。采用当前成片实际画面作为音乐依据，不单靠商品类别刻板选曲；不接入研究原型或宣称复现其效果。

## 实施

1. 正常画面交接启动已准备的视频，不重建音频；真正缓冲时暂停/恢复同一个AudioContext及已调度节点，继续原采样位置。缓冲位置来自全局音频时钟而非新视频的初始位置。显式跳转、切成片和轨道编辑仍重新调度，旧等待不得恢复新作用域。
2. 包装文案模型同时收到依据既有不可变item ID生成的多轴差异化编曲参考（风格、节奏、配器、发展方式），由AI根据实际画面决定适配，不以关键词进行商品分类。重试沿用同一参考与已保存musicBrief，新任务获得新方向；不额外调用模型、不改供应商协议。要求整曲连续，不逐槽重开前奏。
3. 音乐预处理与配音分离：音乐立体声48kHz，配音仍原24kHz。保留整曲长度处理，不按视频边界重播，不在文件内烘焙一遍时间轴已负责的淡出；用户音量、静音、淡入淡出不改变，不加口播自动压音乐。
4. API音乐上传校验额外接受双声道48kHz PCM，旧单声道24kHz继续兼容；口播/字幕配音入口不放宽编码。无数据库迁移、无跨进程字段变化。既有快照及旧音乐仍可播放；新音质/风格只影响用户后续主动包装。

用户补充：整条成片只生成一首完整配乐，不按素材分别配乐；差异化发生在不同成片之间，而非把同一成片内部切成不同风格。整片上下文明确排除逐槽曲风/切点规划；局部口播恢复也只读完整成片，不以残缺片段重新决定配乐。

## 验证

- Web单测：连续切换、缓冲保持节点、显式seek偏移、取消/迟到恢复、独立增益及淡入淡出。
- Worker单测：参考同任务稳定、不同任务分散、视频上下文及整曲要求进入AI请求、保存检查点不重复付费；真实FFmpeg双声道/采样率/时长和声道独立性。
- 回归包装与最终输出测试、Web类型检查/构建、Worker类型检查、`git diff --check`。
- 浏览器在1920、1440及窄屏检查实际音频调度跨素材边界和暂停/seek恢复；结果只说明连续性，不把合成测试当音乐创意听审。
- 不自动改变业务项目当前工程、不导出、不提交Git。历史音乐需用户主动重新包装才会改变，生成音乐听感仍需后续真实试听确认。

## 实施验证记录

- Web聚焦播放/交接/seek测试48项通过；`pnpm --filter @ai-marketing/web build` 通过（保留现有大包告警）。
- API包装/领域/音乐编码测试166项通过，API类型检查通过。标准Nest构建遇到现有 `dist/config` 目录EBUSY占用，未终止其它进程；使用独立 `dist-music-check` 目录执行 `tsc -p tsconfig.build.json` 编译通过。
- Worker全部564项测试通过（含真实FFmpeg），`uv run mypy src` 通过；检查44个稳定创作参考覆盖8类曲风、6类律动及多种配器，验证的是输入差异而非模型输出听感保证。
- 隔离测试项目只读浏览器播放：1920下30秒六素材成片，整首音乐仅调度一次，遇到缓冲仍保留原节点；1440和390宽播放跨素材边界，音乐未额外重建。显式seek到10秒和23秒时，音乐偏移分别为10和23秒，暂停后时间码保持。验收页拦截全部写请求，不修改业务工程、不调用付费生成。
- 无活动混剪、包装及输出任务时重建本地混剪Worker；容器内核对整片音乐上下文、稳定任务身份及48kHz转码代码已加载。API健康检查200，完整 `git diff --check` 通过。
- 本轮未调用音乐供应商，未对新音乐进行真实生成后的主观试听；既有44条音乐未自动重新生成。开源调研用于实现取舍，不宣称复现开源模型音质。
