# 渲染局部更新跨分支自动保存恢复

## 范围与事实

- 效果类 Prompt → 片段渲染，沿用现有隔离编辑、冻结输入、自动提交及共享素材池，不增加任务或状态表。
- 广式腊肠本次隔离草稿已完成生成，两个失败状态均为明确删除标记；自动保存返回 BRANCH_CONFLICT，使工作区读取失败。
- 当前分支已确认 Prompt 为 revision 12，素材池所有者的 Prompt 为 revision 11。合并代码把隔离 Prompt 强制映射为素材池所有者，并在错误的分支查找 revision 12，导致事务回滚。

## 修复

1. 冻结局部更新合并时，按隔离 Prompt 的明确克隆来源恢复真实已采用的 Prompt 身份、历史 revision 与哈希；素材池所有者与 Prompt 所有者不强制相同。旧素材继续保留原消费来源。
2. 逐条依赖及冻结上下文使用真实 Prompt 的 artifactKey；共享素材池只接受同项目、同渲染谱系内已发布分支的冻结 Prompt，继续核验来源与历史哈希，不放宽普通提交。
3. 保留素材池并发编辑、资料包、租约和提交校验；不自动重生成、不覆盖最新 Prompt、不新增分支、不修改无关谱系。
4. 已有工作区后台重新读取失败时保留素材与进度，展示可恢复提示并继续轮询；首次加载失败仍展示错误态。不能掩盖真实保存冲突或标记为已完成。

## 验证

- 回滚事务中的随机项目覆盖共享素材池与不同 Prompt 头、冻结后再次修改、历史来源、重复提交、并发素材修改、跨谱系拒绝；不产生模型请求或真实文件。
- API、Web 定向测试、类型检查、构建和 diff 检查。
- 用既有读取/自动保存恢复链路验证已完成的真实草稿，不改写数据库绕过校验，不调用付费模型；记录实际观察及未验证边界。
