# 渲染素材来源与局部更新同步

范围：效果类片段渲染及宿主页面的 Run 刷新衔接。不改变生成协议、Worker、收费范围或提交规则。

直接上游为已确认的 `prompt-batch:{productId}` 及其 revision。局部更新冻结输入，在隔离编辑 Run 完整成功后原位提交 `render-clip:{taskId}` 与 `render-batch:{productId}`；下游模板混剪仅标记真实依赖差异，不自动执行任务。

修复：

- 来源标签根据持久化 `importedMaterial` 判断，不再根据会被重置的供应商任务 ID 判断。
- 宿主 Run 刷新串行处理最新通知；新通知使旧读取失效，不丢弃完成后的回切通知。局部更新使用后台同步，不加整页遮罩。
- 渲染预取与节点加载共享同一个在途请求，避免先等待预取再重复读取。
- 轮询在旧响应被丢弃后仍继续调度；卸载、切换项目/Run 后不得写回。

无数据库迁移、无新契约。验证来源标签在排队/运行/失败/完成时稳定，人工导入仍保留其来源；验证迟到读取、连续通知、失败恢复、项目隔离及无手动刷新更新。执行相关 API/Web 单测、类型/构建、diff 检查及隔离浏览器验证。不触发真实付费生成。
