# 效果类成片输出完成校验

## 范围

- 在成片输出节点为当前选中的模板增加与前序节点一致的手动“完成校验”。导出和上传仍由现有任务自动完成，校验不重新渲染。
- API 仅在该模板批次所有条目完成、成片文件和项目资产可用、输出引用的已确认来源仍有效时接受校验。
- 校验提交稳定键 `final-delivery:<templateId>` 的 `DELIVERY_MANIFEST` 工作副本，记录本模板当前成片顺序、输出规格及已交付文件，依赖各条 `final-video:<templateId>:<variantId>` 工作副本。相同内容重复校验不增加 revision；重新输出导致成片内容变更或上游变化时，旧校验失效。
- 完成状态按模板隔离，由服务端返回；不把单个模板校验误当作整个 WorkflowRun 完成。项目成片资产仍由逐条上传维护。

## 接口与迁移

- 新增 `POST /projects/:projectId/workflows/effect/final-output/:runId/complete`，返回该批次当前状态；`FinalOutputRun` 增加可选的 `validated` 字段供旧数据兼容读取。
- 复用现有工作副本、文件和资产表，不增加迁移、不修改 Worker 消息。

## 验收边界

- 待渲染、运行中、取消、失败、部分完成、缺失文件/资产或来源过期时，服务端拒绝完成校验。
- 两个模板分别校验，互不影响；同一模板重复提交幂等。重新渲染改变成片版本后旧交付清单失效，必须重新校验。
- 页面切换项目、Run 或模板时只展示对应服务端校验状态，按钮忙碌与错误状态可恢复。
