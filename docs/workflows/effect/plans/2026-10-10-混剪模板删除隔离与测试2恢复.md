# 混剪模板删除隔离与测试2恢复

## 范围与证据

效果类模板混剪删除已确认的目标模板及其专属填充、包装、输出分支。共享 render-batch/render-clip、其他模板、其他项目与人工上游编辑不属于删除范围。删除接受后后台清理，不生成模型任务。

广式腊肠删除测试1的回执包含测试2的历史 Run。旧分支未记录 forkTemplateId，树遍历仅凭父子关系将其继续纳入删除；测试2任务快照仍保留，但工程草稿已缺失。页面节点切换在草稿保存失败时被拦截。

## 实施

1. 先对本地 PostgreSQL 做独立备份；再审计测试2的任务输入、截取、包装、输出及历史 revision 快照。备份只存 Git 忽略的本地目录，不发布商品正文或存储凭证。
2. 为删除范围统一解析可靠模板归属：显式 forkTemplateId 优先，无该字段时采用同 Run 的真实任务归属；不同模板或歧义不得沿父子关系推断属于删除目标。多模板共享容器保留，仅清理目标模板的数据。只读树投影与实际后台删除复用同一边界。
3. 删除前后补充回归：旧版无归属字段的测试2嵌套在测试1下面时，删除测试1仍保留测试2、其子分支、工作副本、文件、任务和写入能力；无明确归属的历史分支保守保留。
4. 修复删除回执交接与节点草稿保存竞态：已接受删除的旧作用域不再写入或阻止到存活作用域的导航；仍保护其他模板真正未保存的修改与旧响应隔离。
5. 恢复测试2优先采用可核验的完整工程快照及其实际依赖，不创建新模型任务。若只剩生成检查点，不将其冒充删除前最后人工编辑；先恢复可靠部分并明确缺失范围。恢复前校验文件、模板/项目/Run 及无活动写入，事务性修改并保留审计；重复执行不覆盖后续修改。
6. 修正已有错误删除回执中的误伤 Run，仅解除测试2的错误墓碑，不撤销测试1的删除。保留其他正确删除目标，不清理历史文件。

## 验收

- API 单元及随机私有 schema 数据库测试覆盖嵌套旧分支、多模板共享 Run、歧义归属、异步清理、幂等、项目隔离与旧写回拒绝。
- Web 覆盖删除后立即切节点、父作用域回退、模板切换、真实未保存修改、迟到回执和重复通知。
- 恢复前后核对测试1仍删除、测试2及可靠工程可读可写、时间轴及来源不伪造、素材总量不减少。验证刷新恢复及 1920/1440/窄屏状态。
- 执行相关测试、类型检查、构建及 git diff --check。默认不付费、不重生成、不重启 Worker、不自动提交 Git。

## 状态

2026-10-10 已完成隔离修复与可靠快照恢复：

- 删除范围不再递归纳入无归属子分支，也不从继承配置的哈希变化推断归属。随机私有 schema 回归验证嵌套旧分支、未知归属容器、旧错误回执的后台阻断及其他模板可写。
- 删除接受仍仅写入持久化回执、隐藏目标及取消目标租约；工程、文件、Redis 清理由后台继续。补充文件清理挂起期间仍能接受另一删除的测试。没有改为同步删除。
