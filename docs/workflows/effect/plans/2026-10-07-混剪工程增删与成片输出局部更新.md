# 混剪工程新增、删除与成片输出局部更新

## 1. 目标与边界

复用现有工程增删局部同步、工作副本、事务及 Outbox，补齐待渲染展示、内容判定、渲染校验和状态联动，保留工程编辑更新逻辑。

视频、音频、字幕任一轨道放入内容并形成有限正时长，即可成为待渲染成片，不要求填满六个槽位。空工程不展示、不计待更新；模板默认槽位和保留结束位置本身不算新增内容。

用户补充：空模板槽位仅作为用途标识牌展示，不参与时长、占位、吸附、框选、编辑操作、更新判定或导出限制；实际放入的素材仍执行来源和截取校验。显式删除来源后保留的黑屏区间不属于模板标识牌，继续沿用既有空白时间轴规则。

不调用真实付费模型，不自动包装，不重做历史成片，不物理删除 TOS 文件，不自动提交 Git；保留工作区已有改动。不新增状态表，不批量迁移历史数据。

## 2. 用户行为与界面

- 保存成功后，以当前模板实际 Run 的工程与输出记录比较，新增内容使成片节点待更新。
- 待渲染区域复用卡片，展示新增工程名称、实际时长、封面和“新增 · 待渲染”；无视频使用系统占位，点击预览对应工程，不可下载或误调用已有输出条目重渲染接口。
- 新增与已输出区域分开；已删除工程的旧成片标记待移除，用户点击局部更新后才移除。
- 尚未渲染的新工程删除或清空，取消新增差异；清空已有工程不等于删除，沿用已有编辑和显式空白时间轴规则。
- 顶部局部更新处理全部增改删，系统确认弹窗分别列出数量；单卡仅处理本条。
- 来源失效工程仍展示具体阻塞原因；读取失败或缺失不能当作删除。

## 3. 数据、接口与执行

- 以 projectId + workflowRunId + templateId + variantId 隔离，共用服务端差异计算；前端不维护第二套差异状态。
- 扩展 projectChanges.added 的时长、封面和阻塞原因，保留 removedItemIds，提供比较使用的草稿 revision。
- 现有 local-update 增加可选 expectedDraftRevision，继续使用 itemIds + syncProjects。新增卡片以 variantId 标识，确认更新后才创建输出条目。
- 内容时长覆盖真实视频、独立音频、口播、音乐、字幕及字幕口播的最晚结束时间；复用并补齐现有时长函数。
- 手动新增工程允许未填槽位及零视频，保留文件、项目、来源 revision、截取、时间轴容量校验。复用快照及 Worker：视频空隙为黑底，仅音频为黑底加音频，仅字幕为黑底加字幕。
- 新增继承当前输出批次分辨率与帧率，画幅与工作台一致；无视频沿用模板输出画幅，缺失回退渲染配置。
- 混合操作先校验，再同一事务创建新增项、移除删除项并写 Outbox；失败不执行任何删除或入队。
- 删除只移除当前分支输出关联并刷新交付清单，全删支持空清单、无 Worker；历史分支、归档资产和文件保留。
- 未变化结果不重渲染；失败恢复不重做成功项；局部更新不新增分支，整批导出分支保持原逻辑。
- 复用锁、唯一性和 attempt token；执行中继续编辑或删除不得被旧回调复活，旧任务不能清除新差异。失败/部分完成/取消仍展示剩余差异并支持恢复或同步删除。

## 4. 验收

- 已导出分支新建空工程、单个视频、仅音频、仅字幕、未填满六槽，展示与实际输出一致。
- 单删、全删、新增后删除、新增清空、增改删混合；纯删除无任务，新增只渲染新增条目。
- 卡片、模板、画布计数一致，刷新恢复；旧成片、其他模板和历史分支保留。
- revision 冲突、重复请求、源文件失效、读取失败、执行中编辑/删除、部分失败、迟到回调和跨项目隔离。
- Contracts/API/Web/Worker 测试、事务回滚、类型/语法检查、构建、git diff --check；浏览器宽窄屏及空/加载/失败/完成回归。

## 5. 工作副本边界

直接上游是当前模板的 timeline-project 与可用 timeline-package 及实际文件来源。混剪自动保存仅产生草稿，差异展示不提交产物；用户明确局部更新时确认相应时间轴与冻结快照。输出逐条确认 final-video，整批成功或纯删除提交 final-delivery。内容相同不增加 revision。最终输出仅影响当前交付/归档，不反向限制混剪，也不自动触发模型。
