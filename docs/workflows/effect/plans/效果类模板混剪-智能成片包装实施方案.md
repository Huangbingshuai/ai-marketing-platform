# 效果类模板混剪：智能成片包装实施方案

## 目标与边界

在 TEMPLATE_MIX 内为当前模板的完整工程逐条生成视觉理解、口播、配音、纯音乐和字幕。复用 effect-template-mix-worker 容器、Python 包、effect.template-mix.requested 队列、内部鉴权及 Outbox；旧消息继续执行智能填充，新消息 schemaVersion=2、taskType=PACKAGING。不自动提交工作副本，不新增付费测试任务。

## 执行与恢复

API 冻结时间轴（实际起点、图层、截取和转场）、确认商品事实及素材 revision。每个工程独立检查点；按数量、时长与输出容量分组，限并发运行。视觉模型分析低清预览与关键帧；商品声明只来自已确认事实。口播分句合成，真实音频时长决定字幕，超时长明确返修；音乐为每条工程独立生成的纯音乐，裁切/循环与淡入淡出由确定性音频处理完成。

包装 Run、Item 持久化，分片编号固定在 Item 中，阶段检查点按 Item 保存。心跳、有效租约和 attempt token 保护所有写回；取消阻止后续写入；同 Run 重试保留成功步骤。单条重新生成创建新 Run，快照一致时按组件保留其他已成功步骤。当前时间轴 hash 改变时标记该条结果过期，不覆盖人工编辑。

## 草稿、确认与接口

新增模板 packaging-runs 创建/列表，Run 详情/取消/重试，Item 单条重做、确认及成片输出输入检查接口。API 返回聚合数量、逐条状态、阶段和耗时；UI 不展示供应商原文。生成文件通过内部上传 API 进入 FileObject，不直接归档 ProjectAsset。

timeline-project 只确认视觉字段，timeline-package 独立确认音频、字幕、混音及精确视觉副本依赖。历史 voice/bgm/captions 继续读取，首次确认时迁移为独立包装工作副本。输出检查验证两份副本及当前草稿 hash，拒绝过期或未确认包装。代码现状：尚无正式最终视频编码服务，本次提供输出消费边界，不把分析预览当最终成片。

## UI

右侧包装按钮打开批量确认和结果面板；查看工作流打开独立包装流程图。沿用浅色/蓝色交互、节点状态卡与详情。保留原智能填充弹窗。展示真实分片、成功/失败/过期数、逐条试听、字幕预览、重试与确认；不生成演示进度。关闭/换项目释放轮询，ESC 与焦点恢复。

## 供应商与部署

视觉使用现有 Ark Provider，TTS 使用豆包语音 HTTP 单向流式接口。凭据仅通过现有容器环境配置传入。纯音乐生成协议必须以已开通的火山服务官方接口文档为准，未核实前不伪造可调用接口，不替换为曲库或音调合成。缺配置/能力明确失败，成功检查点继续保留。

## 验收

覆盖 1/10/100 工程分片、恢复、部分失败、旧租约、取消、跨项目隔离、幂等、时间轴过期、组件级重做和独立 revision。执行 Contracts/API/Web/Worker 聚焦测试、类型检查、构建、diff 检查和浏览器宽窄屏回归。真实火山质量验收单独记录，不将 Mock 协议测试视为真实生成成功。
