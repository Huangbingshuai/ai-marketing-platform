# 效果类模板混剪：智能成片包装实施方案

## 目标与边界

在 TEMPLATE_MIX 内为当前模板的完整工程逐条生成视觉理解、口播、配音、纯音乐和字幕。复用 effect-template-mix-worker 容器、Python 包、effect.template-mix.requested 队列、内部鉴权及 Outbox；旧消息继续执行智能填充，新消息 schemaVersion=2、taskType=PACKAGING。不自动提交工作副本，不新增付费测试任务。

## 执行与恢复

API 冻结时间轴（实际起点、图层、截取和转场）、确认商品事实及素材 revision。每个工程独立检查点；按数量、时长与输出容量分组，限并发运行。视觉模型分析低清预览与关键帧；商品声明只来自已确认事实。口播分句合成，真实音频时长决定字幕，超时长明确返修；音乐为每条工程独立生成的纯音乐，裁切/循环与淡入淡出由确定性音频处理完成。

包装 Run、Item 持久化，分片编号固定在 Item 中，阶段检查点按 Item 保存。心跳、有效租约和 attempt token 保护所有写回；取消阻止后续写入；同 Run 重试保留成功步骤。单条重新生成创建新 Run，快照一致时按组件保留其他已成功步骤。当前时间轴 hash 改变时标记该条结果过期，不覆盖人工编辑。

口播先进行事实 ID、数量和时段等机械预检，再由独立 AI 审核事实与画面关联。拒绝时 AI 给出逐句证据和修正建议，最多重写一次再审；仍不合格则明确失败，不放宽事实标准。背景解说不要求被画面逐字证明，但不得与实际画面直接冲突。包装策划/审核每次只发一个 HTTP 请求，重写前验证租约，日志只保留安全的拒绝代码和请求元数据。

新策划按相邻句起点之间的可用窗口执行保守字符容量检查（含标点，每秒 3 字，留 0.5 秒），这是请求生成时的容量约束，不代替真实配音测量，也不追溯拒绝已经实测合法的历史音频。策划与缩句共用事实/画面审核准则：推荐用法和背景事实无需逐帧展示，画面矛盾必须有直接反证，不从外观推断未确认食物类别；缩句审核检查改动及其上下文影响，不反复重审没有改动的已审核句子。审核输出预算使用当前允许的 8192 上限，输出不完整明确显示容量问题。

时间安排改为容量窗口：按成片总时长划分约 8 秒窗口（最多 200 个），模型只选择唯一 windowIndex 并生成正文/事实引用，Worker 确定性换算起止时间。窗口可跨镜头，因为口播是整条成片的商品解说而非逐镜配词；视觉观察仍按实际镜头保留，独立审核继续验证对应时间的直接矛盾。该调整只改变新生成的模型内部协议，API 检查点、历史草稿、工作副本和 revision 规则不变。验证乱序窗口、重复/越界编号、容量、事实引用、审查恢复及真实 32 秒成片。

真实配音超时只允许对尚未保存音频的当前句进行一次 AI 缩句；传入实测时长和可用窗口，保持句子 ID、起止时间与事实引用不变，独立审核完整口播后保存修订，再配音一次。仍超时明确失败，不截词、不强行加速，不改变已保存句子及其音频。视觉分组输出在 API 写入前检查时间边界与描述结构，最多一次带边界反馈的修正，不静默裁改模型观察。

取消后恢复与失联重领复用同一唯一 Outbox 记录，重新置为待投递并清除旧投递令牌；不重复插入相同聚合键。前端操作失败提示独立于读取失败，轮询成功不能清掉操作错误；试听切句/暂停引起的旧播放请求中断不被误报为权限拒绝。

## 草稿、确认与接口

新增模板 packaging-runs 创建/列表，Run 详情/取消/重试，Item 单条重做、确认及成片输出输入检查接口。API 返回聚合数量、逐条状态、阶段和耗时；UI 不展示供应商原文。生成文件通过内部上传 API 进入 FileObject，不直接归档 ProjectAsset。

timeline-project 只确认视觉字段，timeline-package 独立确认音频、字幕、混音及精确视觉副本依赖。历史 voice/bgm/captions 继续读取，首次确认时迁移为独立包装工作副本。输出检查验证两份副本及当前草稿 hash，拒绝过期或未确认包装。代码现状：尚无正式最终视频编码服务，本次提供输出消费边界，不把分析预览当最终成片。

## UI

右侧“智能成片包装”按用户最新要求直接提交全部完整成片任务，在工作台显示与上方智能填充共用的进度条；按钮提示付费 AI 调用，提交中/运行中禁用重复操作，不再弹批量策略确认面板。“查看工作流”或进度条的“查看当前工作流”才打开独立包装流程图，与智能填充共用浅色竖向节点图样式。点选节点在右侧查看输入、输出和逐条成片执行情况；结果、分片明细、试听、重做与确认放在图下折叠区。保留原智能填充弹窗。进度按后端已完成阶段汇总，不推测模型耗时、不生成演示进度；无任务也展示等待中的完整流程。关闭弹窗保留运行中轮询，换项目清理作用域，支持 ESC 与焦点恢复。

## 供应商与部署

视觉使用现有 Ark Provider；分析代理保留实际镜头顺序、截取起点、上层轨道遮挡和空隙，以硬切表示转场，原转场仍保存在视觉时间轴中。关键帧按容量分组读取。该代理只用于理解，不是精确特效预览或最终视频。

关键帧的时间覆盖范围由冻结时间轴机械计算，镜头切点为硬边界，同一镜头的相邻采样按中点分界；模型仅返回图片编号与画面描述，不自行填写起止时间。编号遗漏、重复或描述结构不合法最多修正一次，每次调用前检查租约。旧检查点不自动改写；若旧视觉内容影响下游质量，应显式重做对应成片，而非重复恢复同一份错误输入。

TTS 使用[豆包语音 SSE 单向流式接口](https://docs.volcengine.com/docs/DoubaoVoice/HTTPChunkedSSEUnidirectionalStreaming-V3?lang=zh)，按句请求 PCM，收到完整结束码后封装 WAV。API 再从 WAV 头验证编码与真实时长；音频登记与检查点写入在同一事务，杜绝文件已保存但恢复时丢失引用。

音乐使用[生成纯音乐](https://docs.volcengine.com/docs/84992/2100970)：GenBGM / GenBGMForTime，版本 2024-08-12，imagination / cn-beijing，HMAC-SHA256 签名。[查询任务](https://www.volcengine.com/docs/84992/2100960)统一调用 QuerySong，传 TaskID，识别 Status=0/1/2/3，读取 Result.SongDetail.AudioUrl。任务 ID 在轮询前保存；提交结果不明时停止，不自动再次收费提交。只允许官方 douyinvod 结果域名、HTTPS、禁止重定向，不把凭据转发给 CDN；转存项目内 WAV，拒绝带歌词的结果。无人声的声学质量仍须真实试听验收，不能仅凭空 Lyrics 宣称质量已通过。

现有 effect-template-mix-worker 的同一 environment 块增加可选配置 `VOLC_TTS_API_KEY / VOLC_TTS_SPEAKER / VOLC_TTS_RESOURCE_ID / VOLC_MUSIC_ACCESS_KEY / VOLC_MUSIC_SECRET_KEY / VOLC_MUSIC_ACTION`。不新增服务、队列或 profile。音频配置缺失仅使包装任务明确失败，旧智能填充不受影响。不得自动回退 Mock。

数据库新增 effect_packaging_runs / effect_packaging_items / effect_packaging_files；同一模板同时仅允许一个活动包装 Run，文件关系保护未确认草稿资产。发布时执行已有 API 的 `db:deploy`，再在无活动任务时更新同一个 effect-template-mix-worker 服务。

## 验收

覆盖 1/10/100 工程分片、恢复、部分失败、旧租约、取消、跨项目隔离、幂等、时间轴过期、组件级重做和独立 revision。执行 Contracts/API/Web/Worker 聚焦测试、类型检查、构建、diff 检查和浏览器宽窄屏回归。真实火山质量验收单独记录，不将 Mock 协议测试视为真实生成成功。

## 当前实施说明与限制

- 已接入任务持久化、Outbox、租约恢复、批量/单条/组件级生成、文件转存、包装确认、输出消费守卫和独立工作流弹窗。
- 分片按数量（最多 4 条）、累计时长（240s）、估算 token（24k）机械划分。为限制 CPU 和文件下载峰值，当前同一 Worker 按条顺序处理，视觉输入再分组；不是宣称 100 条同时并发。包装期间旧填充消息会留在同一队列等待。
- 当前没有正式成片输出编码服务。本次只提供两份已确认工作副本的消费接口，不宣称最终合成已经实现。
- 真实服务配置、音色权限、生成质量与实际计费耗时，必须在有效凭据和用户主动点击后验收。本次自动化测试不得触发真实付费任务。
- 单节点付费诊断脚本必须显式授权；复用已有视觉检查点，口播、配音和音乐分别执行，不自动调用下游，不回写取消的生产 Run。音乐提交先保存回执，结果不明不得重复提交。2026-09-21 真实测试见[逐节点记录](../evidence/browser/2026-09-21-广式腊肠真实包装测试.md)。
- 浏览器隔离回归入口 `apps/web/tests/browser/packaging.html` 只加载显式测试数据，并拦截所有 API 请求，不进入正式应用入口。
