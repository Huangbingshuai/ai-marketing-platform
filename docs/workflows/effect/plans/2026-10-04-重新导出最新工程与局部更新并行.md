# 重新导出最新工程与局部更新并行

## 范围与非目标

效果类成片输出：整批导出创建模板独立子分支，冻结该分支最新已保存的混剪草稿及可用包装；原分支仍可对待更新成片执行覆盖更新。不修改混剪/包装生成规则，不修改历史导出文件，不新增业务状态表，不调用付费 AI 验收。

## 数据与并发

- 复用输出快照、分支克隆及任务 attempt/lease。整批任务重新构建每条成片快照，不复用旧几何。来源失效、工程缺失或槽位不完整时明确拒绝。
- 后台整批分支不抢占当前活动分支；同模板未发布整批任务复用独立分支，避免重复排队。
- 输出列表增加可选后台导出来源标记，刷新后仍能读取进度；后台任务不替代当前模板成片列表或待更新计数。
- 局部更新和新分支整批任务分别锁定自己的输出批次，文件、工作副本和发布回写按各自 Run 隔离；整批失败不发布。
- 前端独立整批启动锁与当前分支操作锁，确认对话框冻结操作目标。新版本完成后可查看新分支。

## 迁移

仅增加可选响应字段，无数据库迁移；既有调用保持兼容。后台导出由既有未发布分支与输出批次查询恢复，不依赖本地临时缓存。

## 验收

1. 部分成片待更新时整批导出全部条目；新快照使用最新画面、时长、音轨及包装，旧快照/文件不变。
2. 新分支渲染中，旧分支局部更新可排队；输入、任务 token、输出文件互不覆盖。
3. 双击启动、失效素材、模板工程删除、失败/取消与刷新恢复覆盖；仅完整成功发布新分支。
4. 执行 API 单测、数据库回滚验收、Web/Contracts 类型及相关测试、Worker 离线渲染测试、diff 检查；浏览器使用明确隔离的测试数据回归进度与按钮并行可用。
