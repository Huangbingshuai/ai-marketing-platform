# 模板混剪：标点逐段配音与采样级字幕边界

## 范围与非目标

- 保持效果类模板混剪的每槽位一条口播文案、已确认事实、视觉来源及统一提交边界；不新增容器、队列或模型策划步骤。
- 每条文案按字幕断句标点拆分，顿号保留。每段独立调用当前冻结音色的 TTS，再按原顺序无缝拼接为该槽位的一份 PCM WAV；成片输出继续消费一条槽位口播音轨。
- 字幕逐段对应一份真实 TTS PCM，起止时间由 24 kHz 采样帧数累加；不再用字数比例估算。不承诺字级或音素级同步，片段首尾可能包含 TTS 自身的静音。
- 不自动重生成历史包装，不自动发起真实付费任务。旧版字幕和音轨照常播放；若要升级旧结果需主动重做口播。

## 数据、恢复和兼容

- 新音轨记录每段 PCM 帧数，布局标记 `SEGMENT_V3`。上传完整 WAV 时连同帧数在同一 API 事务中写入检查点，避免音频已入库而边界丢失。
- API 校验每段帧数为正整数、总和等于 WAV 真实采样数；新布局字幕数与帧数一致，未编辑的字幕边界必须对应采样累加位置，且不越过槽位。旧 V1/V2 不改变读取和播放规则。
- 同槽位配音超时仍只允许整条文案缩句一次；再次超时则失败，不截断音频、不借用下一个槽位。
- 单槽位重做仅重新生成本槽位各段配音和字幕；配乐、其他槽位保持原检查点。仅重做字幕对 V3 复用帧数，不再次调用 TTS。已有部分成功槽位仍可恢复。

## 验证

- 单测覆盖标点/顿号/引号、逐段 TTS 输入、拼接帧数、字幕无缝边界、超时缩句、旧版兼容、部分重做和无新增付费调用的字幕重做。
- API 契约检查无效帧数、总时长不符、伪造字幕边界、槽位越界；运行 Contracts、API、Worker 相关测试与类型检查、`git diff --check`。
- 真实付费耗时及主观听感须在用户主动发起新包装后测量；不把模拟测试当作真实耗时。
