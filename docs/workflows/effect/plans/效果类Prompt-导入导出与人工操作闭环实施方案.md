# 效果类 Prompt：导入导出与人工操作闭环实施方案

状态：已完成

## 一、目标与边界

本次完善效果类第 3 节点“Prompt 生成”的人工操作能力，覆盖批量导入、批量导出、人工新增、编辑、复制、删除、单条重新评估、单条重新生成和完成校验。

- 直接上游仍为当前项目、当前工作流运行中已提交且为 CURRENT 的营销洞察，以及当前全局视频配置。
- 所有人工操作只更新 Prompt 领域草稿和 `WorkflowNodeState` 展示状态，不直接覆盖 `prompt-batch:{productId}` WorkingArtifact。
- 只有用户点击“完成校验”，且数量、重复、用途评估、时长和上游依赖校验通过后，才提交 WorkingArtifact。
- 不修改第 4～6 节点，不新增 Prisma 表，不增加生产依赖，不恢复六类生成配额。

## 二、实现内容

### 1. 批量导入

- 新增结果级批量导入接口，支持读取本节点批量导出的 JSON，以及只包含 `items` 的精简 JSON。
- 支持“追加到当前草稿”和“替换当前草稿”两种模式。
- 服务端不信任文件中的 ID、编号、用途、评分、事实绑定或验证状态；统一生成新 ID/编号，并将导入条目标记为人工内容、`PENDING`、待异步重新评估。
- 导入必须是原子操作：任意条目的正文、六维或标签非法时整批拒绝，不产生半份结果。
- 精确正文重复在导入批次内及追加模式下与当前草稿比较后跳过，并返回导入数与跳过数。
- 导入数量不得超过节点最大数量；替换或追加后允许暂时与目标数量不一致，但完成校验必须继续阻止。
- 使用 revision 与 `If-Match` 做并发校验，其他窗口修改后返回 409 并重新加载。

### 2. 导出与人工操作

- 保持服务端导出权威草稿，导出文件继续拆分正文、六维、用途、时长、渲染参数和共用提示词。
- 人工新增与修改允许次级标签为空，正文和六维仍为必填。
- 新增、编辑和导入后都恢复为待校验状态；新增和编辑继续自动启动单条异步评估，导入条目提供明确的待评估状态和逐条重新评估入口。
- 删除后立即重算数量、重复度和质量状态；复制只复制干净正文。
- 单条重新生成保持稳定 ID、编号、位置和统一时长，允许模型重新判断推荐用途。

### 3. 页面交互

- 在结果工具栏增加“批量导入”，文件解析和确认在独立弹窗完成。
- 弹窗展示文件名、有效条目数、重复条目数、导入模式和导入后的影响。
- 支持 JSON 文件选择、拖放、ESC 关闭、焦点恢复、加载、格式错误、并发冲突和成功反馈。
- 导入运行期间禁止重复提交；运行中的 AI 任务和失败临时预览禁止导入。
- 不改变页面顶部布局和现有 Prompt 卡片信息层级。

## 三、契约与持久化

- Contracts 增加导入模式、导入条目、请求和响应类型。
- API 新增现有路径下的 `POST /results/:resultId/import`，不改变其他 HTTP 路径。
- Repository 在现有 `EffectPromptResult` 事务中锁定结果、校验 revision、写入完整新草稿与人工覆盖记录。
- 导入后的语义评估状态设为待评估，已提交 WorkingArtifact 保持不变，领域草稿 revision 仅增加一次。

## 四、测试与验收

- Contracts：导入模式、条目上限、导出回导兼容。
- API：项目隔离、append/replace、重复跳过、非法条目整批拒绝、最大数量、revision 409、质量状态重算。
- Web：文件解析、两种导入模式、错误提示、按钮禁用、焦点和 ESC、导入后刷新恢复。
- 回归人工新增、编辑、复制、删除、单条评估、单条重新生成、批量导出和完成校验。
- 执行 Contracts、API、Web 相关测试、类型检查、生产构建和 `git diff --check`。
- 浏览器验证正式页面的导入、编辑、复制、删除、重新评估、重新生成和导出主流程；不调用真实 Ark，异步功能只验证任务创建与状态恢复。

## 五、实际实施结果（2026-08-31）

- 新增结果级 JSON 批量导入，支持追加与替换、整批校验、正文去重、最大数量限制、revision 并发校验和安全导入摘要。
- 导入文件只接收正文、六维和可选次级标签；文件中的 ID、编号、用途、评分、事实绑定及验证状态不会成为权威数据。
- 导入条目统一生成新的稳定 ID 和编号，并保存为 `MANUAL / PENDING` 草稿；完成异步评估前不能提交 WorkingArtifact。
- 服务端导出增加 `format` 与 `formatVersion`，导出的完整 JSON 可以直接回导；复制仍只复制干净正文。
- 人工新增与编辑允许不填写次级素材标签，正文与六维仍保持必填；既有删除、单条重新评估和单条重新生成链路保持不变。
- 修复搜索筛选后节点草稿栏错误使用当前分页数量的问题；草稿栏现在始终显示整批权威数量。
