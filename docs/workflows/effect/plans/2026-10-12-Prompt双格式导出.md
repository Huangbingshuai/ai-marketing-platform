# Prompt 双格式导出

## 范围与依据

- 效果类素材 Prompt 节点的批量导出保留现有 Excel 可打开的 CSV，增加独立 HTML 阅读版，一次点击下载含两份文件的 ZIP。
- [Promptfoo 输出文档](https://www.promptfoo.dev/docs/configuration/outputs/)将 CSV 用于表格分析、独立 HTML 用于可视审阅，并支持多格式输出；采用其“数据版与阅读版分工”，不复制其代码或界面。
- [Langfuse 批量导出](https://langfuse.com/changelog/2026-08-06-bulk-import-export-prompts)使用 JSON 保存版本并支持迁移；本需求不是备份恢复，不引入 JSON 或新的导入流程。
- HTML 比 Word 更便于免安装、离线阅读与长正文排版；提供编号目录、逐条正文、来源、时长、用途、折叠辅助信息和打印样式。

## 边界

复用现有项目隔离的结果导出 GET，一次读取同一结果快照生成两份文件；不改变 API 契约、生成任务、营销洞察上游 revision、Prompt 工作副本提交、下游渲染依赖或语义重复度。保持原 CSV 字段与公式转义。未保存编辑不因导出而提交。JSZip 使用仓库已有的 3.10.1 版本，Web 显式声明依赖且仅导出时动态加载。

HTML 不包含内部 ID、哈希、供应商配置或隐藏状态。动态文本全部转义，正文换行原样保留；无脚本、外部字体或网络资源，共用提示词仅出现一次。辅助信息为空不显示占位。

导出文件统一使用当前作用域的项目名称：`项目名称_提示词_数量条.zip`，包内为同名前缀的 `.csv` 和 `_阅读版.html`。不使用商品名称占位或“双格式”后缀，项目名称中的文件名非法字符替换为下划线。

## 验收

- 单元测试覆盖原 CSV、防注入、中文/换行/长正文、条目顺序、来源与可选信息、一次请求生成两份同批文件。
- Web 类型检查、生产构建与相关文件 diff 检查。
- 浏览器点击真实导出按钮核对 ZIP 内两份文件及 HTML 的桌面/窄屏阅读、目录与打印样式；不启动付费生成。
- 初版实测第二份自动下载被浏览器拦截，因此最终采用单 ZIP 交付两种格式，不要求多文件下载权限。
