# 字幕语音区间与采样时钟重构

## 范围与证据

效果类模板混剪包装及正式预览播放器。旧 SEGMENT_V3 将音频划成相邻区间，丢弃第一句起音、各句结束和原始词时间戳；预览以 performance.now 推动字幕，而 HTMLAudioElement 异步开始输出。字段相等并不证明实际说话同步。

## 实施

1. 包装音频保存独立的 24 kHz 语音范围：每句真实 startFrame/endFrame，含第一句起音和句间空隙。保留旧 segmentFrames 读取兼容，不把旧字段冒充新的逐字校准。
2. TTS 流保留同一响应的起止时间，范围不可超出 PCM，上传和恢复时原子持久化；API 机械校验来源、范围、数量、文字和字幕坐标。新布局允许说话间隙，禁止相邻时长估算回退。
3. 正式预览使用一个 Web Audio 采样时钟，先解码再统一调度口播、字幕口播和配乐；所有槽位提前排程，不在槽位进入时依赖异步 play。字幕及播放时码消费输出时钟，暂停、跳转、切换工程作废旧排程。
4. 新包装快照冻结 `captionTimingPolicy: SYNTHESIS_WORDS_V1`。配音上传缺少实际范围时在存储前拒绝；检查点不能改写原子上传的范围，完成时不允许降级到旧布局绕过校验。只重做字幕而原口播缺少合成时间戳时明确失败，不从音量、文本比例或统一偏移推算。
5. Seed 2 请求 `enable_subtitle`、Seed 1 请求 `enable_timestamp`，使用所选音色本次合成响应。完整接收迟到的字幕包及末包音频；缺失、逆序、越界的时间戳报错。拼接后位置由此前实际 PCM 帧数累加，不依据预计语速。
6. 导出仍消费同一份字幕坐标；ASS 百分之一秒量化向上取整，禁止把起音向前舍入。局部源片段更新的内部音频上传接口同时传递并校验 `speechRanges`，避免新字段被 DTO 拒绝或被后续检查点替换。

## 边界

沿用同项目/Run/模板 WorkingArtifact 和原 checkpoint，不新增业务状态。包装节点输出仍为可编辑时间轴，最终编码仍由成片输出节点负责。渲染片段/模板快照的来源、revision、attempt 和提交边界不变；未来包装确认变更仍按现有方式影响成片输出工作副本。

最新用户范围明确为新智能包装链路，不再处理任何现有成片，不追加付费测试，不自动提交 Git。旧字段只保留历史读取兼容；当前改造无需数据库结构迁移，新字段随冻结快照和 checkpoint JSON 保存。

范围变更前已对测试2三条成片备份后更新字幕时间及语音范围，音频、配乐和导出文件未变，并已向用户说明。这次历史操作不作为新生成对齐方案或未来音色校准依据；最新指令之后不再读取、修复或生成历史成片。

## 验收

覆盖首句静音、后句起音、词尾和句间空隙；断流/无时间戳/越界不得估算成功；API 与 Worker 对相同帧范围生成相同字幕。播放器覆盖加载失败、暂停继续、跳转、切换工程、后段槽位及窄屏。以实际音频输出时钟核对字幕，目标不超过一帧的播放器调度偏差；语音模型精度单独报告，不把结构测试当作听感验收。

## 当前验证记录

- Worker 全量：334 项通过；`mypy src`：17 个源文件通过。不同资源/音色、快慢语速、头尾静音和句间停顿使用模拟供应商响应验证来源及帧坐标，不是付费听感测试。
- API 包装及成片输出相关 5 个测试文件最终复跑：246 项通过，包含原子上传时间戳防改写。API、Web、Contracts 类型检查通过，API 构建通过，`git diff --check` 通过。
- Web 时钟、音频接线和播放时钟相关 19 项通过。此前完整 Web 套件 494 项中 484 通过、10 项失败，失败为布局/进度/导入的源码字符串断言，未将全量套件描述为通过。数据库集成套件未执行。
- 前端实际播放检查在最新范围收窄前完成：字幕按音频输出时钟出现，采样检查未发现提前，观察到的显示差不超过 34 ms；不能据此声称所有真实音色都已完成听感验收。
- 不引入强制对齐模型作为生产依赖，不增加模型生成费用，不通过自动重试掩盖时间戳缺失。
- 本地部署前只读检查包装、智能填充、输出活动 Run 均为 0；重建并更新包装 Worker。容器四个核心模块的 SHA256 与本地源码一致。未发起任何生成任务。

供应商字段依据：[火山语音 HTTP Chunked SSE 单向流式 V3 文档](https://docs.volcengine.com/docs/DoubaoVoice/HTTPChunkedSSEUnidirectionalStreaming-V3?lang=zh)。生产保证边界是使用同次音频真实返回的时间戳且机械校验通过；供应商自身音素标注误差不能用本地结构测试宣称为零。
