# 混剪局部更新单一入口

## 范围

- 效果类模板混剪精修工作台，将新增素材追加和已有工程来源替换/删除合并为一个黄色“局部更新”按钮、一条同名进度条；不显示数量、阶段或工作流链接。
- 仅用户点击后执行。混合变化先执行现有来源更新，成功并重读草稿后继续现有 APPEND，追加成片及既有自动包装规则保持不变。
- 项目、Run、模板切换及第一阶段失败时不得继续追加；运行中防重复点击。刷新仍恢复既有服务端任务，不自动创建追加任务。

## 边界及验收

- 不改变全部重新智能填充、包装前置校验、六槽位与真实来源 revision 规则；不新增接口、契约、数据库迁移或 Worker 流程。
- 验证纯新增、仅编辑/删除、混合变化、失败、用户取消确认及切换作用域；所有状态最多一个入口和一条局部更新进度。
- 执行前端相关单测、类型检查、构建、差异检查与关键宽度浏览器回归。不以真实付费任务作 UI 验证。

## 验证结果

- 单一入口、进度、来源更新与项目操作四组测试 45 项通过；类型检查、生产构建及本次差异检查通过。
- 混剪全目录 266 项测试中 252 项通过、14 项失败；剩余失败集中在既有布局、分支交互及包装文案静态断言，不将全套结果记录为通过。与本次入口合并相关的旧断言已同步。
- 浏览器使用真实测试3的“新增两条素材 + 四条成片待更新”状态核验，1920、1440、1024 宽度均仅有一个黄色按钮，名称固定为“局部更新”。确认弹窗包含删除及追加说明，取消后无进度条。
- 开始/运行/成功/失败的单进度选择及删除路径通过 scoped API doubles 验证，未对真实素材执行删除或付费生成；检查所有任务队列及运行计数均为零。
