# 混剪局部更新一次执行与失败衔接修复

## 证据与边界

效果类模板混剪，直接消费同谱系已确认 render-batch/render-clip 与模板草稿；已有工程更新及 APPEND 复用 FROZEN_RENDER_V1 同一次确认。成功原位提交 mix-template、timeline-project 及所需包装，下游成片文件不自动编码。不得把执行中新增的编辑混入已经冻结的操作。

只读检查“广式腊肠 / 测试1”：来源更新已完成，随后 APPEND 失败，两条新增未采用。Worker 下载视频途中 RemoteProtocolError 未经转换，被当作永久内容错误；前端在阶段交接提前释放进度，旧失败追加还会阻挡下一次确认。这不是按两轮编辑依次排队。

## 修复

- 一次点击按服务端当前净差异冻结所有替换、删除、新增。已有工程成功后自动接续冻结 APPEND；统一进度不中断、不在前半程显示全部完成。等待保存、结果安装和追加创建期间保持操作状态，失败明确区分已有成功与未完成新增。
- 新一轮明确确认可替代已失败/取消的 APPEND 操作，重新冻结最新净差异；只处理尚未采用的内容。保留活动任务互斥、未开始的冻结衔接及幂等保护，不自动重试永久失败或付费追赶。
- 素材下载断连/超时/5xx 在同一下载内有界重试，丢弃半段数据，每次仍携带项目与 attempt token；超过预算转换为可重试 ApiError。404/租约拒绝/大小异常不重试，不启动新模型任务。
- 不新增表、契约状态或任务队列，不修改兄弟模板，不改已成功基准及历史文件。旧失败记录不自动改写；由用户主动再次确认。

## 验证

API 覆盖失败/取消后新确认、活动追加互斥、冻结幂等及两轮来源净差异；Web 覆盖一次确认连续衔接、保存暂时失败重连、统一进度、作用域切换与无差异；Worker 覆盖半段断流恢复、耗尽重试、不可重试状态和大小限制。执行相关测试、类型检查、构建及 diff 检查。默认不执行真实付费重试、不部署或重启 Worker、不自动提交。
