# 效果类视频配置归属调整实施方案

状态：已完成

## 目标

- 资料导入只维护商品资料，AI 信息提炼只维护可信营销事实。
- Prompt 生成维护数量、片段时长、视觉风格基调、投放渠道和禁用元素；默认由 AI 根据场景选择风格。
- 视频渲染维护画幅、分辨率与模型能力配置。
- 配置修改只影响真正消费该配置的节点，不再因为视频配置变化重新执行信息提炼。

## 实施边界

- 扩展现有 Contracts、WorkflowNodeState 和异步任务快照，不新增 Prisma 表或 Docker 容器。
- 旧导入配置、旧提炼结果与旧 Prompt `renderProfile` 仅用于历史读取兼容，不再作为新任务权威数据。
- 共用提示词仍为内部批次级编译结果，用户只维护禁用元素，不再编辑重复的共用提示词正文。

## 验收

- 导入和提炼页面不再出现全局视频配置。
- Prompt 页面能够保存并恢复视觉风格基调、投放渠道和禁用元素。
- 渲染页面能够独立保存画幅、分辨率和模型能力设置。
- Prompt Worker 与渲染请求编译器只读取各自节点的权威设置。
- 自动测试、类型检查、构建、浏览器回归和 `git diff --check` 均通过后，将本文状态更新为“已完成”并记录真实结果。

## 实施结果

- 资料导入与信息提炼页面已移除全局视频配置入口；资料确认只提交 `source-package:{productId}`，旧配置字段仅保留读取兼容。
- Prompt 批次设置已集中为总数量、片段时长、投放渠道、视觉风格基调和禁用元素；视觉风格默认显示“AI 根据场景选择”。
- 禁用元素由系统编译为唯一批次共用提示词；修改禁用元素会更新节点草稿但不会覆盖已提交的 Prompt 工作副本。
- 视频渲染节点已增加独立的模型能力、画幅和分辨率设置，Seedance 请求编译只读取该设置和已提交 Prompt。
- 浏览器实测覆盖导入、提炼、Prompt 和渲染页面：导入与提炼无视频配置入口，Prompt 默认风格与禁用元素可见，渲染设置可保存并从 API 恢复。
- 联调环境首次进入渲染页出现 500，定位为仓库已有的 `20260903120000_create_effect_segment_render` 迁移未在本地应用；执行现有迁移后页面与设置接口恢复正常，本次未新增迁移。
- Contracts 24 项、API 267 项、Web 171 项、Prompt Worker 174 项和提炼 Worker 105 项测试通过；TypeScript、两个 Worker mypy、ESLint 与生产构建通过。Prompt Worker 环境未安装 Ruff，因此未执行 Ruff。
