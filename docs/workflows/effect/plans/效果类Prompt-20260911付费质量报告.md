## 第三轮卖点缺失追踪与重构建议

按最终缺失列表逐项核对全部66个候选及66份AI评估，不把择优未选中数当作硬淘汰数。

|卖点（简述）|方向/候选链路|判断|
|---|---|---|

这5项在全候选池中都没有被AI记为完整实现，所以本轮不是MMR把已覆盖候选全部丢掉。第一项存在实际表达与绑定统计之间的盲点，需与其余真实遗漏区分。

### 已确认的结构原因

1. **先分空间槽位，再容纳事实。** 漏项所在空间分别出现2个方向槽位容纳3种动作、3个槽位容纳4或5种动作；多个独立使用事件被压到固定方向容量中。可以自然合拍的事实并不要求一对一方向，但当前缺口没有在规划阶段修复，后面仍扩写已有方向。
2. **覆盖补充沿用旧方向。** COVERAGE只在现有方向里挑选已经引用缺失事实的方向，不为从未进入任何方向的事实创建新观看事件。本轮只有鸡翅符合条件，于是补充继续围绕刷酱；若所有缺项都不在方向里，分配器回退到现有全部方向，更不能保证补到缺项。
3. **计划来源被误用成识别范围。** 评估请求只提供本组候选声明/分配的事实；Worker还只接受单条声明与上下文列表中的证据。正文自然实现了另一条已确认卖点，也可能无法建立绑定。这是来源范围设计问题，不是要求Worker做语义推断。
4. **事实不重复不等于观看事件不重复。** 炸物、蔬菜、肉片是不同使用事实，但多条都拍“蘸入—提起—停留”；光泽、稠度、果粒、叶片也常被压成“舀起—悬停—滴落”。本轮人工确认这些实质近似簇，不只是阈值造成的数字偏高。
5. **修订局部没有同步整条。** 本轮仍有镜头/动作被修正但概览、场景或终态保留旧说法，说明单纯增加指令文字未解决一致性。

### 建议的重构方向（尚未实施）

在当前八阶段与提交边界内，把创意生成内部从“空间配额→方向→多个变体”改为“卖点表达清单→AI规划不同观看事件→独立片段”，空间仅作AI归组或展示，不再是预先限制卖点进入的容器。

- AI为每条卖点提出可展示的局部结果/动作或明确的可信上下文用途。配方、工艺、风味等不能仅凭外观证明，不强求视频把所有句子证明完；也不重新建立核心/辅助事实角色池。
- 先保证可视卖点具有自然对应事件，再扩展备用候选。事件数由独立观看价值与总数量决定，不固定用20方向承载所有卖点。一个事件可自然关联多个事实，但不得为凑覆盖硬绑。
- AI检查不同条目是否只是替换食材、工具、背景或形容词；相同主动作也可保留真正不同的使用价值，不能把“同动作”直接等同于重复。
- 覆盖补充先由AI处理具体缺口：没有事件就规划新事件，拍错结果就修正事件起终态；不再向同一错误方向重复抽样。鸡翅可从已烤制完成的真实状态开始展示，不把腌制和烤熟强塞进15秒。
- 评估AI可参照本次全部确认事实及可视边界，区分计划使用、实际呈现和仅作上下文；数据量大时分批独立读取而非字符匹配。Worker只校验来源存在、结构、ID和报告一致性，不因事实未预分配就丢弃合法绑定。
- 同一物体初态、动作、镜头与终态由同份结构数据生成正文，AI修订后整体重新编译受影响内容；避免多个自由文本字段残留互相矛盾的指令。
- 择优保留已有数量优先与软MMR，不新增语义硬门禁。覆盖不足明确报告，不能通过删除事实、放宽证据等级或调整重复阈值粉饰结果。
