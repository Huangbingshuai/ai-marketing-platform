# 效果类视频渲染：素材导入、导出与删除闭环

## 范围

- 移除视频任务中没有真实算法支撑的“自动匹配模型”语义。
- 保留四款人工选择的视频模型，并统一 Web 与服务端的画幅、分辨率约束。
- 为当前最新渲染批次补齐外部视频导入、已完成素材删除和批量导出接口。
- 保持一条 Prompt 对应一个渲染任务/素材槽位，所有写操作校验项目、工作流运行、批次 revision 与幂等键。

## 非目标

- 不实现自动选模或模型路由算法。
- 不改变 Seedance Worker 的生成、轮询和回写协议。
- 不允许在尚未建立渲染批次时创建游离导入素材；导入必须绑定当前批次冻结的 Prompt 槽位。
- 不修改 Prompt、信息提炼或模板混剪节点的业务契约。

## 数据与接口

- `EffectSegmentRenderTask` 删除固定的 `modelMatch` 字段，新增明确的 `origin` 字段。
- 外部导入以 multipart 请求上传视频及 `taskId` 映射；同一操作中一个文件只能绑定一个任务，一个任务只能被一个文件替换。
- 删除将文件标记为孤立，并把任务重置为失败/待重新生成状态，不删除 Prompt 槽位。
- 导出按任务范围生成 ZIP，可包含视频、JSON 清单和异常 CSV；导出不修改批次 revision。
- 导入和删除增加批次 revision，使已提交素材池显示为草稿已变化；只有再次“完成校验”才提交新的 `render-clip:{taskId}` 与 `render-batch:{productId}` revision。

## 兼容与迁移

- 不增加数据库字段；已完成且没有供应商任务 ID 的片段按外部导入素材展示，当前真实 Seedance 成功任务始终保存供应商任务 ID。
- 内部兼容键 `SEEDANCE_1_5_PRO` 与 `SEEDANCE_1_0` 暂不重命名，仅移除面向业务的“自动匹配”声明。
- Seedance 2.5（兼容键 `SEEDANCE_1_5_PRO`）统一限制为 `480p`、`720p`。

## 验收

- 契约、API Service/Repository、Web 状态与交互测试覆盖导入、删除、导出、revision 冲突及项目隔离。
- Web 类型检查与构建通过；API 类型检查与构建通过；Contracts 测试通过。
- 浏览器验证无批次禁用导入、有批次导入匹配、选择删除、导出面板和主要响应式宽度。
- `git diff --check` 无错误。
