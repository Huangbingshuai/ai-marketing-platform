# 效果类 Prompt 单一当前工作流收敛实施方案

状态：已完成
日期：2026-08-31

## 1. 目标

Prompt 生成节点只保留“输入快照 → 提炼信息应用映射 → 事实视觉使用策略编译 → 共用提示词编译 → 连贯六维创意生成 → 创意评估与用途分类 → 精确数量择优与补充 → 结果保存”这一套固定工作流。

本轮不再保留任何按数字区分的 Prompt 代码版本：工作流拓扑、结果类型、Worker 模型、Prompt 模板、API 解析和前端适配均使用无版本后缀的权威名称；以后直接修改这套固定实现，不再新增并行版本分支。

## 2. 数据处理边界

- 历史 Run、Stage 和 Shard 行可以留在 PostgreSQL 作为不可见审计数据，但运行时代码不再根据其中的旧标识选择执行分支。
- 只有结构满足当前权威契约的 Prompt 结果可继续读取；旧结构不伪造用途分类或产品关联信息，统一显示为需要重新生成。
- 部署前终止仍在排队或运行中的旧结构任务，防止新 Worker 消费旧消息。
- 业务数据的 `WorkingArtifact.revision`、上游 revision、结果 revision 和内容哈希继续保留；它们表示内容变化，不是代码版本。

## 3. 跨层修改

- Contracts：删除工作流版本枚举、版本化节点/边集合、结果类型后缀、历史联合类型和 Prompt 专用结果结构版本字段，只导出一套节点、边、设置、条目与批次结果。
- API：删除版本推断、历史结果解析、设置迁移和按版本选择 Stage/Shard 的分支，只按照当前结构校验；结构不匹配的旧结果返回“需要重新生成”。
- Worker：删除图版本路由和旧执行路径，只构建当前固定图；模型、队列请求与完成结果使用无版本后缀的模型名。
- Web：删除所有版本展示与历史结果适配，直接消费当前契约。
- 视频渲染：删除旧 Prompt 结果编译分支，只消费已验证的当前 Prompt 条目。
- Prompt 模板：文件名改为职责名称；检查点使用模板内容哈希失效，不再维护人工数字版本常量。

## 4. 验收

- 新 Run 固定使用唯一拓扑，公开契约和页面不再包含工作流版本字段或数字版本文案。
- 代码中不再存在按 Prompt 工作流版本选择拓扑、解析器、结果类型或 Worker 路径的运行时判断。
- 旧结构 Run 不再成为工作区当前任务，也不能被 claim、恢复或查看节点详情。
- 当前批次结果列表、编辑、单条重生成、人工评估和 WorkingArtifact 提交语义保持不变。
- Contracts、API、Web、Worker定向测试与类型检查通过，浏览器验证工作流弹窗只显示当前工作流。

## 5. 保留项与非目标

- 不删除 `WorkingArtifact.revision`、结果 revision、上游 revision、attempt token 或内容哈希。
- 本次不物理删除旧数据库审计行，但旧结构数据不再进入当前业务读取和执行路径。
- 本次不修改当前工作流的模型提示词、MMR算法、视频渲染和混剪逻辑。

## 6. 实施与验收结果

- Contracts、API、Web 与 Worker 已统一为一套无数字后缀的 Prompt 契约、拓扑、模型和模板；页面不再接收或展示工作流版本字段。
- Worker 已删除旧关系规划、蓝图组合、六类分支和历史保存路径。清理过程中发现并修复了同名 `save_result` 覆盖当前保存实现的问题。
- API 不再推断或迁移旧 Prompt 结构；不符合当前契约的数据不会进入当前 Run、节点详情或结果编辑链路，只能重新生成。
- 业务 revision、输入指纹、内容哈希、尝试令牌与模板内容哈希保留，继续承担并发控制、失效判断和检查点复用职责。
- Worker：79 项通过，1 项按环境跳过；Ruff、mypy 与 Python 编译检查通过。
- Contracts：17 项测试、类型检查与构建通过。
- Web：151 项测试、类型检查与生产构建通过。
- API：221 项全量测试通过；Prompt 相关 60 项定向测试通过。API 全量类型检查与构建仍被信息提炼模块现有的 Prisma 枚举/客户端生成不一致阻断，本次修改未新增 Prompt 类型错误。
- 浏览器已验证本地应用壳可正常加载；当前本地环境未绑定项目/API，无法从真实项目数据打开工作流弹窗，弹窗结构由前端 151 项回归测试覆盖。
