# 混剪时间轴跨轨道框选与编组移动

## 范围

- 框选矩形覆盖时间轴任意可见轨道时，选择矩形实际命中的全部可编辑视频、音频和字幕素材，不再限制为起始轨道或单行。
- 保留素材类型各自的选择标识和编辑面板；拖动选中组时，所有选中素材共享同一水平时间偏移，保持各自轨道类型与相对时间关系。
- 锁定轨道中的素材不进入可移动选集；单类型选择原有的纵向换轨行为保持不变。混合类型编组以水平同步移动为主，不跨类型重排轨道。
- 混合组作为一次时间轴编辑记录，撤销时整体恢复。

## 非目标

- 不改变轨道锁定、素材碰撞解决、字幕重叠规则、素材来源或包装任务流程。
- 不合并视频、音频和字幕的数据模型，不新增持久化契约。

## 验收

- 框选跨越字幕、视频及多个音频行时，矩形命中的可编辑素材均显示选中；框外素材不选中。
- 从混合选集任一素材拖动，所有成员同步时间移动，轨道归属保持不变；一次撤销恢复整个组。
- 单轨道框选、单类型纵向换轨、锁轨和纯点击选择回归不变。
- 运行混剪时间轴布局测试、Web 类型检查和 `git diff --check`。
