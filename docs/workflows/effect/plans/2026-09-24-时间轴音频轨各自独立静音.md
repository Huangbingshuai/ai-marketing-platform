# 时间轴音轨：口播一条、纯音乐一条，各自独立静音

## 范围

- 把时间轴的单一 `AUDIO` 轨拆成多条音轨：口播（VOICE）、纯音乐（MUSIC）、分离原声（DETACHED）。
- 每条音轨各自持有表头、锁定、静音和区间分层；静音键互不影响。
- 三条音轨的**表头名字统一叫「音频」**，口播 / 纯音乐 / 原声只靠片段颜色区分——它们是同一类音频轨，不是三种不同类型的轨。
- 分离原声（DETACHED）轨**按需出现**：没分离过就不占位，真的分离出原声后才多出这一条。
- 播放器按轨静音：口播元素跟口播轨，纯音乐元素跟纯音乐轨，分离原声跟原声轨。
- 字幕轨与主视频轨保持现状（字幕：锁定 + 显隐；主视频：锁定 + 显隐 + 静音）。

## 现状问题

- 时间轴把口播、纯音乐和分离原声放进同一个 `AUDIO` 轨，再靠区间分层避让成多行；行是分开了，但整段共用一个表头、一个锁定和一个静音键，所以左边只有一个声音开关键，静音会一起静音。
- `EffectTemplateMixPackaging.vue` 用同一个 `audioMuted` 同时静音口播元素和纯音乐元素。
- 音乐素材的拖入判定挂在 `trackLocked.AUDIO` 上，没有「落在哪条音轨」的概念。

## 设计

- `VisibleTrack` 扩为 `CAPTION | VIDEO | VOICE | MUSIC | DETACHED`；`TRACK_LABELS` 里三条音频轨都是 `'音频'`，表头顺序为 字幕、主视频、音频、音频、音频。
- `audioTracks` 是 computed：口播、纯音乐两条常驻；只有 `timelineAudios` 里出现 `DETACHED` 片段时才把原声轨追加进来。没分离过原声的工程不会凭空多出一个空轨。
- 片段按 `TimelineAudio.kind` 归属：`VOICE` → 口播轨，`MUSIC` → 纯音乐轨，`DETACHED` → 原声轨。`detachedAudios` 里带 `sourceAssetId` 的导入音乐本身就是 `MUSIC`，因此归纯音乐轨；`sourceSlotId` 的分离原声归原声轨。
- 片段颜色保留区分：`voice-clip` / `bgm-clip` / `detached-audio-clip`，这是三条音频轨唯一的视觉差异。
- 每条音轨独立做区间分层与轨高计算；口播、纯音乐常驻轨保留一行高度，避免拖动或删除后轨道跳位。
- 时间轴新增 `voiceMuted / musicMuted / detachedMuted` 三个 prop，`toggleAudioMute` 改为按轨上报（`'VIDEO' | 'VOICE' | 'MUSIC' | 'DETACHED'`）；工作台持有三份静音状态并分别驱动播放器。
- 音乐素材拖入只落在纯音乐轨：拖放处理只绑定在纯音乐轨行上，`acceptsMusicAssetDrag` 改判 `trackLocked.MUSIC`。
- 框选、锁定、移动、裁剪、调音量、右键粘贴都按片段所属音轨判定，不再用统一的 `trackLocked.AUDIO`。

## 非目标

- 不改包装 Worker 的配音、音乐生成方式和成片输出契约。
- 不改字幕轨、主视频轨的表头与开关，也不新增手动增删轨道的交互。
- 不改成片播放器的 `forcePlayback` 手势起播（`EffectTemplateMixPackaging.vue` 现有的 `syncAudio(true)` 语义保持不变）。

## 验收

- 左侧表头为 字幕 / 主视频 / 音频 / 音频（原声轨分离后才出现）；每条音频轨各带一个独立静音键。
- 表头名字不出现「口播」「纯音乐」「原声」字样，三者只靠片段颜色区分。
- 没做过分离原声的工程，时间轴上看不到第三条音频轨。
- 口播、纯音乐、原声片段各自只出现在本轨；同轨内重叠加行，不跨轨。
- 静音某条音轨只影响该轨，其他音轨照常出声。
- 锁定某条音轨只约束本轨的移动、裁剪、调音量和框选。
- 相关前端单测与类型检查通过。
