## 实施

- 参考 Prompt 节点“结构化字段 → 机械编译正文”的方法，不跨工作流导入内部模块。
- 模型返回概览五字段、按观察顺序的阶段起点和镜头描述、结束画面及既有用途/创意/六维；不生成正文格式或独立的区间结束时间。
- 首阶段从 0 开始，下一阶段起点就是前段终点，最后终点取冻结时长的 0.1 秒展示值。重复或四舍五入后同起点的极短阶段合并，保留描述；非法倒序、越界和缺字段继续失败，不虚构语义和时间。
- 正文固定三标题及标签，继续校验现有输出契约。每次显式识别仍仅一次付费请求，内部回调幂等重试不变。
- 模型内部 schema 不跨进程；对 API/Web 的 `VideoImportDescription` 回调不变，无数据库迁移，无历史数据改写。
