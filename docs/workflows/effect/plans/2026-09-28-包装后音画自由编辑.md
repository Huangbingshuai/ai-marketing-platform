# 包装后音画自由编辑与字幕重叠修复

## 背景

智能成片包装确认后，时间轴应允许用户独立调整画面与音频，行为与常见剪辑软件一致。当前包装有效性哈希将视频片段的轨道/时间摆放也视为包装来源变化，导致拖动视频后口播编辑被锁定；API 对生成字幕的单行重叠校验又与前端自动分配字幕显示行的规则不一致，移动口播时可能保存失败。

## 范围

- 画面时间轴发生摆放或纯画面剪辑变化（片段起点、轨道、排列、转场）时，保留包装口播、纯音乐和字幕的绝对时间与可编辑状态。
- 素材绑定、素材 revision、源截取偏移、片段时长等包装内容来源变化仍令包装过期，不能静默复用旧包装。
- 口播移动时字幕仍按既有行为随口播移动；发生时间重叠时，与编辑器一致地分配显示行，不因隐式字幕行冲突而拒绝保存。
- API 校验和最终渲染采用相同字幕分行规则；显式字幕轨道内的重叠仍拒绝，防止用户指定同一行却发生覆盖。
- 增加哈希兼容、音频编辑、字幕重叠和渲染输出回归测试。

## 非目标

- 不自动移动口播/音乐/字幕来追随视频片段。
- 不允许素材换绑或裁切变化后继续把旧口播当作有效包装。
- 不改变工作流节点、包装任务提交边界、音频来源文件或最终成片的其他输出规则。

## 数据与契约

- 继续使用既有包装快照、`sourceTimelineHash` 与 WorkingArtifact 依赖，不新增并行状态。
- 包装有效性指纹忽略画面起点与轨道，仅比较包装依赖的画面内容/素材/裁切/时长；读取旧指纹时用冻结快照识别兼容版本。
- 自动生成字幕的隐式行允许重叠，由确定性区间分配器分层；显式 `trackId` 仍表示固定同一行。

## 验收

1. 完成包装后上下移动/横向拖动视频片段，口播时间不变且口播可继续拖动、裁切和调音量。
2. 更换素材、改变源截取或片段时长后，包装仍按现有规则标记过期/禁止复用。
3. 移动口播使字幕与另一条自动字幕重叠，API 保存成功，导出的字幕按不同垂直行显示；同一显式字幕轨道内重叠仍被拒绝。
4. 执行相关 API 单测、Worker 单测/语法检查、Web 类型检查及 `git diff --check`。
