# Prompt 重生成后台分支隔离（仅本地）

## 边界

整批重新生成不是人工编辑。复用既有隔离子 Run、输入快照、Outbox 和完成校验，但保持原 Run 活动及原 Prompt/素材/混剪/任务不变，不提前导航到内部批次草稿。首次无已确认结果仍沿用当前 Run。成功发布同一子分支，不再复制第二个分支；失败只留子任务诊断。

## 实施

- 创建 BATCH 子 Run 使用现有 keepParentActive；creationKey 按原商品和请求幂等键隔离。原 Run 产品行锁下检查尚在执行的同源子任务，防止不同幂等键重复计费。
- 工作区只把后台任务状态投影到原商品进度，结果、revision、设置和重复度继续读原 Run；刷新恢复通过精确父子关系和 creationKey 查询，后台在途时绕过只读缓存。
- 前端接单即按返回 taskId 轮询，不触发 branchActivated，不进入编辑。终态成功经服务端校验发布后才刷新版本树；仅原父 Run 仍为活动且非人工编辑时可激活新分支，用户已切走不抢占。
- 不改服务器部署，不改渲染/混剪在途任务、不改旧付费测试的冻结快照。
- 任务子分支显式保存本次冻结设置，避免 Prompt 来源祖先与当前设置来源不同导致漏复制。历史未发布 BATCH 子分支仅在设置节点确实缺失、冻结设置哈希一致且正常上游校验通过时补建自己的设置节点；不覆盖已有节点、不改父节点、不重做模型请求。

## 验证

真实数据库回滚事务覆盖父活动指针/原内容不变、重复启动拒绝、后台读取恢复、同一子分支发布、用户切走不抢占；无队列提交或模型费用。前端测试接单不切分支与恢复轮询。API/Web 单测、类型检查、构建及 diff 检查。实际浏览器检查本地已完成批次；不再发起第二轮付费任务。
