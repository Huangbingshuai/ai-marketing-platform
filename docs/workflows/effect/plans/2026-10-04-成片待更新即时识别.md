# 成片待更新即时识别

## 范围与边界

加快效果类混剪工程保存后，成片卡片及顶部画布的待更新提示。草稿仍自动保存，不增加已确认 revision，不自动覆盖成片、创建分支或启动渲染。差异继续由 API 按当前模板路径、实际依赖与工程内容计算。

## 实施

- 草稿/包装音画保存成功立即通知当前页面和其他页面读取权威差异，不等待未导出队列同步完成。队列真的更新后再次通知。
- 提示订阅按项目及 Run 隔离，页面卸载清理；轮询保留为外部变化及丢失事件的兜底。
- 成片差异只读取已有工作副本、混剪草稿与素材来源，不重复构建包含 AI 任务、锁定及分类历史的完整工作台。
- 每条模板路径只投影归属它的模板；谱系解析仍先读取完整目录，保留旧分支的模板推断规则。素材使用已有工作副本 Service 的文件来源转换，不把数据库记录直接当作 Web DTO。
- 已有非待渲染批次的单模板同步直接结束，保持已导出文件不被自动改写。

## 接口与迁移

第一阶段无公开契约、数据库或 Worker 变更。新增的是混剪 Service 的轻量内部只读投影和浏览器作用域刷新通知；不建立另一份业务状态。

## 第二阶段：保存与继承查询降耗

用户反馈仍慢后，实测当前项目成片列表读取约 1.7 秒，单次需要 108 次数据库调用。不能仅靠提高轮询频率改善，否则会加重读取负载。

- 工作副本继承改为一次读取本项目分支元数据、一次读取祖先产物身份、一次加载有效继承产物。保持最近键覆盖、每级模板 fork 隔离、项目与工作流边界及稳定排序；不读取被覆盖产物的大 payload，不设置跨请求缓存。深分支与循环引用仍有限终止。
- 多模板成片列表在一次请求内共用原始分支与成片目录，只加载各模板路径祖先的并集。每条路径独立应用原有最近批次与旧 fork 模板推断规则，不使用画布中已折叠的父子关系替代真实继承关系。
- 草稿保存请求新增可选 `compactResponse: boolean`，省略仍返回原完整工作台响应；显式为 true 时仅返回共享契约 `SaveEffectTemplateMixData { draftRevision }`。权限、来源、锁定、手动归槽及 revision 校验全部执行，保存成功后不再加载分类/任务历史与构建素材工作台。
- Web 时间轴自动保存使用精简响应，150 毫秒合并短时连续操作，仍串行保存并传递上次 revision。模板删除等需要完整响应的调用不变。
- 保存通知优先读取成片差异；素材工作台/树的预览信息在成片读取后刷新，不并行争抢资源。草稿通知不重读全部工作副本，确认产物变化仍由既有轮询、页面初始化与作用域切换检查覆盖。
- 不迁移数据库，不修改 Worker 输入或任务行为。补测深层继承与循环、跨域祖先、共享目录的兄弟路径隔离、精简响应的来源校验、HTTP boolean 校验及旧请求兼容；浏览器通过可撤销时间轴编辑测量提示耗时，恢复原工程。

## 验收

覆盖保存通知立即读取、不等待轮询、跨作用域拒绝、卸载清理、旧请求拒绝、轻量读取与完整读取的差异一致，以及仅实际修改条目待更新。运行 Web/API 相关单测、类型检查、构建及 diff 检查，并浏览器回归提示与局部更新入口，不启动付费任务。

## 验证记录

- API 成片/混剪 Service：138 项通过。
- Web/API 类型检查、构建及 `git diff --check` 通过；Web 构建保留现有大 chunk 提醒。
- Web 画布 freshness 与成片布局：23 项通过；混剪同步相关定向用例：4 项通过。
- 完整混剪布局套件：43 项通过，6 条现有包装面板/时间轴源码断言失败；本次未调整那些组件行为或放宽断言。
- 成片数据库集成用例因未启用集成环境被跳过，不计为通过。
- 浏览器测试7：初始仅成片02待更新；在成片01做可撤销编辑后，本页画布与另一个页面的成片01卡片、侧栏、批量局部更新按钮自动显示2条；撤销并保存后恢复只提示成片02。未启动包装、导出或局部渲染，原文件保留。提示依赖保存及权威差异读取完成，不承诺固定毫秒数。
- 证据：[跨页面提示](../evidence/browser/2026-10-04-output-freshness/changed-film.png)。

### 第二阶段实测与回归

- 同一真实项目、同一模板目录：优化前成片列表 HTTP 200，三次读取为 1740 / 1727 / 1751 毫秒；最终版本为 636 / 978 / 573 / 557 毫秒。不是缓存命中或错误响应，返回大小保持 15233 字符。
- 只读 Service 剖析：108 次数据库 delegate 调用降到 36 次；成片目录由 6 次读取降为 1 次。测试环境耗时会随资源竞争变化，不能把接口耗时当作用户编辑到提示的总耗时。
- API 工作副本 Repository/Service、成片/混剪 Service、保存 DTO：195 项通过。Web freshness、成片布局/状态与保存请求：30 项通过；混剪同步定向用例 4 项通过。Contracts 65 项、Worker API/Consumer 16 项通过。
- API/Web/Contracts 类型检查通过，API/Web 构建通过（Web 仍有既有大 chunk 提醒）；diff 检查通过。第一阶段记录的完整布局套件失败与数据库集成跳过不改写成通过。
- 双页面浏览器实测：在成片01分离音频后，本页画布于 2319 毫秒出现2条待更新，另一页面的成片卡片/侧栏/局部更新入口于2338毫秒反映2条。撤销并保存后恢复只提示原有成片02；未触发包装、导出或局部渲染，原文件可下载。仍存在保存与权威差异计算的等待，不宣称毫秒级即时显示。
- 证据：[双页面优化验收](../evidence/browser/2026-10-04-output-freshness/optimized-two-tabs.png)、[还原后的原始工程](../evidence/browser/2026-10-04-output-freshness/optimized-restored.png)。
