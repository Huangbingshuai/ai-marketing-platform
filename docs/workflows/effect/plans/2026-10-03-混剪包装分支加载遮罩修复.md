# 混剪包装分支加载遮罩修复

## 范围与边界

修复效果类模板混剪工作台在智能成片包装期间错误显示全屏分支加载遮罩的问题。仍消费当前分支已提交的渲染素材和模板草稿，包装的冻结快照、工作副本提交和成片输出边界不变。

## 实施

- 分支加载状态只由当前项目、Run 的工作区读取请求持有；等待任务发布和通知父页面不再设置加载状态。
- 用紧凑提示替代整工作台半透明遮罩，等待发布期间仍保留播放器和真实进度。
- 新 Run 数据尚未安装时暂禁编辑和付费任务入口，并阻止旧工程写入新 Run；过期请求不得清除后续请求的状态或回写保存结果。
- 工作区读取设置可取消的 30 秒上限；取消、失败、超时均清理所属请求，展示可重试错误。重试只读取已有数据。

## 非目标与数据

不修改 API、Contracts、数据库、Worker、任务重试策略或历史成片，不创建付费任务，无数据迁移。

## 验证

单测覆盖同 Run 刷新、实际跨分支加载、旧请求、取消、超时及迟到结果；浏览器检查测试6既有结果、切换分支与响应式布局。执行 Web 类型检查、构建和差异检查。

## 验证记录

- 加载状态、工作台交接和包装进度测试：28 项通过；相关布局定向测试：3 项通过。
- Web 构建（含 vue-tsc 类型检查）通过；相关 Git 差异检查通过。
- 浏览器查看既有测试6，七个包装阶段均为 3/3 完成；播放器、字幕与音轨正常显示，无残留遮罩。检查 1920、1440、760 宽度，并恢复浏览器尺寸。
- 未创建、重试或重新付费生成任务。排队/发布等待和超时路径用单测及调用链检查验证，未发起新一轮真实包装来复现。
