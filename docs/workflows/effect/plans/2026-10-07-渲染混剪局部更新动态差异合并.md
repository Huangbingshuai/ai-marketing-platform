# 渲染到混剪局部更新：动态合并待更新差异

## 范围与边界

待更新是每个混剪工程实际采用的素材与同一渲染谱系最新已保存素材之间的净差异，不按编辑次数累计任务。只读取已确认 render-batch、render-clip、来源映射及工程绑定；不新增数据库表、变更队列或平行素材状态。未保存、取消编辑及其他项目/谱系不影响下游。

重新生成和返修只采用最新保存版本，不判断画面等价。同一来源多次修改只替换一次；修改后删除只删除；新增后修改追加最新版本；新增后删除且尚未采用则抵消。删除必须有明确的已保存删除记录，来源异常不能当成删除。

## 数据和接口

扩展共享 Contracts 的可选已采用素材快照及局部更新冻结协议，记录可靠来源、实际 revision、文件和指纹。工程绑定、更换、复制和裁剪同步维护快照；清空绑定同步删除快照。历史来源优先从已有依赖、包装及任务快照恢复，无法可靠恢复则保留结果并提示，不将最新版本伪装成历史基准。

复用现有素材读取、局部更新、APPEND、包装、轮询和工作副本接口。模板列表、工程、按钮、画布和分支树共用净差异口径；差异清零仅清除素材待更新，不清除模板配置或其他独立变化。

## 执行与回写

服务端在确认时读取最新已确认素材，冻结替换、删除和新增集合。净差异消失不创建任务或调用模型；影响范围/费用发生变化要求重新确认。已有工程更新和新增成片追加使用同一冻结来源，不在阶段切换时纳入新的编辑。

采用新协议的在途局部更新不要求渲染来源仍是最新；保留文件可用性、项目隔离、工程/模板/包装编辑、租约及 attempt token 校验。其他任务和旧协议保留原校验。

成功仅回写实际消费的冻结版本。每个成功工程独立推进基准，失败保留旧结果。随后重新计算与最新素材的差异；不自动取消、重启、付费追赶或最终渲染。删除保留空位和时长，替换复用模型选区及关联口播字幕更新，其他槽位和 BGM 不变。

## 兼容与非目标

字段可选、无数据库迁移、不物理删除历史文件、不改写旧分支、不回退 revision、不增加视频等价识别。不因提示抵消改写音画内容。已导出文件仍由用户主动按工程差异更新。

## 验收

- 连续返修只采用最终版本；多次新增合并；新增再删除无差异、任务或模型调用；修改再删除只清空对应引用。
- 混合新增/替换/删除、未使用素材、部分成功/失败重试、重复请求、确认期间变化和工程并发编辑。
- 执行期间再次替换/删除/新增，旧任务正常完成并回写冻结版本，随后准确展示剩余差异。
- 各处标签同步出现和清除，保留独立告警，其他项目、谱系及兄弟分支不串数据。
- Contracts、API、Web、Worker 测试、类型检查、构建、git diff --check；浏览器三种宽度回归。默认不启动付费模型任务。

## 实施记录（2026-10-07）

- 共享 `effectTemplateMixSourceChanges`、新增来源识别与净差异签名供工作台和分支状态复用，替换使用实际采用快照而非当前素材头。保存、复制及裁剪保留服务端认可的历史文件；同 ID 覆盖后仍能定位原文件。
- 新增可选 `bindingSources` 与 `FROZEN_RENDER_V1` 冻结上下文。冻结操作记录素材、商品事实、Prompt 依赖、追加集合和自动包装决定，既有工程刷新与后续 APPEND 使用同一来源；未新增表或执行迁移。
- 局部更新在服务端确认时重算净差异。抵消返回 `noChanges`，无任务；范围或自动包装费用类型变化要求再次确认。操作 ID 支持幂等恢复，页面恢复不重复发起追加。
- 新协议在途任务按冻结文件完成；回写采用冻结 revision、文件和指纹。保留工程、模板、包装、文件、租约和尝试令牌校验；其他任务仍执行原来源校验。
- 历史工程只从同模板成功任务快照及项目文件恢复旧来源，读取不写数据库。无法可靠恢复保留原结果，不把最新版本写成旧基准。
- 阶段衔接处保留同模板追加和包装并发保护。上游保存不被此保护阻止；旧操作完成后重新显示剩余净差异，不自动追赶。
