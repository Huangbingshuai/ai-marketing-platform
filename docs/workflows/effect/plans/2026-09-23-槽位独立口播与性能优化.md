# 智能成片包装：槽位独立口播与性能优化

## 范围与边界

在效果类模板混剪节点内实施用户确认方案。消费同项目、同工作流 Run 已确认的素材、Prompt、商品事实及精确 revision；生成包装草稿，不自动确认工作副本或启动最终输出。不新增容器、队列或服务。

每个槽位恰好一条独立口播，时长 3–15 秒，文案、真实配音和字幕均不得跨槽位。钩子和结尾短句，中间槽位依据自身画面和确认事实生成。真实配音超时仅允许同槽位缩句一次。重叠槽位拒绝包装。单槽位重做保留其它槽位和音乐。

## 数据、接口与迁移

- 检查点增加 `narrationLayoutVersion: SLOT_V1`、文案 `slotId`、按槽位视觉缓存与真实执行统计；快照携带新布局要求和重做槽位。
- 新生成使用必带 slotId 的 Worker 模型；共享读取契约允许无 slotId 的历史结果播放，旧布局不得确认输出。
- 创建接口增加可选 slotId，仅用于单成片 VOICE 重做；服务器校验归属、来源、边界和完整覆盖。
- 视觉缓存以素材内容哈希、截取、时长和画面规格为键，在同项目/Run 的当前包装检查点内复用；不跨项目共享事实、声音或文案。
- 不改变视觉 hash/revision 语义；视觉变更令包装过期。包装编辑不增加视觉 revision。第六步拒绝旧布局或失效结果。

## 性能实现

原素材直接抽代表帧，跳过整片代理转码和拼接。槽位结果逻辑独立，文案合并为一次结构化请求。最多四条成片全局补位调度，分片仅作进度和恢复单元；预处理最多两条，TTS 全局受控，音乐维持独立 QPS 限流和未知提交不重发。记录真实媒体处理、模型/配音请求、音乐等待、缓存命中，不承诺外部供应商固定耗时。

## 验收

契约/API/Worker/Web 覆盖 3/15 秒边界、缺失重复槽位、交叠、跨槽配音字幕、单槽位重做、旧布局输出拒绝、缓存命中失效、无分片屏障、恢复取消和音乐提交幂等。执行类型检查、相关测试、构建及差异检查。浏览器检查六段口播、旧版提示、边界变化提示、单槽位重做和真实统计。

真实付费回归使用广式腊肠「测试1」100 条；记录总耗时、P50/P95、缓存命中与供应商等待。保持失败/限流/中断原始统计，不将调试恢复混作纯性能数据，不自动点击完成进入输出。
