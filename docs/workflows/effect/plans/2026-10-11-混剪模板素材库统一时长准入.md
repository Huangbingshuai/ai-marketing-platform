# 混剪模板素材库统一时长准入

## 范围

效果类模板混剪消费已确认 `render-batch` / `render-clip` 的实际时长与 revision。本次只修正当前模板的只读素材库及新智能填充输入，不删除渲染素材、不修改已绑定工程、工作副本 revision 或其他模板，不启动付费任务。

## 实施

- 复用 Contracts 的 `effectTemplateMixMaterialFitsTemplate`：至少容纳一个当前模板槽位才进入可选素材库，不再只过滤外部导入；用途计数、搜索、分页均使用同一集合。
- 新普通填充和冻结局部追加也排除不能容纳任何槽位的素材，避免全素材覆盖要求错误包含短素材。保留真实来源错误及文件校验，不把异常当删除。
- 快照增加可选 `durationFilteredMaterials`，仅新协议启用全来源过滤；历史缺字段任务沿旧 `durationFilteredImports` 规则校验，不改变在途输入。
- 保留完整上游素材集合供历史时间轴解析；切换模板、改变槽位时长自动重算投影，不清除人工归槽或采用来源。

## 验收

- 六槽均6秒时，5秒 AI 和导入素材均不可见、不进新任务；6秒及更长素材保留。
- 混合4秒和6秒模板仍接受5秒素材；无效时长、不可用、已删除来源排除。
- 切换模板及修改时长恢复对应集合，原始素材、绑定及其他模板不变。
- Web/API/Contracts 定向测试、类型检查、构建、Worker 契约测试及 `git diff --check`；浏览器三种宽度验证可选库和计数。不开启模型任务，不自动提交。

## 实施验证（2026-10-11）

- 根因：Web 素材卡片投影与 API 新填充输入只对 `EXTERNAL_IMPORT` 应用时长准入，遗漏 AI 生成素材；已统一所有来源，新增可选快照标记，保留历史任务完成校验。
- Web 定向31项通过，扩展局部更新／归槽回归57项通过；API 混剪473项通过、4项跳过；Contracts185项通过；Worker消费者／追加契约25项通过、mypy通过。Web/API类型检查及生产构建通过，`git diff --check`通过。没有宣称此前未通过的 Web 全量测试已经修好。
- 实际广式腊肠测试1六槽均6秒、总36秒，待归槽由34变33；1920、1440、900宽度搜索R-035均无结果。新测试2为4秒槽位、总24秒，R-035正常可见，验证模板隔离；未修改模板时长、归槽、渲染素材或创建模型任务。
