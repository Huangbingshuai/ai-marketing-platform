# 效果类 Prompt：语义簇源头去同质化修复计划

状态：已完成

## 目标

在不增加硬门禁、不改变 50 条精确数量和 `70% 质量 + 30% 多样性`择优口径的前提下，降低最终 Prompt 的语义近似重复度。真实验收使用当前已提交营销洞察、50 条、5 秒配置，并与 2026-09-02 的 54.0% 基线按同一 82% 向量相似标准比较。

## 边界

- 所属工作流：效果类 `Prompt 生成`节点。
- 直接上游：已确认营销洞察 WorkingArtifact 与全局视频配置的具体 revision。
- 编辑状态：真实生成只保存 Prompt 节点领域草稿和 `WorkflowNodeState`。
- 提交边界：仅用户点击“完成校验”时提交 `prompt-batch:{productId}`；本次付费测试不点击完成校验。
- 下游：视频渲染继续消费已提交 Prompt 批次，本次草稿测试不使其待更新。
- 不修改公共结果契约、HTTP 路径、Prisma Schema 和八阶段工作流拓扑。

## 实现方案

1. 初始 70 条候选仍按 AI 规划的产品创意方向均衡分配。Worker 只按方向稳定 ID 对任务分组，同一方向的兄弟任务交给同一次模型调用，使模型能在生成前整体安排实质不同的叙事、场景、人物、产品动作、镜头或情绪实现；Worker 不解释这些语义。
2. 生成 Prompt 明确要求同方向兄弟任务不能只换措辞，必须围绕其两个优先变化维度形成可见差异。事实边界、食品逻辑和单场景动作弧优先级不变。
3. 最终择优仍采用 `70% 单条质量 + 30% 相对新颖度`，新颖度内部仍为正文向量与 AI 六轴语义簇组合，不新增字符匹配或关键词规则。
4. 如果精确数量已经满足但 82% 阈值下的近似重复仍超过 15% 参考线，只执行一次软性多样性补充，最多补充目标数量的 20%。补充任务接收高风险候选的模型签名和 AI 分类出的拥挤场景/动作族，重新参与同一 AI 评分与 MMR 排序；相似内容不会被硬淘汰。
5. 数量补充、事实覆盖补充和多样性补充共享现有最多两轮恢复窗口；优先级依次为数量、事实覆盖、多样性。任何情况下不得保存短批次。

## 验收

- 自动测试覆盖同方向任务分组、兄弟变体提示、只触发一次多样性补充、重试恢复、精确数量及不新增语义 Worker 判断。
- 执行 Worker pytest、mypy、Ruff、API 相关测试、API 构建和 `git diff --check`。
- 通过正式浏览器执行真实 Ark 批次，验证 50/50、分页、工作流详情、控制台和最终重复度。
- 记录初始候选重复度、最终重复度、完全重复数、补充数量、硬问题数量和质量均分。
- 重复度没有下降时如实标记未达标，继续定位明确实现问题，不通过提高相似阈值伪造改善。

## 实际实施与测试结果

完成时间：2026-09-02。

实现结果：

- 初始 70 条候选按创意方向稳定 ID 组成同方向兄弟分片，模型在同一次调用中协调兄弟变体；Worker 只负责稳定分组，不解释场景、动作或商品语义。
- 候选 Prompt 模板增加兄弟变体协同要求，优先围绕方向指定的两个变化维度形成可见差异，禁止仅替换形容词、人物性别、镜头名称或同义词。
- 接通原有但未进入主流程的软性多样性补充：精确数量已满足但语义近似仍偏高时，最多补充目标数量的 20%，补充候选继续参加同一 AI 评估和 `70% 质量 + 30% 多样性` MMR，不增加相似度硬淘汰。

自动测试：

- `uv run pytest`：147 passed，1 skipped。
- `uv run mypy src`：通过。
- `uv run ruff check src tests`：通过。
- `git diff --check`：相关文件通过；仅存在仓库既有的 Windows 换行提示。

正式浏览器真实 Ark 验收：

- 当前商品：广式腊肠；目标 50 条；统一时长 5 秒。
- 初始候选 70 条，触发一次多样性补充 10 条，累计候选 80 条。
- 80 条候选全部通过评估，硬问题淘汰 0，完全重复淘汰 0，最终精确保存 50 条。
- 候选池语义重复度由旧基线 63.89% 降至 46.25%。
- 最终语义重复度由旧基线 54.0% 降至 14.0%，下降 40 个百分点，达到 `<15%` 参考线。
- 补充前高风险冗余 11 条，补充后 7 条。
- 必用事实覆盖 35/35，质量状态 `PASS`。
- 最终均分：产品相关性 94.14、创意连贯性 92.30、画面可执行性 91.00、商业素材价值 87.48、视觉表达清晰度 92.30。
- 正式页面验证 5 页 × 10 条，浏览器控制台无 warning/error。
- 本次只保存节点草稿，没有点击“完成校验”，没有覆盖已提交 Prompt WorkingArtifact。

真实测试还观察到部分 3 条一组的 AI 评估输出会达到 3000 Token 上限。现有流程会自动拆成更小批次重新评估，没有丢失候选、没有影响数量和结果正确性；该现象属于后续可单独治理的耗时与费用优化项，不作为本次去同质化结果的规避条件。
