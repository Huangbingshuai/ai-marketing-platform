# 分支树待更新颜色按查看路径隔离

## 范围与原因

工作台模板浏览与项目全局活动 Run 独立，树只接收模板 ID 时可能标红全局活动的旧兄弟版本。本次修正前端路径与样式，不改变工作副本 revision、freshness、模型任务或工程内容；无需数据迁移。

## 实现

- 工作台暴露正在查看的 Run，由父页面打开树时与模板 ID 一起传入布局。
- 精修树优先使用该工程 Run 标记节点和连线；配置树仍展示所有模板各自的当前路径。没有合法查看目标时兼容原有活动路径。
- 用户进一步明确选中的待更新节点需要明显红黄融合，未选中仍纯黄色。选中使用3px单层渐变边框，深红#dc2626保持至40%再过渡黄色#e0c200，底色从#ffe1e1过渡#fff9c2，标题深红#b91c1c；不叠加外圈。未选中保留1px纯黄色细边、深黄色文字和黄色系阴影。未待更新节点的当前红色路径保持不变。
- 用户截图确认旧配色实际仍是橙色边框（#f59e0b）和棕红标题（#b45309），本次改为正黄色边框及图例#e0c200、深黄色文字#8a7600、纯黄色系底色和阴影；深黄色保持小字可读性，不再使用橙棕色。
