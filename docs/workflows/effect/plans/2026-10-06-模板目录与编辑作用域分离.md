# 模板目录与编辑作用域分离

## 范围与非目标

恢复效果类混剪模板列表：展示当前渲染/手动复制谱系下全部模板各自的当前工作流。点击模板只选择编辑作用域，不调用全局活动分支切换。版本树中的显式切换及填充、包装成功后的原有版本交互不变；不合并或复制兄弟分支草稿，不修改历史数据，不触发付费任务。

## 数据与实现

复用 `effectTemplateBranchTips` 与现有分支树、混剪工作区 API。目录是只读投影：按模板实际路径读取名称、工程数量、素材差异。页面保留一个可写工作区及其 revision，选中模板时加载对应 Run；保存、素材刷新、包装和局部更新沿该作用域执行。父页面传入的项目活动 Run 与页面当前编辑 Run 分开，父作用域变化时取消旧请求并重载。目录条目不得进入另一 Run 的草稿序列化。

## 迁移与验证

不变更契约、数据库或 Worker。测试三个模板分属不同 Run、目录不缩减、同 Run 新模板、历史选择、跨项目/复制谱系隔离、切换前保存及读取竞争、失败保留原工作区。运行相关单测、Web 类型检查/构建和 diff 检查；正式浏览器检查全部模板、逐个选择与返回、黄蓝边框及宽度，不启动生成/更新任务。

## 验收记录

已移除模板选择的全局分支激活及“正在同步新分支”提示，复用目录已读取的工作区即时切换。普通选择、局部更新和进入工作台共用同一编辑作用域；目录待更新状态复用画布状态入口，不被单个 Run 的轮询覆盖。已在正式页面验证测试1、测试2、测试3持续显示并正常选择，1920 与 1440 宽度保持黄蓝叠加。测试不启动付费生成，也不保存或取消用户的渲染编辑草稿。
