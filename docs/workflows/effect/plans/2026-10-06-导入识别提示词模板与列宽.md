# 导入识别提示词模板与列宽

范围：效果类视频渲染节点外部素材导入。AI 识别正文对齐当前 Prompt 节点 `shot_plan.py` 的输出模板，视频列略加宽，列区域放不下时底部横向滚动。单列和空态仍保持紧凑，类型选项不换行、不增加自己的滚动条。

输入：现有导入草稿的真实视频、冻结时长、时间标记关键帧；只参考 Prompt 节点正文的结构和标签，不读取其内部模块、不复制规划任务或新增产品事实。输出仍是共享 `VideoImportDescription`，正文为“【视频概览】/【逐秒镜头】/【结束画面】”，概览包含目标、质感、场景、光线、首帧状态，镜头按实际视频阶段给出连续覆盖真实时长的时间段，明确镜头与结果，焦点/驱动按可见证据补充，不推测声音。创意方向及六维与原片保持同一事件。

Worker 仅机械校验格式、区间连续性和真实时长，不推断内容或修补语义；格式失败沿既有失败回调，保留用户旧字段，不自动追加付费重试。人工输入仍自由编辑，不强制此格式。不改接口、Schema、数据库、旧已识别结果、上游工作副本或下游算法；确认导入仍新增当前编辑草稿，保存修改才提交 render-clip/render-batch 并进入原混剪更新逻辑。

UI：单列弹窗 640px，多列默认约 420px、最小 400px，五列过宽时自动显示底部整体列横向滚动条，不能在类型选项上做局部滚动。空态仍为 560px。关闭保留与取消清空逻辑不变。

验证：Worker 隔离模型测试校验模板、6.04/30 秒区间、缺失标题、乱序、空内容、时长错误与一次付费调用上限；模板来源与当前 Prompt 输出一致。Web 单测、类型/构建、diff 与浏览器 1920/1440/768 的五列底部滚动、单行类型及关闭重开。默认不调用付费模型，运行 Worker 更新仅在没有活动任务时执行。

## 验收结果

- Worker 导入测试 35 条通过，包含格式、字段空缺、非整秒/30秒、单/多段、区间缺口/重叠、无自动付费重试；格式错误经既有失败回调返回，不应用不完整结果。修改文件及测试 mypy 通过。没有调用真实付费模型，模型质量不能用隔离响应测试冒充验收。
- Web 相关布局测试 21 条、类型检查和生产构建通过；格式与 diff 检查通过。保留原有包体积提醒。
- 浏览器 1920/1440/768 下最小视频列 400px，两组用途均一行且没有自身溢出；1920 五列区域 clientWidth 1835 / scrollWidth 2032，底部有整体横向滚动条。点击第五列右侧选项后实际 scrollLeft 发生变化；关闭重开仍保留五列和勾选状态，取消后重开零列。测试草稿全部取消，原有用户编辑会话不动、没有正式导入。
- 两次只读确认零活动任务后重建并更新原 Worker；容器运行正常、无异常重启，容器内 `video_import.py` SHA-256 与工作区一致。无需更新 API 或数据库，既有共享描述 Schema 未变。
