# 编辑进退与画布待更新投影

## 范围与非目标

修复效果类画布在上游进入编辑、取消编辑、保存修改及跨节点查看时丢失下游已有待更新状态。只改变只读展示投影，不自动更新成片、不改动 WorkingArtifact revision、不复制或覆盖兄弟分支工程，不变更 API、数据库、Worker。

## 数据与实现

复用分支树 API 的真实 freshness 与 `effectTemplateBranchTips`，画布在所有节点汇总同渲染谱系各模板当前路径的混剪及输出状态；不把历史兄弟版本的待更新叠加到当前已更新路径。上游状态继续读取实际来源头。隔离编辑使用正式父 Run 作为已确认状态的投影上下文，不使用没有下游产物的编辑草稿判定“全部就绪”。节点 Run 变化时终止旧请求，并从已读取的同项目版本树重新投影，随后重新读取服务端；真正换项目或独立谱系时隔离旧告警。当前模板和输出页的即时差异仍复用原展示入口，不因为离开节点而删除。

## 验收

单测覆盖：当前 Run 就绪而兄弟模板待更新、历史版本不计入、独立渲染/手动复制隔离、上游编辑进退、无内容变化保存、内容变化后告警重新计算、跨项目及迟到请求、读取失败不清告警、真实更新后取消告警、订阅与轮询释放。运行 Web 类型检查/构建、相关测试、diff 检查。正式浏览器验证渲染节点进入编辑后取消与无修改保存，检查混剪黄边持续存在以及各模板列表/版本树一致；不调用付费生成或局部更新任务。

## 验收记录

相关状态、目录、导航及局部更新测试 56 项通过；边框与入口布局定向测试 7 项通过（其余 53 项未选择）。Contracts 重新构建与 Web 类型检查/生产构建通过，diff 检查通过。

正式紫苏梅子酱项目验证：混剪列表保留三个模板，测试2/测试3待更新时进入渲染页仍显示混剪黄边；进入渲染编辑再取消，以及再次进入编辑后无修改保存，混剪黄边均保留。1920、1440、960 宽度均保持告警，刷新后仍恢复待更新且无控制台错误。未修改视频素材、未启动付费生成或局部更新。
