# 效果类危险操作统一确认弹窗实施方案

实施状态：已完成（2026-09-03）

## 目标

为正式前端中会删除业务内容或重新生成 AI 结果的入口增加一致的二次确认，降低误触风险；所有入口复用同一个全局确认组件，不再使用浏览器原生 `window.confirm`，也不再由业务页面分别维护删除弹窗样式和焦点逻辑。

## 范围

- 资料导入：单个/批量删除产品、删除资料、删除电商链接。
- AI 信息提炼：已有结果的重新提炼，以及信息卡中各字段条目的删除。
- Prompt 生成：已有批次的重新批量生成、删除单条 Prompt。
- 视频渲染：单条/批量重新生成、单条/批量删除。
- 项目资产：移除当前项目中的资产引用。

## 明确例外

- 单条 Prompt 重新生成已经通过“生成三个备选并人工采用”的专用弹窗完成二次决策，不叠加通用确认弹窗。
- 首次 AI 提炼、首次 Prompt 生成和首次视频批量渲染不是覆盖操作，不增加确认。
- 恢复最近删除内容、重新连接轮询、网络重试、关闭提示信息等非破坏性动作不增加确认。

## 交互与实现

- 在 `apps/web/src/shared/` 新增全局 Promise 式确认服务与唯一确认弹窗组件，并在应用根组件挂载一次。
- 弹窗支持危险/警告两种语气、业务化标题与后果说明、ESC/遮罩取消、默认聚焦确认按钮和关闭后的焦点恢复。
- 删除操作使用红色危险确认；重新生成使用橙色警告确认。
- 用户取消后不得发起 API、修改草稿或改变工作副本 revision。
- 本次只调整前端交互，不改变 API、Worker、WorkingArtifact、revision 或下游待更新规则。

## 验收

- 所有范围内入口均显示统一弹窗，确认后只执行一次原操作，取消后不执行。
- 正式前端不再包含 `window.confirm`。
- 单条 Prompt 重新生成只显示原有专用弹窗。
- 弹窗支持 ESC、遮罩取消、焦点恢复，窄屏不溢出。
- 执行确认服务单测、相关页面布局测试、Web 类型检查、生产构建与 `git diff --check`，并进行浏览器桌面/窄屏回归。

## 实施结果

- 已落地全局确认服务与唯一弹窗组件，资料导入、AI 信息提炼、Prompt 批次、视频渲染和项目资产入口统一复用。
- 已移除正式前端中的原生 `window.confirm`，并删除 Prompt、视频渲染页面原有的局部删除弹窗实现。
- 单条 Prompt 重新生成仍只打开原有“三个完整创意备选”专用弹窗，不叠加通用确认。
- 相关 Vitest 共 65 项通过；Web 类型检查、生产构建和定向 ESLint 通过。
- 浏览器桌面回归确认标题、后果说明、取消行为、ESC 与焦点行为正常；390 × 844 窄屏下弹窗宽 347.2px、无页面横向溢出，控制台无错误。
