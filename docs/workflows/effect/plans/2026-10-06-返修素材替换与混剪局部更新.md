# 返修素材替换与混剪局部更新

## 范围与边界

效果类视频渲染已确认素材 → 模板混剪 → 成片输出。素材库以当前分支已提交的渲染批次和片段工作副本为权威；旧片段仍供既有工程播放，不作为新选材。未采用、未保存的返修候选不进入素材库。

模板归槽仍是项目、Run、模板隔离的草稿。素材更新不静默改变工程绑定、包装音轨、确认 revision 或旧成片文件；用户主动局部更新后沿用原任务校验、工作副本提交及下游待更新机制。

## 实施

1. 当前素材识别优先当前 Run 的已确认批次，消除祖先批次/片段副本造成的旧新并列；按稳定渲染键或已确认 Prompt 来源识别替换，不按素材名字猜测。旧绑定仅保留播放别名。
2. 同一素材返修、重生成后，继承模板已有人工/AI归槽，包括人工退回待归槽；新素材上明确设置的分类优先。沿用草稿和分类池，不新增归槽数据库。
3. 时间轴视频片段依据共用来源差异函数显示待更新及黄色边框，不改变播放源。
4. 工作台顶部以局部更新按钮替代素材变化说明，一次处理当前模板全部受影响成片，复用成片输出的当前分支局部更新；更新进度、完成恢复及作用域清理复用既有任务状态。不创建整批重新导出分支。未导出工程与已导出工程须明确区分处理，不能假装导出任务已存在。
5. 右侧工具按钮和成片卡片随面板宽度切换单列/双列，名称、状态、删除按钮保留空间，卡片行高随内容增长，避免固定行高与强制不换行溢出。

## 非目标与迁移

不重新生成素材、不自动付费、不删除历史文件、不重做全模板包装、不重写冻结原型、不改固定节点。沿用当前接口/任务；如需契约扩展，保持可选及兼容。无数据库迁移，历史归槽通过读取边界兼容继承。

## 验收

- 返修同键新文件、重生成新键同来源、祖先批次别名、未保存候选、跨项目素材及无唯一替换候选。
- 素材库仅当前版本；人工/AI分类和待归槽继承，模板隔离，刷新保存不丢失。
- 工程仅变化槽位黄边待更新，旧工程仍可播放；一键局部更新所有受影响条目，完成后清除提示，未受影响内容和分支不变。
- 右侧面板窄/宽、1920/1440/窄屏与加载/空/错误/运行/完成状态。
- 执行 Contracts、API、Web、相关 Worker 回归、类型检查、构建和差异检查；浏览器检查实际页面，不发起未经授权的付费模型测试。

## 局部更新启动失败修正

- 原因：工作台在局部更新之前无条件调用普通草稿同步；返修后工程绑定 revision 仍是旧值，同步先校验旧引用并抛出“当前画面素材不可用”，实际来源更新任务尚未创建。
- 修正：已有当前模板批次直接执行局部更新，仅缺失批次时尝试确认工程同步。普通自动同步跳过有来源变化的工程，保留基线及待更新提示，由用户主动更新选择新截取、补齐相关音画。
- 回归：API 98 项通过；Web 调用链/API 9 项及相关布局 3 项通过；真实 PostgreSQL 已导出/未导出回滚回归 2 项通过。额外使用本地“测试1”真实草稿、素材及数据库执行事务回滚验证，全部 3 个受影响工程可排队，未受影响条目不变，不新建批次，不向 Worker 派发任务、不产生供应商费用。
- Web 构建（含类型检查）、API 类型检查与构建通过。本地 API 在无运行任务时更新；浏览器确认按钮数量、弹窗及取消恢复。没有以取消弹窗代替后端调用链验证，也没有声称实际付费生成已经完成。

## 局部更新工程锁定

- 排队、运行期间按任务参与的成片锁定画面、字幕和音频轨道，复用首次包装的锁图标与遮罩；其他成片可继续编辑。模板配置暂时锁定，完成、失败或取消后解除任务锁，不清除用户手动轨道锁。
- 草稿与包装音画保存须在事务中校验同项目、同 Run 的参与工程，拒绝修改或删除正在更新的工程，不锁整批重新导出的父分支。
- 沿用通用进度条，局部更新不显示工作流入口。验证参与/未参与成片切换、恢复任务、终态解锁、跨分支隔离与窄屏布局；不启动付费测试任务。
- 验收：Web 调用链及实际计算/轨道锁函数 7 项、通用进度条 3 项、相关 API 144 项通过；真实 PostgreSQL 已导出/未导出回滚测试 2 项通过，覆盖冻结工程及包装音画拒绝保存、未参与工程允许保存。Web/API/UI 类型检查与构建及差异检查通过。
- 浏览器使用正式轨道与进度组件的隔离运行态验证参与/未参与切换、不能手动解锁、完成后清除进度和保留手动轨道锁，1920/1440/1024 无溢出；正式工作台实际完成态恢复正常。未向供应商发起任务。临时验收页面已移除；截图位于 `.tmp-source-replacement-qa/local-update-track-lock.jpg`。
