# 导入素材主用途与兼容用途

范围：效果类视频渲染节点的单视频导入抽屉。复用四类素材用途及现有选择控件；提示词、主用途和至少一个兼容用途完整后才能确认。兼容用途包含主用途，可追加其它用途。

AI 识别视频仅在用户主动点击时执行；读取原视频关键帧，同时产出描述、主用途和兼容用途，成功后原子覆盖三项草稿；失败保留原输入。人工随后可编辑。类型不得由 Worker 关键词规则推断，不读取用户原选择作为答案，不生成六槽位归槽结论。

契约：导入草稿增加可空 primaryPurpose 与 compatiblePurposes；确认请求必须提供合法四类枚举；AI 完成回调须包含完整三项。旧导入草稿初始类型为空，重新选择即可；旧已导入素材不迁移、不重新识别。增加两个数据库列，不改上游 Prompt 或旧成片。

输出：类型冻结进独立导入素材 requestSnapshot/generationRequestSnapshot，保存修改时沿用 render-clip/render-batch 提交与后续混剪入口。推荐用途不替代混剪独立 AI 六槽位归槽。

非目标：不改导入时长范围、模板时长上限、混剪组合算法或包装；不自动调用模型、不扩展批量导入、不改其他聊天文件。

验证：契约枚举一致性；API 缺失/非法类型及空描述拒绝、幂等回调与旧租约；数据库外层回滚检查人工选择持久化；Worker 结构化分类与无自动付费重试；Web AI 成功覆盖/失败保留、必填门禁与响应式浏览器回归。真实付费识别不作为默认验证。

追加范围：复用 Prompt 节点 creativeCore 与六维 dimensions（narrative、scene、persona、productRelation、camera、emotion），提供选填文本框。AI 同时输出并覆盖全部字段，但用户可以留空或清空创意信息后确认；必填/选填用小标签标识。创意信息冻结进入导入素材，预览和来源 Prompt 沿用既有详情组件，不写入上游 Prompt 批次。新迁移增加 creativeCore 与 dimensions，不更改已应用迁移。

模型：独立 ARK_VIDEO_IMPORT_MODEL 默认 doubao-seed-2-1-pro-260628，沿用 ArkProvider/Responses 结构化适配器及现有密钥；中等推理预算，最多 12 帧，4096 输出 token，显式操作只调用一次。参考提示词节点的“同一事件一致性”“结构补齐只概括既有内容”和事实边界，不复用新增拍摄脚本职责，不读取用户旧描述或分类作为答案。缺失配置显式失败，不回退 Mock。

AI 输出须包含非空创意方向和完整六维；具体不确定的信息注明未能确认，而非编造事实。人工确认仍允许这些字段留空或清空。每次显式识别使用独立 Outbox 记录，沿用草稿锁、requestId 和 Worker 租约；已投递的旧 requestId 重放不再次生成，识别失败保留前次全部结果。

验收：正式 API 与 Worker 已构建并在零活动任务时更新；真实浏览器覆盖 1920/1440/768 宽度、视频解码预览、空态、提示词单独填写不能确认、必填类型齐备且选填为空可确认、六维展开与清空、取消测试草稿及取消隔离编辑。测试素材未确认导入，未调用付费 AI；数据库集成用外层事务回滚验证类型/创意持久化、AI 失败保留、重复请求和回调。

追加视频信息展示：导入弹窗两列三行展示时长、分辨率档位（如 720p）、画幅、帧率、大小、格式；沿用原弹窗与样式，不新增提示。显示视频实际参数，不套用当前渲染设置。API 复用现有 ffprobe 读取视频流平均帧率，无法读取时为空，不根据播放速度估算；草稿新增可空 frameRate 字段并回传既有 width/height，旧记录无需回填，不改变素材工作副本、上游 revision 或模板配置。测试覆盖横竖屏、非标比例、分数帧率、未知帧率、持久化及三个浏览器宽度，无付费模型调用。

视频信息验收：API 38 项、Web 47 项、契约 5 项及数据库外层回滚集成 1 项通过；Web/API 类型检查与构建、格式检查、git diff --check 通过。新增可空列迁移已部署，零活动任务时更新 API 并确认健康。真实上传竖屏 720×1280/30fps 与横屏 1280×720/30000÷1001fps，分别显示 720p、9:16/16:9、30/29.97 fps，浏览器 1920/1440/768 宽度信息区均无横向溢出。测试草稿取消且不确认导入，保留已有编辑会话，不调用付费模型。
