# 包装旧进度残留清理

效果类模板混剪的包装展示修复：新任务提交期间不能引用上一轮终态的进度、完成数及失败提示；任务受理立即交接至真实任务，不等待历史查询；终态隐藏横条和文字。相同任务的新后台终态优先于迟到的历史运行状态。失败统计仅保留在主动打开的工作流详情中，不删除后台记录或改动重试、锁定、工作副本及下游提交。

验证：提交带旧 PARTIAL、受理后历史查询未返回、成功/部分失败/失败/取消、旧响应迟到、单条与整批隔离；相关 Web 单测、类型检查、构建、git diff --check；隔离浏览器1920/1440/窄屏使用拦截请求验证，不启动付费任务。

## 补充：原分支与新增包装分支隔离

用户确认整批重新包装必须新增分支。API 已按子 Run 冻结与执行，新协议不锁父分支；本次修复前端错误地仅按相同 variantId 投影子任务的锁定、临时清理及包装选择。原分支保留原口播/字幕/配乐并可编辑，提交阶段也不清理或锁住整批父工程。只有当前工作区 Run 自己的包装任务可以清理视图和锁住目标条目；单条原位包装继续锁定本条。后台子结果仍按现有机制实时交接到其真实 Run，不能写回父分支或与父分支音轨混播。不修改 API、Worker、业务 revision 或在途任务。
