# 音色试听静态缓存实施计划

日期：2026-09-23
状态：已完成

## 目标

将效果类模板混剪音色库的试听改为共享预生成音频：音色样本按音色 ID 与版本存入共享对象存储，API 负责项目授权后的读取；用户点击卡片只播放已保存音频，不触发 TTS 合成。现有按项目/Run/模板创建付费试听的接口保留兼容，但正式音色库 UI 不再调用。

## 范围与边界

- 继续使用唯一账号音色目录源；ID、speaker 与资源版本留在源码/数据库，不进入 `.env` 或前端响应中的供应商字段。
- 新增共享样本记录（音色 ID、版本、storage key、SHA-256、大小、媒体类型、时长）；不绑定项目 FileObject，不随任一项目删除。
- 对象存储增加明确的共享目录写入能力；样本只允许由内部 Worker 凭据写入，面向 UI 的读取仍先校验 `projectId + workflowRunId + templateId`。
- 提供可恢复的一次性预生成脚本：先读当前已启用音色与样本状态，只对尚无样本的版本执行真实 TTS；提交结果不明时停止该条，不自动二次付费。英语音色使用英语样本文案。
- 预览接口只流式读取已保存音频；成功样本设长缓存头，并验证音频完整性及绑定。
- Web 点击音色卡只请求样本文件并播放；移除首次选择时生成试听任务的路径，保留正在播放时的动态指示。

## 非目标

- 不改变音色列表、包装音色选择、包装任务或音频轨道行为。
- 不增加音色 ID 的环境变量，不向浏览器暴露 speaker、resourceId、凭据或 storage key。
- 不删除既有按项目试听记录/接口，以免破坏历史试听与兼容性。

## 验收

- 迁移在现有库中只增加共享试听样本表，不更新工作副本 revision 或项目资产。
- 内部上传需 Worker Guard，项目播放端必须通过现有项目工作区范围校验。
- 预生成脚本支持断点续跑、逐项登记付费尝试、按样本语言使用正确文本并记录不含密钥的结果；TTS 提交结果不明时禁止自动重试。仅有明确标记的音频上传失败可由内部任务显式重试。
- 浏览器选择音色只产生静态样本 GET；不创建 VOICE_PREVIEW 记录、不提交 TTS。
- 覆盖 Contracts/API/Web/Worker 测试、类型检查与构建，浏览器验证首次播放、重复播放、样本缺失错误及分页。
- 付费预生成针对清单内 99 个音色均已保存可读样本，实际付费合成 100 次：第 99 个音色首次合成后遭遇本地 API 断连，上传未落库，最终为补齐样本额外合成一次。结果记录见同日验收证据。
