# 外部导入素材返修与重新生成

## 范围与验收

- 效果类视频渲染节点复用现有任务、确认弹窗、编辑分支、Outbox、租约及候选采用机制。
- 独立导入素材使用已确认的反推正文重新生成，不向 Prompt 节点查找导入草稿 ID，也不重新识别视频。
- 导入素材真实时长超过 15 秒时，重生成和返修自动选择 Seedance 2.5；否则读取渲染节点当前模型配置。重生成时长按供应商整数秒要求四舍五入，原参考文件不截短。
- 2.5 返修使用 edit/adaptive/-1 协议；2.0 系列采用其支持的视频参考生成协议，不发送 2.5 专有参数。冻结具体协议与模型，不能由 Worker 猜测。
- 参考视频接受 4–30 秒、MP4/MOV、最大 200 MB；TOS 签名读取复用已有能力，不要求额外旧公网代理配置。
- 保留供应商返回的小数时长；2.5 编辑允许最多缩短 0.4 秒，普通生成继续严格验证输出参数。候选采用后记录实际时长，放弃不改变活动时长。
- 以活动素材的短边像素与用户配置为分辨率下限，选择不向下取整的标准档位。当前模型不支持时升级：1080p 使用 2.5，4K 使用 2.0；超过 15 秒只能采用 2.5，最高 1080p。超过能力上限时按用户要求兜底为短素材 2.0/4K、长素材 2.5/1080p。前后端共用选择函数，确认信息展示实际配置，不修改全局设置。
- Worker 用已有 ffprobe 读取输出视频轨道真实时长，回调增加可选 actualDuration；Ark 查询返回整数向下取整不能当成真实时长。编辑返修按真实时长校验 0.4 秒容差，普通生成仍校验目标参数与真实媒体误差。

## 接口与迁移

现有请求快照增加可选返修协议和输出实际时长字段。旧返修快照默认视频编辑协议，旧输出回退到原请求时长；无需数据库迁移，不重写历史数据。保留 importedMaterial 和上游 Prompt 时长上限，混剪槽位上限不受导入/重生成时长影响。

## 非目标

不改全局 Prompt 时长上限，不重建混剪算法，不自动付费测试，不自动提交 Git，不覆盖其他聊天的改动。

## 验证

Contracts、API 编译器/服务/仓储、Worker 模型与供应商模拟测试；Web 按钮条件及浏览器三种宽度回归；类型检查与 diff 检查。禁止真实提交付费生成。部署前检查正在运行任务，避免中断付费调用。

## 依据

火山官方 Seedance 2.5 教程和创建任务 API：视频编辑仅 2.5 支持显式 edit 引导，参考 4–30 秒，duration=-1、ratio=adaptive；2.0 系列支持 reference_video。https://docs.volcengine.com/docs/ark/seedance-2-5
