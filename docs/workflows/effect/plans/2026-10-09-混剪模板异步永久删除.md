# 混剪模板异步永久删除

## 范围与边界

- 效果类模板混剪节点；上游仍为已确认的 `render-batch` / `render-clip`，删除不修改其 revision。
- 独立删除接口确认后持久化删除回执，立即隐藏模板、填充、包装和输出分支；后台清理，不等待文件与 Redis。
- 删除同项目中该模板身份的配置、工程、包装、交付、任务、检查点、资产和历史副本。模板专属子分支删除；其他模板分支及独立上游来源保留。
- 删除中的模板禁止新增任务、恢复、旧草稿保存及迟到回调重新写入。重复请求返回同一回执。
- 当前查看的分支被删除时返回最近可保留的上游 Run，界面切回配置；不创建业务版本。

## 数据与执行

- 新增持久化后台清理记录，保存模板身份、目标 Run 集合、回退 Run、租约、阶段、重试及文件清单。完成后只留防复活的删除回执，不保留业务快照。
- 数据库阶段按模板精确删除，并处理 Restrict 依赖、导航记录与活动指针。共享上游文件及其他模板引用不能删除。
- 文件只从类型化 storageKey / FileObject 关系收集；删除前再次核对全库引用，保留跨分支、项目、全局音色引用，不扫描 JSON 猜测路径。
- 极少数历史数据若其他模板直接依赖目标分支中的上游复制快照，保留该共享来源和最小不可写来源容器；仍移除目标模板所有业务数据与树节点，不强行破坏其他模板依赖。
- Redis 仅清理该项目效果类的聚合读取缓存，使用 SCAN + UNLINK 小批次，不使用 FLUSHDB；缓存不可用持续重试，不阻塞页面。
- 后台任务有租约和可恢复阶段，进程重启继续执行；仅删除动作取消目标模板的在途任务，不中断其他模板。
- 墓碑纳入缓存版本及读取投影，旧缓存、旧请求不能使模板重新出现。

## 非目标

- 不删除共享渲染素材、商品资料、其他模板或其他项目；不触发生成、包装、导出。
- 不根据截图直接删除真实项目的数据；本任务只实现功能与隔离测试。
- 不自动部署、迁移真实数据库或提交 Git。

## 验证

- 空模板、有填充/包装/输出模板、历史和未发布子分支、重复请求、活动分支回退。
- 兄弟模板/项目隔离、共享文件保护、迟到回调和旧草稿防复活、重启恢复及 Redis/存储失败重试。
- 单元测试、隔离数据库测试（环境允许时）、Contracts/API/Web 类型检查与构建、`git diff --check`。
- 浏览器验证确认文案、即刻移除、删除后的继续操作；不能以静态检查代替真实数据库/后台清理验收。
