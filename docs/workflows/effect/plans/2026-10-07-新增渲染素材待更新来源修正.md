# 新增渲染素材待更新来源修正

## 范围与原因

渲染编辑保存时新增片段为 revision 1，已有来源判定仅识别同 Prompt 片段 revision 增长，错误选择历史返修分支的旧素材池。当前 Run 已确认的 render-batch revision 增长必须同样参与共享渲染来源头选择。

## 实施与边界

- 复用既有来源头与 pendingAddedMaterialIds 投影，不新增状态或接口。
- 已确认素材池的版本变化与单片段返修共同参与来源头判定；克隆、未发布编辑、独立渲染头及手动复制保持隔离。
- 已有模板按其填充快照识别新增素材；空工程模板不伪造过期。
- 不自动改写时间轴，不启动 AI、包装或导出任务，不修改现有业务数据。
- 无契约/数据库迁移。

## 验收

- 来源头单测：新增 revision 1 片段、素材池删除、根来源后续保存、克隆与未发布编辑隔离。
- 真实数据库只读检查：22 条当前素材，新导入两条 activeSource=true；已有模板新增素材待更新，空模板无告警。
- API/前端相关测试、类型检查与 diff check；浏览器渲染画布、混剪列表及分支树核对。
