# 静音素材事实覆盖口径统一修复

状态：已完成统计修复及一次真实复测；本轮内容质量未完全达标（2026-09-08）

## 范围与原因

仅修复效果类 Prompt 节点的事实覆盖统计与结果保存。择优按 AI 视觉策略排除 TEXT_ONLY、FORBIDDEN_VISUAL_PROOF，结果指标却使用原始必用清单，API 因此将合法结果重新判为 NEEDS_REVIEW。

## 实现

- 沿用当前视觉策略计算本批必用事实 ID，Worker 只执行 ID 集合运算。
- 择优与结果保存都基于最终条目的实际绑定统计覆盖。
- 输出覆盖清单的 required 只含本批必用事实，其余可信事实保留在 adaptive/deferred，不删除原始洞察，不伪造绑定。
- API 沿用同一 required 清单进行完成、刷新和编辑后的重算；真实必用事实丢失仍须 NEEDS_REVIEW。
- 保存节点保留 Worker 上报的覆盖统计，避免完成事务丢失详情。
- 不改变生成模板、评分、数量、去重、HTTP 路径或数据库表。历史结果不批量迁移；新批次使用修复口径。

## 验证

- API 覆盖完成解析、读取重算和编辑删除绑定后的状态。
- 跑相关 Worker/API 测试、类型检查与 diff 检查。
- 浏览器真实生成紫苏梅子酱 100 条 × 15 秒，检查数量、覆盖、质量状态、重复度与刷新恢复。只保存领域草稿，不提交 WorkingArtifact，不调用视频渲染。
