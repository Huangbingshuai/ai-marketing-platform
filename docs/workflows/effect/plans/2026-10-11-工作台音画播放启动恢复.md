# 工作台音画播放启动恢复

## 范围与边界

效果类模板混剪工作台只读预览已有画面和包装文件，不创建任务、不修改工程或业务 revision，不重跑模型，不中断在途包装。复用当前工程的素材绑定和实际包装检查点，保留后台新分支结果的只读编辑限制。

## 修复

- 已有音频文件 GET 遇到连接错误、超时及可恢复 HTTP 错误时有限重试；权限、文件不存在、解码错误不无限重试。
- 视频、口播、字幕共用一次启动屏障。拖动播放位置只由父播放器启动，子组件不能另起无画面屏障的音频时钟。
- 启动或缓冲期间保留原画面和时间位置，明确显示加载；允许立即暂停、切换成片。过期启动不能恢复或停止新播放。
- 音频启动失败不能被当作成功；完整停止音画时钟并展示播放器错误。原生 play Promise 长期不返回时有界退出。

## 验证

覆盖暂时性读取失败恢复、永久失败、重复点击、拖动定位、暂停和切换期间旧响应、只读包装结果播放及视频启动超时。运行相关前端测试、类型检查、构建和 diff 检查；用真实工程只读浏览器回归，阻止全部业务写请求及付费任务。

## 本次观察与验证记录

- 测试2真实工程在隔离挂载的正式工作台组件中读取并预览，所有非 GET/HEAD/OPTIONS 业务请求均拦截；未创建包装、配音或视频生成任务，未重启 API/Worker。
- 已有视频正常读取后可播放；旧播放流程中也观察到口播/配乐错误令播放停止。不能仅凭截图认定视频文件损坏。本轮修复读取失败恢复及双端启动竞争，不修改媒体内容。
- 最终代码真实播放时，画面时间从 0.597 秒推进至 2.048 秒，已解码帧数 24 → 59，音频时钟 0.262 → 1.715 秒；可见视频不是首帧海报，播放未出现错误。
- 模拟一次音频 GET 503 后实际发起第二次 GET 并恢复；模拟慢读取时立即显示加载，点击暂停后迟到读取不能自动播放；模拟 404 时停止全部媒体并明确显示错误。恢复文件访问后可再次播放，播放中定位到 9.5 秒后继续正常推进。
- 检查 1920、1440、390 宽度的播放按钮可见、未被编辑锁禁用；截图为真实工程的隔离组件预览，不是原应用完整导航链路验收。普通应用进入工作台曾遇到草稿保存接口 500，此独立问题未在本轮修改。
- 7 个定向测试文件共 76 项通过，Web 类型检查及生产构建通过（保留既有大包体警告）；`git diff --check` 通过。混剪目录首轮全量回归为 570 通过 / 52 失败，存在导航夹具遗漏状态及旧源码字符串断言；其中只读预览锁的夹具已随本轮补齐并通过，不能将全目录记为通过。
