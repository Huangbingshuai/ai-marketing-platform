# 分支待更新提示与局部更新隔离

## 范围与边界

效果类六节点沿用 WorkingArtifact 依赖和当前分支定位。局部更新只覆盖所选 Run、模板和成片，不自动更新子节点或创建分支。上游修改影响实际消费者时，各历史分支可独立发现待更新，版本树以黄边提示。

不新增工作流节点、任务协议或通用付费更新接口，不自动修改历史工程，不改变整批重新生成/导出的新分支语义。

## 数据与实现

- 读取时沿合法祖先路径识别上游复制快照：渲染素材使用稳定 Prompt 身份；独立渲染头和手动复制边界停止继承。保留旧素材供原工程预览，最新权威素材用于来源变化判断和用户主动更新。
- 基于实际 artifact 依赖计算各分支待更新，不将整个节点有部分 CURRENT 当作全节点已确认。混剪模板、填充、包装、输出分别返回可选状态，避免不相关模板/层级被标黄。
- 分支树黄边覆盖选中节点样式，但保留红色路径；点击仍跳转对应 Run 和节点。
- 局部更新仅接受当前选中的合法分支/模板路径，在原 Run 冻结输入、提交结果。上游变化只传播待更新，不能传播工程内容。

## 兼容与迁移

后续修正：画布和版本树的上游节点状态必须读取实际来源头，不把下游复制快照的 STALE 算成来源头 STALE。混剪 `needsAiFill` 仅表示模板配置变化，素材返修/重生成通过原有按槽位来源差异与局部更新处理；配置页和工作台共用当前分支的局部更新操作。兄弟分支各自保留绑定与状态，不同步工程。

本轮补验：素材库仅展示当前确认批次的最新素材并继承原槽位；不展示历史引用说明。旧工程的素材引用只用于预览和待更新判断，由用户局部更新，不在读取时改写工程。包装分支编号按同一填充头下的已发布包装分支递增，局部更新导致的工程 revision 不占用编号，首次包装保持版本01。读取投影修复无需迁移历史数据，不启动付费任务。

来源定位补正：`forkNodeId` 只记录分支创建位置，不能抹除后续在同一 Run 确认的上游修改。历史上游副本缺少克隆来源标记时，按稳定 Prompt 身份与直接父副本的确认 revision 区分本地返修提交和普通复制；确认 revision 较新的本地来源成为此谱系的来源头。包装01已使用返修素材则清除其待更新，仍引用旧素材的包装02/03继续待更新。不得以主干旧素材覆盖该返修头，不改写兄弟分支工程。

契约新增可选状态字段，旧客户端和历史结果保持兼容。读取投影不增加 revision，不执行数据库内容迁移；未生成结果不伪造待更新。

## 新模板智能填充来源修复

新模板创建于素材确认更新之后却立即待更新，原因是智能填充直接读取当前 Run 的旧复制工作副本，而素材库已解析真实来源头。统一智能填充创建、事务输入校验、抽帧文件授权与完成校验到现有 `WorkflowWorkingRepository.listArtifacts` 来源解析，仅允许当前合法谱系的可用确认来源；旧复制快照不参与选材。冻结真实 artifactId/revision/hash，运行期间来源改变仍拒绝过期回写。独立渲染头、手动复制与项目隔离保持，不自动改写历史工程、启动付费任务或新增契约。无需数据库迁移。回归覆盖最新来源选材、合法祖先文件、越界文件拒绝、来源变化拒绝、新模板完整完成后不立即待更新。

## 验证

重新生成漏标黄补正：同一个已发布渲染头下，混剪/输出 Run 内保存的素材重生成和返修都属于该共享渲染来源，不能只让保存位置的后代看见。服务端按合法渲染谱系、稳定 Prompt 身份、确认 revision 和更新时间解析实际来源池；独立上游头、手动复制、未发布编辑分支隔离。分支树与素材库使用相同来源解析，历史工程仍保持原绑定，只有实际消费者待更新。旧分支局部更新提交仅允许该来源池中当前确认素材的精确 ID/revision/hash，不开放任意兄弟分支引用。无需迁移数据，不自动启动任务或改写其他工程。

局部更新后画布残留修复：模板记录保存的全量归槽素材池依赖不等于成片绑定依赖；画布不再把仅渲染素材池变化导致的 `mix-template` STALE 当作成片待更新，仍保留实际时间轴/包装和服务端槽位差异、未分类新增素材的提示。当前分支局部更新成功后通过既有同步事件增加确认标记，立即重读工作副本和差异，不等定时器；草稿保存仍只读差异，跨项目/Run 或迟到结果不得清除当前告警。无需数据迁移或任务重跑。

模板节点漏显修复：分支树按各 Run 的已保存模板目录筛选，旧兄弟分支的活动指针不能全局隐藏另一个分支新建的模板。没有目录的历史 Run 继承最近祖先目录，仍不凭残留产物复活已移除模板。不修改模板/工程内容、不新增工作流节点、不迁移数据、不派发任务。验收切回只含测试1的旧兄弟时，测试2配置、填充、包装路径仍完整且不重复；已删除目录的旧产物仍隐藏。

- 两个混剪兄弟分支均引用同一返修素材时均显示待更新，更新其中一个只清除该分支，其他分支仍待更新。
- 覆盖依赖链、部分 CURRENT/STALE、独立渲染头、手动复制、无依赖结果及跨项目隔离。
- 覆盖历史分支局部更新入口与按所选 Run 提交；任务快照、原文件可用和锁定行为保持。
- Contracts/API/Web 单测、类型检查、构建及 diff 检查；浏览器验证版本树黄边与分支点击在宽屏及窄屏保持可用。
