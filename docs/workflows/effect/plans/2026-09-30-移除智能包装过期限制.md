# 移除智能包装后的过期限制

## 目标

智能成片包装成功后，画面时间轴和独立音画轨道由用户自由编辑。即使之后改变素材来源、截取区间、槽位时长或画面排布，也不把已完成包装标为过期，不隐藏、不锁定、不阻止预览、编辑、包装确认或成片输出。系统不判断旧口播/字幕是否仍适合新画面。

## 范围

- 移除模板混剪中包装结果对当前视觉时间轴和上游素材 revision 的过期判断、标签、待更新状态和由此产生的确认/导出拦截。
- 移除成片输出中因时间轴变化而给已导出文件标记过期、阻止校验或强制局部更新的行为；用户仍可显式重新导出。
- 保留在途异步任务的快照、租约、attempt token、文件存在性、项目隔离和未完成任务检查。这些保护任务完整性，不限制包装完成后的自由编辑。
- 不移除其他工作流节点针对上游 WorkingArtifact 的待更新状态。

## 验收

1. 包装成功后修改画面素材、截取、槽位长度或轨道排布，包装仍可试听、编辑并进入成片输出；界面无“过期/来源待更新”。
2. 已导出的成片不会因混剪编辑被系统自动标记过期或拒绝完成校验；用户主动重新导出时使用当前已确认的工程。
3. 未完成/在途包装仍按冻结输入安全写回；实际文件不可用、工程不存在、任务未完成等结构错误仍明确失败。
4. 聚焦 API/Web 测试、类型检查、构建检查和 `git diff --check`。
