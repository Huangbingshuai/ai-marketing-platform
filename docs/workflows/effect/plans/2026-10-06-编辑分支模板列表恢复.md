# 编辑分支模板列表恢复

## 范围与原因

效果类上游隔离编辑分支不包含混剪结果，且不进入正式分支树；混剪页面按该 Run 读取，目录为空。列表必须读取已发布来源及其全部模板当前工作流，不能将空编辑草稿当作模板删除。

## 实施边界

复用父页面已有 WorkflowRun 的隔离编辑标记和 parentWorkflowRunId，为混剪页面提供已发布读取上下文。模板选择仍为页面本地作用域，不激活全局分支。KeepAlive 退出时中止目录读取，隐藏期间不安装工作区；恢复后重读，完整目录与可写工作区一起安装。序列化仍仅保存实际加载的单 Run，不合并兄弟模板，不覆盖上游编辑草稿。

不修改 API、数据库、Worker、素材或已确认 revision，不启动 AI 任务，无数据迁移。

## 验证

增加真实页面上下文 watcher 与加载生命周期回归，覆盖编辑分支首次进入、取消回到来源、保存后换来源、隐藏期间切换、跨项目隔离。相关单测、Web 类型与构建、diff 检查；浏览器确认测试1/2/3持续显示、普通选择不激活全局分支、待更新边框保留及宽屏/窄屏布局。

## 验收记录

9 个相关测试文件共 89 项通过；Web build（含 vue-tsc）与 diff 检查通过。正式页面复现修复前列表 0 个、分支树仍有三个模板；修复后首次读取、刷新后从渲染编辑页返回、选择测试2再返回均保留 3 个模板。1920、1440、960 宽度可见完整列表，控制台无 error。未保存或取消用户的渲染编辑草稿，未主动触发智能填充、包装或局部更新任务。
