# 效果类广告素材与成片表现差距调研改造计划

状态：待完成调研并确认方案
建立日期：2026-09-09
所属工作流：效果类
涉及节点：Prompt 生成、视频渲染、模板混剪、成片输出

## 一、背景与问题

当前效果类 Prompt 已经能够批量生成结构较完整、事实可追溯且相对差异化的无口播素材描述，但用户观察到：即使单条素材能够独立生成，将这些素材直接拼接后，最终广告仍容易显得普通，缺少成熟产品广告所具备的创意概念、镜头分工、节奏推进、品牌记忆和整体完成度。

这不能简单归因于“单条 Prompt 不够长”或“镜头描述不够多”。需要分别检查以下四层问题：

1. 创意源头：是否形成了能贯穿一条广告的核心传播概念，而不仅是大量独立画面点子。
2. 素材覆盖：素材池是否具备可供剪辑组合的不同镜头功能，而不仅是主体、场景和动作的表面变化。
3. 混剪编排：模板是否按照广告叙事和信息推进选择素材，还是仅按标签与时长填槽。
4. 品牌资产：产品、包装、颜色、构图、标志性动作和结尾画面是否形成稳定的品牌识别。

本计划先完成行业调研和当前系统审计，再提出可逐项确认的改造方案。未经确认，不直接大规模修改工作流代码。

## 二、固定业务边界

### 2.1 工作流边界

固定流程保持不变：

```text
资料导入
→ AI 信息提炼
→ Prompt 生成
→ 视频渲染
→ 模板混剪
→ 成片输出
```

不得为了提升广告表现新增、删除或改义用户可见业务节点。

### 2.2 单条素材边界

- 一条 Prompt 仍对应一个可独立渲染、可被混剪复用的素材片段，不写成完整广告脚本。
- 新素材保持无人物口播、旁白、逐字台词、歌词、字幕文案和可辨识说话口型。
- 商品价值需要在静音状态下仍可通过产品、人物行为、场景关系和可见结果被理解。
- 单条素材时长继续使用当前 4～15 秒范围，不恢复 16～30 秒素材。
- 配乐、统一口播、字幕、节奏总线和完整广告信息顺序属于模板混剪与成片输出职责。

### 2.3 Prompt 生成边界

- 当前六维继续是：叙事结构、场景、人物、产品关联点、镜头语言、情绪基调。
- 创意主线、六维、事实关系、结构化拍摄计划和最终正文必须服务于同一个素材创意。
- 钩子、产品展示、效果、结尾转化只作为生成后的推荐用途和兼容用途，不恢复生成配额或独立分支。
- 共用提示词仍由禁用元素确定性编译，生成时作为约束，视频请求编译时只追加一次。
- Worker 只校验来源、事实 ID、稳定 ID、数量、枚举、结构、revision、哈希和幂等，不使用商品关键词、字符相似度或自由文本规则判断语义。
- 产品关系、镜头功能、事实是否被实现、素材之间是否实质相似等语义判断继续由 AI 或人工验收完成。

## 三、数据流与工作副本

| 环节 | 直接输入 | 草稿或过程数据 | 确认产物 | 直接下游 |
| --- | --- | --- | --- | --- |
| Prompt 生成 | 已确认营销洞察 revision、数量、时长、渠道、风格和禁用元素 | 创意版图、方向、候选、评估、择优结果 | `prompt-batch:{productId}` | 视频渲染 |
| 视频渲染 | 已提交 Prompt 批次、参考产品资料、渲染参数 | 渲染任务与素材片段 | 渲染素材片段集合 | 模板混剪 |

调研和方案设计不得改变上述 WorkingArtifact 提交边界，也不得把节点草稿误标为已确认产物。

## 四、调研问题

### 4.1 主流产品广告如何形成创意

重点研究：

- 广告如何从单一传播命题发展为可执行的视觉概念。
- 产品、受众需求、痛点、利益点、使用情境和品牌资产如何形成一条信息主线。
- 成熟广告如何区分“创意概念”和“镜头表现”，避免只用不同场景包装相同动作。
- 不同投放平台如何处理前段注意力、产品出现、利益演示、品牌识别和行动收束。
- 大批量广告变体如何保持共同品牌识别，同时让概念、开场和证明方式真正变化。

### 4.2 广告素材池需要哪些镜头功能

不只统计场景和动作，还要研究素材在剪辑中的功能，例如：

- 建立环境和人物需求的开场素材。
- 立即产生视觉注意力的钩子素材。
- 产品身份、包装和关键外观的识别素材。
- 使用过程、质感变化和结果表现素材。
- 人物非语言反应和使用价值素材。
- 宏观、中景、近景、微距和过渡素材。
- 可用于承接前后镜头的入画、出画、方向、速度和构图状态。
- 可形成品牌记忆的英雄镜头、标志性构图和结尾定格。

需要验证当前素材池是否只有“不同的单镜头”，却缺少可组成完整广告的镜头覆盖。

### 4.3 主流广告如何完成混剪编排

重点研究：

- 成片是否先确定广告命题与信息顺序，再选择素材，而不是先随机填充再解释结果。
- 钩子、需求、产品出现、演示、结果、品牌和转化之间如何推进。
- 相邻镜头如何保持主体、动作、视线、屏幕方向、构图和运动节奏的连续性。
- 同一素材池如何生成多条结构不同但仍连贯的广告。
- 配乐、音效、字幕和口播如何在后置阶段统一组织，而不反向污染单条无口播素材。

### 4.4 品牌资产如何进入画面

重点研究：

- 包装、品牌色、材质、道具、背景、标志性动作和产品英雄镜头如何长期复用。
- 产品参考图与品牌规范是否真正进入渲染请求并保持身份一致。
- 品牌识别是靠稳定资产实现，还是仅依赖每条 Prompt 重复写产品名称。
- 结尾品牌画面如何与前面创意形成视觉呼应，而不是统一追加一个孤立产品定格。

## 五、当前系统审计范围

### 5.1 Prompt 生成

需要核实：

- 产品专属创意版图是否定义传播概念，还是主要提供场景和动作变化。
- 动态创意方向是否产生了真实叙事差异，还是同一事件的换词表达。
- 六维是否真正驱动最终拍摄计划，而不仅用于展示和评分。
- 结构化拍摄计划是否明确首帧、连续动作、镜头获得的新信息和结束状态。
- 当前用途分类能否满足混剪选择，是否缺少更直接的剪辑功能信息。

### 5.2 视频渲染

需要核实：

- Prompt 正文、共用约束、参考图片、时长、画幅和分辨率如何编译为供应商请求。
- 产品参考素材是否稳定进入每次渲染，而不是仅依赖文字描述保持产品身份。
- 渲染结果是否保存足够的画面状态和质量信息供混剪使用。
- 同一产品不同素材之间是否存在无法控制的包装、颜色、比例和质感漂移。

### 5.3 模板混剪

需要核实：

- 正式代码和冻结原型分别实现了哪些能力，不能把原型演示误认为生产能力。
- 素材选择当前主要依赖用途、标签、时长还是广告级故事结构。
- 时间轴是否有明确的信息推进、节奏曲线和相邻镜头兼容判断。
- 同一批素材生成多条广告时，是否只是替换片段，还是能够改变传播结构。
- 口播、字幕、音乐和 Foley 的后置职责是否已经具备真实数据模型与执行链路。

### 5.4 成片输出

需要核实：

- 成片输出是否只负责技术渲染，还是承担品牌收束与渠道适配。
- 输出前是否存在广告级质量检查，而不只是单素材质量检查。
- 最终成片能否追溯到所使用的营销事实、创意概念、素材和模板槽位。

## 六、调研方法与证据要求

### 6.1 外部资料

优先使用以下一手或权威资料：

- TikTok for Business / Creative Center 的视频广告创意指南。
- Meta for Business 的 Reels 和短视频广告创意建议。
- Google / YouTube 的 ABCD 视频广告创意原则与效果研究。
- Amazon Ads、Pinterest Business 等商品广告制作指南。
- Adobe、Frame.io 等专业剪辑与镜头连续性资料。
- Kantar、System1、Ehrenberg-Bass 等品牌资产和广告效果研究。

每项外部结论必须保存可访问链接，并区分官方平台建议、行业研究和合理推断。不得用未打开的搜索摘要代替来源正文。

### 6.2 内部证据

- 读取当前 Prompt、视频渲染和混剪的正式代码、契约、测试与工作流文档。
- 抽取已有真实 Prompt 批次与渲染结果时，只记录必要的脱敏样例和统计。
- 明确区分正式实现、冻结原型、历史计划和尚未实现的设想。
- 不用一次偶然批次代表整体质量；需要跨商品、跨创意方向和跨广告结构比较。

## 七、预期交付物

调研完成后应提供：

1. 主流产品广告生产流程说明：从传播命题、创意概念、镜头清单、拍摄/生成、剪辑到成片验收。
2. 当前系统真实数据流图：营销事实如何进入 Prompt、渲染素材、混剪时间轴和最终成片。
3. 四层差距矩阵：创意源头、素材覆盖、混剪编排、品牌资产。
4. 典型失败链路：说明“单条素材看起来合格，拼成广告仍普通”的具体原因。
5. 分阶段改造方案：每项写清改造节点、输入、输出、是否调用 AI、Worker 职责、契约影响和回归风险。
6. 验收方案：同时评价单条素材质量、素材池覆盖、成片连贯性、品牌识别和广告传播效果。

## 八、候选改造方向

以下仅作为待调研验证的候选方向，不代表已经确认实施。

### P0：先补齐广告级创意命题与镜头需求

- 在不新增用户可见节点的前提下，为一次成片或一组变体建立明确传播命题、受众需求、核心利益、证明路径和品牌收束。
- Prompt 节点仍生成独立素材，但生成目标来自“成片需要哪些素材功能”，而不是只追求单条候选互不相似。
- AI 负责语义规划和镜头功能判断；Worker 仅保存、校验结构和来源。

### P0：让素材携带可用于剪辑的衔接信息

- 评估是否需要在内部结果中增加素材功能、入场状态、出场状态、主体位置、运动方向、视觉焦点和可承接位置。
- 这些信息用于混剪选择，不应全部复制到视频模型 Prompt 中，也不能成为新的机械硬配额。
- 若涉及公共契约，必须先定义历史兼容和 WorkingArtifact revision 规则。

### P1：把模板混剪升级为广告结构编排

- 模板先定义信息槽位和叙事作用，再从素材池选择兼容片段。
- 相邻素材选择同时考虑传播逻辑、视觉连续性和重复风险。
- 同一素材池应能生成不同广告结构，而不仅是相同模板的随机换片。

### P1：建立产品与品牌视觉资产基线

- 明确产品参考图、包装正面、品牌色、比例、关键材质和英雄构图的权威来源。
- 在渲染边界编译供应商 Prompt 和参考资产，避免在每条创意正文中重复塞入品牌规则。
- 品牌一致性检查应由视觉模型或人工完成，Worker 不解释图片语义。

### P2：建立成片级质量评估

- 保留现有单条素材质量评估，同时新增针对时间轴或成片的评估维度。
- 至少检查传播命题是否清楚、信息推进是否完整、相邻镜头是否连贯、品牌是否可识别、节奏是否符合渠道以及素材是否实质重复。
- 成片级语义评价由 AI 或人工执行，确定性程序只计算时长、数量、槽位和引用完整性。

## 九、避免反向退化

- 不通过给每条 Prompt 追加同一套广告结构、镜头模板和品牌长尾句解决问题。
- 不把一条 4～15 秒素材重新写成带完整钩子、讲解、证明和转化的整条广告。
- 不恢复人物口播来弥补画面信息不足。
- 不以固定场景、动作或镜头配额代替真实创意差异。
- 不让 Worker 使用关键词、字符包含、字符串相似度或自由文本规则判断广告语义。
- 不因为新增元数据恢复大量硬门禁；数量精确和可用素材产出仍是首要目标。
- 不未经验证直接增加新的付费模型调用；每次调用必须说明它解决的独立判断问题和失败恢复方式。

## 十、实施前确认点

完成调研后，由用户逐项确认：

1. 是否先改造 Prompt 素材规划，还是优先改造模板混剪。
2. 是否需要在 Prompt 工作副本中增加剪辑衔接信息，还是只保存在内部阶段元数据。
3. 广告级创意命题应由用户选择、AI 推荐，还是两者结合。
4. 产品与品牌参考资产在哪个节点确认，并由哪个 WorkingArtifact 传递。
5. 成片级质量评估是只给提醒，还是影响自动混剪候选排序。

用户确认前，本计划不授权代码实施、真实付费模型测试、Seedance 渲染、Git 提交或远程推送。

## 十一、验收框架

后续实施不能只验证“Prompt 数量正确”或“单条评分较高”，至少应同时检查：

- 单条素材：事实可信、无口播、动作可执行、时长合理、产品关系清楚。
- 素材池：具备不同镜头功能、景别、动作阶段、人物关系和品牌画面，而非只换场景换措辞。
- 时间轴：相邻镜头在动作、方向、构图、节奏和信息上能够承接。
- 成片结构：开场有注意力，产品与利益点出现清楚，证明方式合理，结尾能够品牌收束。
- 批量差异：不同成片具有不同传播概念或证明路径，而非同一模板随机换片。
- 品牌一致：产品身份、包装、品牌色和英雄镜头在多条素材中可识别且不发生事实漂移。
- 工程边界：历史结果可读、项目隔离、revision、幂等、Mock 隔离和 WorkingArtifact 提交边界不回归。

真实质量结论必须来自跨商品、跨批次的浏览器端到端验收，并明确记录实际调用、失败、耗时和样本，不得把自动测试通过等同于广告效果已提升。
