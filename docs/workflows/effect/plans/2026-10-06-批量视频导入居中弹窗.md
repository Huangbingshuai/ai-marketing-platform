# 批量视频导入居中弹窗

范围：效果类视频渲染节点外部素材导入。替换现有右侧导入布局为居中大弹窗，复用原视频预览、六项文件信息、必填类型与选填创意表单。导出抽屉不改。最多同时待导入 5 个文件，按选择顺序独立一列，窄屏保留列隔离并横向滚动，不把字段压窄。每列独立滚动，底部固定 AI 识别和确认按钮；提供批量识别入口，不自动付费识别。

输入与输出：同项目/Run 的已确认 Prompt 批次与渲染批次，仅复用既有导入草稿、独立识别 Outbox/租约、单条确认接口。确认新增当前编辑草稿，保存修改仍是 render-clip/render-batch 工作副本提交点，按原逻辑进入下游混剪，不改模板/包装算法。无数据库迁移。

并发与隔离：每列保留独立文件、预览 URL、请求幂等键、错误、状态和表单；上传并发最多 2 路；AI 识别可同时发起，复用 Worker 现有受控并发。轮询独立处理各列异常，单条移除不终止其他列。确认逐条排队并读取最新批次 revision；成功仅移除自己的列，失败保留输入与重试幂等键。会话关闭/项目切换/卸载取消待导入草稿、停止轮询、释放预览；迟到上传成功需取消对应草稿，不串新会话。确认请求中禁止关闭弹窗；全部确认后保持空态可继续添加。

验证：控制器测试覆盖 1/5/6 文件、并发上传、部分失败、同步识别与重复点击、AI 成功覆盖和失败保留、独立移除、轮询失败隔离、连续确认 revision、失败重试、关闭与迟到结果。Web/API/契约类型、相关测试及构建、Worker 回归、diff 检查。浏览器覆盖 1920/1440/768、1/2/5 列、单条成功动态缩列、超限、错误、空态、键盘焦点、取消清理。默认不调用付费模型；确认测试仅在可安全撤销的自建编辑分支内执行，不取消用户已有编辑。

## 实施验收

原批量导入验收结果见下方列表。本次新增调整如下。

### 后续交互调整

用户反馈单列和空态过大、竖屏视频出现宽黑边。本次缩紧空态到 560px、单列到 600px、多列仍按数量扩展；空态高度按选择框内容自适应，视频容器按真实宽高比和最大 240px / 30dvh 高度缩放。关闭、遮罩和 Esc 仅隐藏并暂停预览，继续保留当前批次的文件、表单和识别进度；重开相同项目/批次复用会话。新增“取消导入”明确清空全部待导入列，停止轮询、取消草稿并释放 URL。切换项目/Run、重新加载作用域、卸载节点仍清理，不能串项目；不增加刷新持久化或修改确认接口。

验证要求：单列竖屏/横屏/方形比例、紧凑空态、多列隔离、关闭重开保留、取消后重开空态、识别中隐藏继续恢复、作用域变更不继承。模型测试用隔离 API fixture，不调用付费服务。

后续验收：相关 Web 单测、类型检查及生产构建通过。浏览器实测 1920/1440/768/600 宽度，空态宽 560px、高约 364px、选择框 180px；单列宽 600px，竖屏预览 135×240、横屏与方形容器分别保持 16:9 / 1:1。关闭重开保留同一 blob URL、手工提示词及用途选择；取消导入重开为零列空态，原用户编辑状态未动。AI 隐藏期间继续恢复及跨项目清理由单测验证，未付费识别。截图：`docs/workflows/effect/evidence/browser/2026-10-06-import-adaptive-resume.jpg`。

### 初次批量导入验收

后续单行选项修正：主用途与兼容用途强制单行、不缩文字，不使用选项横向滚动条。视频列最小宽度由 300px 调整为 360px，多列弹窗随数量扩展，同时调整列间距与内边距；1920 下五列可完整显示。实测四个选项总宽约 322px，最窄列可用 328px。浏览器在 1920/1440/768 宽度的 10 组选项中，全部同一行，`scrollWidth === clientWidth`。相关布局单测 21 条、类型检查、生产构建与 diff 检查通过；仅使用取消的自建测试草稿，没有付费识别和正式导入。截图：`docs/workflows/effect/evidence/browser/2026-10-06-import-purpose-single-row.jpg`。

- Web 相关测试 58 条、API 相关测试 68 条、契约测试 6 条、导入 Worker 测试 14 条通过；另运行回滚式数据库测试，验证 5 个独立草稿逐条确认、revision 连续增长、原任务不变。
- Web/API 类型检查与构建、Contracts 构建、Prettier 与 `git diff --check` 通过。Web 构建保留原有大于 500 kB 的包体提醒。
- 浏览器实际验证 1920/1440/768 宽度、1/2/5 列、6 文件立即拒绝、3 秒文件独立报错、其他列仍可编辑、移除中间列保持输入与类型、Esc 关闭和焦点恢复；1920 五列完整展示，较窄视口仅内部横向滚动，每列表单独立滚动、操作按钮固定底部。纠正了旧列表 `align-items: center` 导致单列内容未铺满的问题。
- 当前项目已有用户编辑草稿，未确认导入测试视频、未取消用户编辑、未调用付费 AI。成功确认后仅移除对应列由协调器单元测试验证，真实逐条确认由独立数据库事务验证，不冒充浏览器付费或确认验收。
- API 无运行任务时重启到当前构建，健康检查返回 200；验收上传草稿均已取消，测试标签页关闭、视口恢复。截图：`docs/workflows/effect/evidence/browser/2026-10-06-import-batch-five-columns.jpg`。
