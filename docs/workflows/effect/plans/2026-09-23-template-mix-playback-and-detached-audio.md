# 模板混剪播放优化与素材分离音频

## 范围

- 降低混剪工作台视频播放和包装口播播放的卡顿。
- 转场播放期间只在进入转场时定位两侧素材，播放过程中交还给媒体元素的原生时钟。
- 播放针与播放器进度指示使用浏览器动画引擎仅动画 `transform`，不依赖 Vue 重渲染或主线程逐帧写样式；其余播放头派生 UI 限频更新。
- 播放期间暂停后台视频缩略图抽帧与音频波形解码/缓存通知，停止后恢复队列。
- 将口播、纯音乐和分离音频显示在统一“音频”轨道中，片段可使用不同颜色。
- 为视频素材增加右键“分离音频”，将源音频做成独立、可编辑的时间轴片段，并静音对应视频片段。
- 将分离音频状态写入混剪草稿和确认的时间轴工程；最终成片输出时移除原视频片段的音频并按分离片段位置混音。

## 数据与确认边界

- 上游仍为当前效果类 Run 的渲染素材片段和混剪模板。
- 分离音频复用视频素材已有的 `fileObjectId`，记录源片段槽位、时间轴起点、源偏移、时长和增益；不另建素材池或文件实体。
- 分离操作更新模板混剪节点草稿并遵守现有自动保存、显式完成校验及 `timeline-project:<templateId>:<variantId>` 工作副本确认边界。
- 视觉时间轴指纹包含分离音频片段与对应原声静音状态。已生成包装或成片若源视觉时间轴改变，按现有规则判定过期。
- 最终输出 Worker 对有分离音频的源视频片段不再混入其内嵌音频，并将独立音频片段与包装口播、配乐合成。

## 交互

- 视频片段右键菜单提供“分离音频”；成功后在统一音频轨道增加同起点、同裁剪范围的音频片段，视频片段不再发声。
- 分离片段沿用时间轴现有选择、移动、裁剪、音量、撤销和删除交互；删除最后一条关联分离片段时恢复视频原声。
- 音频轨道的静音和锁定作用于轨道内全部音频片段；片段颜色区分包装口播、纯音乐与分离音频。

## 非目标

- 不改变 AI 包装的口播/音乐生成和任务队列。
- 不重新编码或上传独立音频文件；输出时从已确认源视频提取音轨。
- 不改变固定工作流节点、上游素材版本或成片输出任务状态机。

## 验收

- 常规播放时视频素材由原生播放时钟驱动；进入转场后不反复 seek 两侧素材。
- 播放针和播放器进度指示由合成线程线性移动，主线程短时繁忙时仍连续；暂停按下时立即冻结媒体与视觉时钟。
- 播放期间不运行后台胶片抽帧或波形解码任务与界面通知。
- 口播、纯音乐和分离音频只显示在同一音频轨道，轨道静音/锁定对所有音频生效。
- 对带音轨的视频执行分离后，预览中视频原声静音且对应音频片段可独立播放、移动、裁剪和调音量。
- 保存草稿、刷新恢复、完成校验和最终成片输出都保留分离结果；输出不重复播放原视频音频。
- 无音轨素材提供明确提示且不产生空音频片段。
