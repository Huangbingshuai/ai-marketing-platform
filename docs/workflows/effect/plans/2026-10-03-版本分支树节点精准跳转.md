# 版本分支树节点精准跳转

## 范围与非目标

修复效果类版本树点击未携带节点类型、当前分支普通节点被忽略，以及模板/填充/包装/输出定位丢失。复用六节点工作流与现有分支激活接口，不改变产物、revision、分支布局或任务提交规则，不自动触发生成及付费。

## 实施

- 点击传递产物所属 workflowRunId、nodeId、模板 ID 与混剪阶段，当前分支也能跳转。
- 跳转前保存已有草稿；跨分支激活后显式进入所点节点，不恢复该分支旧页面。
- 混剪加载完成后定位模板及配置/精修/包装工作流，覆盖旧的恢复位置；一次性消费定位请求，后台加载不反复抢走用户选择。
- 成片输出加载后定位对应模板。定位按项目与 Run 隔离，不存在的目标明确提示。
- 无接口、数据库及迁移变更；保留编辑分支与异步任务隔离。

## 验收

测试八类可视节点、同分支/历史分支、同一目标重复点击、目标加载延迟与作用域隔离。执行相关 Web 测试、类型检查、构建及 diff 检查；浏览器在 1920、1440、窄屏检查模板/填充/包装/输出及普通节点点击，不执行生成任务。
