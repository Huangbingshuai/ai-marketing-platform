# 效果类工作流-AI 视频片段批量渲染节点前端实施方案

- 当前状态：已完成
- 最后更新时间：2026-08-26

## 目标与实施范围

本次只实现效果类工作流第 04 步“AI 视频片段批量渲染”的前端页面、独立 Mock Service、必要状态模型、父工作流接线和前端测试。页面以 `references/prototypes/effect/effect-workflow.html` 为冻结视觉基准，在 1280×720、DPR 1.25 下复刻标题区、统计卡、批量工具栏、双列任务卡、分页、预览弹窗、来源 Prompt 弹窗、工作副本状态栏和节点底栏。

本次不修改后端、数据库、Prisma、HTTP 接口和 `packages/contracts`；不调用 Seedance、外部模型或任何真实网络；不修改已完成的资料导入、AI 信息提炼和 Prompt 生成页面；不开发模板混剪和成片输出节点；不提交 Git。

## 开发前强制核对

1. 当前属于效果类工作流第 04 步 `SEGMENT_RENDER`，用户可见名称为“AI 视频片段批量渲染”。
2. 直接上游是第 03 步已完成校验的 `prompt-batch:{productId}` 工作副本；不存在第二个必要上游。前端 Mock 以稳定 Prompt ID 模拟该快照，不读取 Prompt 页面临时草稿。
3. 真实业务应产生 `render-batch:{productId}` 和 `render-clip:{taskId}`；本次仅在独立前端 Mock Service 中维护同形态的会话数据，不伪造服务端记录。
4. 任务筛选、选择项和弹窗状态只属于页面交互状态；开始渲染、重生成、导入和删除由 Mock Service 更新当前会话中的模拟结果。本次不调用 `WorkflowNodeState` 或提交真实 `WorkingArtifact`。
5. 真实业务中，已提交视频素材池的有效内容变化会使第 05 步模板混剪的既有结果 STALE；本次不开发或模拟第 05 步状态传播。
6. 下游稳定依赖应包含 Prompt ID、Prompt 内容指纹、片段类型、渲染任务 ID、素材版本和内容哈希。本次 Mock 使用 `projectId + workflowRunId + productId + promptId` 生成稳定任务标识，不依赖页面数组序号。
7. 本次明确不开发 Prompt 生成、模型选择策略、Seedance Worker、真实视频播放、模板混剪、成片合成和项目归档。

## 页面结构与视觉基准

- 节点主卡：白色背景、28px 内边距、26px 圆角、`#dbe4f6` 边框与浅阴影。
- 标题区：44px 橙色步骤徽标，21px 主标题，13px 说明；右侧为当前商品、素材池入口和 40px 高主按钮。
- 统计区：四等分卡片，12px 间距，约 109px 高，17px 圆角，使用灰、青、琥珀和浅红蓝配色。
- 工具栏：约 54px 高，12px 圆角；包含全选、选中数量、210×32px 搜索框、导入、批量重生成、批量删除和批量导出。
- 任务列表：桌面端双列、12px 间距；任务卡 14px×16px 内边距、12px 圆角；预览区 112×92px；标题 13px，元数据、标签和进度信息 10px。
- 分页：默认 12 条/页，右对齐；小屏下任务卡改为单列，工具栏换行，弹窗适配窄屏。
- 原型中的“一条任务四个分镜”修正为“一条 Prompt 对应一个独立视频素材片段”。
- 原型中的节点级“保存到项目资产库”不复刻，改用现有工作副本状态栏和节点底栏。

## Mock 数据与交互

Mock Service 按项目、工作流、产品隔离会话数据，统一负责加载、批量渲染、自动重试、单条/批量重生成、导入、删除和本地导出。组件通过 `AbortSignal` 取消产品切换和卸载后的旧操作，不在组件中散落定时器。

默认演示批次包含 50 条 Prompt 对应的 50 个渲染任务，视觉初态与原型一致：47 条完成、3 条生成中、0 条异常。批量渲染后按确定性规则推进进度；可恢复失败最多自动重试两次，仍失败则标记异常，支持人工单条重生成。

## 测试与验收标准

- Mock Service 测试覆盖项目/产品隔离、一条 Prompt 对应一个片段、自动重试上限、异常恢复、筛选、分页、批量操作和无网络请求。
- 布局契约测试覆盖标题、统计区、工具栏、双列任务卡、分页、两类弹窗、工作副本状态栏和节点底栏，并禁止出现“4 个分镜片段”和“保存到项目资产库”。
- 运行 Web 类型检查、定向与完整 Web 测试、Web 构建和相关 ESLint。
- 在同一浏览器 1280×720 下对比冻结原型与正式页面，关键区域几何差异控制在约 4px 内，并完成主要交互验证。
- 保留工作区无关修改，不覆盖 Prompt 生成及其他模块的现有变更。
