# 播放器提前解码与即时交接

## 边界

仅调整效果类第五节点精修预览。继续消费已返回的素材 URL、内容哈希、
来源 revision、工程绑定和截取起点；不改变业务工作副本、下游状态、版本，
不创建生成或最终编码任务。

## 实施与验收

- 当前片段之外，提前缓冲和定位后面两段；按实际时间轴顺序，跳过无素材槽位，
  不一次加载整个素材库。不调用 load() 丢弃已有解码帧。
- 音频与视频并行启动，不等待音频准备才启动原生视频。
- 保留整秒低频编辑器更新；未完成交接的解码器由 RAF 逐帧重试，
  已就绪后立即交接，不再额外等整秒。保持原有暂停和作用域取消校验。
- 正常播放仍复用已定位的原生视频、不在自然边界重复 seek，
  就绪前保留上段已解码画面，不显示整块加载占位。
- 硬切通过来源/解码帧检查后立即交接原生媒体层，与随后 Vue 状态保持一致，
  不让大型时间轴渲染成为切换画面的前置条件；转场保留原有合成动画。
- 起播、重播及播放中定位取消重复 seek；固定目标帧完成解码并允许原生播放后，
  才启动共享时钟。音频上下文在点击时解锁，音视频并行准备，音频调度等待画面。
- 原生 waiting 与无事件的媒体时间停滞统一保留最后帧并冻结全部时钟，恢复后
  从实际素材时间继续，不以“没有黑屏”掩盖漏播。350ms 无媒体时间推进触发恢复；
  主动暂停、seek、切换作用域不误判。旧起播请求不得暂停已被新请求接管的元素。
- 单测覆盖有界前瞻、顺序、末尾、空槽、seek 与首帧来源隔离；Web 类型与构建、
  聚焦媒体测试、diff 检查。浏览器核对实际连续播放、切换、暂停恢复及三个宽度。

真实缺失素材或用户删除形成的空槽不伪造画面；极端网络/解码停滞下无法保证
始终零等待，不能用静止截图声称所有设备都无黑帧。

## 验证记录（2026-10-09）

- 工作区 500 查明为 Prisma P2021：代码读取模板删除记录，而本地尚缺
  `effect_template_deletions` 表。只读诊断后核对 Prisma 状态，唯一待应用迁移为
  `20261009030000_effect_template_deletion`；执行既有 additive migration deploy 后
  工作区恢复。没有删除工程、素材，没有强制重启或触发生成。
- 补测捕获两类真实问题：重播重复 seek 导致画面未解码时项目时钟先走；
  连续播放中原生媒体时间偶发不再推进，项目时钟仍到结束。以上作为本轮修正依据，
  不能仅以 readyState/截图判断播放通过。
- 八套媒体、导航、起播和音频测试 81 项通过；本轮中间 Web 构建（含 vue-tsc）通过，
  保留既有大包体积警告。最后一次全量重建受工作区其他并行改动阻断：
  `CustomizedInfoExtractionNodePage.vue:143` 的 multiline 传入 boolean | undefined，
  不符合 exactOptionalPropertyTypes。没有修改该定制类页面，不把最新构建记为通过。
  聚焦媒体模块 ESLint 与 git diff --check 通过。测试覆盖起播解码屏障、取消、超时、无事件停滞、
  音频等待画面、前瞻、seek、来源隔离和导航。
- 1920 宽度最终代码下，“紫苏梅子酱 / 测试3 / 成片01”实际播放到 48 秒，
  连续读取 1326 次媒体状态；4/14/24/34/40 秒五次交接都有 readyState=4 的入场画面；
  起播未解码期间显示已缓存真实首帧，时钟固定在 0。片尾实际素材时间推进到 9.965s；
  没有无解码画面且无缓存图片的样本。截图保留 36 秒运行中的画面。
- 1440 宽度快速切换 03→02→04 后播放：当前工程真实首帧先显示，解码完成后时钟推进；
  暂停 1.2 秒，媒体时间与项目时钟均保持不变。768 宽度恢复播放，跨过首个交接继续至
  8 秒，无黑屏/加载占位样本。截图见下方证据。
- 最后补齐音频预解码与原生 play promise 屏障后，再测起播至 5.67 秒及首次硬切，
  无无画面样本；起播尚未完成时立即暂停，后续 1.2 秒项目/媒体时间保持为 0，
  没有迟到恢复。最终代码没有遗留临时播放器诊断属性。
- 额外检查测试1：当前所选成片没有包装轨道，片尾是未绑定素材的空槽；
  前五段正常播放，34–38 秒显示真实“素材缺口黑屏”。不把此缺口计为播放器交接通过，
  不自动替用户选片或生成。已有包装任务未执行，真实口播/BGM听感和全部转场端到端
  尚未验收，不能宣称已验证；音频调度目前以聚焦测试为证据。
