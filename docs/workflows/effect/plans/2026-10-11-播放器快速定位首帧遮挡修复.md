# 播放器快速定位首帧遮挡修复

## 边界

效果类模板混剪精修预览，读取当前 Run、模板及成片工程实际绑定的素材和 revision。不修改上游来源、时间轴、包装、WorkingArtifact 或输出文件，不创建生成任务，不增加业务 revision。

## 原因与实施

- 预览身份同时包含素材身份与 seek 序号，暂停定位时每次都重新显示素材截取起点封面。快速拖动反复取消两帧绘制等待，用户看到封面而不是已解码视频。
- 拆分来源身份与定位请求身份：同素材已呈现后持续使用原生视频画面，不因连续 seek 盖回首帧。新成片、来源、截取起点及作用域变化仍等待正确画面；旧请求仍按完整定位身份隔离。
- 重复 loadeddata/canplay/seeked 对同一目标帧的通知不重置绘制等待；新目标、源替换、卸载仍取消旧回调。
- 保留现有最新目标合并队列，不为每次鼠标事件重新加载媒体，不更改播放时钟或音轨规则。

## 验证

- 五个定向单测文件共 53 项通过，覆盖首帧呈现、重复通知及最新回调、过期回调、来源切换、定位合并及正常播放启动。
- Web 生产构建通过，包含 vue-tsc 类型检查；既有包体大小警告保留。
- 正式应用工作区读取出现 HTTP 502，不能据此宣称真实项目导航验收通过。另提供显式隔离浏览器夹具，使用本地 4 秒测试 MP4、合成六槽工程，拦截全部业务请求；不写真实工程，不调用付费服务。
- 隔离夹具在 1440、1920、390 宽度执行同素材连续 60 次往返及跨素材 5 次定位。同素材期间首帧遮罩出现次数为 0；最终工程播放头为 10.3 秒，第 3 槽原生视频时间为 2.300 秒，首帧遮罩为 0。该结果证明定位时间及遮罩逻辑，不代表真实网络素材加载耗时或恒定帧率。
- 播放中执行同样 65 次定位，最终目标对应视频在 300ms 观察时已推进至 2.501 秒且封面为 0，随后正常播放至工程末尾；切入此前未呈现的来源时保留短暂首帧等待，不承诺所有跨来源定位零等待。
