# 模板混剪时间轴音频与字幕交互修复

## 范围

- 修复包装口播、纯音乐在工作台播放时无声的问题，并按轨道独立静音。
- 允许字幕卡片在只读包装中被选中并在播放器中显示；仅编辑动作受只读状态限制。
- 将原单一音频轨拆为口播轨和纯音乐轨，轨道锁定只约束本轨交互。
- 视频轨隐藏时播放器显示黑屏；字幕轨隐藏时播放器不显示字幕；音频轨不提供可见性按钮。
- 视频与音频波形统一为底部基线向上增长，并由当前音量缩放高度。
- 消除时间轴横向缩放时音频片段跨行、溢出或留在旧行的问题。
- 在音频片段上绘制与实际淡入、淡出时长一致的包络遮罩。

## 现状问题

- 时间轴把口播和纯音乐放入同一个 `AUDIO` 轨，再通过区间分层避让，导致两个业务轨道共享高度、锁定、静音和缩放布局。
- 只读包装的字幕点击会清空选择，播放器字幕又被包装预览开关和 stale 状态额外拦截。
- 波形组件使用垂直居中布局，音量只改变一条控制线，不改变波形高度。
- 播放器只维护当前口播元素，切换口播段落时会替换媒体元素；源裁剪偏移也未计入音频播放位置。

## 设计

- 轨道类型改为 `CAPTION | VIDEO | VOICE | MUSIC`，口播和纯音乐各自计算区间行、轨高、锁定和选区。
- 工作台持有视频/字幕可见性与口播/音乐静音状态，时间轴只发出轨道控制事件。
- 包装播放器同时保留所需媒体元素的稳定绑定，播放位置使用 `playhead - start + offset`，并分别应用口播/音乐静音。
- 字幕选择与字幕编辑解耦：所有可见字幕都可选，只读状态仅禁止移动、裁剪、改文案和改样式。
- 波形增加 `gain`，所有柱形从底部生长；音频片段按淡入淡出秒数绘制包络遮罩。

## 非目标

- 不改变包装 Worker 的配音、音乐生成方式和工作副本提交边界。
- 不改变音频参数 API、字幕内容结构或最终成片编码契约。

## 验收

- 播放成片时口播与纯音乐均可听见，两个静音按钮互不影响。
- 字幕卡片可选，播放头进入其时间段时播放器显示字幕；字幕轨隐藏后不显示。
- 视频轨隐藏后播放器为黑屏，恢复后继续显示当前画面。
- 口播、纯音乐分轨；音频轨无眼睛按钮；锁定后本轨无法移动、裁剪或调音量。
- 波形底部对齐，音量变化会同步改变波形高度；缩放前后片段仍留在所属轨道内。
- 淡入淡出时长变化后，片段两端包络遮罩同步变化。
- 相关前端单测、类型检查和 `git diff --check` 通过。
