# 精修入口即时切换

## 范围与原因

效果类模板混剪的配置到精修入口。当前入口先等待草稿保存，慢网络使用户已经在看的模板迟迟不切换视图；有效的模板当前 Run 快照仅支持配置跳转，进入编辑又走一次读取。本次只修 Web 导航，不改智能填充、包装、付费、分支、业务 revision 或下游提交规则。

## 实施边界

- 当前模板、真实 Run 及已安装工作区一致时，配置到精修只是同一草稿的视图变化，立即切换，不等待自动保存。已有保存继续按原队列执行，保存失败保留本地编辑和错误，不回退配置页。
- 跨 Run 可复用目录中已通过 revision fence 的完整工作区快照进入精修；先安装正确 owner，再切换视图。不把目录展示条目或旧副本直接变成可写工程。
- 跨 Run 仍须排空旧编辑；失效或缺失快照仍走真实读取，旧响应不能覆盖新项目/模板。来源局部更新操作仍要求原有新鲜读取，不走编辑视图捷径。
- 不新增工程、不自动开始智能填充，不为进入工作台增长业务 revision。

## 验证

同模板 dirty/saving/慢保存/保存失败、空工程、有效跨 Run 缓存、旧 revision、两轮切换、项目切换迟到、SOURCE_UPDATE 不绕过；相关 Web 单测、类型检查、构建、diff --check；1920、1440、窄屏隔离浏览器延迟或拦截请求验证点击到工作台 DOM 的时序，不操作用户任务。
