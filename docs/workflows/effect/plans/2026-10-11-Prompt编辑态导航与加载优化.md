# Prompt 编辑态导航与加载优化

## 范围与边界

修复效果类 Prompt 编辑态切换渲染节点后返回时的误拦截，以及进入编辑时整页重建和重复读取。直接上游仍是 `marketing-insight:<productId>` 的已确认 revision；编辑草稿仍隔离于临时 Run，只有明确保存才提交 `prompt-batch:<productId>`，按真实变化使渲染待更新。导航不提交、不取消、不新建任务，不改变 AI 重复度快照。

## 实施

- 完整编辑生命周期补充：进入/退出编辑导致产品 ID 重新映射时，只读保留同项目、本次明确交接目标 Run 的旧产品、状态与分页内容，直到新工作区和结果加载完整后一次替换；独立切分支不复用。空态只能由完整加载后的权威空结果触发。父页面的工作区、草稿和概览并行读取，若发生批量模式归一化则重新读取归一化后的草稿。测试必须实际执行空编辑会话的进入与取消，不能仅以按钮可点或节点往返代表完整切换通过。

- 区分只读工作区同步与真实写入：只读加载可离开，正在交接 Run 时等待交接完成，不误报保存失败。
- Prompt 组件按项目缓存，不再按编辑 Run 重建；父页面提供已读取的编辑状态，取消子页面重复查询全局活动 Run。
- 编辑/保存/取消的 Run 交接使用完成回调，期间阻止旧作用域写入。切换编辑态不使用全页遮罩，保留分页、筛选及位置。
- 交接完成同时包含父页面作用域安装与 Prompt 当前工作区/结果读取；若读取被替换，等待最新读取。进入、取消及保存期间保留来源侧操作模式，并明确显示“正在进入／正在退出／正在校验”，只有目标数据就绪才一次切换控件，不能父页面先改变编辑态、目标按钮再等待数据。此机制不缩短后端副本事务，也不放宽 revision 校验。
- 批量导出按钮不设置 disabled，后台读取、编辑态及生成状态不影响其可点击性。交接中点击等待完成后导出权威结果，结果身份不一致时等待读取；无完整批次给出提示，重复请求合并为当前一次下载，不提交或修改任何工作副本。实际导出仍按项目、产品和结果身份校验。
- 工作区预取不阻塞父页面交接；停止离开页面后的延迟保存、搜索及任务恢复回写，防止跨 Run 的旧响应覆盖。

## 非目标

不修改生成模型、提示词、评估、付费执行、API 契约及 revision 规则。不自动保存或丢弃用户现有编辑。

## 验收

- 慢只读加载期间可从渲染返回 Prompt，不出现草稿保存失败。
- Prompt 编辑态往返保持草稿及分页，编辑切换无整页空白。
- 保存/取消及真实写入仍受保护；迟到请求不能覆盖已切换作用域。
- 执行相关导航、页面回归测试、Web 类型检查/构建、浏览器往返回归与 `git diff --check`；不启动付费任务。

## 本轮验证（2026-10-11）

- 导出补测：相关 48 项测试、类型检查与生产构建通过；腊肠已有编辑草稿下实际完成一次批次下载，1920/1440/768 宽度各连续采样节点往返加载期间，批量导出均可点击。未修改草稿、未调用付费任务。

- 完整交接补测：新增异步用例覆盖父安装先结束、节点读取延迟，以及被中止读取的替代请求；相关 93 项测试、Web 类型检查与构建通过。实际三轮空副本进入测试，目标编辑控件出现后保存、新增均可用且未再回灰；取消后“进入编辑”出现即启用。第二轮进入约 1.04 秒、退出约 0.59 秒，仅为本机观察；首轮退出在约 2.9 秒采样截止时仍在交接，后续确认完成，不能把所有退出均称为 0.6 秒。1440/768 宽度复测，第二页保留，窄屏新增弹窗可打开并取消。未修改任何 Prompt、未付费，取消的均为本轮空副本，原腊肠编辑草稿保留。

- 完整生命周期补测：在无既有编辑草稿的紫苏梅子酱项目中，真实创建并取消未修改的测试副本。修复前进入约 1.08 秒、退出约 0.70 秒，均采样到“暂无产品”；修复后两轮进入约 1.10/1.13 秒、退出约 0.59/0.58 秒，所有采样均保留内容和第二页，无空态。进入总耗时未测到明显下降，不把并行读取和减少预取表述为已经显著提速。最新副本 `createdAt` 至最终 `lastActiveAt` 相差约 415ms，仅作为数据库内副本准备时段的近似，不等同完整请求耗时。测试未修改 Prompt、未付费、未取消腊肠项目原有草稿。
- 进入/取消不再预取已发布版本树及相邻节点；保存和实际生成发布仍刷新树。父页面并行读取后校验 Run 与草稿身份再安装。增加 ID 映射过渡、取消返回、迟到完成及跨项目/分支边界检查，相关 89 项测试及 Web 类型检查/生产构建通过。
- 最终补测：明确编辑交接时，Prompt 工作区与已复制结果列表也改为并行读取；预读结果必须匹配项目、Run、产品、页码、每页数量及全部筛选条件，否则走正常加载。最终一轮进入约 1.11 秒、取消约 0.57 秒，采样未出现假空态，第二页保留。89 项相关测试、Web 类型检查及生产构建再次通过；仍不宣称进入编辑已经明显提速。测试完成恢复广式腊肠项目，保留其原有编辑草稿。
- 按钮补充修正：保存入口按编辑态显示，不再按瞬时操作权限挂载/卸载。同一项目/Run 已有完整工作区和结果时，后台工作区与列表读取不构成编辑锁；首次交接、结果身份不符、真实保存/删除仍锁定。实际修改开始前中止旧读取并推进请求代次，服务端 revision 校验不变。浏览器在 1920/1440/768 宽度各采样约 3 秒的节点往返，保存持续可见、新增持续可用；全新测试副本进入后连续观察约 4 秒（含延迟刷新），约 0.99 秒起两入口就绪且未再次闪变，空新增弹窗可打开并取消。未保存任何内容，随后取消本轮空测试副本并恢复原腊肠草稿。相关测试 90 项、类型检查及生产构建通过。

- 后续修正：返回同一 Run 的后台刷新不再禁用“进入编辑”。仅当已有成功快照与当前项目/Run 一致时允许立即进入；进入前中止后台读取并使旧请求失效，初次加载、错误及跨作用域仍受保护。三轮浏览器返回均确认按钮立即可用，新增作用域边界用例后相关 55 项测试及 Web 构建通过。

- 导航、预取、Prompt 状态及两个节点页面的 6 个测试文件：124 项通过；Web 类型检查及生产构建通过。
- 广式腊肠项目已有 Prompt 编辑草稿下，在 1920、1440、768 宽度各完成快速往返；第二页、编辑态及原 AI 重复度 6.7% 均保留，没有保存失败提示或浏览器错误。暖缓存往返约 0.73–0.76 秒，仅代表本机导航，不是编辑副本创建或生成任务耗时。
- 为保留用户现有草稿，未替用户执行保存、取消或新建付费任务，也未测量全新编辑副本创建的端到端耗时。
- 全量 Web 测试另有 34 项失败、1510 项通过，失败涉及混剪/导出等页面断言、全局动作及健康检查；不将本次相关用例通过表述为全仓库通过，未扩大修改其它功能。
