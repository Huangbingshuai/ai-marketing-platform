# 效果类 Prompt 人工编辑、导出与分页修复实施方案

状态：已完成

## 范围

- 保留单条新增、编辑、复制、删除、重新生成和批量导出。
- 人工新增与编辑允许调整单条片段时长，保存后继续进入异步用途评估。
- 批量导出改为 Excel/WPS 可直接打开的 UTF-8 CSV。
- 修复结果数量或筛选条件变化后出现“第 2 / 1 页”的页码越界。
- 彻底移除 Prompt 节点的批量导入入口、API、契约和解析逻辑。

## 非目标

- 不恢复六类生成配额或六类独立生成分支。
- 不自动提交 WorkingArtifact，不修改视频渲染节点。
- 不提供 Prompt 批量导入或通过导出文件回写草稿的能力。

## 数据与交互

- `UpsertEffectPromptItemRequest` 增加 `targetDurationSeconds`，API 按当前渲染能力校验范围。
- 编辑弹窗展示片段时长与动作复杂度提示；时长作为结构化渲染参数，不写入正文。
- CSV 每行包含商品、编号、干净正文、时长、推荐/兼容用途、六维、提炼来源、素材标签、共用提示词、画幅和分辨率。
- CSV 不包含内部 ID、revision、哈希、评分、模型信息、分类状态或存储信息，并防止单元格公式注入。
- 加载结果时先校正页码，再展示结果，避免短暂或持续显示越界页码。

## 验收

- Contracts、API、Web 相关测试与类型检查通过。
- Web 生产构建和 `git diff --check` 通过。
- 浏览器确认无批量导入入口，新增/编辑时长、批量导出和分页交互正常。
- 仅提交本任务文件，不覆盖工作区内其他未提交改动。

## 实施结果

- 已移除 Prompt 批量导入的契约、API、持久化分支、页面入口、解析逻辑和对应测试。
- 新增/编辑 Prompt 均可保存独立片段时长，API 会按当前模型能力范围二次校验。
- 导出文件已改为带 UTF-8 BOM 的 CSV，并增加公式注入保护。
- 分页在结果总数或用途筛选变化时先校正页码，再展示返回结果。
- Contracts 7 项、API 46 项、Web 20 项相关测试通过；全工作区类型检查、Web/API 构建及 `git diff --check` 通过。
- 正式浏览器验证了编辑弹窗 4～15 秒范围、5/5 页切换至单页筛选后的 1/1 页纠正、50 条 CSV 下载和零控制台错误。
