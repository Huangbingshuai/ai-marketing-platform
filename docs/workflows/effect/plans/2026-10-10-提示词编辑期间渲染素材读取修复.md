# 提示词编辑期间渲染素材读取修复

## 证据与提交边界

广式腊肠当前活动 Run 是未发布的 PROMPT_GENERATION 隔离编辑分支，具有已复制的产品及 Prompt，但没有下游 render-batch。渲染 workspace 将所有编辑分支视为自己的素材所有者，返回 batch=null；已确认父分支和渲染来源头仍有视频及工作副本，并未删除。

效果类视频渲染仍只消费已确认提示词。提示词草稿保存才发布上游差异，渲染草稿保存才影响混剪；读取不能保存、取消或发布任何编辑分支。

## 修改范围

- 渲染 workspace 为未发布的上游节点编辑（资料、提炼、Prompt）解析只读的已确认父作用域，用现有 editIdMap 的 productIdMap 找到父产品；身份缺失或映射不唯一明确报错，不猜名称、不混用其它项目。
- 在父作用域读取已确认 Prompt、渲染设置及共享渲染素材池，并用同一作用域计算真实待更新；响应保留请求的查看 Run/productId，防止前端轮询或迟到响应错判。
- 渲染自己的隔离编辑继续读取自身草稿；已发布分支继续按自身已保存 Prompt 与真实素材池计算差异。独立渲染边界保持不变。
- 提升 workspace 缓存投影版本，旧空投影不复用。不新增表、复制视频、自动生成、改写草稿或批量修复历史数据。

## 验证

覆盖三种上游编辑、渲染自身编辑、已发布分支、产品 ID 映射与跨项目拒绝。API 检查父作用域素材、提示词及设置一致；当前真实接口验证 batch 从 null 恢复且草稿 Run 不变。执行相关测试、类型检查及 diff 检查，不启动付费任务。

## 实施与实际验证（2026-10-10）

- 已实现只读父作用域解析与缓存投影升级。产品映射先限定实际直接父分支的有效产品，再检查唯一性，不将祖先别名误判为多产品。
- 真实 workspace 接口从 batch=null 恢复为 34 条完成素材；活动提示词编辑 Run 保持不变，未保存、取消或重新生成任何素材。
- 正式渲染组件连接该真实接口，在 1920、1440、390 宽度检查结果列表与分页；第二页 R035、R036 均存在。为避免切换用户正在操作的其它项目，使用临时只读入口挂载正式组件，验证后删除入口。
- API 渲染 repository/service/refresh 三组测试 133 项通过；Web 渲染 activation/prompt-scope/state 三组 39 项通过。API 生产 TypeScript 编译、Web 类型检查与生产构建通过（Web 保留已有大包体积警告）。
