# 智能填充工作流分片进度与只读详情

## 范围

- 移除模板混剪智能填充详情面板内的总进度条及其“关闭工作流”操作入口；关闭按钮只负责收起面板，不取消后台任务。
- 保留五个真实阶段，在节点卡片及详情中显示各阶段准确的已完成数/总数。
- 输入、输出摘要仅展示本次运行的真实素材与结果，最多各四项，不暴露 Prompt 原文或内部存储标识。
- 分类进度来自分类检查点；匹配按单次匹配操作计数；关键帧和截取按实际素材检查点计数；最终时间轴按真实 Run 终态计数。

## 数据与持久化

- 复用 `effect_template_mix_ai_runs` 中冻结的输入快照、分类、匹配与截取结果。
- 新增按 `materialId` 幂等合并的关键帧完成检查点；仅从有效 `projectId + runId + attemptToken` 写入并在 Worker 重新领取时返回。
- 扩展共享智能填充 Run 响应，提供五阶段进度与最多四项的用户可读输入/输出样例；保持旧消费者可选读取。
- 不改变 Run 的排队、取消、重试、输出草稿或 WorkingArtifact 提交边界。

## 非目标

- 不修改智能成片包装流程图或其任务进度。
- 不新增任务取消操作，不修改工作流整体阶段或任务编排。
- 不把总百分比线性换算成分片数量。

## 验收

- 分类检查点能呈现例如 `3/30`，刷新与 Worker 重领后保持一致。
- 并发关键帧/截取处理按已持久化素材数分别推进，不因阶段百分比估算。
- 详情输入/输出来自冻结快照与真实检查点，最多展示四条。
- API、Contracts、Worker、Web 定向测试、类型检查/构建与 `git diff --check` 通过。
