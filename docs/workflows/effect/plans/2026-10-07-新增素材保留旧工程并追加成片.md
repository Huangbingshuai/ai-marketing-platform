# 新增素材保留旧工程并追加成片

## 范围与非目标

- 修正共享渲染素材池变更后，既有时间轴跨兄弟混剪分支的精确素材依赖漏读。
- 新素材池决定成员集合，单素材已确认返修/重生成独立决定最新版本；新增素材不能把已采用修复退回旧文件。
- 新增素材使用现有 APPEND 智能填充链路，只追加包含新增素材的新组合。已包装模板仅自动包装新增工程。
- 不自动执行付费任务、不改写历史成片绑定、不删除文件、不自动更新兄弟混剪工程或已导出文件。

## 数据与提交边界

- 同项目、同效果类渲染来源头内，读取已确认时间轴依赖的精确 render-clip 工作副本；独立渲染头、手动复制与未发布编辑分支不得串入。
- 精确旧绑定用于播放与待更新判断，素材库仍只展示活动素材。素材成员删除后不得通过版本合并复活。
- 沿用 WorkingArtifact dependency 与 branchSourceOwner 投影，不新增 DTO、数据库字段或第二套状态。
- APPEND 冻结旧 variant ID 与新增 material ID，确认只提交新 timeline-project；包装与待渲染同步限定新 variant ID。

## 迁移

- 只读兼容投影，无数据库迁移；现存槽位绑定与文件未被删除，不需要还原或批量重写工程。

## 验收

- 新素材保存后，旧工程六槽位仍能解析；跨分支已确认返修仍为活动素材，不退回旧版。
- 精确历史引用可播放但不重复进入素材库；删除成员、未发布编辑及独立头严格隔离。
- APPEND 不改变旧工程，新增组合使用新素材，已包装模板仅对新工程包装。
- 执行相关单元/数据库回滚测试、API 类型检查与构建、diff check；浏览器核查旧工程完整槽位，不发起付费生成。

## 实施与验证记录

- 精确依赖补读与单素材版本合并已实施，画布渲染状态也使用实际单素材来源头，不能被旧复制件反向标黄。
- 修复追加任务准备时旧素材手动归槽 ID 漏投影：只继承可信同源用途与显式重置，不将旧视频传入新任务、不改写原绑定。
- 9 组 API 单测 241 项通过；3 组数据库测试 7 项通过、1 项条件跳过；3 组 Web 回归 30 项通过。API 类型检查、构建和 diff check 通过。
- 当前真实数据的只读追加输入检查：22 个活动素材、2 个新增素材、5 个旧工程、自动包装开启、整批替换关闭；在写任务前中止，没有付费调用。
- 浏览器旧工程六槽位解析恢复，5 条均为 38 秒，已包装音频/配乐/字幕仍保留。后续核查纠正：测试1剩余三条并非未处理的旧素材更新，而是先前已采用第2版的R-004在之后保存中被另一分支的第1版覆盖；详见[回退防护与恢复](2026-10-07-已更新成片素材回退防护与恢复.md)。
