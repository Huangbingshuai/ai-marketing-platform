# 混剪分支切换后渲染工作区为空修复

## 边界与事实

- 效果类视频渲染节点，直接上游为当前 Run 的 `prompt-batch:<productId>`；广式腊肠当前提示词 revision 11、渲染素材池 revision 5，接口仍返回 33 条有效素材。
- 新增模板、智能填充及包装可能改变 Run 和映射后的商品 ID。渲染页面按项目缓存，离开期间的 watcher 跳过加载，返回时却未重新选择新 Run 的商品，旧 ID 无法匹配而显示空状态。
- 本次仅修复 Web 的读取上下文，不改变提示词、素材、工作副本 revision 或保存边界，不新增任务、分支或数据库表，不重新生成素材。

## 实施

1. 每次读取渲染工作区前，使用父页面当前作用域的有效商品重新核对选择；原选择仍有效则保留，否则选择当前有效商品，没有有效商品才显示空状态。
2. watcher、页面重新激活及后台刷新统一进入同一加载入口，避免只在 watcher 中纠正商品选择。
3. 保留请求取消、加载代次、轮询及分支隔离保护；选择变化只触发一次加载，不重复请求。

## 验收

- 覆盖新增模板/智能填充后的 Run 商品重映射、离开期间多次切换、同 Run 返回、商品移除及空商品列表。
- 回归组件加载入口先纠正商品再读取工作区，旧响应不能覆盖新作用域。
- 执行相关 Web 单测、类型检查、构建及差异检查；浏览器验证节点往返和相关宽度。
- 不启动付费智能填充、包装或视频任务，不修改真实项目内容。真实付费任务完成时的回调路径由已有契约及新增回归测试验证。
