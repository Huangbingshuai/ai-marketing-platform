# 效果类全节点恢复性能优化

状态：第一阶段已实施；成片输出聚合待实施，浏览器真实计时受本地 API 500 阻塞

## 目标

优化效果类 `资料导入 → AI 信息提炼 → Prompt 生成 → 视频渲染 → 模板混剪 → 成片输出` 的首次进入、节点返回和刷新恢复速度，同时保持：

- `projectId + workflowRunId` 隔离；
- 草稿 revision、工作副本 revision 和后台任务租约语义不变；
- 旧请求不能覆盖新编辑；
- 页面恢复不触发生成、提交、归档或付费任务。

## 当前差异

| 节点        | 当前恢复链路                                                   | 主要问题                                 | 第一阶段                                 |
| ----------- | -------------------------------------------------------------- | ---------------------------------------- | ---------------------------------------- |
| 资料导入    | 工作区 → 草稿/模式归一 → Run 概览 → 最近删除 → 上传目标        | 多段串行，非关键数据阻塞首屏             | 并行独立读取，最近删除与上传目标后台恢复 |

| Prompt 生成 | 工作区快照 → Run 概览 → 当前结果 → 恢复任务                    | 概览串行，导航预取易过期                 | 并行读取；点击节点时立即预取             |
| 视频渲染    | 工作区快照 → Prompt 工作副本列表 → 轮询                        | 工作区与只读 Prompt 元数据串行           | 并行读取；点击节点时立即预取             |

## 第一阶段：不改 HTTP 契约

1. 节点点击后、等待当前节点草稿刷新期间，立即启动目标节点工作区预取；页面激活后复用同一在途请求。
2. 资料导入在取得基础工作区后并行读取草稿/模式归一与活动 Run 概览。
3. 最近删除产品和默认上传目标不再阻塞已有项目首屏；首屏成功后在相同项目和 generation 保护下后台恢复。
4. 信息提炼、Prompt 生成并行读取工作区快照与活动 Run 概览。
5. 视频渲染并行读取工作区快照与 Prompt 工作副本元数据；元数据失败仍保持现有非致命降级。
6. 所有并行请求继续共用作用域检查、AbortSignal 和 generation；项目或 Run 切换后旧响应不得安装。

## 第二阶段：成片输出聚合

新增只读的成片输出工作区聚合查询，一次返回：

- 当前模板路径的轻量目录；
- 每个模板最后确认的时间轴摘要和实际来源 revision；
- 成片 Run、待更新计数与导出进度；
- 首屏所需的三帧预览引用。

禁止成片页面为了读取而逐模板调用同步 POST。待渲染投影改在以下边界维护：

- 智能填充提交；
- 包装提交；
- 混剪草稿在尚无正式成片版本时的允许同步；
- 成片局部更新或整批导出提交；
- 独立的幂等修复任务。

聚合响应按 `projectId + workflowRunId + templateId` 校验，并返回目录 revision/ETag。页面已有相同 revision 时保持现有内容，只在后台更新导出进度。

## 不采用的方案

- 不把完整工作区长期缓存在浏览器并无条件复用；这会隐藏跨标签页、后台任务和分支切换产生的新 revision。
- 不通过删除历史 Run、减少模板或关闭任务轮询换取速度。
- 不将异步任务状态改为前端推测值。
- 不在页面进入时创建工作副本、同步资产或启动付费任务。

## 验收

- 六个节点首次进入、同 Run 返回、跨 Run 切换和刷新恢复均记录首屏可用时间。
- 同一节点的独立请求在浏览器网络记录中并行发起。
- 目标节点预取从用户点击导航时开始，当前节点保存失败时预取结果不得改变页面或业务状态。
- 后台恢复失败不清空已有可用内容；目标作用域主请求失败仍显示可重试错误。
- 成片输出第二阶段完成后，首屏不得再按模板 Run 发起 N+1 完整混剪工作区读取，也不得因页面读取逐模板 POST 同步。
- 运行相关 Web/API 测试、类型检查、生产构建及 `git diff --check`，再完成浏览器真实项目回归。
