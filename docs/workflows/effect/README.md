# 效果类工作流文档

固定流程：`资料导入 → AI 信息提炼 → Prompt 生成 → 视频渲染 → 模板混剪 → 成片输出`

- [Agent 必读业务指南](agent-guide.md)
- `plans/`：各节点实施方案和历史决策记录。
- `guides/`：面向开发者的通俗说明。
- `deployment/`：效果类专属存储和部署方案。
- `evidence/`：效果类浏览器回归与验收截图。

Prompt 节点只生成片段素材 Prompt；视频渲染生成素材片段池；模板混剪生成时间轴工程；成片输出才生成最终视频。

模板混剪当前已接入正式工作台和异步智能填充，具体数据和提交边界见 [正式前端实施方案](plans/效果类模板混剪-正式前端实施方案.md) 与 [模板混剪 Worker](../../../workers/effect-template-mix/README.md)；不把节点草稿或 AI 任务成功误称为已编码成片。
