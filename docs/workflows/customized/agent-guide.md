# 定制类工作流指南

固定流程：`资料包导入 → 标准化提炼 → 分镜脚本 → 镜头 Prompt → 视觉资产 → 逐镜渲染 → 素材交付`

## 业务目标

面向品牌宣传和定制视频：围绕一个明确 Brief 逐层确认脚本、镜头语言和视觉一致性，再逐镜渲染并交付素材。

| 节点 | 作用 | 直接上游 | 主要工作副本 | 直接下游 |
| --- | --- | --- | --- | --- |
| 资料包导入 | 导入 Brief、产品、人设、风格参考和约束 | 项目资料 | 定制资料包 | 标准化提炼 |
| 标准化提炼 | 统一客户诉求、卖点、受众、品牌调性和禁忌 | 定制资料包 | 标准化 Brief | 分镜脚本 |
| 分镜脚本 | 生成、导入、自定义和编辑多个分镜版本 | 标准化 Brief | 分镜脚本版本 | 镜头 Prompt |
| 镜头 Prompt | 为主脚本每个镜头生成可编辑 Prompt 与校验建议 | 主分镜版本 | 逐镜 Prompt 包 | 视觉资产 |
| 视觉资产 | 绑定项目内产品、人物、场景、字幕和音频资产 | Prompt 包、项目资产 | 视觉资产绑定方案 | 逐镜渲染 |
| 逐镜渲染 | 按镜头创建独立渲染任务并保留失败重试 | Prompt、资产方案 | 逐镜素材集合 | 素材交付 |
| 素材交付 | 选择、整理、导出镜头素材和交付清单 | 逐镜素材 | 交付包、清单 | 项目归档/交付 |

## 固定规则

- 每个分镜版本是独立工作副本；版本名称可修改，镜头文本可直接编辑。
- 自定义分镜版本初始为空白，不复制现有版本内容；删除最后一个镜头时可删除该空版本。
- “导出当前版本”导出一个完整分镜脚本版本，不是勾选若干镜头批量导出。
- 镜头 Prompt 必须引用实际分镜字段；每条可查看对应分镜、编辑建议并重新生成，即使校验通过也允许人工修改。
- 逐镜渲染是一镜一任务；镜头失败不应导致已完成镜头丢失。
- 工作流资产选择器默认只读取当前项目资产；跨项目资产先复制到当前项目再绑定。

## 下游依赖

镜头 Prompt 绑定主分镜版本的具体 revision。切换主脚本或确认脚本新 revision 后，已有 Prompt 包待更新；视觉资产方案和逐镜素材依次根据自己真正消费的上游版本判断，不进行全链路盲目失效。
