# 定制类工作流指南

固定流程：`资料导入 → 信息提炼 → 脚本创作 → 资产准备 → 视频制作 → 素材交付`

## 2026-10-12 节点拆分

依据用户确认，第三至第五节点已按[修订计划](plans/2026-10-12-定制类脚本资产视频制作节点拆分.md)改为脚本创作、资产准备、视频制作。技术 nodeId 暂保留 STORYBOARD / SHOT_PROMPT / SHOT_RENDER 以兼容既有数据。下文旧“分镜创作与独立脚本分支”章节记录拆分前的实现；新的生成边界以本节为准。

新脚本任务冻结 STORY_ONLY，只输出完整故事，移除 ASSETS/SHOTS 阶段；旧任务保持原检查点恢复。新故事包括正文、开场、发展、收束、对白安排及叙事段落；段落不是镜头。多方案、单份成功发布、编辑与导入导出继续使用现有 storyboard API。

资产准备消费选定脚本和简报，生成产品/人物/场景/道具定义。已确认信息、设计内容、来源与图像制作要求分开保存；图片可以稍后准备。视频制作在同一工作台完成分镜、实际绑定和单镜 Prompt。制作任务采用输入快照、制作规划、创作、独立审校、定向修订/复核、保存六阶段；长分镜按不超过60秒的叙事段落分批并保存检查点，模型并发最多2。Prompt模型只收到本镜及绑定子集。

资产/分镜生成先写草稿，用户保存修改确认；Prompt完整生成并审校通过自动提交。key为 customized-asset-catalog、customized-object:<id>、customized-video-plan、customized-shot:<id>、customized-shot-prompt:<shotId>。同内容不增revision；只将实际依赖改变对象的Prompt标为待更新。旧脚本只读投影，明确保存才建立新产物。

各已接通异步节点使用独立 Worker，调用受保护 API，不直接访问数据库：

| 节点 | Worker | 队列 |
| --- | --- | --- |
| 资料导入 | 无 Worker | 无 |
| 信息提炼 | customized-extraction-worker | customized.extraction.requested |
| 脚本创作 | customized-storyboard-worker | customized.storyboard.requested |
| 资产准备 | customized-assets-worker | customized.assets.requested |
| 视频制作 | customized-production-worker | customized.production.requested |
| 素材交付 | 异步交付尚未实现，接通时独立部署 | 尚未创建 |

资产 Worker 只处理 ASSETS，视频 Worker 只处理 SHOTS / PROMPT；独立入口、镜像、锁文件、队列和凭据，两者复用共享执行底座。内部 API 在领取及所有回调校验节点归属；旧视频队列的排队资产任务通过 Outbox 转交。来源快照、草稿、正式提交和下游待更新规则保持不变。运行见[资产 Worker](../../../workers/customized-assets/README.md)及[视频制作 Worker](../../../workers/customized-production/README.md)，隔离依据与验证见[实施计划](plans/2026-10-13-节点Worker隔离与资产Worker补齐.md)和[验收记录](evidence/2026-10-13-资产Worker隔离验收.md)。UI继续复用效果类共享卡片、字段、编辑动作、进度条、工作流图、确认和底部导航。

本轮止于提示词生成，资产图片生成/上传替换、视频渲染、成片及交付未接通；不得以节点存在声称渲染可用。验收结果单独记录，不用历史付费测试代表新链路质量。

资产准备已整体改为分类侧栏、搜索/图片状态过滤和封面卡片网格；公共定义、事实、设计、图像要求和来源在共享详情弹窗编辑。单项/批量图片制作入口可查看实际内容，服务未接通时禁止提交。视频制作使用镜头列表、画面与氛围、完整候选素材库、提示词及逐镜预览/输出设置/历史面板；候选素材不等于本镜绑定，只有勾选项进入本镜 Prompt。没有真实图片、视频记录时展示空态。取消编辑重新读取权威工作区，恢复绑定与提示词状态。调研及实施见[UI 重构计划](plans/2026-10-12-资产工作台与视频制作UI重构.md)，浏览器检查与工程结果见[UI 验收记录](evidence/2026-10-12-资产与视频工作台UI验收.md)。


## 业务目标

面向品牌宣传和定制视频：围绕一个明确 Brief 逐层确认脚本、镜头语言和视觉一致性，再逐镜渲染并交付素材。

## 当前实现边界

正式前端已接入固定六节点画布，直接复用效果类画布组件。资料包导入分为“视频创作简报”和可选的“品牌素材”两个区域。制作目标、产品介绍和规格、希望的呈现方式统一写在一份简报文档里再上传，也可同时导入多份补充文档。页面不提供文本编辑或从项目资产库选取功能。不另设需求摘要、品牌调性、视频规格或禁止元素的必填配置表。

品牌素材图片可标注品牌 Logo、品牌标准字、品牌图案、品牌 IP、包装平面图五种用途，新上传不猜测用途；不要求用户提供产品成品图片，品牌规范文档可作为左侧补充文档上传。保留 VISUAL_REFERENCE 区域标识、schemaVersion 3 以及全部旧图片和固定文件版本，原产品、人物、场景、风格、其他用途仅在对应条目中显示为历史资料，不自动改写。图片仍可不上传；本节点不生成资产。正式页面、校验提示和模板均使用面向使用者的称呼。

上传卡片、拖拽上传框、文件行、图片缩略图与内容阅读器从效果类抽为共用展示组件。选择或拖入文件后直接上传到当前项目定制资料库并自动保存引用，失败项保留供重试；文档进入视频创作简报区域，图片进入视觉参考区域。支持下载视频创作简报模板及只读查看文档/图片；移除引用不删除原资产。无法站内阅读的文件可打开原文件。

视频创作简报模板提供可编辑的 Word 表格，沿用采集表的表格形式，列为“填写项 / 填写内容 / 备注与示例”。按最新需求分为品牌基础信息、产品核心信息两部分，共 12 项。品牌部分包含品牌名称、项目名称、项目背景、品牌调性、视觉统一规则、画面禁用元素；产品部分包含产品名称、产品介绍、产品规格、产品外观、核心卖点、目标受众，严格分开品牌与产品名称，不以混合名称猜测归属。产品介绍、产品规格、产品外观分别填写，不增加使用方式字段，也可上传已有补充文档。外观未确定时可注明待确认或请 AI 提方案，不将生成方案当作已知产品事实。核心卖点支持分行填写多条资料支持的独立优势，不固定条数、不划分核心与次要层级；后续脚本可选择重点或自然组合，不要求每个版本覆盖全部卖点，也不按卖点数量分配脚本版本。目标受众为一个文本字段，可描述年龄、性别、地域、兴趣、消费习惯和内容偏好，未限定的可留空或填不限，不另设受众筛选与必填校验。移除视频规格区域及视频时长、视频分辨率、视频画幅、视频格式，两个部分第三列均为备注 / 示例，每项均提供同一虚构陶瓷杯产品的具体例子，卖点示例每行一条。品牌调性、视觉统一规则和画面禁用元素合并到品牌部分；记录品牌应保持的气质、已明确的视觉规则与禁止出现的画面内容，可留空，不要求提前锁定故事结构或创意方案。人物和产品外观、品牌标识等一致性要求写入视觉统一规则；各脚本版本可在已明确约束内探索不同叙事与表现方式。未知内容可写待确认或请 AI 提方案，不涉及的留空；涉及成分、性能、数据和效果时提供说明资料。模板不另设参考资料、其他补充、文案、声音、配乐及交付栏目，图片仍独立上传。不使用“客户”称呼，不要求样片、专业机位或已有故事。页面下载直接引用[Word 模板](templates/视频创作简报模板.docx)，另提供[虚构填写示例](templates/视频创作简报填写示例.docx)，两份文件由同一字段定义生成。历史文字导出为 TXT。设计依据见[项目分析与开源调研](plans/2026-10-08-视频创作简报模板设计.md)，最新字段布局以[前端修订计划](plans/2026-10-09-信息提炼前端.md)为准。信息提炼与分镜创作已接通以下真实链路，Prompt 及后续生产仍属于后续消费设计。

当前草稿格式为 schemaVersion 3。v2 的两块文字合并并保留产品资料标题，文档引用合并到简报区域；v1 的原需求、调性、禁忌和已填写的视频规格保留为文字，旧图片按实际文件身份归入图片区。读取投影不修改历史数据；旧版填写文字保留为只读内容，可下载为简报文档，至少上传一份有效文档后才可确认新内容。已确认历史内容原样保存不增长业务 revision；实际变更须满足文档校验。

资料包导入复用效果类的“进入编辑 / 取消编辑 / 保存版本”按钮、编辑提示条和取消确认。自动保存仅写 `SOURCE_IMPORT` 节点草稿；用户“保存版本”经服务端校验草稿 revision、完整性及资料作用域后提交 `customized-source-package` WorkingArtifact。资料引用锁定同项目、定制资料库的资产版本。首次确认在当前 Run 保存；已确认内容只读，进入编辑创建隐藏子 Run，刷新恢复编辑，取消返回原版本。同内容保存不增加业务 revision、不发布空分支；实际变更保存后发布新资料分支，父版本保持不变。

六节点画布和版本分支树直接使用效果类组件，共用布局尺寸、节点连线、当前路径、缩放、查看全图、定位当前、滚动、键盘关闭与焦点恢复。普通节点导航与效果类共用后台同步队列，保存草稿后立即切换，连续点选只同步最新待执行目标；编辑切换共用提示组件，保留当前内容与滚动位置。画布前序步骤高亮仅表达导航位置；确认状态、下一步校验及版本树仍只读取真实产物。分支树读取定制类专用作用域接口，导航与显式历史切换不增加业务 revision。信息提炼已接入专用 API / Worker，直接消费已确认资料包的 `artifactId + revision`；分镜创作已接通独立 Worker 与逐份发布；资产定义、分镜和单镜Prompt已按上文接通；图片、视频渲染与交付尚未接通。

## 信息提炼链路与提交

第二节点已接入“视频创作信息卡”前端，字段名称、分组与顺序和下载的 Word 模板一致：品牌基础信息、产品核心信息两块卡片，共 12 项。项目名称读取简报中的名称，不修改系统项目；品牌名称、产品名称使用独立字段，不从历史混合文本推断归属；产品介绍、产品规格、产品外观和目标受众为独立多行文本，不增加使用方式字段。核心卖点复用效果类抽出的 WorkflowSellingPointsEditor 共享组件，以独立字符串数组维护，逐条添加、编辑、删除；已有内容删除前确认，不通过换行合并条目，不另设产品事实分类。品牌调性、视觉统一规则和画面禁用元素合并到第一张品牌卡，均为多行文本；移除视频规格卡和四项规格字段，不另设风格、色彩、情绪选项和品牌规范字段。两卡复用品牌 / 产品标记、浅色背景与标题分隔，宽屏左右并列，窄屏按模板顺序单列。卡片和基础字段从效果类提炼页面抽为共用组件，加载、编辑动作、进度、底部导航及资料阅读器继续复用现有组件。顶部不另设资料摘要和确认提示栏；字段来源与差异入口仍读取当前已确认资料的固定引用，未确认的导入编辑草稿不作为提炼来源；图片保留参考用途，不由文件名推导产品事实。未恢复模板已删除的声音、文案、交付等栏目。

信息提炼已接通真实工作区、异步任务、阶段详情、编辑草稿与版本确认。两类页面直接引用同一工作流图弹窗、动作和提示组件，使用同一轮询工具及 WorkflowRunProgress。效果类保留三路并行图；定制类内部图为资料快照 → 文档解析 → 文档信息提取 → 多文档融合 → 语义精炼 → 标准化与保存。状态、进度及详情来自 API，切换项目 / Run 取消旧请求，查询断网不把任务标记失败。409 保留本地修改，用户主动加载最新内容才替换。

独立 `workers/customized-extraction` 使用独立队列 / Token / 生命周期，与效果类共同依赖 `workers/shared/extraction-runtime` 的 Docling、模型初始化、分片、表格、结构化请求与内部 HTTP 工具。支持 docx/pdf/xlsx/txt/md；新上传不接受 doc/xls，历史引用保留并提示转换。标准表格只读取填写内容，排除备注 / 示例；非标准资料分片提取，多文档由 AI 融合及核对事实、归属与差异，代码只校验结构、来源、版本和索引。品牌图片固定引用供后续视觉生成，不进入模型输入；引用缺失独立提示，不冒充文档失败。

语义精炼对标准模板与自由文档都执行独立原文审校：清除示例列后逐文档分片检查全部 12 字段，报告遗漏、归属错误、错误断言和实质冲突，引用固定版本原文并校验引文存在。有问题时由 AI 修正，保留未涉及字段和独立卖点，再核对冲突候选。自由文档分片结果由 AI 语义整理，不机械拼接。成功文档审校可在同任务恢复时复用；审校失败不允许确认。共享工作流详情展示审校文档、片段、问题及原文依据，历史已确认产物不自动重写。设计见[原文审校增强](plans/2026-10-10-原文审校与提炼增强.md)。

任务、阶段、结果、解析产物及文件持有记录使用定制类独立表，以项目 + CUSTOMIZED + Run 隔离，复用 Outbox、权限、存储和清理基础设施。任一应处理文档失败，成功检查点保留，整体未完成不可确认；重试同任务同输入复用成功文件和步骤，主动重新提炼创建新执行。租约、attempt token、来源指纹、活动编辑作用域共同拒绝迟到结果。已完成工作区使用现有 Redis 只读投影缓存，每次 PostgreSQL 复核；活动任务绕过缓存，不缓存原文、文件和签名 URL。

AI 完成只形成待确认结果，自动保存只写结果草稿。用户保存版本才提交稳定 key `customized-brief`，依赖本 Run 的准确资料包 artifactId + revision。产品名称与至少一条有效卖点必需，其他字段可留空；全部阶段完整成功且差异已处理才可确认。项目名称是简报字段，不修改系统项目名称。同来源重提继承人工覆盖；资料版本变化清除旧覆盖，全部字段按新来源重新提取，历史仍保留。

首次确认在当前 Run 保存；已确认信息编辑 / 重提创建隐藏编辑 Run，取消返回原版本并拒绝失效执行回调。同内容保存不增加业务 revision、不发布空分支；变化保存才发布。来源变化后旧结果可查看，重新提炼并确认后才可继续分镜；仅使实际依赖旧 Brief revision 的已有产物待更新，不创建尚未实现的下游产物。实施和验证边界见[后端与共享交互](plans/2026-10-09-信息提炼后端与共享交互.md)，运行见[Worker 说明](../../../workers/customized-extraction/README.md)。

## 分镜创作与独立脚本分支

暂时模型故障按同任务、同输入检查点自动恢复：请求有限重试后，任务退避 15 / 30 秒，总计最多领取 3 次，只重试相关方案；已完成脚本不覆盖。故事及镜头分段结构不合法时保留模型结果，最多纠正一次，预算跨重启保存。审校问题最多修订与复核一次，仍有错误不发布、不反复付费修订。修订以有类型的变更字段应用于完整原稿，正常内容保留，完整修订稿仍独立复核；补丁与合成稿保存后再复核，恢复不重做已有修订。审校及复核按当前脚本准确镜头 ID 收紧输出 Schema，并按真实累计镜头时间轴核对顺序；语义修改仍由 AI 判断。新任务连续故事段落可合并为不超过 60 秒的请求，固定分片计划后再生成，历史检查点保持原边界。优化边界见[性能计划](plans/2026-10-12-分镜性能与定向修订优化.md)，本轮实测见[性能付费验收](evidence/2026-10-12-分镜性能优化付费验收.md)，基线见[真实付费验收](evidence/2026-10-12-分镜真实付费验收.md)。

第三节点已有正式前端工作台：创作设置、多方案卡片、脚本概述、逐镜编辑、排序、完整方案对比、整套导出及 JSON 脚本导入。共享画布、版本树、编辑动作、字段、确认、加载、工作流弹窗及底部导航继续复用系统组件；使用效果类相同的标题按钮尺寸。宽屏方案横排，逐镜脚本与资产需求左右组织，窄屏自适应。

分镜使用专用 `projects/:projectId/workflows/customized/storyboard` API。创作设置默认展示目标时长（30 秒）及新增方案数（3 份），AI 范围为整数 15–180 秒、1–5 份；更多设置包含 AI / 参考 / 自定义叙事结构及补充要求。已有超范围草稿仍可阅读与手工编辑，AI 生成前要求调整设置，不截断历史内容。

冻结已确认有效的 `customized-brief` 的 artifactId / revision / fingerprint，以及本次设置、固定模型名称和品牌素材版本引用。独立 `workers/customized-storyboard` 不解析原文、不调用视觉模型；按信息卡快照、多方案构思、完整故事、资产目录、逐镜脚本、独立审校、定向修订、保存分支执行。每份脚本可选适合故事的真实卖点，代码不代替 AI 进行语义判断。长故事按叙事段落分片，保持完整故事、对象目录与相邻镜头上下文；模型调用全局并发默认为 2。

单份脚本完整成功、审校通过且符合引用与时长校验后立即事务性发布自己的兄弟分支，稳定产物 key 为 `customized-script:<scriptId>`；每份脚本都有独立实际 Run，不借用 templateId。首次成功的方案作为默认查看项，选择和刷新不增加业务 revision，也不发布分支；再次创作追加方案，部分失败保留已发布脚本。相同任务恢复使用有效检查点，不重新生成成功脚本；主动再次创作创建新批次。

手工编辑写独立脚本草稿，显式保存修改才更新该脚本当前分支；取消恢复已确认内容，内容相同不增加业务 revision。expectedRevision 冲突保留本地修改；项目、任务及脚本切换取消旧请求。人工新建为空白，首次有效保存才建立分支；导入重映射脚本及对象身份。旧多方案草稿只读兼容，主动进入编辑才迁移为独立草稿，打开页面不会发布。

效果类 Prompt 与本节点直接引用同一个 `WorkflowExecutionGraphDialog` 和 `WorkflowRunProgress`。八个节点详情只投影已持久化的故事、对象、镜头、审校问题和修订前后内容，完整内容分页加载；不展示系统提示词、模型思考、原始 JSON 或内部存储标识。无任务时为空状态；正式界面不再提供虚构示例与未接通的单镜头重新创作入口。

界面精简以实际后端能力和完整业务内容为准：基础设置展示时长、数量，创作依据与高级设置按需查看；只读镜头不堆叠禁用编辑按钮，进入编辑后仍支持完整编辑、排序和删除。空台词、音效与衔接不展示重复占位，实际内容保持可见或可展开；对比包含衔接说明，脚本资产目录包含未被镜头引用的对象。真实生成、发布、导入导出、任务状态、恢复与阶段详情保留，不用删字段换取简洁。说明见[前端精简计划](plans/2026-10-12-分镜前端真实交互与界面精简.md)。

当前脚本已提交且来源有效时，可进入其自身的 Prompt 路径，本次未实现 Prompt 模型任务。上游变化仅使实际依赖旧 revision 的产物待更新，历史脚本保留。实现与验证见[实施计划](plans/2026-10-12-分镜生成与独立脚本分支.md)、[验收记录](evidence/2026-10-12-分镜生成验收.md)及[Worker 运行说明](../../../workers/customized-storyboard/README.md)。

分镜统一查看不设置主脚本：同一信息卡版本下的所有已发布脚本属于当前工作流，版本树同时高亮，仅当前查看项带查看标记。列表或版本树点击脚本只保存查看偏好，不激活其 Run；刷新优先恢复偏好。点击下一步或画布后续节点时，才进入所选有效已确认脚本的实际路径；独立存储、版本和下游引用仍按脚本隔离。进度条仅在排队 / 运行时展示，终态移除，失败原因、恢复操作和顶部工作流详情入口保留。规则与验收见[统一查看计划](plans/2026-10-12-分镜统一查看与路径选择.md)。

每镜另维护人物、产品、场景三类资产需求，宽屏位于脚本右侧，窄屏排在下方。脚本内对象使用稳定 ID 与公共外观定义，镜头引用对象并独立描述本镜姿态、露出和光线等要求；同一对象跨镜复用，不以名字或画面关键词推断关联。三类分别区分尚未定义、本镜不需要和已定义。公共定义编辑提示关联镜头，保存镜头后同步引用显示，取消不泄漏修改；移除本镜关联保留其他引用。对比、TXT/JSON 导出及草稿恢复保留需求；导入复制对象身份并重映射引用，旧 v1 无新字段仍兼容读取。此处只定义资产需求，不生成图片、不绑定真实 ProjectAsset、不展示模拟生成状态。实际图片生产仍归逐镜视频工作台。设计见[分镜资产需求补全](plans/2026-10-10-分镜资产需求补全.md)。

## 资料包后端与文件版本

SOURCE_IMPORT 已接入专用上传 API，仍复用共享项目、资产、文件存储、节点草稿和版本提交机制。上传入口按 `projectId + workflowRunId + CUSTOMIZED + CUSTOMIZED_PROJECT` 校验当前编辑作用域；文档和图片分别校验扩展名、MIME、实际大小及文件头。单文件上限 100 MB，失败文件保留在前端供重试。按原文件名与内容 SHA-256 幂等，同内容重试不增加资产版本；同名不同内容生成独立资产，避免覆盖历史资料包。

读取、预览和下载按资料包固定的 `assetId + assetVersion` 返回当时的文件；当前资产出现新版本不会使旧资料包失效或自动替换其内容。保存版本前确认固定文件可读取，事务内再次校验所有引用版本的项目、工作流、目录、类型与状态。上传过程中取消或切换 Run，迟到结果不能写入新的草稿；已上传文件按现有项目资产规则保留。

实现计划见[资料包后端接通](plans/2026-10-08-source-import-backend.md)。隔离真实接口验证脚本为 `apps/api/scripts/verify-customized-source-import.mjs`，只操作随机测试项目，不触发模型。

活动 Run 概览、SOURCE_IMPORT 文件引用草稿及版本树复用效果类的 Redis 只读投影缓存。每次读取核对 PostgreSQL 的项目、CUSTOMIZED / CUSTOMIZED_PROJECT 作用域及依赖行版本，编辑/取消/发布/切换或保存后立即换键；迟到读取复核失败后重新加载。只缓存无历史文字的当前资料草稿，其他节点、历史文字、文件正文、二进制和签名 URL 不进入缓存。Redis 故障回源，业务 revision、固定文件版本、确认提交及存储可读校验保持原边界。配置复用 `EFFECT_READ_CACHE_*`，无数据库迁移；项目删除会同时清理定制类缓存。计划和验证边界见[资料导入 Redis 缓存](plans/2026-10-09-资料导入Redis缓存.md)。

## 固定规则

- 六节点顺序按使用者确认的截图定义；资产准备与渲染共用第五节点。旧 `VISUAL_ASSETS` 导航与分支节点在读取时映射为 `SHOT_RENDER`，历史记录和业务 revision 不变。画布及版本树使用效果类组件的同一尺寸。调整与验收范围见[六节点画布调整](plans/2026-10-08-六节点画布调整.md)。

- 每个分镜版本是独立工作副本；版本名称可修改，镜头文本可直接编辑。
- 自定义分镜版本初始为空白，不复制现有版本内容。当前脚本操作区支持永久删除：确认后硬删除脚本及其全部后代分支的任务、检查点、草稿、工作副本、历史版本和该路径归档的项目资产，独占文件进入持久后台清理队列；兄弟脚本及共享上游保留，仍被引用的文件不删除。活动分支被删除时返回保留的上游版本，同批任务按剩余脚本继续，迟到回调不能恢复已删除脚本。已确认脚本的最后一个镜头被移除时只形成不完整编辑草稿，不能保存为正式版本。
- “导出当前版本”导出一个完整分镜脚本版本，不是勾选若干镜头批量导出。
- 镜头 Prompt 必须引用实际分镜字段；每条可查看对应分镜、编辑建议并重新生成，即使校验通过也允许人工修改。
- 逐镜渲染是一镜一任务；镜头失败不应导致已完成镜头丢失。
- 工作流资产选择器默认只读取当前项目资产；跨项目资产先复制到当前项目再绑定。

## 下游依赖

产品视觉资产由后续逐镜视频节点内的资产准备生成。简报中的产品介绍、规格、外观共同说明产品身份、结构比例、材质颜色、内容物状态和标识位置；外观注明已经确定的特征与允许 AI 设计的范围，不新增模板必填字段。品牌素材提供已有标识与图形依据，不能单凭 Logo 推断真实产品外观。后续应先生成产品基础形象供用户确认，再按脚本补充多角度、材质和细节资产并绑定镜头；不同脚本版本在各自叙事中保持已确认产品特征。资料不足的外观是待确认方案，不能作为已还原实物。这是后续实现要求，本轮仅完成导入与模板调整，未接通资产生成任务。实施见[品牌素材导入与产品形象依据](plans/2026-10-09-品牌素材导入与产品形象依据.md)。

镜头 Prompt 应绑定当前独立脚本的具体 artifactId + revision。浏览其他脚本不使已有 Prompt 失效；确认当前脚本新 revision 后，仅实际引用旧版本的 Prompt 包待更新；逐镜视频节点内的视觉资产方案和逐镜素材分别根据自己真正消费的上游版本判断，不进行全链路盲目失效。

原文审校建议不直接作为修正答案：涉及字段会独立重读全部文档片段，收集带逐字引用的支持事实，再结合跨片段上下文修正，保留互补品牌调性、规格与条件。逐字引用核验失败或依据收集失败仍未完成。原文审校及真实验证见[增强计划](plans/2026-10-10-原文审校与提炼增强.md)。
