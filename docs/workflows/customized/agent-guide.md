## 当前交互与任务规则

2026-10-20 逐片段 Prompt 与 Render 支持不同片段并行，同片段两种任务互斥。已保存的提示词可以立即渲染，不必等待其他片段的提示词完成；整体分镜、资产和历史无片段目标任务仍占用整个 Run。页面按当前片段锁定提示词与渲染，其他片段可切换操作，整体分镜编辑继续冻结；并行任务分别轮询和原位提交，不新增分支。Worker 有界并发默认 4，文本模型并发上限保持 2。见[并行计划](plans/2026-10-20-逐镜提示词与视频并行.md)。

2026-10-20 按用户最新要求，脚本卡片选择保存成功后同步激活对应路径，版本树仅高亮当前路径。当前 Run 已属于所选脚本的制作后代时保留该 Run；切回其他脚本优先恢复本页面记住的有效后代，否则选择其已有最新制作后代，无后代才进入脚本 Run。版本树明确选择版本仍精准激活。下一步、画布及上游回看继续沿该路径；导航不生成付费任务、不增加业务 revision。切换请求串行，过期响应不刷新旧路径，失败保留原选择。详见[选择与路径同步计划](plans/2026-10-20-脚本选择与当前路径同步.md)；本规则覆盖历史“只保存查看偏好”和“同源全部脚本高亮”行为。

普通画布/下一步导航进入资产准备或视频制作时，当前路径若属于同一脚本的制作后代，保留当前 Run；换选脚本才切换，版本树显式选择仍精准激活目标。附属对象按 `preparation` 复用有效父资产图片，不作为独立缺图/默认生图项；单项入口直接打开父对象图片制作窗口，视频缺图入口导航到父对象，原镜头绑定 ID 保留。人工调整归属仍走资产编辑及保存流程。详见[前端验收](evidence/2026-10-19-资产归属与上游回看前端验收.md)。

2026-10-20 资产卡片与跨节点定位直接打开图片制作窗口，移除中间的只读资产查看页；“编辑定义”保留独立的编辑入口，不经只读预览。图片制作窗口宽屏最大 1320px，窄屏自适应；移除输入框底部的参考图说明与“恢复默认提示词”入口。点击卡片仅查看和准备输入，仍需用户主动点击生成才创建图片任务，原有图片、引用与任务状态不因此改变。

视频参考素材的缺图交互参考火宝：保留类别占位；已绑定且无图片时显示“未生成 / 去生成”，点击沿正常节点导航返回资产准备，不在视频制作直接打开生图弹窗、不触发付费任务或变更绑定。已有图点击缩略图预览；未绑定项点击卡片绑定后再显示缺图入口。导航复用现有分镜/提示词保存保护，冲突保留当前页面和本地修改。

末节点视频制作按用户最新要求直接编辑、自动保存，移除进入编辑、取消编辑、保存修改和提示词保存按钮。真实修改防抖确认，生成前及离开前等待保存；恢复草稿即使没有新按键，也在生成前确认。提示词输入`@`可选择本镜已绑定素材，支持名称筛选、缩略图和键盘；未完成引用保留文字，不自动保存错误引用。正常浏览不提交，模型运行期间保护输入，失败保留本地改动。资产准备编辑流程保持原样；下文旧版“人工保存分镜”描述以本节为准。见[交互计划](plans/2026-10-19-视频制作直接编辑与素材引用交互.md)。

已引用素材在编辑时显示为浅色行内标签，顺序为`@、缩略图、完整名称`；AI正文与粘贴的已知引用也使用相同显示。标签整体删除、撤销重做，复制/剪切/保存保持纯文字，不持久化编辑器JSON或图片地址。菜单跟随光标并限制在可视区，图片缺失不改变引用。富文本编辑器按需加载；真实五镜付费结果、已修复误报与响应式证据见[验收记录](evidence/2026-10-19-五镜提示词付费与行内素材引用验收.md)。

逐镜提示词新任务冻结`promptWorkflowVersion=3`（V3问题须引用当前提示词原句；历史V2保留原Schema）：本镜创作依据 → 画面与素材安排 → 视频提示词创作 → 独立审校 → 按需修订复核 → 原位保存。正常两次主要模型调用，成功自动提交当前`customized-clip-prompt:<clipId>`，不新增分支或改上游。右侧提示词“查看工作流”只查看当前分镜PROMPT任务，顶部入口只查看SHOTS，均使用`WorkflowExecutionGraphDialog.vue`。页面顶部进度仅用于SHOTS；PROMPT在当前镜头提示词区域显示阶段及紧凑进度，RENDER在右侧播放器内显示加载与细进度。两者均不占用页面顶部的分镜进度条，终态后局部进度消失，旧视频在重新生成时保留。切镜只显示对应任务，轮询与锁定仍使用真实运行状态。见[进度分区计划](plans/2026-10-19-视频制作任务进度分区.md)。候选素材不等于实际引用；右栏只显示当前正文完整`@素材名称`对应的已有参考图，手动编辑实时同步。服务端及Worker校验实际引用与`assetIds`一致，新提示词可只用候选子集，历史任务规则不变。逐镜渲染已接通，见后文渲染边界。见[计划](plans/2026-10-19-逐镜提示词工作流与右侧查看入口.md)。

节点任务展示按操作归属隔离：资产准备仅使用 ASSETS / IMAGE，视频制作使用 SHOTS / PROMPT / RENDER；进度、工作流详情、按钮运行态和前台轮询不借用另一节点任务。视频素材库发起的 IMAGE 只静默刷新图片，不显示为视频制作进度，异步刷新不得覆盖请求期间的新编辑。

资产生图使用局部加载交互（2026-10-20）：资产准备顶部`WorkflowRunProgress`仅展示ASSETS，IMAGE不进入页面进度条。单图提交后`ProductionRenderDialog`保持打开，`ProductionImageComposer`在当前图片上显示转圈与排队/生成状态，原图和输入继续保留，可关闭窗口让后台继续。`ProductionAssetStudio`对应独立资产卡片同步显示状态并可重新打开；批量按真实已保存对象逐项结束等待。`ProductionImageStatus.vue`只显示状态，不模拟百分比。只读`completedImageAssetIds`来自任务已持久化图片，刷新可恢复，失败保留已成功项、旧图与输入；新任务、轮询和提交规则保持不变。见[局部加载计划](plans/2026-10-20-资产生图局部加载交互.md)。

视频制作页面不额外展示总时长“制作设置”面板；沿用已有脚本参考时长与持久化的制作时长策略，任务快照、固定时长校验及逐片段时长不因隐藏该面板而改变。

## 当前剧情创作策略（2026-10-16）

代码中新剧情任务冻结 `2026-10-16-drama.11`；其他线路独立版本不变。用户只选“剧情短片”，对话、反转、悬念、情绪和产品植入自然组合，允许幽默、荒诞、幻想及拟人，不设五类配额或二级选择。围绕产品宣传，尊重真实产品依据和品牌约束，不强制温情和解、人物成长、产品救急或不可替代。每次固定一份完整稿，内部开发三个短候选择优；独立选择只决定采用与保留项，不重写候选。两次调用在同一节点分别持久化并展示实际候选和取舍。弱组最多替代一次；历史多份批次保留原数量和恢复机制。

## 当前实现边界

正式前端已接入固定五节点画布，复用 `EffectWorkflowCanvas.vue` 的画布呈现与导航外壳；节点确认状态、产物和分支数据仍由定制类接口提供。资料包导入分为“视频创作简报”和可选的“品牌素材”两个区域。制作目标、产品介绍和规格、希望的呈现方式统一写在一份简报文档里再上传，也可同时导入多份补充文档。页面不提供文本编辑或从项目资产库选取功能。不另设需求摘要、品牌调性、视频规格或禁止元素的必填配置表。

品牌素材图片可标注品牌 Logo、品牌标准字、品牌图案、品牌 IP、包装平面图五种用途，新上传不猜测用途；不要求用户提供产品成品图片，品牌规范文档可作为左侧补充文档上传。保留 VISUAL_REFERENCE 区域标识、schemaVersion 3 以及全部旧图片和固定文件版本，原产品、人物、场景、风格、其他用途仅在对应条目中显示为历史资料，不自动改写。图片仍可不上传；本节点不生成资产。正式页面、校验提示和模板均使用面向使用者的称呼。

资料导入界面使用 `ImportSourceCard.vue`、`ImportDropzone.vue`、`ImportMaterialRow.vue`、`ImportImagePreview.vue` 和 `ImportContentViewer.vue`。选择或拖入文件后直接上传到当前项目定制资料库并自动保存引用，失败项保留供重试；文档进入视频创作简报区域，图片进入视觉参考区域。支持下载视频创作简报模板及只读查看文档/图片；移除引用不删除原资产。无法站内阅读的文件可打开原文件。

视频创作简报模板提供可编辑的 Word 表格，沿用采集表的表格形式，列为“填写项 / 填写内容 / 备注与示例”。按最新需求分为品牌基础信息、产品核心信息两部分，共 12 项。品牌部分包含品牌名称、项目名称、项目背景、品牌调性、视觉统一规则、画面禁用元素；产品部分包含产品名称、产品介绍、产品规格、产品外观、核心卖点、目标受众，严格分开品牌与产品名称，不以混合名称猜测归属。产品介绍、产品规格、产品外观分别填写，不增加使用方式字段，也可上传已有补充文档。外观未确定时可注明待确认或请 AI 提方案，不将生成方案当作已知产品事实。核心卖点支持分行填写多条资料支持的独立优势，不固定条数、不划分核心与次要层级；后续脚本可选择重点或自然组合，不要求每个版本覆盖全部卖点，也不按卖点数量分配脚本版本。目标受众为一个文本字段，可描述年龄、性别、地域、兴趣、消费习惯和内容偏好，未限定的可留空或填不限，不另设受众筛选与必填校验。移除视频规格区域及视频时长、视频分辨率、视频画幅、视频格式，两个部分第三列均为备注 / 示例，每项均提供同一虚构陶瓷杯产品的具体例子，卖点示例每行一条。品牌调性、视觉统一规则和画面禁用元素合并到品牌部分；记录品牌应保持的气质、已明确的视觉规则与禁止出现的画面内容，可留空，不要求提前锁定故事结构或创意方案。人物和产品外观、品牌标识等一致性要求写入视觉统一规则；各脚本版本可在已明确约束内探索不同叙事与表现方式。未知内容可写待确认或请 AI 提方案，不涉及的留空；涉及成分、性能、数据和效果时提供说明资料。模板不另设参考资料、其他补充、文案、声音、配乐及交付栏目，图片仍独立上传。不使用“客户”称呼，不要求样片、专业机位或已有故事。页面下载直接引用[Word 模板](templates/视频创作简报模板.docx)，另提供[虚构填写示例](templates/视频创作简报填写示例.docx)，两份文件由同一字段定义生成。历史文字导出为 TXT。设计依据见[项目分析与开源调研](plans/2026-10-08-视频创作简报模板设计.md)，最新字段布局以[前端修订计划](plans/2026-10-09-信息提炼前端.md)为准。当前五节点主流程已接通，包含后续资产图片、分镜、逐镜 Prompt 和视频渲染；各节点完整局部更新仍待补齐。

## 分镜创作与独立脚本分支

2026-10-13 脚本方案浏览使用独立横向卡片目录，取代原生下拉框。显示真实名称、概述、时长和当前查看标记，支持分组浏览、展开全部及键盘导航；只有激活卡片才走原有查看偏好保存，滚动和焦点移动不触发保存。正文阅读、创作说明、版本树及下游路径选择沿用现有能力。见[目录重构计划](plans/2026-10-13-脚本方案目录重构.md)与[验收记录](evidence/2026-10-13-脚本方案目录验收.md)。本段为当前 UI 规则，以下旧节点业务描述以文首拆分边界为准。

暂时模型故障按同任务、同输入检查点自动恢复：请求有限重试后，任务退避 15 / 30 秒，总计最多领取 3 次，只重试相关方案；已完成脚本不覆盖。故事及镜头分段结构不合法时保留模型结果，最多纠正一次，预算跨重启保存。审校问题最多修订与复核一次，仍有错误不发布、不反复付费修订。修订以有类型的变更字段应用于完整原稿，正常内容保留，完整修订稿仍独立复核；补丁与合成稿保存后再复核，恢复不重做已有修订。审校及复核按当前脚本准确镜头 ID 收紧输出 Schema，并按真实累计镜头时间轴核对顺序；语义修改仍由 AI 判断。新任务连续故事段落可合并为不超过 60 秒的请求，固定分片计划后再生成，历史检查点保持原边界。优化边界见[性能计划](plans/2026-10-12-分镜性能与定向修订优化.md)，本轮实测见[性能付费验收](evidence/2026-10-12-分镜性能优化付费验收.md)，基线见[真实付费验收](evidence/2026-10-12-分镜真实付费验收.md)。

第三节点已有正式前端工作台：创作设置、多方案卡片、脚本概述、逐镜编辑、排序、完整方案对比、整套导出及 JSON 脚本导入。字段、确认、加载、工作流弹窗及底部导航按 [`apps/web/AGENTS.md`](../../../apps/web/AGENTS.md) 中的共享组件索引复用；方案、脚本与资产需求仍使用定制类专属组件和契约。宽屏方案横排，逐镜脚本与资产需求左右组织，窄屏自适应。

脚本使用专用 `projects/:projectId/workflows/customized/storyboard` API。创作设置展示视频类型（新设置默认品牌广告）和参考时长（30秒，整数15–180秒），新任务固定一份，API 对旧设置数量也投影/归一为 1，历史任务快照与幂等恢复不修改。脚本结构支持经典结构及有序段落编辑；不再设置创作要求。进度置于设置下方，终态消失；网络、429/5xx 查询临时失败自动退避恢复，真实业务错误仍可处理，不提供取消本次创作按钮。历史草稿保留读取，旧 instructions 不进入新任务模型输入。已有超范围草稿仍可阅读与手工编辑，AI生成前要求调整本次参考设置，不截断历史内容。

冻结已确认有效的 `customized-brief` 的 artifactId / revision / fingerprint，以及本次设置、固定模型名称和品牌素材版本引用。独立 `workers/customized-storyboard` 不解析原文、不调用视觉模型；按信息卡快照、多方案构思、完整故事、资产目录、逐镜脚本、独立审校、定向修订、保存分支执行。每份脚本可选适合故事的真实卖点，代码不代替 AI 进行语义判断。长故事按叙事段落分片，保持完整故事、对象目录与相邻镜头上下文；模型调用全局并发默认为 2。

单份脚本完整成功、审校通过且符合引用与时长校验后立即事务性发布自己的兄弟分支，稳定产物 key 为 `customized-script:<scriptId>`；每份脚本都有独立实际 Run，不借用 templateId。首次成功的方案作为默认查看项，选择和刷新不增加业务 revision，也不发布分支；再次创作追加方案，部分失败保留已发布脚本。相同任务恢复使用有效检查点，不重新生成成功脚本；主动再次创作创建新批次。

手工编辑写独立脚本草稿，显式保存修改才更新该脚本当前分支；取消恢复已确认内容，内容相同不增加业务 revision。expectedRevision 冲突保留本地修改；项目、任务及脚本切换取消旧请求。人工新建为空白，首次有效保存才建立分支；导入重映射脚本及对象身份。旧多方案草稿只读兼容，主动进入编辑才迁移为独立草稿，打开页面不会发布。

效果类 Prompt 与本节点直接引用同一个 `WorkflowExecutionGraphDialog` 和 `WorkflowRunProgress`。八个节点详情只投影已持久化的故事、对象、镜头、审校问题和修订前后内容，完整内容分页加载；不展示系统提示词、模型思考、原始 JSON 或内部存储标识。无任务时为空状态；正式界面不再提供虚构示例与未接通的单镜头重新创作入口。

界面精简以实际后端能力和完整业务内容为准：基础设置展示时长、数量，创作依据与高级设置按需查看；只读镜头不堆叠禁用编辑按钮，进入编辑后仍支持完整编辑、排序和删除。空台词、音效与衔接不展示重复占位，实际内容保持可见或可展开；对比包含衔接说明，脚本资产目录包含未被镜头引用的对象。真实生成、发布、导入导出、任务状态、恢复与阶段详情保留，不用删字段换取简洁。说明见[前端精简计划](plans/2026-10-12-分镜前端真实交互与界面精简.md)。

## 资料包后端与文件版本

SOURCE_IMPORT 已接入专用上传 API，仍复用共享项目、资产、文件存储、节点草稿和版本提交机制。上传入口按 `projectId + workflowRunId + CUSTOMIZED + CUSTOMIZED_PROJECT` 校验当前编辑作用域；文档和图片分别校验扩展名、MIME、实际大小及文件头。单文件上限 100 MB，失败文件保留在前端供重试。按原文件名与内容 SHA-256 幂等，同内容重试不增加资产版本；同名不同内容生成独立资产，避免覆盖历史资料包。

读取、预览和下载按资料包固定的 `assetId + assetVersion` 返回当时的文件；当前资产出现新版本不会使旧资料包失效或自动替换其内容。保存版本前确认固定文件可读取，事务内再次校验所有引用版本的项目、工作流、目录、类型与状态。上传过程中取消或切换 Run，迟到结果不能写入新的草稿；已上传文件按现有项目资产规则保留。

实现计划见[资料包后端接通](plans/2026-10-08-source-import-backend.md)。隔离真实接口验证脚本为 `apps/api/scripts/verify-customized-source-import.mjs`，只操作随机测试项目，不触发模型。

活动 Run 概览、SOURCE_IMPORT 文件引用草稿及版本树使用 Redis 只读投影缓存。每次读取核对 PostgreSQL 的项目、CUSTOMIZED / CUSTOMIZED_PROJECT 作用域及依赖行版本，编辑/取消/发布/切换或保存后立即换键；迟到读取复核失败后重新加载。只缓存无历史文字的当前资料草稿，其他节点、历史文字、文件正文、二进制和签名 URL 不进入缓存。Redis 故障回源，业务 revision、固定文件版本、确认提交及存储可读校验保持原边界。配置复用 `EFFECT_READ_CACHE_*`，无数据库迁移；项目删除会同时清理定制类缓存。计划和验证边界见[资料导入 Redis 缓存](plans/2026-10-09-资料导入Redis缓存.md)。

## 固定规则

- 固定五节点以视频制作结束；资产准备为第四节点，视频制作为第五节点。旧 `VISUAL_ASSETS` / `DELIVERY` 导航在读取时映射为 `SHOT_RENDER`，历史记录和业务 revision 不变，旧交付产物不计入视频确认状态。画布和版本树组件的具体职责见“前端共享实现索引”及“当前实现边界”。当前边界见[移除素材交付节点](plans/2026-10-19-移除素材交付节点.md)；[六节点画布调整](plans/2026-10-08-六节点画布调整.md)仅作为历史记录。

- 每个分镜版本是独立工作副本；版本名称可修改，镜头文本可直接编辑。
- 自定义分镜版本初始为空白，不复制现有版本内容。当前脚本操作区支持永久删除：确认后硬删除脚本及其全部后代分支的任务、检查点、草稿、工作副本、历史版本和该路径归档的项目资产，独占文件进入持久后台清理队列；兄弟脚本及共享上游保留，仍被引用的文件不删除。活动分支被删除时返回保留的上游版本，同批任务按剩余脚本继续，迟到回调不能恢复已删除脚本。已确认脚本的最后一个镜头被移除时只形成不完整编辑草稿，不能保存为正式版本。
- “导出当前版本”导出一个完整分镜脚本版本，不是勾选若干镜头批量导出。
- 镜头 Prompt 必须引用实际分镜字段；每条可查看对应分镜、编辑建议并重新生成，即使校验通过也允许人工修改。
- 逐镜渲染是一镜一任务；镜头失败不应导致已完成镜头丢失。
- 工作流资产选择器默认只读取当前项目资产；跨项目资产先复制到当前项目再绑定。

## 下游依赖
