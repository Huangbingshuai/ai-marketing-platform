# 定制类工作流文档

固定流程：`资料导入 → 信息提炼 → 脚本创作 → 资产准备 → 视频制作`

## 当前状态（2026-10-19）

**定制类主流程已开发完成，当前进入各节点局部更新补齐及少量 Bug 修复阶段。**

已接通简报与品牌素材导入、信息提炼、完整脚本创作、资产拆分与图片生成、分镜及素材绑定、逐镜提示词和视频渲染，配套页面、API 与独立节点 Worker 已实现。视频制作是当前流程终点，支持逐镜预览及下载；不以整片合成或另加交付节点作为本次完成范围。

仍需完善各节点在上游资料或产物改变后的影响识别、按需执行和原位提交等局部更新闭环，并修复少量交互及恢复 Bug。已有自动保存、重生成或待更新提示不代表该闭环全部完成。真实付费测试发现的重复物品、产品端口及动作偏差继续作为生成质量问题保留，不因开发完成而视为已解决。
