# 上游回看保留制作路径

问题：当前资产子分支回看提炼后，普通导航把所选脚本的祖先 Run 激活，导致正确隔离在子 Run 的资产显示为空。

修复仅限 Web 导航。依据现有版本树确认当前 Run 的脚本归属：当前路径确属所选脚本，且中间只在资产/视频节点分叉时，继续使用当前 Run；换选脚本时使用所选脚本 Run。版本树的显式切换仍精准激活目标 Run，不改变 API 查询隔离，不复制或投影资产，不创建任务或增加产物 revision。

覆盖画布从提炼进入资产/视频、脚本页画布与底部下一步。异步目录响应需检查原 Run、页面和请求序号，拒绝迟到导航。测试同脚本后代、多层后代、其他脚本、显式版本切换、刷新及失败保留，浏览器用本地合成夹具验证，不操作线上项目、不部署和付费。
