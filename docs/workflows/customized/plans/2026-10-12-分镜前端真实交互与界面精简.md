# 分镜前端真实交互与界面精简

## 范围与边界

定制类第三节点分镜创作。仅修改正式 Web 展示与交互、测试及说明；复用现有分镜 API，不修改后端、Contracts、Worker、数据库或固定六节点，不触发付费生成，不自动提交 Git。

直接上游是当前项目 / CUSTOMIZED Run 已确认的 `customized-brief`，保留 artifactId、revision、fingerprint。生成任务冻结输入，每份成功脚本独立发布 `customized-script:<scriptId>`；人工编辑仍为独立草稿，显式保存才提交，取消恢复。选择与导航不增加业务 revision。下游 Prompt 只消费已提交、来源有效的具体脚本版本，本次不实现 Prompt 模型任务。

## 原型与正式组件映射

已在浏览器打开 `references/prototypes/customized/customized-workflow.html` 第三节点。页面壳和六节点画布继续由外层维护；标题与真实创作动作对应 `CustomizedStoryboardNodePage` 和共享编辑/任务动作；方案卡、脚本概述与对比继续复用现有布局；逐镜内容对应 `StoryboardShotCard`，需求对应 `StoryboardAssetRequirements`；真实阶段详情对应 `StoryboardExecutionDialog`。

用户授权精简，因此有意偏离旧原型的 Mock 版本回溯、单镜生成、音色绑定等展示，不将其移植为正式能力。保留既有蓝白视觉、信息层级、对比、导入导出及关键资产需求。

## 实施项

- 删除生产界面示例入口、演示状态及仅用于虚构交互的旁路；示例数据只保留在显式测试 fixture 中。
- 删除没有对应后端能力的单镜头重新创作入口与事件。
- 只读镜头不展示整排禁用编辑/排序/删除控件；进入真实编辑态后才出现。空台词、空音效、空衔接不显示重复占位，编辑字段仍完整保留。
- 创作设置只保留时长、数量两个基础字段，创作依据收拢为按需查看；高级叙事设置继续可编辑。移除重复引导步骤、重复新建动作和方案卡查看提示；不足两个方案时不显示无用对比入口。
- 保留真实排队、执行、完成、失败、取消及恢复能力，状态和历史详情均可查；不把失败伪装成功。
- 对照后端逐字段核对：脚本名称、概述、叙事结构、产品重点在概述；镜头名称、景别、运镜、时长、画面、对白、音效、衔接在逐镜卡片；对象名称、公共定义、镜头需求和三种定义状态在资产需求。完整故事、方案差异、审校和修订通过真实工作流详情查看。内部身份、指纹等只用于隔离，不作冗余展示。
- 更新旧的“尚未接通 AI / 正式工作副本”说明，准确描述真实后端边界。

## 验收

- SSR / 单元覆盖无示例入口、无单镜生成、真实空态、只读与编辑控件、可选字段按内容展示、运行和完成/失败状态。
- 现有排序、导入身份重映射、TXT/JSON 完整输出及草稿隔离测试继续通过。
- 执行 Web 相关测试、类型检查、构建与 `git diff --check`。
- 浏览器核对 1920、1440、窄屏及创作设置/方案对比/真实工作流详情；需要隔离 fixture 的空态/失败态明确标注为测试，不向项目写入虚构内容。

## 迁移与风险

无数据迁移。旧草稿只读兼容与主动编辑迁移逻辑不变；迟到响应、冲突保护、真实 API 和作用域不变。工作区存在大量已有后端与效果类改动，仅补丁修改本任务前端范围，不回退其他改动。
