# 分镜浏览器联调详情修正

真实付费浏览器联调发现，脚本审校的自然语言说明包含模型使用的内部资产编号。

范围：修改分镜节点详情的只读 API 投影和脚本资产目录中的引用名称展示。使用该方案持久化的原始、修订及资产阶段目录，将完整编号转换为真实对象名称；尚未建立的候选对象显示“待定义人物/产品/场景对象”，不猜测身份。故事段落及字段引用转换为业务名称。保留问题、依据、建议和分页内容，目录替换只用于展示，不回写编辑草稿。工作流详情的打开脚本和继续阅读按钮直接复用共享 BaseButton。

边界：直接上游仍是已冻结的信息卡版本；输出仍是 `customized-script:<scriptId>`。不改模型输出、检查点、脚本、工作副本、业务 revision、分支或下游状态，无数据库迁移。

验收：覆盖原目录、修订新增对象、未定义候选、相邻中文和输入不可变；相关 API 测试、类型检查及 diff 检查通过后，在已完成任务的浏览器工作流面板中刷新审校详情，核实不再展示内部编号。无需再次付费生成。
