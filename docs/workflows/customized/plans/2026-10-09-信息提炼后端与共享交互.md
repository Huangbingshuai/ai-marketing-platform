# 定制类信息提炼后端接通与效果类组件复用

状态：实现完成，无付费验收已记录。2026-10-09。常规总构建受到本机输出目录占用影响，付费质量验收未执行。

## 目标

接通 CUSTOMIZED / INFORMATION_EXTRACTION 的真实 API、独立异步 Worker、编辑及版本保存。直接上游为已确认的 `customized-source-package` 的准确 artifactId + revision；输出为 `customized-brief`，由分镜创作消费。AI 完成只保存待确认结果，人工保存版本才提交；同内容不增加业务 revision、不发布空分支。

保持六个业务节点及 Word 模板两组 12 项字段。品牌图片只传递固定版本引用，不调用视觉模型，不据此推断产品事实。不实现下游生成，不执行付费验收。

## 共享界面

从效果类提炼页抽出工作流执行图弹窗、节点卡及右侧详情，两类页面同时回接。共用样式、键盘选择、加载、错误、重试、遮罩/ESC 关闭、焦点约束与恢复。节点、连线、文案和数据使用配置适配，支持效果类并行图及定制类线性图；移除定制类静态列表。

共用 WorkflowRunProgress、加载、字段、卡片、卖点编辑器、编辑动作、确认、导航和资料阅读器；抽取公共按钮、状态反馈及轮询生命周期。真实进度来自后端，断网不判失败，409 保留本地草稿。定制类保持单产品品牌/产品双卡，下一步为分镜创作，差异及来源靠近字段展示。

## Worker

独立 `workers/customized-extraction`，独立队列、配置、进程。将 Docling、初始化、分片、通用表格读取、结构化模型请求、超时重试及通用内部请求抽到 `workers/shared/extraction-runtime`，两 Worker 使用同一份代码，不跨 Worker 导入。

内部图：LOAD_AND_SNAPSHOT → DOCUMENT_PARSE → DOCUMENT_EXTRACT → FUSION → SEMANTIC_REFINEMENT → NORMALIZATION。文档阶段有界并发，持久化各阶段和文件检查点，大文件经内部 API 外部化。

模板仅提取填写内容，不采集备注/示例。自由文档使用定制提示词。品牌诉求和产品事实分开，卖点逐条保留，不编造未知规格、外观或功效。AI 处理语义，程序检查结构、引用、版本和合法值。

## 已确认规则

- 支持 docx/pdf/xlsx/txt/md；新上传拒绝 doc/xls，历史文件保留并提示转换。
- 任一文档失败保留成功检查点，部分完成不可确认；同任务同输入恢复成功步骤，主动重提是新执行。
- 同来源重提保留人工覆盖，资料版本变化后不套用旧人工覆盖，历史版本保留。
- 产品名称及至少一条有效卖点必需，其他字段可空；完整执行并处理冲突后才可确认。
- 已确认内容编辑/重提进入隐藏编辑 Run，取消恢复原版本，变化保存才发布；仅实际引用旧 Brief 的已有下游待更新。

## 契约与持久化

共用契约定义字段、来源、冲突、任务、阶段及详情。接口位于 `projects/:projectId/workflows/customized/information-extraction`，提供工作区、创建/查询任务、节点详情、草稿、重试、确认。独立内部接口处理 claim、文件、产物、进度与回调。

新增定制提炼任务、步骤、结果、产物、文件持有记录；共用 Project、WorkflowRun、WorkflowNodeState、WorkingArtifact、JobOutbox、存储、租约和权限。按 projectId + workflow + workflowRunId 隔离，校验预期 revision、attempt、活动编辑作用域。接入项目清理和只读 Redis 投影，缓存不含正文、文件及签名 URL。

顺序：共享前端并回归效果类 → 共享解析并回归 → 契约/API/迁移/编辑分支 → 独立 Worker/前端接通 → 跨层和浏览器验证。

验证模板与自由文档、PDF/Excel、空模板/示例排除/长文/冲突/失败恢复；1920/1440/窄屏及空、加载、失败、运行、完成、待更新；同内容、两轮资料更新、取消、刷新、兄弟分支和迟到请求；任务幂等、租约、缺配置与非法模型输出。运行相关单测、类型检查、构建、Python pytest/mypy、git diff --check。真实 Docling 本地验证；模型使用显式测试适配器，真实付费另行授权。

新增 Compose 独立服务并共享 Docling 模型卷，不中断活动任务，不自动 Git 提交。完成后更新节点指南与运行文档，并如实记录未验证范围。

## 实施结果

已新增独立契约、五张提炼业务表及迁移、公开 / 受保护内部接口、Outbox 编排、租约恢复、文件检查点、草稿与隐藏编辑分支。共享 Docling / 表格 / 分片 / 请求底座，效果类继续三路并行，定制类执行六阶段线性图。两类前端均引用同一工作流弹窗、动作与反馈组件，沿用共享进度、编辑、信息卡、卖点编辑和轮询。
