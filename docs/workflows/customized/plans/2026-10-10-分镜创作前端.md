# 分镜创作前端

## 范围与边界

按已确认的 UI 设计实现定制类第三节点。保持六节点、效果类共享画布与版本树不变。直接上游为已确认 `customized-brief` 的 artifactId + revision；读取信息卡，不消费未确认的提炼结果。分镜方案分别维护镜头与编辑内容。

本轮只实现前端与已有通用节点草稿 API 的接入。`STORYBOARD` 的 WorkflowNodeState 保存创作设置、手工方案及查看选择，不提交 WorkingArtifact，不增加业务 revision，不发布版本分支。分镜专用 AI 任务、正式版本确认、主脚本下游绑定尚未实现；下一步保持禁用。新增契约仅描述节点草稿，不声明已存在分镜产物接口或稳定产物 key。

## 页面与复用

- 复用 WorkflowNodeEditActions、WorkflowEditingBanner、WorkflowInformationCard、WorkflowInformationField、WorkflowInformationDialog、WorkflowExtractionActions、WorkflowExtractionGraphDialog、WorkflowPageLoading、WorkflowNodeFooter、WorkflowRunProgress 和公共确认弹窗。
- 创作设置维护目标时长、方案数量、AI / 参考 / 自定义叙事结构与可选创作要求，不恢复上游视频规格、音色或资产生成配置。
- 方案卡横排，镜头卡纵排；镜头内容与对白左右组织，底部音效提示。使用现有蓝色动作、白色及浅色卡面、细边框，不引入另一套主题。
- 支持空白手工方案、重命名、增删镜头、拖动及按钮排序、编辑取消、整套导出和双方案对比。主脚本仅维护候选选择草稿，明确尚未正式确认。
- 显式界面示例使用固定虚构青梅酱内容，默认关闭，不自动运行、不持久化、不消费项目数据。可以编辑和比较示例，但不能冒充保存成功。
- 工作流弹窗复用现有组件，明确为预定执行步骤，无任务时全部等待；不模拟任务进度。

## 生命周期与隔离

读取固定 projectId + CUSTOMIZED + workflowRunId 的信息卡产物和节点草稿；切换作用域取消请求，迟到响应不覆盖当前内容。草稿写入携带 expectedRevision，409 保留本地内容，只由用户主动重新加载替换。同内容不重复保存；查看方案的选择不进入内容指纹，不单独触发写入。导航及退出先刷新待保存草稿，失败阻止离开。其他节点隔离编辑期间禁用分镜写入。

## 验收

契约恢复校验、空白方案、独立镜头 ID、排序、删除、对比及示例隔离；草稿请求取消、冲突与保存期间的新修改。执行 Contracts/Web 单测、类型检查、Web 构建及 diff 检查。在 1920、1440、390 宽度检查空态、示例卡片、编辑、对比、弹窗 ESC 和焦点恢复；不调用模型。

## 原型偏离

原型功能来自 `references/prototypes/customized/customized-workflow.html`。保留多版本选择与逐镜卡片，移除默认首版为主脚本、固定六镜、以生成记录冒充脚本对比及提前音色绑定。原型源码已核对；本地 file URL 受浏览器协议限制，未运行冻结页面，不声称像素级一致。
