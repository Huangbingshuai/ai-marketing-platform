# 视频类型、脚本结构与软时长改造

依据：用户确认的创作设置及[飞书产品手册](https://ncnejrxxru2v.feishu.cn/wiki/GyzNwFRdBi1ZQXkbL4FcPQjunzg)的电商带货、同城到店、品牌广告、剧情短片分类。本计划覆盖定制类第三节点及直接下游的时长消费，不改固定六节点。

## 边界

直接上游为已确认 customized-brief 的 artifactId + revision；设置仍存 STORYBOARD 导航草稿。输出继续使用 customized-script:<scriptId>，完整生成、独立审校及结构校验成功自动提交。新增设置不改历史脚本；来源隔离、幂等、检查点、分支及下游 stale 机制保持原职责。

## 实施

- UI 移除创作要求，默认展示视频类型、参考时长、方案数量。脚本结构可选择经典结构并添加、删除、编辑、排序段落；不要求用户设计故事或写创意提示词。
- 类型固定为电商带货、同城到店、品牌广告、剧情短片，新设置默认品牌广告。历史无类型设置按旧剧情路径显示兼容，明确保存新设置后采用新规则。
- 新任务冻结 VIDEO_SCRIPT_V2；旧 SCREENPLAY_V1 任务及无标记任务保持原校验和恢复。兼容保留 instructions 字段但新任务不消费其历史文字。
- 新正文统一使用连续 P01 等篇章标题，可写传播段落、视觉篇章或剧情场次；剧情内容可保留内外景、地点及时间，不强迫广告出现人物。正文仍只有一份，由 beats 拼接。
- 脚本保存所选类型、参考时长和有序结构，供详情、导出与下游使用；结构段落通过稳定有序 ID 一对一对应正文篇章，非自定义时由系统决定段落。
- 构思明确核心创意、开场吸引点、产品参与方式、记忆点，联合检查方案差异；正文与独立审校按类型适配。缺少背书、门店、价格、活动等资料不得编造；允许适配缺依据段落并在正文/说明中明确待补充事项，不能用虚构事实凑结构。
- 参考时长只指导信息规模；代码不以偏差触发修订。预计时长由实际段落相加，前端并列展示参考/预计；保留正时长、单段/总容量安全上限和结构引用校验。下游分镜消费实际正文段落估时，不将原参考时长再次硬套。
- 独立审校检查传播/视觉/剧情质量与结构落实，具体重大创意问题可定向修订；轻微优化建议不触发额外付费循环。复核事实及严重结构问题仍硬阻断；最多一次修订/复核。

## 验收

四类型、默认/经典/自定义结构、结构排序与保存恢复、软时长偏差不失败、历史硬时长不变、正文拼接/结构编号校验、审校与有限修订、下游使用实际估时、来源与重复回调。相关 Contracts/API/Web/Worker 单测及类型检查、构建、浏览器 1920/1440/窄屏、diff 检查。付费生成与质量结论单独记录，不以受控测试冒充创意验收；不自动提交 Git。
