# 多产品真实付费提炼验收

用户已授权本轮真实付费测试。范围为定制类 INFORMATION_EXTRACTION，不触发下游分镜或视频任务，不自动提交 Git。

采用八个虚构产品：食品、护肤、家清、电子、服饰、家具、工具、数字服务。每个产品独立项目、独立 Run，保存当前十二字段 Word 简报到素材目录，部分产品增加同产品补充文档。品牌图片不进入模型。

通过公共上传、资料包确认、异步任务接口执行独立 Worker 和真实 Ark。核对品牌/产品隔离、字段归属、完整规格、逐条卖点、已知外观与待设计范围、来源引用和不自动提交。每个产品执行两轮，保存任务账本，轮询和恢复不重复创建任务。

输入消费确认的 customized-source-package artifactId + revision；输出只写待确认结果，用户保存版本才提交 customized-brief。测试不改固定节点、字段及下游实现。发现 Bug 后添加对应回归测试，空闲时更新 Worker，再真实复测受影响案例。

记录每轮任务、阶段耗时、供应商调用与安全 usage 元数据；不记录密钥或签名 URL。速度统计区分排队与执行，不用演示数量证明普遍质量。验证脚本语法、相关 Worker 测试、类型检查和 git diff --check。Word 复制保留模板格式；文档渲染缺失单独记录，不冒称通过。
