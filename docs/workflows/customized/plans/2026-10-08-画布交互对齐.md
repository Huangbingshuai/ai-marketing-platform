# 定制类画布交互对齐

沿用效果类正式页面的交互基线，修正已有定制页面在行为上的差异。

- 提取效果类后台导航队列与节点切换、编辑切换、分支切换提示，供两类页面共同使用。保存当前草稿后立即切换页面，后台按顺序同步最新节点，失败重试一次；切换分支、进入或退出编辑前排空旧导航，卸载时失效旧请求。
- 七节点的选中与前序步骤高亮由共用画布统一处理。高亮只表示导航位置，真实确认产物仍单独控制编辑权限、下一步校验与版本树，不新增业务 revision 或伪造下游产物。
- 编辑切换保留当前内容和滚动位置，加载成功后一次替换作用域；同 Run 的树跳转复用普通节点导航，跨 Run 才重新加载。
- 不更改固定七节点、源资料保存边界、资产隔离和生成链路，不触发付费任务，不迁移数据库。
- 验收延迟接口、连续点选、旧请求与失败恢复、切换分支和刷新、进入及取消编辑时内容保持可见，并回归共享画布、版本树与导航队列，运行 Web 类型检查、构建、diff 检查。
