# 定制类六节点画布调整

按使用者确认的截图调整为：资料导入 → 信息提炼 → 分镜创作 → Prompt → 逐镜视频 → 素材交付。

- 移除视觉资产独立节点；资产准备、绑定和逐镜渲染归入逐镜视频，保留 `SHOT_RENDER` 标识。
- Web 和 API 使用契约中的六节点顺序；版本树同步六个阶段，旧 `VISUAL_ASSETS` 导航与分支来源在读取边界映射为 `SHOT_RENDER`。
- 历史数据库、工作副本及业务 revision 不迁移、不删除；只调整读取投影，原资料确认边界保持不变。
- 画布与版本树继续直接复用效果类组件及其尺寸，不增加定制类节点样式。六节点同容器宽度下具有相同宽高。
- 不实现后续生成任务，不调用付费服务。资料包仍以 `customized-source-package` 确认输出，信息提炼消费其实际 `artifactId + revision`；后续节点尚未接入。
- 验收：契约兼容测试、定制画布/版本树与 API 测试、Web/API/Contracts 类型检查及构建；浏览器检查六节点、刷新恢复、版本树及 1920/1440/窄屏的效果类尺寸对比。
