# 分镜统一查看与路径选择

本次按新的交互要求调整分镜创作，不执行模型生成，也不改动独立脚本的存储和提交边界。

- 同一信息卡版本下的已发布脚本共同属于当前工作流，版本树同时高亮这些脚本及其连线，仅给正在查看的脚本显示当前查看标记。
- 脚本列表和版本树中的脚本点击只切换查看内容、保存查看偏好，不调用分支激活接口，不发布版本。
- 刷新优先恢复查看偏好，不用活动 Run 的脚本强行覆盖选择。不设主脚本。
- 从分镜点击下一步或画布后续节点时，校验当前脚本已确认、未过期且不在编辑中，再进入它实际所属的 Run。其他历史节点的显式版本切换仍保留。
- 执行中的进度直接复用现有组件；完成、部分失败、失败和取消后移除进度条，失败原因和恢复入口继续显示，顶部查看工作流入口保留。

上游仍为准确的 customized-brief artifactId + revision；输出仍为 customized-script:<scriptId>。浏览只修改导航草稿，不改变业务 revision、脚本内容和下游依赖。

验收包括同源全部脚本高亮、历史来源隔离、唯一当前查看标记、浏览不激活分支、刷新选择恢复、画布和下一步消费所选脚本，以及终态进度消失和失败恢复入口保留。使用已有项目在浏览器验证，并执行相关单测、数据库测试、类型检查和构建。
