# 定制类资料包导入后端接通

## 范围与提交边界

仅实现 CUSTOMIZED / CUSTOMIZED_PROJECT 的 SOURCE_IMPORT。该节点没有上游工作副本；输入为视频创作简报文档及可选视觉参考图片。上传保存项目文件，引用及图片用途保存在既有 WorkflowNodeState（schemaVersion 3）；明确保存版本才提交 `customized-source-package`。复用当前隐藏编辑分支、取消、版本确认、内容指纹和 revision 机制。标准化提炼及后续节点仍未实现，不触发模型或付费任务。

## 实施

- 增加定制类专用、按 projectId / workflowRunId 隔离的单文件上传入口；后端检查活动 Run、未完成状态及资料导入编辑权限，文件写入期间发生分支切换则拒绝将结果写入草稿。已上传项目文件按现有资产规则保留。
- 文档支持 Word、Excel、PDF、TXT、Markdown；图片支持 JPG、PNG、WebP、PSD。复用效果类的文件验证方式与共用 FileModule / StoragePort / AssetService，加强扩展名、MIME、文件签名对应验证，规范 MIME。
- 定制类上传按原文件名及内容 SHA-256 幂等，不以文件大小判断相同内容。重复上传不增加资产版本，同名不同内容保存独立资产，避免改动已确认资料包。
- 通过共享资产版本读取接口按资料包固定的 assetVersion 返回元数据、预览和下载，旧资料包不跟随当前资产版本改变。
- 在既有资料包版本提交事务中检查每个引用的实际版本、所属项目/工作流、可用状态及资料类型。提交前确认文件可读取；不新增草稿表、任务系统或资产系统。
- 前端改用专用上传与固定版本读取，保留当前复用效果类的画布、编辑、读文档、图片预览和拖拽组件。

## 迁移与验证

不迁移数据库，已有 schemaVersion 1/2/3 继续确定性恢复。已有资产使用已有 AssetVersion，不覆盖旧文件。

验证文件类型及伪装文件、同内容重试、同名不同内容、跨项目/工作流/Run 拒绝、只读与完成状态、文件失败清理、固定版本读取、草稿保存与刷新恢复、保存/取消编辑及无变化不增加 revision。执行相关测试、契约/API/Web 类型检查、构建及 git diff --check；使用隔离测试项目验证真实上传接口和浏览器，不调用生成任务。
