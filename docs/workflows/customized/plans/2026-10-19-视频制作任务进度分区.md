# 视频制作任务进度分区

依据使用者最新补充，分镜生成、逐镜提示词及逐镜视频不再共用页面顶部的分镜进度条。

- 本次只改定制类视频制作的前端任务呈现，不更改任务、轮询、自动重试、来源版本或提交规则。直接上游仍为确认脚本、资产目录及当前分镜；提示词及视频分别原位提交自己的工作副本，不增加分支。
- 页面顶部 `WorkflowRunProgress` 仅展示分镜生成；资产准备原有 ASSETS / IMAGE 展示保持原样。
- 逐镜提示词在对应提示词区域显示紧凑的阶段、真实百分比及局部进度，查看工作流入口留在该区域。仅显示当前选中分镜的 PROMPT 任务，切换分镜不借用其他镜头进度。
- 视频参考效果类素材渲染卡，在右侧播放器卡片显示加载状态及卡片内细进度，不在页面顶部显示分镜进度。再次渲染时继续保留旧视频，状态显示本镜实际 RENDER 任务。
- 进度来自服务端，不增加计时模拟；运行完毕局部进度消失。原有输入保护、缺图和失败提示不变。不增加取消、恢复、手动保存功能。
- 验证运行、排队、完成和切镜隔离；相关 Web 测试、类型、构建及 diff 检查。浏览器用受控任务响应验证不同状态，不为纯展示改动额外付费生成；已有五镜真实视频继续用于完成态及刷新恢复验证。
