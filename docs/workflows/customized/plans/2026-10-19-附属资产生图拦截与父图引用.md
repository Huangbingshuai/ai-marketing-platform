# 附属资产生图拦截与父图引用

本轮仅本地 API、Contracts 与共用 Worker 底座，不提交、推送、部署、操作线上任务或调用付费模型。前端由联调会话协调，不改其页面、咖啡杯联调文档或截图。

作用节点为资产准备 IMAGE 及视频制作 PROMPT/RENDER。资产准备直接消费当前 Run 已确认脚本、Brief 和资产目录的准确 revision；渲染消费当前完整分镜、已确认提示词和资产目录。继续既有草稿/确认/原位提交边界，不新增分支、迁移或第二套资产数据。

1. 共用确定性归属解析器只在当前目录按精确 ID 解析 preparation.treatment 与 parentId，校验唯一身份、缺父、类别、自引用和循环。无归属的历史项保留自有图逻辑；明确附属项不因自有历史图而变为独立项。
2. API 创建 IMAGE 前逐项检查：只接受独立或历史未记录归属的资产；附属项明确拒绝整次请求，指出随父对象准备，不静默删选或付费。所有拒绝发生在创建任务与 Outbox 之前。Worker 同样在调用模型前整体校验。
3. 视频提示词保留附属对象身份与文字定义，并投影其父对象名称、归属用途；不读取图片、不推断外观、不自动把未选父对象写成额外 @ 引用。
4. RENDER 冻结每个实际 @ 对象所使用的独立父图、固定版本与文件校验信息。可选 sourceObjectId/sourceName 标明图的归属；同图多个逻辑引用仅向供应商发送一次，编号一致，细节引用表达为父图中的对应对象。缺图、缺父、不可用文件或跨项目版本在付费前拒绝。
5. 原始正文、绑定、资产分类和历史产物不自动重写。Run 隔离沿现有受保护工作区及固定来源校验；父对象只能来自本 Run 的目录，不去其他 Run 查找同名/同 ID 对象。
6. 无付费测试覆盖14对象中10独立/4附属、混合选择整体拒绝且无任务/Outbox、父图固定版本及去重、缺父/循环/错类、跨作用域和历史兼容；执行相关单测、跨端类型/构建与 Worker pytest/mypy。实际生图质量及线上付费联调由主会话另行进行。
