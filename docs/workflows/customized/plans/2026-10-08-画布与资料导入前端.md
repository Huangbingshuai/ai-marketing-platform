# 定制类画布与资料包导入

## 范围与验收

- 使用效果类 `EffectWorkflowCanvas`，通过节点配置显示固定七节点；保留原有布局、选中和待更新样式。导航不表示业务完成。
- 原型 `references/prototypes/customized/customized-workflow.html` 仅作功能参考，正式效果类页面作为视觉参考。
- 接入系统定制类入口；开发 Brief、品牌调性、核心诉求、禁止元素、总时长、画幅、附件分类、下载模板、上传、移除引用与当前项目资产选择。
- 复用效果类可创建选择器、公共节点页脚、项目上下文、HTTP 客户端、节点草稿与资产 API。

## 数据边界

节点为定制类 `SOURCE_IMPORT`，上游为当前项目资料，无上游 WorkingArtifact revision。输入保存为 `WorkflowNodeState`，用 expectedRevision 防止并发覆盖。

当前定制类尚无资料包提交或提炼 API。本次补充幂等初始化定制 Run 的小型入口，不创建任务、不提交 WorkingArtifact。页面明确使用“保存草稿”；后续六节点展示待接入状态，不模拟 AI 结果。正式定制资料包提交与标准化 Brief 的 dependency/revision 链留待后续节点开发。

附件选择先保留在本页，用户点击“保存到项目资产库”才复用原始资料资产导入；成功项逐项保存引用，失败项可重试。移除仅解除当前资料包引用，不删除项目资产。已有附件按当前项目、定制空间读取，并锁定选择时的资产版本。项目或模块切换前保存草稿，未保存本地文件需要先处理。

## 实施与迁移

增加兼容性的定制节点/资料草稿契约和定制 Run 初始化 POST；复用已有 Run 表、唯一活动键和草稿表，无数据库迁移、Worker 变更或付费调用。

- Run 初始化的项目校验、唯一作用域及重复调用。
- 定向单测、工作区类型检查、Web/API 构建、格式检查与 git diff --check。
- 浏览器检查 1920 / 1440 / 窄屏、七节点导航、空态、加载、失败、字段保存/刷新恢复、上传/移除和效果类画布回归；未调用 AI 或付费服务。
