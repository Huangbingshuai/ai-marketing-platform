# 脚本资产初始字段保护修正

## 问题与边界

定制类资产准备直接消费已确认脚本的 artifactId/revision，以及信息卡。脚本资产首次投影到制作工作区时未声明 manualFields，Worker 因而按历史资产兼容规则保护非空字段，导致 AI 审校发现的源描述问题无法修订。生成与导入脚本均走同一投影，不按来源区别处理。

## 实施

- 只为脚本首次投影的资产显式设置 manualFields: []，允许资产整理和限定范围的审校修订。
- 已保存资产目录、制作草稿及真正人工编辑字段继续使用现有保护规则；不迁移历史数据，不修改冻结任务快照。
- 来源描述统一显示“脚本资产定义”，不标注导入方式。
- 本次咖啡杯脚本修正办公室遗漏鼠标的描述后明确保存；新任务消费新 revision，失败任务保留。

## 提交与下游

资产整理成功仍通过服务端校验后提交资产目录及独立资产工作副本；失败不提交。图片、分镜、提示词和视频沿现有来源快照消费，不增加节点或版本机制。

## 验收

- API 集成测试核实初始脚本投影及任务快照含显式空保护列表。
- Worker 受控测试核实初始来源可被审校修订，人工保护与历史兼容仍阻止覆盖。
- 运行相关 API 测试、类型检查、Worker 测试和 git diff --check。
- 无活动任务时部署；真实生成检查商品一致性、人物连续性、场景道具及六段总时长。记录真实失败与耗时，浏览器工具不可用不算浏览器验收通过。
