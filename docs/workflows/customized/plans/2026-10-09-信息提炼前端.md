# 定制类信息提炼前端

## 范围与边界

实现固定六节点中的 INFORMATION_EXTRACTION 页面，替换当前占位页。直接上游为已确认 `customized-source-package` 的 artifactId + revision 及固定文件版本；当前没有提炼专用 API/Worker，因此不从导入草稿生成结果，不写提炼 WorkingArtifact、不发布提炼分支。未来输出为标准化 Brief，人工保存版本才提交；直接下游为分镜创作，仅已有且实际引用旧 revision 的结果待更新。输出 key 与跨层契约留给后端实施确定。

## 页面与复用

- 保留既有共用画布、版本树和导航队列，不增加项目或 Run 状态。
- 五块信息卡：项目与视频用途、品牌与产品信息、目标受众、创意与风格、视频规格。承接现有 Word 模板，项目名称只展示、不修改项目；不恢复已删除的声音、文案、交付等栏目。
- 抽取效果类基础字段为共用展示组件；复用编辑动作、加载、进度、底部导航、资料行和阅读器。
- 前端使用受控展示模型承载空、加载、失败、部分失败、运行、已完成、待更新、编辑和来源差异状态；它不是 API DTO。正式入口没有服务适配器时禁用生成、编辑、提交和下一步，不展示演示结果。
- 来源入口只展示当前已确认资料的固定引用；编辑中的未确认导入资料不冒充提炼来源。图片保留参考用途，不由文件名推断产品事实。
- 模态框支持 ESC、焦点约束及关闭后焦点恢复；项目/Run 改变时关闭弹窗。

## 数据与迁移

仅 Web 展示，无 API、数据库、Worker 或共用业务契约迁移。现有资料包、草稿、revision、分支和 Redis 行为不变。不产生付费任务。

## 验收

- 正式入口切入第二节点，五块卡片与共享画布各出现一次；返回资料导入、来源阅读与刷新导航正常。
- 隔离展示用例覆盖受控字段修改、条目增删、来源/差异处理、编辑取消、保存事件以及加载、空、运行、失败、部分失败、完成和待更新。用例不代表后端执行或持久化成功。
- 在 1920、1440、390 宽度检查布局及弹窗；验证未接入时生成/保存/下一步均不可用。
- 相关单测、Web 类型检查、构建、格式及 diff 检查。保留其他已有改动，不提交 Git。

## 实施结果

前端页面、共用字段/卡片和来源阅读入口已实现。相关 71 项测试及 56 项浏览器断言通过，实际视口 1920、1440、390 已核对。完整 Web 构建受既有混剪删除测试类型错误阻塞；仅排除该范围外文件的类型检查、独立 Vite 打包通过。详见[验收记录](../evidence/browser/2026-10-09-information-extraction-frontend.md)。
