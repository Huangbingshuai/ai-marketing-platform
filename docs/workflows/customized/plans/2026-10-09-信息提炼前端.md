# 定制类信息提炼前端

## 范围与边界

实现固定六节点中的 INFORMATION_EXTRACTION 页面，替换当前占位页。直接上游为已确认 `customized-source-package` 的 artifactId + revision 及固定文件版本；当前没有提炼专用 API/Worker，因此不从导入草稿生成结果，不写提炼 WorkingArtifact、不发布提炼分支。未来输出为标准化 Brief，人工保存版本才提交；直接下游为分镜创作，仅已有且实际引用旧 revision 的结果待更新。输出 key 与跨层契约留给后端实施确定。

## 页面与复用

- 保留既有共用画布、版本树和导航队列，不增加项目或 Run 状态。
- 五块信息卡：项目与视频用途、品牌与产品信息、目标受众、创意与风格、视频规格。承接现有 Word 模板，项目名称只展示、不修改项目；不恢复已删除的声音、文案、交付等栏目。
- 抽取效果类基础字段为共用展示组件；复用编辑动作、加载、进度、底部导航、资料行和阅读器。
- 前端使用受控展示模型承载空、加载、失败、部分失败、运行、已完成、待更新、编辑和来源差异状态；它不是 API DTO。正式入口没有服务适配器时禁用生成、编辑、提交和下一步，不展示演示结果。
- 来源入口只展示当前已确认资料的固定引用；编辑中的未确认导入资料不冒充提炼来源。图片保留参考用途，不由文件名推断产品事实。
- 模态框支持 ESC、焦点约束及关闭后焦点恢复；项目/Run 改变时关闭弹窗。

## 数据与迁移

仅 Web 展示，无 API、数据库、Worker 或共用业务契约迁移。现有资料包、草稿、revision、分支和 Redis 行为不变。不产生付费任务。

## 验收

- 正式入口切入第二节点，五块卡片与共享画布各出现一次；返回资料导入、来源阅读与刷新导航正常。
- 隔离展示用例覆盖受控字段修改、条目增删、来源/差异处理、编辑取消、保存事件以及加载、空、运行、失败、部分失败、完成和待更新。用例不代表后端执行或持久化成功。
- 在 1920、1440、390 宽度检查布局及弹窗；验证未接入时生成/保存/下一步均不可用。
- 相关单测、Web 类型检查、构建、格式及 diff 检查。保留其他已有改动，不提交 Git。

## 实施结果

前端页面、共用字段/卡片和来源阅读入口已实现。相关 71 项测试及 56 项浏览器断言通过，实际视口 1920、1440、390 已核对。完整 Web 构建受既有混剪删除测试类型错误阻塞；仅排除该范围外文件的类型检查、独立 Vite 打包通过。详见[验收记录](../evidence/browser/2026-10-09-information-extraction-frontend.md)。

## 使用者反馈修订

移除顶部资料摘要与未确认提示条。信息卡与下载的 Word 模板五组、17 项一致：补上简报中的项目名称，移除独立产品事实列表，必须避免的元素改为文本字段，分组名称对齐品牌与产品介绍、创意需求。项目名称仅属于受控信息卡，不重命名系统项目，不改变资料包或业务 revision。宽屏使用两列组合卡片，窄屏按模板顺序单列；不改共享效果类布局。验收直接读取下载的 Word 模板，逐项比较页面字段名称、顺序与分组，避免页面和文档漂移。

## 字段命名与受众合并调整

按最新需求，将目标受众融入首张项目与受众卡，同步 Word 模板和填写示例为四组、17 项。标题使用发布渠道、品牌与产品名称、品牌与产品介绍、产品规格与使用说明、受众画像、核心传播信息、情绪基调、禁用元素、画幅与尺寸等明确名称，去除标题中的“或”和斜杠。宽屏按两行两列布局，窄屏按模板顺序排列。既有字段键与状态、提交边界保持一致；模板对齐测试同时核对受众字段所属卡片。

## 品牌与产品隔离修订

按最新截图替换前两张卡片：品牌基础信息仅包含品牌名称、项目名称、项目背景；产品核心信息仅包含产品名称、核心卖点、目标受众。取消品牌与产品混合字段，受众以一个文本字段描述，项目名称仅属于简报。视频用途和发布渠道移到视频规格；创意方向不改。采用共享卡片与字段，前两卡增加品牌 / 产品标记、分隔标题和纵向字段布局，窄屏顺序不变。模板与示例同步为四组、15 项。UI 展示模型独立品牌与产品字段，不通过旧混合文本推断归属，不改已导入文件、API、Worker 或已确认业务 revision；提炼后端仍未接通。验收核对模板、卡片字段及编辑隔离。

## 视频规格与创意字段精简

按最新反馈，视频规格改为视频时长、视频分辨率、视频画幅、视频格式；移除视频用途、发布渠道和创意方向中的核心传播信息。前两张品牌与产品卡保持原结构，创意方向保留四项。Word 模板和填写示例同步四组、14 项，UI 独立维护分辨率与文件格式，不将分辨率合入画幅，也不把偏好值当成已执行的渲染参数。保留现有受控草稿、编辑、来源和禁用边界，不改变导入文件、API、Worker、提交或业务 revision。测试核对模板全字段和卡片归属，浏览器验证三种宽度及字段编辑。

## 创作偏好与必须遵守的约束

按已确认方案，将创意方向改为创作偏好。视觉风格、主色调、情绪偏好为可选参考，可留空或填写多个方向；视觉与情绪参考选项支持追加多个值。品牌规范使用独立字段，与禁用元素共同放在必须遵守的约束分组，不将颜色偏好自动升级为品牌规范。模板、示例与 UI 同步四组、15 项；前两卡和视频规格保持现有结构。

多版本脚本生成应遵守确认产品事实、品牌规范和禁用元素，各版本可探索不同方案；只有选定脚本后再确认该版本内部统一风格。专用 API/Worker 尚未接通，本次仅调整受控 UI 展示模型、提示与模板，不伪装模型消费已实现，不改变导入资产或工作副本 revision。未来接通共用契约时须分别承载偏好和约束，不能通过关键词或 AI 推断把软偏好变成硬约束。验收包括模板全字段与分组、偏好与约束标记、空偏好无自动补值、多选追加及取消恢复。

## 品牌调性约束替换

最新需求替代前述创作偏好方案：移除整个创意方向区域，按截图展示品牌调性约束卡，包含品牌调性、视觉统一规则和画面禁用元素三个多行文本。使用共享卡片与字段，复用品牌 / 产品卡的浅色背景、标题分隔和风格标记。四组共 13 字段，Word 模板与示例同步，取消独立风格、色彩、情绪及品牌规范字段。既有确认来源、编辑隔离、取消恢复及禁用边界不变，不改变导入资产、API、Worker 或业务 revision。验证模板分组与字段一致，浏览器核对截图布局、三字段编辑与状态恢复。

## 产品核心信息补齐

产品卡增加产品介绍、产品规格、产品外观，不增加使用方式。顺序为产品名称、产品介绍、产品规格、产品外观、核心卖点、目标受众；页面和 Word 模板、填写示例统一四组、16 项。三个新增字段复用多行文本组件，明确产品本身的事实与外观要求，不自动补值或根据卖点推断真实规格和包装。未确定的外观可在文档中说明需要 AI 设计，后续生成方案仍须确认。

核心卖点保持一个多行文本栏目，允许分行描述多条独立优势，不划分核心 / 次要层级，不设固定数量，不让每条卖点对应一个脚本版本或要求每个脚本覆盖全部。未来标准化提炼应保留独立条目与依据，分镜节点按完整叙事选择和组合；本次不更改提交契约、API、Worker 或资料引用版本。验收核对模板全字段、取消恢复与新字段独立编辑、加载 / 空 / 错误 / 完成 / 待更新状态及三种宽度。

## 品牌约束合并与视频规格移除

按最新需求，品牌调性、视觉统一规则、画面禁用元素合并到第一张品牌基础信息卡，保留品牌标记、共享字段和来源入口。第二张产品核心信息卡的六项不变。页面与 Word 模板、填写示例改为两组、12 项，宽屏左右并列，窄屏品牌在前、产品在后。移除视频规格卡、四个规格字段、选项交互及专属样式，同时修订画布与页头描述。

仅调整定制类信息提炼受控 UI 与简报文档。直接上游仍为已确认 customized-source-package 的 artifactId + revision，未确认导入草稿不作为来源；专用提炼 API/Worker 和标准化 Brief 提交尚未接通，本次不新建输出、不推进 revision、不修改已导入文档或受影响下游。未来标准化 Brief 的直接下游仍为分镜创作。验收核对 Word 与页面的两组 12 项顺序、品牌三项合并后的编辑取消恢复、视频字段彻底移除，以及加载/空/错误/完成/待更新状态和三种宽度。

## 核心卖点逐条编辑与具体示例

按最新反馈，将核心卖点由整段文本改为独立字符串数组，每次添加只增加一条，可独立编辑、删除及清空。抽取效果类已有卖点列表为共享展示组件，两条工作流复用输入行、空态、删除控件、来源与语义提示插槽；效果类保持原有标题计数、添加入口、推荐数量、确认与保存逻辑。定制类复用相同添加样式及删除确认，保留产品卡中的核心卖点位置，不恢复其他卡片或视频规格。取消编辑由现有受控宿主恢复，不在组件内持久化。

模板两组 12 项不变，所有备注改为同一虚构陶瓷杯产品的具体例子，核心卖点示例明确每行一条。仅修改 UI 展示模型，直接上游仍为已确认资料包固定 artifactId + revision，未来输出标准化 Brief 与直接下游分镜创作的边界不变；无专用提炼后端，不改 Contracts/API/Worker、导入资产和业务 revision。删除确认等待期间须检查作用域与原数组，避免迟到操作移除新的条目。验证两工作流共享组件、独立增删改与取消恢复、只读禁用、空/加载/失败/待更新状态、三种宽度及 Word 全字段顺序。
