# 资产多视角设定图

依据用户本轮截图，将资产图片的默认交付改为同一对象的多视角设定图，而非单一角度展示图。属于定制类资产准备节点；直接消费当前脚本、Brief 和已确认对象目录，沿用准确的 artifactId/revision 与图片任务快照。

- 人物：面部特写及全身正、侧、背面，同一身份、服装及比例；只有局部出镜的对象按已定义可见范围制作，不补造真人身份。
- 实体产品：同一设计的正视、侧视、三分之四角度，补充已明确的关键结构；背部、底部和插脚等结构未提供或被明确要求避开时，不为凑视图展示该部位，改用已知部位的其他角度与细节。未知外观方案不能冒称资料事实。软件改为一致的界面/必要状态，不强制实体三视图。
- 场景：同一空间的全貌与不同方向，空间结构、陈设和光照对应；不是四套不同场景。
- 道具：同一对象的多个角度，必要时展示已确认的结构或状态。
- 每次每项仍生成一张 PNG；一张图内包含多个视角，不等于一次调用生成多张候选。保持无装饰标题/参数标注、干净底色与统一材质，不加入截图里的工具栏。

共用布局文案由 Contracts 内 JSON 定义，Web 默认提示词与批量输入读取同一实现，Worker 的无自定义输入兼容路径读取经过一致性测试的同文件副本。新批量任务显式冻结逐项默认提示词；单项支持编辑和恢复新默认。历史自定义提示词继续原样恢复，不静默覆盖人工文本；本轮通过恢复默认主动更新充电器提示词。

图片生成依旧写草稿，用户保存修改才提交 customized-object:<id> 与 customized-asset-catalog。同内容不增 revision；不新增分支，不影响兄弟脚本。资产引用供视频制作消费，本次不接通视频渲染，不拆图或为同一视角创建新资产身份。

验收：Contracts/Worker 布局一致性，Web 单项/批量与历史提示词恢复，Worker 参考图/失败/恢复测试；类型、构建和 diff 检查。使用现有充电器脚本在浏览器真实生成带 Logo 的多视角产品图，再重新生成验证旧图保留、结果保存与刷新恢复；模型调用次数、耗时和未确认设计单独记录。
