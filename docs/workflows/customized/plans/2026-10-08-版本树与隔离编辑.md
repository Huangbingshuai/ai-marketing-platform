# 定制类版本树与隔离编辑

用户要求画布交互、版本分支树和进入编辑操作与效果类一致。本次复用效果类画布、分支树弹层及其视图控制、取消编辑确认、节点编辑操作按钮，不复制第二套画布或弹层。

- 固定七节点保持不变。资料包导入没有直接上游；输出为 `customized-source-package`，包含需求摘要、规格和同项目定制资料资产的明确版本引用。
- 首次资料草稿直接保存在当前 Run。人工“保存版本”校验完整性、资产作用域和草稿 revision 后提交 WorkingArtifact。自动保存仅保存草稿。
- 已确认资料只读；进入编辑创建隐藏子 Run，复用通用 WorkflowRun、WorkflowNodeState、WorkingArtifact、指纹提交底座。刷新恢复隐藏编辑，取消返回原版本；同内容保存返回原版本且不增加 revision；变更成功保存才发布子分支。项目锁串行化切换、保存和退出，拒绝旧 Run 迟到写入。
- 分支树只查询 `projectId + CUSTOMIZED + CUSTOMIZED_PROJECT`，显示实际确认产物及七个阶段；导航不生成任务或增加业务 revision。其余六节点仍未实现生成任务，不能伪造确认产物或待更新。
- 不迁移数据库、不调用付费模型、不发布全局资产。后续节点以已提交资料包的 artifactId/revision 接入依赖。
- 验收：七阶段布局与效果类弹层共用；1920/1440/窄屏；首次保存、隔离编辑、取消、相同内容保存、两轮变更、历史切换与刷新、跨项目/工作流拒绝、旧草稿写入、错误恢复；回归效果类树与画布测试，类型、构建、diff 检查。
