# 视频制作工作台对齐火宝布局

使用者要求其余区域与火宝一致，仅适配系统颜色、不增加额外内容。参考[官方 episode.vue](https://github.com/chatfire-AI/huobao-drama/blob/master/frontend/app/views/drama/episode.vue)中的 video-main-grid、video-task-inspector 和 video-inspector-footer；沿用 develop-workflow-node 的状态、确认与验证边界，不复制上游实现。

## 实施范围

- 保留系统画布、编辑动作、真实任务进度与查看工作流；工作台内部改为统一边框三栏。左侧沿用刚完成的火宝式列表。
- 按使用者追加要求移除列表顶部“生成中 / 完成 / 失败”三枚统计标签及过滤逻辑，只保留标题、任务数与逐镜列表；每个镜头本身的真实状态保留。
- 资产准备和视频制作移除失败/取消终态横条及关联的恢复任务、候选查看、人工核对草稿入口，清理前端状态、弹窗和请求适配；运行中“已有内容 / 取消任务”横条和对应前端调用也按追加要求移除，保留真实进度。
- 中间上部是分镜描述（画面描述、氛围）与完整参考素材，下面是单一视频提示词编辑区。去掉卡片套卡片、重复标题、固定显示的保存区和展开参数表；原参数在编辑态从镜头参数弹窗维护，提示词有修改时在标题区保存。
- 参考素材只显示类别、紧凑图文项、绑定数和缺图“去生成”；移除额外搜索、全部/本镜筛选、查看定义和解释段落。点素材维护绑定草稿，点已有缩略图只读预览，缺图可走原真实图片制作入口。
- 右侧是分镜标题/状态/时长、视频空态、绑定参考图，底部固定时长和生成视频入口。无真实视频时不展示下载、主视频、历史记录；移除重复名称、输出设置表及常驻说明。未接通提示仍在真实制作弹窗中明确展示。
- 直接上游仍为当前脚本、已确认目录的准确 artifactId/revision；产物 customized-video-plan / customized-shot / customized-shot-prompt 不变。此轮不改 API、Worker、合同字段、提交和 stale 规则；不付费、不生成模拟媒体。Prompt 人工修改仍明确保存，切镜保存失败保留本地文字。
- 素材绑定、镜头参数和时长修改只写当前编辑草稿，取消可恢复；切换项目、Run、镜头关闭局部弹窗，拒绝旧图响应。

## 验证

单测和浏览器覆盖完整库、缺图/已有图、预览不修改绑定、绑定/取消、提示词保存与409保护、镜头切换、参数弹窗、时长、生成入口、空镜头和窄屏。运行定制类 Web 测试、类型与构建、格式/diff check。使用隔离受控夹具验证布局，不冒称真实项目/付费验证；截图保存在本流程 evidence/browser。
