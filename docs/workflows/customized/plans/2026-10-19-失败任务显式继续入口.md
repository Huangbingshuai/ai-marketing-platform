# 失败任务显式继续入口

补充 C13：接入现有 `POST production/tasks/:id/retry`，服务端校验 Run/来源/草稿及并发、保留原任务检查点并重新排队。前端不以新建任务替代恢复。

将局部失败反馈复用为 Prompt/Render 共用组件。只有当前最新 FAILED 任务提供“继续本次任务”，明确沿原快照、未完成步骤可能产生模型费用；无自动调用、不声称免费。通过原 Workspace 请求作用域和真实轮询处理，使用准确任务 ID，防重复点击、迟到回调和跨 Run 写回。

不为继续旧快照强制保存或清除本地修改；未保存时提示核对，服务端 409 原样保留草稿、旧提示词和旧视频。POST 响应不确定时只查询同一任务，不自动重发。取消、部分未完成及已完成状态不提供这次失败恢复入口。

验证两类任务、精确 ID/接口、轮询、重复请求、未保存输入、409、网络不确定、范围不匹配和作用域切换，复用 C15 浏览器键盘回归。仅本地，不改服务端、不操作线上、不付费、部署或执行 Git 写操作。
