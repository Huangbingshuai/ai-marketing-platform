# 定制类信息提炼深度付费验收

用户已授权真实付费测试，并要求关注耗时与稳定性。范围仅为定制类信息提炼，消费各测试 Run 已确认的 `customized-source-package` 固定 revision，输出待确认结果；不自动提交 `customized-brief`，不调用后续生成。

在已有验收基础上增加：长文分片、多工作表 Excel、PDF、多文档补充与规格冲突、标准表格附带正文及其他表格、空模板、单文件解析失败与检查点重试。全部使用无敏感信息的合成资料，通过正式上传、确认、任务 API 和真实 Worker/Ark 执行。测试台账持久化至系统临时目录，重跑默认查询，不重复创建任务。

记录总耗时、各阶段状态和模型安全用量日志；区分排队时间与执行时间。测试以明确输入事实和来源作为校验依据，不将任务成功等同于质量通过。失败文档不得确认，成功检查点在同输入重试时复用。发现事实丢失或无效调用后增加回归测试，Worker 空闲时更新代码再真实复测。

优化遵循有界并发、有限重试、取消及租约校验，不删除语义校验、不静默降级，不为速度牺牲完整事实。记录样本规模和运行环境，不以少量样本承诺固定耗时或 SLA。检查相关 pytest、mypy、差异格式；涉及 API 变化追加 API 测试和类型检查。不自动提交 Git。
