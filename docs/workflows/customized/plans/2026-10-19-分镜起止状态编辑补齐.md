# 分镜起止状态编辑补齐

范围：视频制作分镜参数弹窗。`VideoShot.startState/endState` 与 `VideoClip.startState/endState` 已存在，当前弹窗遗漏输入。Prompt 消费已确认的镜头及片段状态，单独修改正文会保留旧状态。

直接在现有参数字段加入开始/结束状态，沿用 `mutateTask`、历史多镜头合并、`update-plan` 和 Workspace 的同 Run 自动保存确认。一次明确编辑同步当前镜头与片段状态，不修改其他分镜、上游脚本或已有提示词，不创建新任务/分支，不根据正文猜测起止状态。API 与 Worker 契约不变。

验证：单镜及历史合并、起止同步、兄弟分镜隔离、只浏览不写、运行中只读、自动保存后刷新恢复、原作用域及已有来源/声音数据保留；相关测试、类型、构建与浏览器受控检查。不部署、付费或执行 Git 写操作，保留其他任务已有改动。
