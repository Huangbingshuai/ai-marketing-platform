# 逐镜提示词与视频并行

## 目标

按用户要求，已保存提示词的片段立即进入 Seedance 渲染，同时生成其他片段的提示词；不同片段可并行，同一片段的提示词与渲染仍互斥。

## 边界

- 定制类视频制作节点，直接消费当前已确认片段及实际引用资产 revision。
- 提示词和视频分别原位提交现有工作副本，不新增 Run、镜头或版本分支。
- 资产整理、生图、整份分镜、旧版无片段目标任务仍保持 Run 级互斥；整体编辑仍冻结。
- API 在项目事务锁下检查活动目标，创建及手动重试使用相同规则。保存某片段提示词仅与该片段及整体任务互斥。
- Worker 对视频节点进行有界并发消费，模型调用并发限制、租约、attempt token、取消及故障恢复保持独立。资产 Worker 保持原消费方式。
- 页面保留整体编辑保护，但允许切换并生成其他未被任务占用的片段；所有活动任务持续轮询。
- 不改变审校标准，不伪造失败任务成功，不自动重渲染已有视频。

## 验收

1. 不同片段 Prompt/Render 可同时排队运行，同片段及整体任务拒绝冲突。
2. 创建和重试幂等；迟到回调、来源变化和其他分支隔离仍有效。
3. Worker 多个消息独立执行，单项异常不取消兄弟任务，停机保留可恢复消息。
4. 本地测试、类型、构建通过后，在无活动任务时部署。
5. 咖啡杯项目已完成提示词立即渲染，其余片段继续生成；记录真实重叠时间并验证最终 MP4。
