# 定制类需求资料合并

本次用户修订取代三区方案：制作需求与产品介绍、规格统一进入“需求资料”，视觉参考图片继续独立、可选。正式页面、下载模板和校验提示使用面向使用者的表述。

- 节点仍为 `CUSTOMIZED / SOURCE_IMPORT`，无上游工作副本。文字或有效需求文档满足保存条件，图片不替代需求资料。
- 复用效果类上传卡片、拖拽框、文件行、阅读器、图片缩略图、画布与版本编辑交互。不增加结构化必填配置表。
- 单一需求文本使用 schemaVersion 3。v2 两块文字按原顺序合并，保留产品资料标题；旧文档引用归入统一需求区域。v1 的原始需求、调性和约束保留。读取投影不改数据库，规范化新旧内容后比较，格式转换不增加业务 revision。
- 保存版本仍提交 `customized-source-package`；标准化提炼消费具体 artifactId/revision，后续专用生成链路仍未接入。
- 需求模板按“制作目标、产品介绍与事实、呈现与交付要求”组织内容，各段提供提示而非强制字段；未知内容可留空，附件可替代重复填写。图片在可选参考区补充并标注用途。
- 验证旧格式合并、附件与图片分流、模板内容、错误重试、刷新、编辑取消、历史切换、同内容不增 revision、相关类型/构建和响应式布局。无付费模型调用。
