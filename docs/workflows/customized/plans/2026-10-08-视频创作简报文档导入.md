# 视频创作简报文档导入

本次用户修订取代原文字填写方案。统一名称为“视频创作简报”：用一份文档整合制作目标、产品信息及展示重点、创作方向和交付要求；允许补充多份文档，图片区仍独立可选。

- 范围为定制类 `SOURCE_IMPORT`；直接输入为本地文档、可选图片，不新增上游工作副本。
- 移除文本框及两个区域的项目资产选择按钮、查询、绑定状态和界面。保留共用上传、文件阅读器、缩略图、加载组件、画布和编辑/版本树。
- 新确认至少包含一份有效文档；纯历史文字或图片不能满足新确认条件。服务端沿用真实资产类型、项目/Run 隔离、资产版本及草稿 revision 校验，不只依赖前端。
- 保留 schemaVersion 3 中历史文字兼容字段，只提供只读查看和下载为文档，不静默丢弃或伪造上传。已经确认的同内容保存继续保持原业务 revision。
- 用户保存版本仍提交 `customized-source-package`，标准化提炼消费具体 artifactId/revision。后续专用任务未接入，不触发模型或付费任务。
- 模板提供制作目标、产品与展示重点、创作与交付要求；名称及页面不使用“客户”。未知项可留空，主简报覆盖完整信息，补充文档按需上传。
- 验证文档必需、图片可选、多文档上传、错误重试、旧文字保留/下载、移除引用、版本保存/刷新/取消及 1920/1440/390 布局；执行契约/API/Web 测试、类型/构建、Lint、格式和 diff 检查。
