# 附属资产图片前端交互

范围：定制类资产准备与视频制作。复用 Contracts 的图片归属解析和选择校验，不修改后端、Worker 或线上任务，不执行付费、部署及 Git 写操作。

- 直接读取当前 Run 的资产目录及 `preparation`；独立对象和无 preparation 的历史对象可独立备图，场景/人物附属对象沿有效父级复用图片。
- 保留全部定义；附属对象不计作独立缺图项、不默认加入批量付费选择。非法或缺失归属禁止生成。批量及单项提交再次校验当前目录，保存后的归属变化也必须重新检查。
- 查看附属对象可阅读、明确编辑制作归属；单项图片入口转向父对象定义。视频参考素材保留原对象绑定 ID，缩略图、预览和缺图导航使用父级图片来源；导航沿用现有自动保存保护。
- 不复制父图到子对象、不新增业务状态，不改变资产目录确认及下游 WorkingArtifact revision 语义。人工归属变化继续保存现有编辑草稿，明确保存后提交。
- 验证 14 项中 10 独立/4 附属的默认选择、非法选择与父级环路阻断、父图预览及导航、归属人工编辑、历史数据兼容；执行相关单测、Web 类型检查/构建、响应式浏览器合成夹具验证与 diff 空白检查。
