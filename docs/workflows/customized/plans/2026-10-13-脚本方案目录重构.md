# 脚本方案目录重构

## 范围与边界

定制类脚本创作（STORYBOARD）前端方案选择器。上游为已确认的 `customized-brief`，各方案继续使用现有独立脚本草稿及 `customized-script:<scriptId>` 产物；显式保存才提交。浏览方案仍只保存查看偏好，不切换实际 Run、不发起生成、不增加业务 revision；下游资产准备、视频制作的引用规则不变。

保留当前未提交的脚本阅读层级整理，替换其中的原生下拉框；不修改 API、Contracts、Worker、正文和创作说明布局。

## 调研与设计

- [Carbon 可选择 Tile](https://www.carbondesignsystem.com/building-blocks/core/components/tile/guidelines)：借鉴整体点击、明确选中边框及选择标记。
- [Adobe Spectrum Cards](https://spectrum.adobe.com/page/cards/)：借鉴标题、摘要及元信息的层级，编辑、导出、对比继续放在独立工具栏，不嵌套在可点击卡片中。
- 冻结定制原型的第三节点已有横排方案卡片，但其“主脚本”语义和旧资产/分镜流程不适用于当前系统。仅参考并排浏览方式，继续使用系统现有配色和组件。

独立方案目录组件：默认单行横向卡片，宽屏四列、中屏三列、窄屏一张完整卡片并露出下一张。显示真实编号、标题、两行概述、时长；只标记“当前查看”，不虚构评分、封面或发布状态。上一组/下一组只滚动目录，展开全部将同一目录切为网格，不重复挂载方案。

点击复用原 select 事件；受控选中值只跟随父级确认后的 activeScriptId。方向键/Home/End 移动卡片焦点，Enter/Space 选择，避免焦点浏览触发草稿保存。刷新、追加方案、收起目录时使当前项可见；组件销毁清理尺寸监听。项目切换重建本地目录状态。

## 验证

覆盖空列表、单方案、八方案、长标题与无概述的真实渲染；相关前端测试、Web 类型检查、构建及 diff 检查。浏览器使用已有充电器项目检查 1920、1440、窄屏的卡片、滚动边界、展开/收起、鼠标/键盘切换及刷新恢复；不调用模型。
