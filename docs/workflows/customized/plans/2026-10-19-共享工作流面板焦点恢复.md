# 共享工作流面板焦点恢复

C15：详情错误恢复时，当前“重新查询”按钮会被加载/结果内容替换，焦点落到 body；共享面板只接收内部 keydown，所以 ESC 失效。现有契约为打开聚焦关闭按钮、面板内 Tab 约束、ESC/遮罩/按钮关闭、关闭后回到触发按钮。

仅修改共享 `WorkflowExecutionGraphDialog` 与相关测试，不新建弹窗、不改各工作流状态或详情请求。活动面板观察 DOM 中的焦点目标失效，在没有更上层弹窗接管时恢复到当前关闭按钮；仍然有效的输入、选区和嵌套控件不抢焦点。关闭/卸载释放观察器，并拒绝迟到焦点恢复。完善 Tab 的输入/文本域/可编辑控件及无控件退路，ESC 尊重 defaultPrevented、输入法组合和嵌套对话框，只关闭当前层。

验证当前定制查询失败→重查、效果类对同一面板的使用、错误/加载/成功切换、嵌套控件和原生对话框、正反 Tab、焦点返回、关闭后迟到更新、重复打开/卸载；单测、类型、构建及浏览器合成回归。无 Git 写操作、线上操作、付费或部署。
