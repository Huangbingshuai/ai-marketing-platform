# 生图输入刷新与作用域保护

已在独立 Composer 组件复现：同 ID 的资产对象替换会触发数组 getter watcher，静默中止上传、清空参考图并重新启用生成。当前 Workspace 的普通刷新对照未复现，因此不认定它是首次线上漏引用原因。

仅修改 Composer 及相关测试。相同项目/Run/对象身份、相同资产制作依据及历史设置重新物化时，不重置本次提示词、模型参数、参考图片或上传。图片投影和人工字段标记变化不作为制作依据冲突，不复制父图到子对象。

真正换身份中止旧请求，载入新对象设置并显示切换提示；同身份制作依据发生变化时保留本次输入、中止未完成上传、暂禁生成，并明确提供“沿用本次输入”或“载入最新设置”核对动作。上传冻结作用域、检查取消与迟到响应，不能将旧图片写入新对象。复用现有弹窗与局部状态，不新增缓存、API、任务或数据模型。

验证上传中与完成后对象替换、历史设置重物化、制作依据变化、真实项目/Run/对象切换、迟到成功/失败回调、批量多文件、运行中禁用、Workspace 刷新对照和三个宽度浏览器合成测试。不部署、付费或执行 Git 写操作。
