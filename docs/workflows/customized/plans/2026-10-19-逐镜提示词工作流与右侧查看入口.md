# 逐镜提示词工作流与右侧查看入口

## 范围与依据

完善定制类第五节点视频制作中的PROMPT操作，继续复用独立视频Worker、任务表、租约、共享进度条及工作流弹窗，不新增业务节点或另一套任务状态。直接上游为当前已确认`customized-video-clip:<clipId>`及准确revision，间接冻结简报、分镜文字、实际素材和声音来源。成功自动原位提交`customized-clip-prompt:<clipId>`，不发布分支、不修改分镜或兄弟任务；同内容不增revision。实际视频渲染不在本次范围。

开源参考：

- [火宝视频提示词规范](https://github.com/chatfire-AI/huobao-drama/blob/master/backend/workspace/skills/prompt-generator/video-prompt/SKILL.md)：采用当前分镜驱动、素材名称引用、连续时间段、可见动作及原台词保持。适配本项目已有4–15秒规划，不照搬其8–15秒或内部子镜头编辑结构。
- [火宝逐镜任务服务](https://github.com/chatfire-AI/huobao-drama/blob/master/backend/src/services/video-prompts.ts)：采用单镜生成和原位保存；保留本项目数据库检查点与恢复，不采用进程内任务Map。只学习交互和设计，不复制上游提示词正文、代码或许可证声明。

## 六个真实执行阶段

| 阶段                    | 执行与点击查看内容                                                                        |
| ----------------------- | ----------------------------------------------------------------------------------------- |
| SNAPSHOT 本镜创作依据   | 已确认完整画面、氛围、时长、实际素材及固定来源                                            |
| PLAN 画面与素材安排     | 代码整理实际动作/镜头要求、素材用途、原稿声音和屏显时间窗；不额外调用模型、不虚构规划产物 |
| GENERATE 视频提示词创作 | 依据当前分镜组织可执行时间段、场景/人物/产品/道具名称引用及原声音文字                     |
| REVIEW 独立审校         | 核对画面兑现、容量、事实、连续性、实际引用及原句保持，展示问题和证据                      |
| REPAIR 定向修订与复核   | 有确切问题才最多一次修订和一次复核；无问题明确说明无需修订；不能静默改上游                |
| SAVE 原位保存提示词     | 服务端检查冻结来源、租约、完整审校与目标身份，自动保存到当前分镜，不新增分支              |

正常两次主要模型调用；已有有界供应商/结构纠错和检查点继续复用。新任务冻结独立`promptWorkflowVersion=2`，历史任务按原策略恢复。品牌图片不进入文字模型，也不声称看过图片或渲染。正文用可读素材名，不展示内部ID或字段标签。

## 前端与隔离

提示词标题右侧并排显示生成/重新生成与“查看工作流”，复用共享弹窗，不复制弹窗和样式。该入口仅查看当前选中分镜PROMPT任务，尚未生成显示真实空态；页面顶栏查看仅对应SHOTS，资产页面仍对应ASSETS。运行进度入口按正在执行操作打开准确任务。通过鉴权的`GET /prompt-task`按项目、Run及当前clip按需读取最新任务，避免30条全局记录上限使旧分镜失去入口。

按用户补充，参考素材区维护分镜可使用的候选；提示词可以从中选择实际引用，不要求全用。右侧绑定参考图只从当前提示词的完整`@素材名称`解析，去重后显示已有图片；未生成提示词不展示候选图，缺图不伪装就绪。手动编辑实时同步，明确保存时由API核对`assetIds`与正文引用一致。新AI任务同样核对实际引用，旧任务继续原冻结规则。此点明确采用用户要求，区别于本地核对的火宝版本：其`boundRefAssets`来自分镜绑定，`resolveVideoPromptRefs`再把正文引用映射到图片编号，并非按`@`筛选右栏。未接通渲染，不编造实际供应商图片提交。

切换分镜、Run或项目拒绝迟到详情；查看不付费、不保存、不发布。生成失败保留旧提示词及真实详情；成功静默刷新，保留当前分镜选择；进度条结束即消失。不恢复取消/恢复任务控件。

## 验收

覆盖任务按操作/分镜隔离、首次空态、历史查看、运行/失败/成功、切换与迟到响应；验证原位提交与同内容不增revision、重复回调及兄弟分镜不变。执行相关Contracts/API/Web/Worker测试、类型检查、构建及diff检查，实际浏览器验证右侧入口、六节点业务详情和关键宽度。沿用用户已有授权，在现有充电器项目做一次限定逐镜真实付费验证，记录耗时、调用量及未验证范围，不生成图片或视频。
