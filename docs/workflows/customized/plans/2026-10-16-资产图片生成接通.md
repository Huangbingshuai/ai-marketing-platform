# 资产准备图片生成接通

## 范围与提交边界

在现有资产准备节点接通单项、批量和重新生成图片，复用 CustomizedProductionTask、Outbox、资产 Worker、项目文件存储及共享进度/工作流面板。不改变六个业务节点，不接视频渲染，不改写脚本与镜头。

输入是当前选定脚本的准确 WorkingArtifact revision、已确认资产目录及待生成对象定义。生成前明确保存资产定义；任务冻结模型、尺寸、对象清单和品牌文字约束。每项生成一张公共形象图，图像需求用于构图，不将多个独立图片交付要求伪装成多张文件。暂不提供多视图图库、品牌图片参考或视觉审校；未知外观仍属设计方案。

每张合法图片通过受保护文件回调保存为当前项目视觉资产，并原子记录任务检查点及生产草稿引用。不自动确认资产目录；用户保存修改才更新对象工作副本，使实际引用旧对象的下游待更新。已完成图片即时可查看，失败恢复复用检查点，重生成失败保留旧图。取消后拒绝迟到写回。

## 模型与 UI

模型目录来自共享契约和服务端校验，手动选择固定型号 Seedream 5.0 Pro / Flash，提供 1K / 1.5K / 2K 与常用画幅；不接受任意模型字符串。基于[官方 API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=en)和[模型列表](https://docs.volcengine.com/docs/ark/model-list?lang=zh)，不静默换模型。使用已有图片确认弹窗、字段、进度与工作流组件，保留视频渲染未接通提示。

## API 与 Worker

增加 IMAGE 操作，沿用资产队列和 Token；任务消息仍只有标识。服务端验证 Run、revision、对象身份、配置、幂等及项目删除状态。图片经 Ark Provider 使用 b64_json 返回，避免任意外链下载；文件大小、签名、MIME 由共享上传校验检查。文件 IO 在数据库事务外，最终事务再次验证租约和输入；失败清理本次暂存文件。

图片调用和上传有界重试，任务续租/取消沿用现有机制。逐项保存后重试跳过成功对象；整体失败不会伪装完成。图片调用独立配置，不能更改文字整理模型。

## 验收

契约正常/非法模型、尺寸、数量；API 幂等、跨项目、租约、重复文件回调、部分失败恢复、取消、旧来源、同内容保存；Worker 真实协议受控响应、429、超时、非法图片、取消及恢复；浏览器模型设置、单项/批量入口及共享面板；相关单测、类型检查、构建、pytest/mypy、Compose 配置与 diff 检查。受控测试不代表真实付费生图质量验收。本次不主动触发新付费任务，不自动提交 Git。

## 开源交互参考

[火宝](https://github.com/chatfire-AI/huobao-drama/blob/master/README.zh-CN.md)的资产逐项/批量生成、模型手动切换和生成前核对适合当前任务；采用这些交互原则，保持本系统现有共享组件和配色。[RichiDrama](https://github.com/Moemu/RichiDrama)用于核对资产与分镜的工作台分工，不引入其账号、计费或媒体状态体系。模型设置与对象清单分栏，批量允许勾选、优先选择缺图项；每项完成立即关联，错误恢复保持已有成果。
