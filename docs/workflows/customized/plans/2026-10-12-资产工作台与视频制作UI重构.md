# 资产工作台与视频制作 UI 重构

本轮按用户最新要求整体替换资产准备的表单墙，并重组视频制作。只改变 Web 展示与交互，不改固定节点、模型执行图、已确认内容和业务 revision。图片与视频真实生成沿用此前“另行接通”的边界；本轮补齐可打开的制作入口及真实未接通状态，不显示模拟生成结果。

## 开源调研与采用

- [火宝 episode.vue](https://github.com/chatfire-AI/huobao-drama/blob/master/frontend/app/views/drama/episode.vue)：实际源码中资产区使用分类、封面、生成/上传动作和详情；视频区使用镜头任务列表、画面/氛围编辑、完整候选资产库、提示词和右侧播放器/历史。参考素材包含完整候选集合，通过 bound 区分当前绑定；不是把所有候选自动传给模型。采用此信息架构，保留本系统产品独立分类。
- [RichiDrama](https://github.com/Moemu/RichiDrama)：官方仓库说明涵盖素材、分镜和视频生成。API 源码目录查询被 GitHub 限流，本轮不把未经核对的内部实现作为依据。
- [DramaClaw](https://github.com/dramaclaw/dramaclaw)：官方 README 说明资产库与制作工作台组织方式；借鉴对象库独立于镜头视图的职责，不引入其节点编辑器或运行底座。
- 本仓库冻结原型的逐镜视频区在浏览器核对：保留逐镜预览、绑定、提示词、输出设置与生成入口；原型的 Mock 成片及成功状态不复制。

## 边界与数据

资产准备直接消费当前脚本及 Brief 的固定 revision，继续输出 customized-asset-catalog / customized-object:<id>；视频制作消费完整脚本、已确认目录，继续输出 video-plan、shot、shot-prompt。浏览、筛选、查看图片和打开制作配置不创建任务、不确认版本。所有数据沿用 productionApi / 当前项目与 Run；不建立第二套素材状态。

## 实施

1. 资产准备：分类侧栏、搜索/备图过滤、分类卡片网格、图片封面与状态、单项/批量图片制作入口；定义/依据/图像要求放入共用详情弹窗。保留添加、删除、合并、编辑、取消与显式确认。
2. 视频制作：镜头任务列表；中部画面与氛围、可折叠细节、完整素材库及勾选；下方提示词；右侧逐镜预览、输出规格、素材准备状态、历史与渲染入口。绑定与未绑定视觉区分，单镜请求仍只传实际绑定子集。
3. 抽出两页共用的资产缩略图、素材库和渲染入口组件。图片引用只读取固定 assetId/version；没有文件时显示空态，不使用样例充当结果。
4. 图片/视频生成未接通时入口可打开制作详情，提交按钮明确不可用；不虚构模型选项、生成历史、上传能力或进度。

## 验收

使用现有充电器项目验证两页、分类搜索、详情查看、取消编辑、素材绑定、提示词保存、工作流弹窗及渲染入口；1920 / 1440 / 430 检查布局。运行定制类测试、typecheck、build、diff check。无付费生成、无数据库迁移、无自动 Git 提交。截图和结果另记 evidence。
