# 定制类资料导入 Redis 缓存

## 范围与提交边界

仅接入 CUSTOMIZED / CUSTOMIZED_PROJECT 的资料导入恢复读取：活动 Run 概览、SOURCE_IMPORT 草稿、版本分支树。复用效果类 Redis 连接、版本核对、同进程合并、回填租约、大小限制和故障回源，不新增缓存底座或接口。

资料导入没有上游工作副本；输入为项目上传资料的 assetId + assetVersion 引用。自动保存仍只写 WorkflowNodeState；保存版本仍提交 customized-source-package，内容未变化不增加业务 revision。信息提炼是直接下游，本次不实现生成任务或新建下游产物。

## 新鲜度与隔离

- 键包含项目、工作流、实际 Run、资源、参数及 PostgreSQL 依赖版本；效果类原键和读取行为保持兼容。
- 数据库单语句核对定制类 Run / 草稿 / 工作副本行版本，覆盖编辑子分支、发布、取消、切换、保存和删除。缓存命中和加载完成再次核对，迟到读取不能返回已过期内容。
- 活动概览保留 Run 导航和更新时间依赖，不能用效果类业务投影忽略导航时间的策略。
- 只缓存 schemaVersion 3、requirements 为空的文件引用草稿；历史文字草稿、其他节点、未知扩展字段不写 Redis。文档正文、文件二进制、签名 URL、任务权威状态不缓存。文件预览、固定资产版本、确认时存储可读校验保持原读取边界。
- 复用现有 EFFECT_READ_CACHE_* 配置；项目异步删除的同命名空间扫描同时清理定制类缓存。无迁移，无前端契约变化。

## 验收

单测验证 SQL 作用域、依赖完整性、安全边界、缓存键隔离和服务接线。真实 PostgreSQL / Redis 随机项目验证重复读取命中、两轮草稿变化、无变化保存、编辑/取消、分支发布/切换、刷新恢复、旧请求迟到、兄弟项目/工作流隔离及 Redis 故障回源；测试应用禁用后台调度，不处理用户任务。执行 API 类型检查、相关测试、构建和 diff 检查，记录实际结果。
