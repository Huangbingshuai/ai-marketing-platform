# 脚本选择与当前路径同步

用户于 2026-10-20 明确调整规则：脚本创作中切换脚本，同时切换版本树当前路径；继续资产准备、视频制作及返回上游后再往下，保持该脚本路径。覆盖此前“只保存查看偏好、不激活 Run”和“同信息卡脚本同时高亮”的规则。

## 边界

- 作用于定制类 STORYBOARD 选择、版本树显示和普通节点导航。
- 上游仍为该脚本引用的 `customized-brief` revision；脚本工作副本、资产和视频内容不变。
- 复用脚本设置的 selectedScriptId、已有分支激活接口及项目 Run 上下文。导航不生成任务、分支或业务 revision。
- 同脚本当前制作后代优先保留；切回脚本时优先恢复本页面记住的有效路径，否则选已有最新制作后代。版本树明确选择资产/视频版本仍精确激活。
- 不改生成模型策略、数据库或业务契约。

## 实施与验收

1. 在脚本选择保存成功后，等待父页面同步活动路径；失败恢复选择，旧响应不得覆盖后来选择。
2. 分支高亮只沿实际当前路径，不再将同信息卡的全部脚本标为当前。
3. 复用现有祖先关系判断，防止跨脚本、已删除分支或循环祖先误命中。
4. 覆盖 A→B→A、下游与上游导航、刷新读取、同脚本多资产分支、迟到响应和失败保护。运行相关单测、类型检查、构建及 diff 检查。
5. 浏览器及线上生成记录分别报告。无活动任务时部署；只更新前端时不重启付费 Worker。
