# 脚本与后代分支永久删除

范围：定制类脚本创作节点。直接上游为脚本记录冻结的 customized-brief artifactId/revision；删除不修改上游 revision，不创建新版本。

- 在当前脚本操作区增加永久删除入口，复用系统确认弹窗，说明脚本及全部后代资产准备、视频制作和交付分支均会删除。
- API 按项目及 CUSTOMIZED_PROJECT 隔离，在项目锁内检查脚本 revision，计算完整后代闭包。数据库事务硬删除脚本、分支、节点草稿、工作副本、历史版本、任务、检查点、Outbox 和该分支归档的项目资产。共享上游及兄弟分支保留；当前活动分支被删除时回到保留的上游。
- 同批多个脚本共享任务：移除被删除脚本的输入与检查点，保留其他脚本。租约仍有效的旧脚本回调只返回已移除，不重新创建记录；任务完成数量以剩余脚本计算。无剩余脚本的任务一并删除。
- 文件使用现有 StorageCleanupTask 持久队列异步清理，不等待对象存储。仍被保留分支引用的 FileObject 转移至保留上游，独占文件记录删除后才排队。不是归档、软删除或仅隐藏分支。
- 前端删除确认后仅当前脚本进入删除中状态，无整页遮罩；取消自动保存定时器、串行完成已发出的写请求，再用最新 revision 删除，不为即将删除的本地内容额外保存一次草稿。删除成功刷新脚本目录及分支树；当前存储 Run 被移除时重新读取服务端活动 Run。
- 不新增固定工作流节点，不生成模型任务，不删除测试之外的真实项目数据，不提交 Git。

验证：随机数据库项目构建兄弟及两层后代，检查实际表删除、文件清理队列、共享文件保留、活动版本回退、重复删除、revision 冲突、跨项目访问和迟到回调。运行相关 Contracts/API/Web 测试、类型检查和构建；浏览器检查删除入口、确认取消及隔离测试项目删除。
