# 2026-10-19 定制类逐镜视频渲染接通与真实验收

本轮完成视频制作节点的逐镜视频渲染，复用效果类模型选项、能力配置、下拉选择组件及 Seedance 传输适配。没有新增业务节点或 Worker；RENDER 由现有 customized-production-worker 执行。本轮不包含整片合成、包装或交付。

## 已实现

- 每镜独立选择模型、画幅、分辨率；按所选模型限制可选值，设置自动保存，切镜与刷新后可恢复。模型仍从 API 配置冻结，不在前端直连供应商。
- 消费已确认分镜及提示词 revision，只读取正文真正 `@` 引用的固定图片版本，不使用所有候选素材；缺图、非法规格、来源变化均阻止付费创建。没有实际引用可纯文字生成。
- 五阶段：渲染依据、准备参考图、生成视频、视频文件校验、原位保存视频。共享进度在完成后消失；右栏工作流入口可以继续查看真实结果。
- 供应商任务身份持久化，断点恢复继续查询或下载。限流有界重试，明确拒绝与创建结果未知分别处理；未知结果不自动重买。
- 视频与封面通过文件校验、项目/Run/租约/输入版本校验后自动提交 `customized-clip-video:<clipId>`。不创建版本分支；相同来源及相同视频、封面不增加业务 revision。失败保留旧视频。
- 浏览器可播放与下载；API 支持视频 Range，文件和图片地址均经项目权限读取。公共任务不返回供应商任务身份、原始请求或存储地址。

## 修复与受控验证

- Contracts：`pnpm --filter @ai-marketing/contracts test`，25文件312测试通过，含Python渲染输入Schema一致性、未知键、模型参数及边界。
- Web：定制类production、效果类segment-render和共享选择器相关测试，22文件231测试通过。
- API：开启隔离数据库测试后production目录12文件38测试通过；效果类视频文件解析23测试通过。覆盖跨项目、Worker角色、重复任务、参数不同的幂等冲突、租约、两轮来源变化后的迟到写回、兄弟Run读取隔离、同文件不增revision、失败保留、未知创建与明确拒绝、缺图付费前阻断及纯文字输入。
- customized-production：pytest 67通过，mypy 23源文件通过；包括已创建任务恢复、未知创建停止、401/429区别及Schema一致性。
- effect-segment-render：pytest 44通过，mypy 8源文件通过；保留效果类请求编译及返修业务，只共享传输。
- 工程：工作区类型与生产构建通过；大于500KB主包的既有拆包提示仍存在。相关ESLint及diff检查通过。
- Compose：开发配置检查通过；生产配置以占位变量及`--no-env-resolution`检查结构通过，本机没有`.env.production`，不表示生产凭据已验证。
- 已重新构建并实际更新customized-production-worker，确认消费者就绪、FFmpeg可用并完成上述真实任务。效果类只做镜像构建回归，不重启其运行消费者。

异常回归使用受控适配与隔离数据库，没有为制造故障额外购买视频。其他模型、画幅、清晰度和批量真实生成未逐一付费验证；不把这一条视频的耗时推广为服务保证。
