# 脚本类型分流实施与验收记录

日期：2026-10-13。对应[实施计划](../plans/2026-10-13-脚本创作类型分流与创作线路重构计划.md)。

结论：四类条件分流、真实阶段详情、柔性结构映射、局部修订与独立复核已接通并部署。工程回归和充电器实测完成；创意质量、跨产品矩阵及稳定性能基准尚未全部达标。本记录不把模型审校通过等同于人工创意验收通过。

## 1. 实施内容与边界

- 新任务使用 `TYPED_CREATION_V1 / VIDEO_SCRIPT_V3`，当前策略版本为 `2026-10-13.3`；输入冻结已确认 Brief 的 artifactId、revision、fingerprint、设置和阶段模型。旧 V1/V2/无标记任务仍走原恢复路径。
- 输入快照、资料整理、类型路由为确定性步骤。电商带货、同城到店、品牌广告、剧情短片分别有自己的构思、正文、审校节点；只执行选中的线路，不为另三类发起模型调用。
- 构思产物包含对应类型的真实规划与资料充分性结果。正文按自然篇章阅读；结构要求通过正文 ID 和真实引文映射，不要求营销环节就是篇章标题，也不要求两者数量相同。
- 审校后有实质错误才进入定向修订。`.3` 使用稳定正文 ID 的替换补丁，正常段落保持；独立 RECHECK 复核完整稿，失败不发布。正常单方案主要调用为构思、正文、审校三次；修订另加两次。
- 输出超限时，在供应商已有有界扩容仍不足后，按自然篇章生成；保存提纲和已完成篇章，恢复只补缺失部分。该恢复机制通过受控测试，未在本轮付费样本中触发。
- 共享工作流弹窗支持条件连线、选中线路及全部线路视图；效果类继续使用同一组件。节点详情展示实际规划、正文、审校与修订结果；进度来自服务端，完成后隐藏。
- 未实现新的资产图片、视频渲染能力，未改变固定六个业务节点，未提交 Git。

## 4. 人工质量判断

- 品牌首轮偏“取出、展示、接线、收回”的操作目录，未达到品牌创意目标。强化规则后的三份仍有类似倾向；有视觉切入点，但方案间观看体验差异不足。模型没有判出 ERROR，说明仅增加审校指令尚不足以稳定识别此问题。
- 电商稿具备明确问题与产品关联，结构兑现、端口事实和估时通过本轮核对；表达仍属常规功能演示，不据此宣称高级创意。
- 剧情稿已有目标、关系、阻碍与选择，篇幅不再是概述；但部分对白仍明显用于解释功率参数，人物互动自然度有提升空间。审校给出插座位置连续性与时长容量提醒；没有 ERROR，故按规则发布。
- 当前 Brief 自身要求准确呈现多项规格。后续质量优化应区分“全片不可违背的事实”与“这份脚本必须表现的内容”，不能擅自删改用户 Brief，也不能用重复参数代替叙事。

工程实现已完成，人工创意质量仍需独立迭代。没有把普通审美意见全部升级为硬错误，也没有通过无限修订、跳过审校或降级模型掩盖问题。
