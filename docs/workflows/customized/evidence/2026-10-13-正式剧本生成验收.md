# 正式剧本生成与充电器付费验收

日期：2026-10-13。范围：定制类脚本创作；现有「充电器」项目，消费已确认信息卡 revision 1。用户已明确授权真实付费测试。本次未执行资产图片或视频渲染，未提交 Git。

## 实现结果

新任务冻结 `SCREENPLAY_V1` 格式。完整正文按 `S01｜内景 · 地点｜时间` 组织场次，写清实际动作、人物对白、环境及必要画面文字；概述、叙事结构和产品关联点保留为创作说明，不替代正文。不通过强制字数灌水，同一时间地点允许连续动作及明确时间省略。

每场正文只生成一份，由代码拼接最终完整正文，减少模型重复输出。独立 AI 审校仍保留；发现问题最多一次定向修订及一次复核。代码校验场次编号、结构、正文一致性、正时长及总时长偏差不超过 1 秒。新格式每个叙事段落最多 60 秒，叙事段落不等于最终渲染镜头。历史任务保留原检查点规则，历史方案不自动改写。

主页面直接阅读完整正文，缺少正文时明确提示；对比与导出同样不使用概述兜底。TXT 导出仅包含标题、正文及总时长。工作流继续使用共享组件及持久化节点产物。

## 发现与修正

- 首轮独立复核拦下「交接窗口的一个插座」：修订将过多收纳和离场动作挤入最后 4 秒。补充全剧时间重新分配与删减非必要步骤规则，禁止仅将过密动作平移到结尾；后续两轮按新规则执行。
- 180 秒「靠岸前的三口整理」初稿包含没有资料依据的“两端插脚”。审校指出后定向修订为插脚面收合状态，再复核通过。完整正文见 [180 秒正式剧本](2026-10-13-充电器正式剧本180秒.txt)。
- 30 秒机场方案直接通过独立审校，无需修订；便利店方案修订过密收尾，以明确剪切及时间省略简化收纳，再复核通过。第一份单独保存后第二份继续执行。
- 来源功率事实保持单 C 最高 65W、双 C 45W+20W、三口 45W+15W 合计及后两口共享 15W，不宣称每台设备 65W或虚构充电速度。
- API 新格式检查拒绝概述冒充正文；重复提交保持 revision 1。公开场次编号应原样展示，工作流不将其当内部 ID 替换。
