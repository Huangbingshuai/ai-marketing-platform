本轮修复：

1. 对象识别先持久化候选，聚合引用、身份及归属机械错误，最多一次纠错；候选和预算跨恢复保留，不反复付费。
2. 定义和审校区分公共资产参考与逐镜画面：无需在一张资产图复现所有故事阶段；核对已明确状态，保留未知产品结构。顶层字段和结构化清单中的同一问题同时定位。
3. 完整候选语义复核失败可显式转入人工核对草稿；继续校验项目、来源、草稿 revision、有效检查点与对象集合，只写草稿、不伪造 AI 成功；保存才提交。
4. 查询断网仅提示进度查询中断，恢复查询后清除提示，不将后台任务判为失败；真实业务保存错误独立保留。
5. 图片入口不再错误要求 API 进程拥有 Worker 专属 Ark Key；检查独立 Worker 通道配置，供应商密钥仍由 Worker 自己校验。
6. 通用文件名规范化避免把正常中文按 Latin-1 截断。仅对本轮两张图片的资产、版本和文件元数据做精确修复，未更改文件内容、哈希、版本号或工作副本引用。
