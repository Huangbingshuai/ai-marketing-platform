# 共享焦点与原任务继续前端验收

日期：2026-10-19。范围：C15 共享面板焦点，以及 C13 新增原任务继续入口。仅本地；没有 Git 写操作、线上操作、付费模型或部署。保留 C12/C14 后端改动。

## C15

详情重查按钮被加载/结果区域移除后，焦点回到 body，原面板收不到 ESC。共享 `WorkflowExecutionGraphDialog` 在活动期观察焦点目标失效，只有没有更上层弹窗接管、当前焦点确实失效时才恢复到关闭按钮；正常编辑不抢焦点。观察器关闭/卸载释放，迟到恢复无效。

ESC 尊重子控件已处理事件、输入法组合及嵌套对话框，只关闭当前层。Tab 约束包括输入、文本域及可编辑内容。关闭后的触发按钮恢复延后到子组件卸载结束，避免已关闭的内层资料弹窗在卸载时把焦点又拉回正在移除的工作流面板；已移除/禁用触发按钮及新上层弹窗不会被强行聚焦。

浏览器验证了当前定制真实 Workspace/执行面板的“失败详情查询中断→重新查询成功→ESC→焦点回到查看失败详情按钮”。另用同一共享组件、效果类真实图定义和 `buildEffectPromptGraphRows` 验证图节点、键盘与关闭；未执行效果类模型任务，不将此称为效果类付费端到端。嵌套选项先处理 ESC，原生资料弹窗先关闭，外层随后 ESC 关闭并返回原触发按钮；正反 Tab、编辑焦点保留、关闭后的状态更新均通过。

## C13 原任务继续

公共失败反馈现共用于 Prompt/Render，组件从 `ProductionPromptTaskFeedback` 调整为 `ProductionTaskFailureFeedback`。仅当前最新 FAILED 任务显示“继续本次任务”，旁边明确“沿原任务快照继续，未完成步骤可能产生模型费用”。取消/部分未完成/已完成不显示失败继续入口。

API client 接入已有 `POST production/tasks/:id/retry`，无新建任务 body。Workspace 使用当前项目及准确任务 ID，服务端继续负责 Run、来源、revision、检查点和 Outbox 校验；前端不改这些状态。真实返回写入原任务并沿现有轮询查询，原文档、Prompt、视频及草稿 revision 不被前端重写。

重复点击、其他任务运行、历史失败及未保存本地编辑会被阻止；不为恢复旧快照强制保存或清空修改。409 安全错误留在对应失败卡，内容保留。POST 网络结果不确定时只 GET 同一任务，不自动重发；旧作用域返回及范围不匹配结果不能回填。
