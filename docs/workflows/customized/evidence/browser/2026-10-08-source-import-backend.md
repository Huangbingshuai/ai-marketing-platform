# 2026-10-08 定制类资料导入后端验收

## 实现范围

仅接通 CUSTOMIZED / CUSTOMIZED_PROJECT 的 SOURCE_IMPORT：多份视频创作简报文档、可选视觉参考图片、自动保存引用与图片用途、刷新恢复、明确保存版本、隔离编辑及取消、版本切换、按固定文件版本预览和下载。标准化提炼及后续生成节点未在本次实现，不调用模型。

上传复用共用文件存储、项目资产、资产版本和工作流草稿/工作副本；效果类和定制类共用扩展名、MIME、文件头及实际大小验证。定制类上传按文件名与 SHA-256 幂等，重复和并发上传不增加资产版本；同名同大小的不同内容保存为独立资产，归档后可重新导入。事务内检查当前 Run 与资料编辑权限，迟到上传结果不能写入另一分支。

保存版本前检查固定文件可读取，提交事务再次检查项目、工作流、目录、类型、实际资产版本、可用状态和草稿 revision。同内容不增加业务 revision，不发布隐藏空分支。预览与下载均使用固定版本；修正了阅读器原先自行拼接当前资产地址的问题，并允许共用图片预览组件的有限缓存参数。
