## C07：上游回看后返回制作路径

根因位于 `CustomizedImportNodePage.vue`：从提炼进入制作直接激活所选脚本的 Run，脚本页的画布导航与底部下一步也使用这个祖先 Run。已有资产仍正确保存在子 Run，页面跳到祖先才显示为空。

普通导航现在通过版本树核对准确的脚本归属。当前 Run 是该脚本的资产/视频后代时保留当前路径；换选其他脚本时才进入该脚本。版本树显式选择继续使用准确目标，不套用普通导航规则。异步目录返回增加原 Run、页面及请求序号检查。

未修改 API 查询隔离、资产投影、服务端激活行为或 WorkingArtifact，也不推测“最近的子分支”。

## C06：附属对象与父级图片

- 直接复用 Contracts 新增的 `resolveCustomizedAssetImageSource` 和 `customizedAssetImageSelectionIssue`，不在前端按文字猜测归属。

- 视频素材缩略图/预览及右侧参考图使用有效父图；同一父图去重。原绑定仍是子对象 ID，不把父图复制进子对象或持久化文档。
- 定义编辑增加明确的制作方式及所属资产选择；限制产品独立、父级类别和循环，继续通过原有应用草稿及保存流程。
