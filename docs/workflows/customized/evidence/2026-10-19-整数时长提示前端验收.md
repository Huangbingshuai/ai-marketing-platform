# 整数时长提示前端验收

日期：2026-10-19。范围：C16 前端窄修；无线上操作、模型调用、部署/重启或 Git 写操作。未修改 Contracts、API 或 Worker；新 SHOTS 的整数冻结由并行后端处理。

## 改动

1. `ProductionShotRenderPanel` 继续使用共享 `customizedVideoRenderIssues` 决定是否允许生成。仅在合法模型配置、当前小数时长确被契约拒绝时，将前端提示明确为“当前模型仅支持整数秒”并显示实际值；不再对半秒建议切模型。不复制时长范围、不放宽校验、不自动取整。
2. 新版分镜右侧现有时长展示改为可点击按钮，保留原样式并加编辑图标，直接打开 Workbench 原有分镜参数弹窗。数值仍由原镜头和片段投影计算，没有第二个时长输入状态；运行/保存/提交期间禁用。旧版片段保持只读展示，避免指向不存在的编辑项。
3. 原参数弹窗的明确修改仍沿同 Run 自动保存；打开或关闭不触发保存，更不会生成 Prompt 或视频。
