# 逐镜提示词失败反馈前端验收

日期：2026-10-19。范围：C13，本地 Web。未操作线上项目、付费、部署或执行 Git 写操作；保留并行 C12 等任务改动。

## 查证与修复

`ProductionTaskActivity` 只展示 QUEUED/RUNNING，终态即消失；提示词区此前没有终态反馈，首次生成失败时恢复成空编辑器和“AI 生成”，无法直接获知失败。

新增 `ProductionPromptTaskFeedback`，内部直接复用 `WorkflowExtractionFeedback` 及 `safeApiErrorMessage`。新版完整分镜和历史逐镜页面都只传入当前对象最新 PROMPT 任务；FAILED、PARTIAL、CANCELLED 分别显示失败、未完成、取消。正常完成和运行中不显示终态卡，不串用兄弟片段、SHOTS 或 RENDER 状态。

局部详情按钮读取准确任务 ID，成功后优先选中已持久化的失败步骤。查询失败后的“重新查询”仍读取该记录，不启动模型；查看历史记录不会将它排到新尝试之前。详情只消费公共任务及业务详情，不新增 Worker 原始异常、模型输出或内部 ID 展示。

旧提示词和未保存本地修改保留。现有手动生成按钮在失败/取消后显示“重新生成”；不新增默认重试，不恢复页面全局的失败/取消横条、任务恢复或人工核对草稿动作。
