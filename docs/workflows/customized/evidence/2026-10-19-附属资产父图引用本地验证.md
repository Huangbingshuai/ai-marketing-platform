# C06 附属资产父图引用本地验证

2026-10-19。本轮仅本地 API、Contracts 与 Worker，不执行 Git、部署、线上任务或付费调用；未修改咖啡杯联调文档、截图及前端页面。实现边界见[计划](../plans/2026-10-19-附属资产生图拦截与父图引用.md)。

## 查证与处理

原 IMAGE 创建入口只校验对象身份和公共形象，未检查 `preparation.treatment`；原渲染入口只读取被 @ 引用对象自己的图片。视频提示词投影也未携带明确父归属。

- API 使用当前 Run 已确认目录作精确归属解析。明确的 SCENE_DETAIL / CHARACTER_DETAIL 不允许单独 IMAGE；单选或与独立项混选均整次拒绝，指出随父对象准备，不静默过滤或创建部分任务。校验位于 Task 创建与 Outbox 之前，Worker 在任何 API/供应商调用前再次整体校验。
- 父图生成从冻结目录附加明确归属的细节名称、定义及已知/设计内容，作为父场景或人物的一部分；不独立排任务、不将细节改成 INDEPENDENT，不按名称关键词推断归属。自定义图片提示词仍保留，并附带同一归属约束。
- 提示词仍引用实际细节身份，不强制额外 @ 父对象；文字上下文提供来源对象名称及归属用途，不输入图片、文件地址或推断视觉事实。内部父身份不能进入用户可见提示词正文。
- 渲染使用归属链终点的固定图片版本，冻结 SHA、字节数及文件信息，校验同项目正式资产版本和可用文件。缺父、错类、循环、缺图或不可用文件在供应商请求前失败。同一固定图片的多个逻辑引用只下载和发送一次，编号相同；细节引用在供应商边界表达为“图片N中的细节名称”。正文、绑定和目录不被此编译过程改写。
- 无 preparation 的历史对象保留自身图片逻辑。已有明确附属归属时，即使留有旧子图，也不优先使用该旧图；不删除旧图或迁移历史记录。

## 契约及前端交接

Contracts 新增并导出：

```ts
resolveCustomizedAssetImageSource(assets, objectId);
customizedAssetImageSelectionIssue(assets, objectIds);
```

解析器返回 `{ ok: true, source, path }` 或 MISSING / DUPLICATE_ID / CYCLE / INVALID_PARENT。输入应是当前 Run 的目录；函数不查其他项目或 Run。前端可用 source 读取有效图片和引导准备父资产，不将投影后的父图写回子项草稿。

`CustomizedVideoRenderInput.references[]` 向后兼容增加可选 `sourceObjectId`、`sourceName`；只有附属引用写入。objectId/name 仍表示原始 @ 对象，assetId/version 表示真正使用的父图文件版本。JSON Schema 与 Python RenderReference 已同步，历史字段缺失保持原编号规则。

普通导航、选中脚本路径与 API 查询作用域未改。API 不会为父脚本 Run 混入后代资产；归属只能在已读取的当前目录解析。文件可以来自该目录已确认的继承版本，不按文件最初生成 Run 擅自拒绝合法历史引用。既有来源 revision / hash、项目隔离、租约和迟到回调校验继续生效。
