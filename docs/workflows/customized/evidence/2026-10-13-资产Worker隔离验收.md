# 资产 Worker 隔离验收（2026-10-13）

## 实施范围

资产准备此前与视频制作共用 `customized-production-worker`。本次增加 `workers/customized-assets` 独立服务，并将视频制作服务迁至 `workers/customized-production`。资产只处理 ASSETS；视频制作只处理 SHOTS / PROMPT。两者拥有独立队列、Token、入口、镜像及锁文件；共用结构化请求和制作执行底座，不互相导入 Worker 内部模块。

不改变现有业务 DTO、来源快照、工作副本提交、人工确认、自动重试及检查点语义。旧视频队列排队资产消息经 API Outbox 转交新队列。本次未接通资产图片生成、视频渲染和素材交付，没有执行付费模型调用或提交 Git。

## 实际部署与无付费联调

部署前检查持久化任务状态，没有正在执行的后台批次任务；未中断活动任务。执行：

```powershell
docker compose --profile customized-assets --profile customized-production build customized-assets-worker customized-production-worker
docker compose --profile customized-assets --profile customized-production up -d --no-deps customized-assets-worker customized-production-worker
docker compose --profile customized-assets --profile customized-production ps customized-assets-worker customized-production-worker
docker compose exec -T rabbitmq rabbitmqctl list_queues name consumers messages_ready messages_unacknowledged
```

两个服务均已启动。RabbitMQ 实际显示：

| 队列 | 消费者 | 等待消息 | 未确认消息 |
| --- | --- | --- | --- |
| customized.assets.requested | 1 | 0 | 0 |
| customized.production.requested | 1 | 0 | 0 |

API 使用现有开发进程，确认新路由及资产凭据已实际加载。用已有终态资产 / Prompt 任务进行只读领取验证，不产生新 attempt 或模型执行：

| 请求 | 实际结果 |
| --- | --- |
| 资产路由、资产凭据、ASSETS | 201，terminal |
| 资产路由、视频凭据 | 401 |
