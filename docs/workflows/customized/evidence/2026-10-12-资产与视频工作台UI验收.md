# 资产准备与视频制作 UI 验收 · 2026-10-12

## 范围

资产准备整体替换旧表单墙；视频制作重组为镜头列表、画面/氛围、完整参考素材库、提示词与逐镜渲染面板。使用已有充电器项目《晚点广播响起之后》的真实 8 项资产、5 个镜头及已保存提示词。未创建付费任务，未修改已确认内容，未部署或重启 API/Worker。

调研采用点、官方来源及读取限制见[实施计划](../plans/2026-10-12-资产工作台与视频制作UI重构.md)。火宝采用完整候选库与绑定状态分离的组织方式；本系统保留产品独立类别及现有提交边界，没有移植其代码或图片。

## 实际浏览器检查

- 1920、1440、430 宽度检查资产与视频工作台；430 页面及各制作区无水平溢出，分类和图片条保留内部滚动。
- 产品/人物/场景/道具分类；“道具 + 线材”搜索找到对应项；已关联图片筛选正确显示空态，清除恢复 8 项。
- 资产定义读取完整真实内容；详情临时改名后 ESC 不应用；新增资产自动打开编辑详情，取消全局编辑后恢复 8 项。
- 单项、详情内和批量图片制作入口均显示实际资产内容；批量包含 8 项；从详情打开制作面板不会叠加两个弹窗。
- 素材库“全部”显示 8 项，“本镜”显示镜头一的 5 个绑定；切换镜头四为 3 / 8。查看定义不改变绑定。
- 临时绑定智能手机后镜头一变为 6 / 8；取消恢复 5 / 8、手机未勾选，且无残留待更新提示。修复方式是取消保存成功后刷新权威工作区。
- 视频入口展示当前真实提示词、实际绑定子集和选择的 9:16 / 1080P / MP4；服务未接通按钮禁用。ESC 可关闭并恢复触发按钮焦点。
- 共用“查看工作流”弹窗仍展示持久化阶段内容、历史任务及切换入口。浏览器检查时未记录控制台 error。

## 验证边界

图片生成、上传替换、视频渲染尚未接通。本轮恢复制作入口和组件，不生成模拟结果、历史或进度。输出规格仅为当前页面制作入口的预览设置，未伪装成已持久化渲染配置。未重新付费生成资产/分镜/提示词，未覆盖模型质量、生成失败或实际媒体播放状态；既有付费验收结论不变。
