# 移除 MinIO 运行配置与产品说明

## 目标

应用运行与当前开发说明只保留 TOS 和本地文件存储；移除已退役的 MinIO 驱动、客户端依赖、环境变量、Compose 服务和用户可见的 MinIO 说明。当前本地 `.env` 使用 `STORAGE_DRIVER=tos`；所有活动对象迁移和真实媒体读取须通过校验后才算完成。

## 范围

- 删除 API 对 `STORAGE_DRIVER=minio` 与 `MINIO_*` 环境变量的支持；对象存储适配器改为火山官方 SDK 原生 TOS 实现。
- 删除 Compose 中 MinIO 服务和镜像构建目录；从 `.env.example`、README、当前本地开发指南、当前 UI 文案及维护规则中移除 MinIO 运行配置说明。
- 删除已退役的一次性 MinIO 迁移/清理脚本及其包命令；更新相关自动化测试。
- 保留 TOS、本地文件存储、已有 TOS 对象及原 MinIO Docker 命名卷中的数据。此任务不执行数据卷或桶对象删除。
- 保留历史实施方案和迁移审计记录，避免改写当时真实发生的存储与验证事实。

## 验收

- 生产 API 环境契约只接受 `local` / `tos`；`.env.example` 与 Compose 不再包含 MinIO 配置或服务。
- API 的 TOS 存储读写、签名 URL、Range 读取及初始化测试通过；相关 API 类型检查和构建通过。
- `docker compose config --quiet`、`git diff --check` 通过；当前产品界面与有效部署说明中不再展示 MinIO。
- 不删除命名卷或任何 TOS 数据，不提交 Git。

## 实施结果（2026-10-06）

### 用户确认后的完整替换

- 当前视频无法加载的已确认原因：本地 `.env` 切换了 TOS，但最新批次的 20 个视频、20 个封面仍只存在原本地对象存储中。之前启动与模拟测试不能代替真实文件可读验证。
- 将运行时和维护脚本的 MinIO npm 客户端替换为官方 `@volcengine/tos-sdk`，保持 StoragePort、项目鉴权、Range、文件大小验证和短期供应商签名访问边界不变。
- 盘点原活动桶和数据库引用；迁移活动桶全部对象（包括历史成片、共享音色），优先恢复当前渲染视频/封面。已删除项目的隔离备份桶不纳入活动数据迁移。
- 单次本地迁移脚本和脱敏校验日志保存在忽略目录 `.local-storage/migrations/`，不重新引入生产 MinIO 配置。按原 key 复制；源文件与目标文件 SHA-256、长度校验一致才算成功。目标已有对象先比对，冲突时停止，不覆盖。
- 不变更任何数据库记录、工作副本 revision 或分支关系；不重新生成视频、不调用付费模型。可重复运行迁移，跳过已校验相同的目标。
- 真实验证 TOS 上传、完整下载、Range、签名读取、删除测试对象；重启 API 并回归当前页面的封面与播放。确认后停止原容器，保留源数据卷作恢复备份，不自动提交 Git。

- API 已移除 `minio` npm 依赖，接入 `@volcengine/tos-sdk@2.9.1`；配置支持 local/tos，维护脚本也改为官方 SDK。类型检查、生产构建、存储/配置测试通过。
