# marketing.richbest.cn 域名与 HTTPS 接入

## 范围与依据

正式页面品牌为瑞池传媒 / RICH MEDIA · AI MARKETING；既有产品采用 lens.richbest.cn、drama.richbest.cn。选用 marketing.richbest.cn，用户已添加 A 记录至 101.96.224.33，并确认主域名已备案、已接入火山引擎。服务器元数据地域为 cn-guangzhou。

## 接入方案

- 保持既有 80、443 网关：HTTP 入口 lens-rhyme-nginx-1，HTTPS 入口 avatar-proxy-api-gateway-1。仅增加精确主机名虚拟站点，不修改既有站点规则。
- HTTPS 网关连接本项目 Docker 网络：静态页面代理至本项目 Web，/api/ 直接代理至本项目 API，保持浏览器到 API 仅一层可信代理。覆盖转发头，不将限流来源合并为中间代理 IP。
- 网关使用 Docker DNS 动态解析本项目容器名，防止营销平台停机影响既有网关启动。共享 Compose 配置增加对应配置文件和网络引用，保证容器重建后保留入口；修改前保存限权备份。
- HTTP-01 验证通过现有 HTTP 网关完成，不停止其他服务。使用已安装 Certbot 与独立证书名称，提供验证文件的认证/清理 Hook；续期后校验并热加载 HTTPS 网关。
- 证书与入口验证通过后，在无活动任务时更新 WEB_ORIGIN、AUTH_COOKIE_SECURE、SEEDANCE_REFERENCE_PUBLIC_BASE_URL，并仅重新创建本项目 API。账号和数据库保持原值。

## 验收与回退

验证 DNS、证书链/域名、HTTP 跳转、桌面/窄屏登录、Secure Cookie、真实项目读写/文件读取、匿名拦截、退出撤销、Worker 队列及既有站点响应。不得调用付费模型验证。失败保留原 IP 测试入口和配置备份，不删除既有网关/证书或数据卷。

当前会话无 Context7 工具，配置核对 [Nginx 官方文档](https://nginx.org/en/docs/http/ngx_http_proxy_module.html)、[Docker 网络文档](https://docs.docker.com/reference/compose-file/networks/)和 [Certbot 文档](https://eff-certbot.readthedocs.io/en/stable/using.html)。
