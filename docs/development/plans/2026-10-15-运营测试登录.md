# 运营测试登录

## 范围与验收

增加单一运营账号的登录入口；账号和密码哈希仅由服务端环境变量提供。登录前不挂载工作台，不读取业务数据；全部业务 API 默认要求有效会话。登录成功恢复工作台，刷新保持登录，退出立即撤销会话，过期后回到登录入口。保留现有项目、工作流、工作副本与 revision 语义，不增加注册、找回密码、用户管理或第三方登录。

## 设计依据

- [shadcn/ui 登录布局](https://v3.shadcn.com/blocks/login)：采用克制的双栏、明确标签和单一主操作；自行实现 Vue 页面，不引入其框架或图片。
- [NestJS Guards](https://docs.nestjs.com/guards)：全局访问控制，明确声明独立鉴权入口。Context7 在当前工具集中不可用，使用官方文档核对。
- [OWASP Session Management](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)：随机不透明会话，数据库只存摘要；Cookie 使用 HttpOnly、SameSite 和可配置 Secure。

界面复用瑞池品牌标志、系统蓝色、深灰文字和现有字体。以留白、排版和静态剪辑画面构成品牌区，避免发光渐变、AI 图标堆叠和冗长营销文案。

## 数据与接口

- 新增 PostgreSQL 登录会话与尝试计数表，独立迁移，不改业务表；会话保存凭据指纹，变更密码后旧会话失效。
- 共用契约定义登录请求、当前会话响应和鉴权错误码。
- `POST /api/auth/login`、`GET /api/auth/session`、`POST /api/auth/logout`；登录和退出检查请求来源，业务写请求同样检查来源。
- 默认保护所有路由。健康检查显式公开；Worker 控制器和供应商签名输入显式标记独立鉴权，保留其 Token / 签名校验。
- PostgreSQL 原子计数限制同一网络来源在 15 分钟内最多 10 次登录尝试；会话有效期 12 小时。无鉴权缓存或未配置回退。

## 配置与部署

本机被 Git 忽略的 `.env` 配置指定账号的 scrypt 密码哈希；示例文件仅留占位符。部署先迁移、配置账号和精确 WEB_ORIGIN，再构建启动。HTTPS 配置 Secure Cookie；同站反向代理 `/api`。不包含外部发布或付费任务。

## 验证

执行真实 HTTP 的正确/错误登录、匿名业务访问、会话过期/撤销、来源校验、限流和独立鉴权回归；执行 Contracts/API/Web 类型与相关单测、生产构建、格式和 diff 检查。在 1920、1440 与手机宽度浏览器检查布局、错误、加载、密码显示、刷新恢复和退出。使用隔离测试账号，不在截图或日志保留密码、Cookie 或 Token。
