## 服务器更新与回滚

服务器原目录没有 Git 元数据。使用提交生成的源码归档及同一源码构建的 Web 产物，上传后校验 SHA-256；API 与 Worker 镜像在独立暂存目录构建。发布记录保存源码提交、归档哈希和实际镜像 ID。

切换前再次核对无排队/运行任务、Outbox 与队列为空，执行数据库和原发布文件备份。先应用迁移并更新 API，再更新 Worker 与静态 Web，最后检查 HTTPS、鉴权、容器、队列和迁移状态。`PENDING_RENDER` 是等待用户主动导出的业务状态，不等同于排队消息，不因部署自动导出。

旧镜像标识、静态资源和服务器配置保留在本次 `deployment-logs/` 备份目录。出现问题时恢复旧发布标识和前端入口，再核对运行容器；数据库迁移单独评估，不自动回退生产数据。当前入口、运维命令及配置边界见[服务器部署说明](../server-deployment.md)。
