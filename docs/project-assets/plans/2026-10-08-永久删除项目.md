# 永久删除项目

用户要求提供删除项目按钮并删除项目全部数据。范围包括项目所有工作流、历史 Run、节点草稿、工作副本、修订快照、依赖、项目资产及版本、上传/生成/导出任务、Outbox、缓存和项目存储文件；共享音色/全局资产不属于项目所有权范围。

- 项目资产库列表提供独立红色删除按钮；复用危险操作确认弹窗，显示项目名称和无法恢复的影响。取消不调用删除。当前项目删除成功后卸载页面并清除所有工作流的本地绑定和列表缓存，其他项目保留。
- `DELETE /projects/:projectId` 使用 UUID 校验及共用项目服务。锁定项目行后检查生成、上传任务；进行中任务明确拒绝，避免并发写入存储。空项目和重复删除幂等。
- 同一事务收集项目拥有的所有存储键，按 FK 限制解除关系并删除业务记录/项目；独立持久化文件清理队列不依附已删除项目，进程重启可继续。对象存储调用置于事务外。共享文件和其他项目仍引用的文件保留。
- 新增一个独立文件清理表及迁移；不改变固定工作流或节点产物契约，不调用付费模型。不在验证中删除用户实际项目；只使用明确的隔离测试项目、数据库事务夹具和临时本地存储。
- 验收：全关联删除、文件清理/失败恢复、重复删除、跨项目隔离、进行中任务拒绝、列表与当前绑定清理、失败保留、刷新恢复、键盘与窄屏；执行 Contracts/Web/API 类型与构建、相关单测、真实测试项目数据库与本地文件清理验证、diff 检查。
