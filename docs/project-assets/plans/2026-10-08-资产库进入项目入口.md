# 资产库进入项目入口

## 范围

- 在资产库项目详情右上角新增“进入项目”，复用蓝白按钮样式；当前项目标识仍保留。
- 点击项目行仅浏览资产，点击进入按钮才绑定工作项目并关闭资产库。
- 复用统一项目上下文和现有退出流程。跨项目或工作流进入前先保存草稿并暂停原工作区，失败时不切换并在资产库展示错误。
- 进入当前项目直接返回工作区，不改资产库中查看的历史版本，也不复制资产。
- 操作期间禁用重复进入、关闭、返回及工作流切换；校验项目和工作流分区归属。

## 非目标和接口

不新增 API、状态表或版本状态；不启动模型任务，不修改资产或历史分支，不迁移数据，不自动提交 Git。
通过 AssetDrawer 的进入事件将 projectId、workflow、space 交给既有项目宿主处理；复用退出、列表读取和 selectProject。

## 验收

覆盖空工作区进入、当前项目返回、跨项目保存顺序、保存失败、退出失败、无效绑定、工作流隔离与重复请求保护。
执行资产及项目测试、类型检查、构建、ESLint 和 diff 检查；浏览器验证 1920、1440 和窄屏入口、点击关闭资产库并返回当前工作区。

## 实施验证

- 资产及项目测试共 82 项通过；构建（含 vue-tsc）、ESLint、git diff --check 通过。
- 浏览器 1920、1440、600 宽度验证按钮高度 34px、未发生弹窗横向溢出。
- 当前项目“进入项目”点击后资产库关闭，原工作项目保持绑定。只有一个真实项目，跨项目与保存失败使用模拟回调单测，不创建测试项目或付费任务。
