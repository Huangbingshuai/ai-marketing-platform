# 资产文档全文预览与导出

## 范围

- 版本下拉框仅显示版本编号，来源路径继续作为独立说明与版本树保留。
- 产品信息和素材提示词采用可直接阅读的全文文档，不再显示占位图标卡片。
- 展示基础信息、完整卖点、提示词正文、创意方向、六维、用途、来源事实和批次约束；不展示内部任务/供应商字段。
- 提供当前选中版本的文本导出，读取现有已确认工作副本或项目资产内容，不调用节点最新结果接口。

## 实现边界

- 复用现有列表、版本与模板筛选以及只读资产数据，新增展示投影和全文阅读组件。
- 无新增状态表、接口、迁移或模型调用，不更改节点、版本与工作副本提交规则。
- 文本展示使用 Vue 插值，不解释 HTML；下载文件名规范化，下载对象 URL 及时释放。
- 缺失内容明确展示，不生成推测信息；不截断卖点或提示词条目。

## 验证

- 单测覆盖完整卖点、批次全部提示词与六维、空内容、安全输出、版本隔离导出内容。
- Web 类型检查、构建、静态检查与差异检查。
- 浏览器回归 1920、1440、窄屏下全文、版本编号和下载，保留视频预览及模板筛选。
- 不付费生成，不修改历史版本，不自动提交 Git。

## 实施验收

- 新增只读文档投影与阅读组件，产品信息和整批提示词完整展开，下载使用同一选中快照。

## 补充：原始资料的图片与文档隔离

- 资料包展开为实际文件；文档和音频不再继承资料包首图，图片使用自己的内容地址，源视频使用自己的视频内容，不借用包内商品图。
- 产品资料下增加独立分类筛选，全部视图按文档、图片、视频、音频分区；沿用现有工作流、节点、版本作用域及分页。
- 文档采用紧凑文件卡，展示格式、名称、大小与状态；详情去掉大图标占位和重复文件名，提供原文件下载，不伪造 DOCX 正文预览。
- 文件详情不展示所属资料包的内部产品标识或共用标签，图片仍可点击查看对应原图。
- 回归覆盖源文件映射和分组；资产相关 8 个测试文件共 54 项通过。
- 浏览器核对真实项目的 1 份 DOCX 与 3 张图片，文档区图片数量为零、3 张图片各自正常加载；验证分类、清除筛选、空态、网格/列表、详情及 1920、1440、600 宽度。
