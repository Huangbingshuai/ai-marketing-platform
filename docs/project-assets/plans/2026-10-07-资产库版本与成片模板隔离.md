# 资产库版本与成片模板隔离

## 范围

项目资产库独立浏览效果类所有已确认分支，按产品资料、产品信息、素材提示词、视频素材、最终成片隔离。最终成片再按稳定 templateId 隔离。版本编号、来源路径及分支树复用现有实现，不把继承快照当成新版本。不展示混剪工程。

浏览不激活工作流，不保存导航或草稿，不更新 WorkingArtifact，不调用生成/导出，不物理删除文件；其他工作流保留现有业务空间隔离。本次不自动提交 Git。

## 数据与接口

- 使用现有效果类分支树作为版本目录，复用布局解析得到实际节点版本及上游路径。
- 在既有工作副本列表接口增加可选 `view=SNAPSHOT`，必须指定 workflowRunId；只读取该 Run 保存的工作副本，不执行最新来源替换或依赖闭包扩展。支持已结束 Run，保持项目、工作流、业务空间约束。默认工作台读取不变。
- 前端选定节点版本后查询该 Run 快照，按节点和模板筛选。正式资产仅通过 sourceArtifactId 或明确 sourceRunId 归属，不按文件名、标签推测来源。最终成片通过 final-video/final-delivery 键及明确模板元数据隔离；正式成片优先依据关联工作副本判断模板。
- 视频素材有既有的共享来源头语义：在混剪子 Run 保存的人工导入/返修仍属于同一视频版本，不产生新的渲染分支编号。此节点使用既有服务端同渲染头读取，且只展示 `branchSourceOwner=true` 的已采用素材，不展示旧消费副本或任意兄弟分支；其他节点及最终输出使用精确 Run 快照。
- 同一成片的正式资产与工作副本只展示一次。缺少可靠版本/模板来源的旧记录不混入已选版本。
- 切换项目、节点、模板、版本立即清空旧预览，取消过期请求。查询失败不回退到活动分支。历史浏览不提供误导性的“返回节点编辑”。

## UI

保留现有中性配色和紧凑布局。在节点标签下增加一行范围工具栏：最终成片的模板选择、版本选择、版本树入口；下方用轻量路径展示来源关系。版本树增加资产浏览模式，隐藏新建分支，点击仅选择可浏览版本。窄屏控件自然换行，资产区域维持独立滚动。

## 兼容与迁移

只增加可选读取参数，无新表、无数据迁移、不修改历史 revision。版本编号仍为原分支树显示编号，工作副本内部 revision 不充当额外版本。其他工作流版本模型本次不臆造。

## 验收

覆盖来源头去重、多个上游头同号版本、手动复制边界、跨项目/工作流/Run 隔离、同 Run 多模板、正式资产关联、重复成片、缺少模板来源、快照读取与默认读取兼容、无 Run 的快照拒绝、迟到读取不覆盖选择。运行相关 Contracts/API/Web 单测、类型构建、diff 检查；浏览器验收 1920、1440、窄屏、版本切换、模板切换、版本树、空/错误状态。无 Worker 协议变更，不发起真实付费任务。

## 实施与验收记录

- 已增加只读快照查询及缺少 Run 的拒绝校验，默认工作台来源投影保持不变。视频页复用已采用来源头投影，实际可见 R-021 / R-022 人工导入素材；批次索引不计入视频数。
- 复用效果类版本树的来源头、编号和上游路径。资产浏览模式隐藏新建分支，不可选择混剪工程层，点击仅改变资产浏览范围；历史资产不提供指向活动分支的误导性编辑入口。
- Web 相关 8 个测试文件、93 项测试通过；API 快照及工作副本相关 3 个文件、73 项测试通过；Contracts 11 个文件、98 项测试通过。API/Web 类型检查和构建通过，Web 仍有既有的大包体积提示。相关 ESLint 与 diff 检查通过。
- 成片交付清单仅作为索引，不重复显示为第一条成片；正式成片与关联工作副本去重，并保留来源中记录的实际时长。
- 浏览器实际验收 1920×1080、1440×900、600×900，验证加载、接口旧进程的失败态、服务更新后的恢复、版本树选择、四个模板选择、空成片、视频与导入素材详情。窄屏筛选区没有横向溢出。选择提示词版本后工作台仍为测试3混剪配置。
- 当前项目的确认分支树没有已确认成片输出，未通过真实成片生成创建测试结果。成片的跨 Run / 同 Run 跨模板与正式资产关联去重由单测验证，实际界面验收模板空态。
- 本地 API 为普通 dist 启动，旧进程拒绝 view 参数。只读数据库确认无排队/运行任务后重启并验证健康接口及实际快照读取成功。没有付费调用、分支激活、历史内容修改或 Git 提交。
- Worker 请求与回调协议未改变，本次不修改或重启 Worker。
