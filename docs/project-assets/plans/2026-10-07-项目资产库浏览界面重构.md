# 项目资产库浏览界面重构

## 范围

将共享资产抽屉改为工作流导航、项目列表、项目资产浏览三级布局。保留效果类、定制类、裂变类以及各业务分区隔离；复用 Project Store、项目列表、正式资产和工作副本读取接口。不修改工作流、版本、归档和资产发布规则，不创建付费任务，不物理删除数据，不自动提交 Git。

## 开源调研与取舍

- PhotoPrism 集合页：单一搜索工具栏、集合导航与内容分离。参考 https://github.com/photoprism/photoprism/blob/develop/frontend/src/page/albums.vue 。
- PhotoPrism 媒体卡片：缩略图优先、文件信息次级、点击预览，视频非主动播放时不加载。参考 https://github.com/photoprism/photoprism/blob/develop/frontend/src/component/photo/view/cards.vue 。
- Immich 搜索：媒体类型、文件名等筛选集中管理。参考 https://docs.immich.app/features/searching/ 。不引入其语义搜索或图库权限体系。
- 只借鉴交互和职责划分，自行实现，不复制开源组件或引入外部 UI 框架。

## 实施

1. 移除重复标题、上下文条、装饰型工作流卡片、双搜索、UUID、英文状态与旧当前项目模式。三大工作流使用简洁导航；窄屏使用同一导航的横向布局。
2. 项目列表显示名称、客户/产品、状态、更新时间，不把正式资产数量当作完整素材数量。单次请求始终携带 workflow + space，搜索不越过工作流隔离。
3. 点击项目直接进入资产浏览，不再以草稿概览作为默认页面。正式资产和当前 Run 工作副本保留不同身份，不伪造 ProjectAsset。
4. 工作副本资料包按真实文件展开，渲染片段逐项显示，批次索引不冒充视频。文件按实际身份去重；工程、配置等结构化内容不展示原始 JSON。
5. 支持分类、名称搜索、排序、分页、网格/列表视图，按需打开图片/视频/音频预览及详情。保留正式资产引用、版本和移除能力；工作副本只提供读取、下载和受控返回节点入口。
6. 作用域切换立即清空旧内容，中断请求并使用 generation guard；部分读取失败显式提示且保留成功来源，不伪装为空。关闭/卸载释放请求和定时器，ESC 及焦点恢复沿用抽屉交互。

## 数据与兼容

仅扩展前端展示模型，使用 discriminated source 区分工作副本和正式资产。无数据库迁移、无新增状态表和业务接口。正式资产分页读取完整列表后在浏览器做展示筛选；服务端项目/工作流/分区隔离不变。当前 Run 读取失败不认为其不存在。

## 验收

- 项目点击、返回、搜索、工作流/分区切换、刷新及关闭重开。
- 实际视频/图片/音频缩略图与预览、正式资产与工作副本身份、去重及不可用状态。
- 加载、空、错误、部分错误、完成与禁用状态。
- 单元测试覆盖分区隔离、文件展开、去重、筛选和安全摘要；类型检查、构建、diff check。
- 浏览器检查 1920、1440、窄屏，以及资源错误、预览、分页和键盘操作。不进行真实生成、删除或引用写操作。

## 实施记录

### 节点分类调整（2026-10-07）

后续按用户反馈收敛为五个资产入口：产品资料、产品信息、素材提示词、视频素材、最终成片。资产库不再展示模板混剪入口及其模板/工程/包装产物，也不会将它们转入“未标注来源”；仅过滤展示，不删除工作台或后台数据，不影响最终输出视频。

- 效果类项目的类型分类改为六个固定来源节点，默认进入视频渲染；同一节点内保留搜索、排序和列表/网格。没有权威节点来源的历史正式资产独立展示“未标注来源”，不根据名称或内容猜测归属。
- 混剪成片工程及包装工程不再作为资产卡片展示，也不计入节点数量；模板配置仍保留，最终导出视频不受影响。仅在展示边界过滤，不删除工作副本、正式资产或文件。
- 本次不接入历史分支浏览，不改变活动 Run、版本树、草稿或任务状态。节点分类与版本隔离是不同维度，后续版本选择仍需单独接入。
- 其他尚无统一节点枚举的工作流保持原类型分类，本次不推测其节点 ID 或改变业务流程。
- 验证节点归属/别名、未知来源、工程过滤、模板及最终视频保留、项目/Run 隔离、搜索及节点切换的空态与预览。
- 本轮资产测试共 40 项通过，Web 类型检查与构建、相关 ESLint 和 diff check 通过。真实项目混剪节点只展示一个模板配置，资料导入四个文件、视频渲染二十个片段；切换节点关闭旧详情，搜索不越过节点边界。成片输出空态及视频预览实际加载已检查。

- 已重构抽屉、项目列表和项目资产浏览，默认使用“素材优先”排序。原当前项目概览不再作为资产库入口。
- 只展示真实项目业务分区：数字人口播按项目浏览，尚未实现的共享音色库不伪装成项目入口；不改变共享库契约或后台数据。
- 真实项目读取到 20 条视频、3 张图片与工程/文档；已检查视频实际解码与播放、搜索无结果、分页、列表切换、返回、工作流/业务分区隔离、加载与空态。
- 浏览器完成 1920×1080、1440×900、600×900 检查，窄屏详情按需覆盖，未出现容器横向溢出；ESC 关闭详情并恢复焦点。
- 资产范围 6 个测试文件共 35 项通过；Web 构建包含类型检查通过。构建保留既有大 chunk 提醒。
- 正式资产为空，因此版本、引用、移除仅保留既有 API 链路及作用域限制，未执行真实写操作；错误及部分读取失败处理未在真实服务中故障注入，不声明完整故障浏览器验收。
