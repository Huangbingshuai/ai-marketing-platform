# 原始文档内容与图片自适应预览

## 范围

- 产品资料全部视图按图片、文档、视频、音频顺序展示，保留独立分类筛选、工作流及版本隔离。
- 图片缩略图按真实比例显示完整图片，不再放入固定高度的宽横框；点击仍查看原图。
- DOCX、TXT、Markdown、CSV、JSON 在资料区直接阅读正文，复用资产全文阅读组件；PDF 通过本地 Blob 使用浏览器原生阅读，不上传第三方。旧 DOC、电子表格等未支持格式明确提示并保留原文件下载，不用其他版本内容代替。

## 数据与安全

- 现有资产列表无原始正文；提炼 Worker 的文档解析文件属于提炼任务，不作为另一资料版本的正文来源。
- 只经现有项目文件/工作副本/资产内容 API 读取选中版本的原文件，不新增业务接口、状态表、迁移或写回。
- 按需加载 DOCX 解析器，在独立 Worker 中提取纯文本；不注入文档 HTML、不加载外部关系、不把商品图片充当文档封面。
- 20 MB 预览输入上限、解析超时、取消与组件卸载清理；切换版本后迟到结果不可回写。真实错误用安全文案显示并提供重试。
- 图片与文档原文件下载继续可用；无 AI、无付费任务、不改历史文件、不自动提交 Git。

## 验收

- 原始 DOCX 的段落与表格文字完整可读，空文档、损坏文件、越界、读取失败、取消与不支持格式有明确状态。
- 图片在文档上方，图片自身无宽框产生的左右留白，图片文档仍隔离。
- Web 单测、类型检查、构建、ESLint、格式及差异检查；浏览器验证真实项目、加载/空态、下载入口、分类切换与 1920、1440、600 宽度。

## 实施结果

- 复用全文阅读组件，通过既有内容 API 读取实际文件；DOCX 以固定版本 Mammoth 1.13.0 在独立 Worker 中读取段落、表格文本，正文作为纯文本展示。解析器仅出现在独立约 301 KB Worker 包中，不进入主页面包。
- 已实现 TXT/MD/CSV/JSON 原文展示及 PDF 本地 Blob 浏览器阅读入口；旧 DOC、XLS/XLSX 提示暂不支持在线阅读并保留下载。没有新增数据库、接口或模型调用。
- 9 个资产测试文件共 62 项通过，覆盖真实 DOCX ZIP 段落与表格、尾部、空/损坏文件、范围限制、安全文本、API 路径、读取异常、Worker 完成/失败/超时/取消清理。
- Web 类型检查、构建、ESLint 通过；构建保留原有主包体积告警。
- 浏览器核对真实紫苏梅子酱 DOCX 全文，末尾卖点存在；三张图片宽高比与原图一致，图片位于文档之前。1920、1440、600 宽度下正文未发生横向溢出；分类和原文件下载入口正常。真实 PDF、旧 DOC 和表格文件未做浏览器实文件验收，不声称其已通过。
