# 项目与资产文档

本目录维护跨工作流共用的项目上下文、工作流草稿、工作副本、Revision、项目资产和全局发布规则。

效果类、定制类等工作流复用统一项目上下文，各自独立保留一个当前项目。切换工作流先保存当前节点草稿，再恢复目标工作流绑定；目标尚未绑定时显示空项目，不带入其他流程的项目，也不退出或暂停另一类流程的任务。刷新分别恢复各类绑定，退出或更换项目只影响对应工作流。所有已绑定的当前项目均禁止删除，包括暂时未展示的工作流项目。`workflowSpaces` 仅表示已有内容索引，不作为项目所属权限制。

项目资产库的状态列表示当前工作台的操作状态：进入并绑定的项目显示“进行中”，其他项目显示“未打开”。仅浏览资产不激活项目；成功退出后取消“进行中”，刷新后按恢复的项目绑定显示。删除中、清理文件和删除失败优先展示。该展示不修改数据库中的项目生命周期，也不表示后台任务是否运行。
